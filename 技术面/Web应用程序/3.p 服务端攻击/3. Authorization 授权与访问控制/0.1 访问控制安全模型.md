# 访问控制安全模型

在本节中，我们将解释什么是访问控制安全模型，并讨论最常见的模型。

## 什么是访问控制安全模型？

访问控制安全模型是一组访问控制规则的正式定义，它独立于技术或实现平台。访问控制安全模型在操作系统、网络、数据库管理系统以及后台办公、应用程序和 Web 服务器软件中实现。多年来，人们设计了各种访问控制安全模型，以使访问控制策略与业务或组织规则以及技术变革相匹配。

## 程序化访问控制

在程序化访问控制中，用户权限矩阵存储在数据库或类似存储中，访问控制通过参考该矩阵以编程方式应用。这种访问控制方法可以包括角色、组、单个用户、流程的集合或工作流，并且可以具有高度细粒度。

## 自主访问控制（DAC）

在自主访问控制中，对资源或功能的访问基于用户或命名的用户组进行约束。资源或功能的拥有者能够将访问权限分配或委托给用户。该模型具有高度细粒度，访问权限被定义为针对单个资源、功能和用户。因此，该模型的设计和管理可能变得非常复杂。

## 强制访问控制（MAC）

强制访问控制是一种集中控制的访问控制系统，其中主体对某个对象（文件或其他资源）的访问受到约束。重要的是，与 DAC 不同，资源和功能的用户及拥有者没有能力委托或修改其资源的访问权限。该模型通常与基于军事安全级别的系统相关联。

## 基于角色的访问控制（RBAC）

在基于角色的访问控制中，定义了命名角色，并向这些角色分配访问权限。用户随后被分配到单个或多个角色。RBAC 提供了比其他访问控制模型更好的管理能力，如果设计得当，还具有足够的细粒度，可在复杂应用程序中提供可管理的访问控制。例如，采购员可以被定义为一个角色，具有对采购分类账功能和相关资源子集的访问权限。随着员工加入或离开组织，访问控制管理被简化为定义或撤销采购员角色的成员资格。

当存在足够的角色来正确调用访问控制，但又不会多到使模型过于复杂和难以管理时，RBAC 最为有效。
