# 密码重置投毒

密码重置投毒是一种技术，攻击者通过操纵易受攻击的网站，使其生成指向攻击者控制域名的密码重置链接。这种行为可被利用来窃取重置任意用户密码所需的秘密令牌，并最终危害其账户。

> **研究**
>
> [此技术最早于 2013 年由我们的研究总监 James Kettle 记录。](https://www.skeletonscribe.net/2013/05/practical-http-host-header-attacks.html)

## 密码重置如何工作？

几乎所有需要登录的网站都实现了允许用户在忘记密码时重置密码的功能。有几种不同的实现方式，安全性和实用性各不相同。最常见的方法之一大致如下：

1. 用户输入其用户名或电子邮件地址并提交密码重置请求。
2. 网站检查该用户是否存在，然后生成一个临时的、唯一的、高熵的令牌，并在后端将其与用户的账户关联。
3. 网站向用户发送一封包含密码重置链接的电子邮件。用户的唯一重置令牌作为查询参数包含在相应的 URL 中：
   ```
   https://normal-website.com/reset?token=0a1b2c3d4e5f6g7h8i9j
   ```
4. 当用户访问此 URL 时，网站会检查提供的令牌是否有效，并使用它来确定正在重置哪个账户。如果一切正常，用户将被授予输入新密码的选项。最后，该令牌被销毁。

这个过程足够简单，与其他一些方法相比也相对安全。然而，其安全性依赖于这样一个原则：只有预期的用户才能访问其电子邮件收件箱，从而访问其唯一令牌。密码重置投毒是一种窃取此令牌以更改其他用户密码的方法。

## 如何构造密码重置投毒攻击

如果发送给用户的 URL 是基于可控输入（如 Host 头）动态生成的，则可能按如下方式构造密码重置投毒攻击：

1. 攻击者根据需要获取受害者的电子邮件地址或用户名，并代表其提交密码重置请求。在提交表单时，他们拦截生成的 HTTP 请求并修改 Host 头，使其指向他们控制的域。在此示例中，我们使用 `evil-user.net`。
2. 受害者直接从网站收到一封真实的密码重置电子邮件。该邮件似乎包含一个用于重置密码的普通链接，并且关键在于，它包含一个与受害者账户关联的有效密码重置令牌。然而，URL 中的域名指向攻击者的服务器：
   ```
   https://evil-user.net/reset?token=0a1b2c3d4e5f6g7h8i9j
   ```
3. 如果受害者点击此链接（或以其他方式获取，例如由防病毒扫描程序获取），密码重置令牌将被传送到攻击者的服务器。
4. 攻击者现在可以访问易受攻击网站的真实 URL，并通过相应参数提供窃取的受害者令牌。然后，他们可以将用户的密码重置为他们想要的任何内容，随后登录该账户。

在实际攻击中，攻击者可能会试图通过事先发送虚假的泄露通知等方式来“预热”受害者，以提高其点击链接的可能性。

即使您无法控制密码重置链接，有时也可以使用 Host 头向敏感电子邮件中注入 HTML。请注意，电子邮件客户端通常不执行 JavaScript，但其他 HTML 注入技术（如[悬挂标记攻击]）仍然可能适用。
- 当敏感信息位于注入点之后：逃逸注入上下文，并设置新的未闭合链接元素。若被用户点击或邮箱加载或防御扫描访问，则攻击者成功使用悬挂标记攻击窃取敏感信息
