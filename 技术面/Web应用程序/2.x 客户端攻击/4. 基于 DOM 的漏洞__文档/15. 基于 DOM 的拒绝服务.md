# 基于 DOM 的拒绝服务

在本节中，我们将介绍基于 DOM 的拒绝服务漏洞，分析可能导致此类漏洞的汇，并讨论减少 DOM 拒绝服务攻击风险的方法。

## 什么是基于 DOM 的拒绝服务？

当脚本以不安全的方式将攻击者可控制的数据传递给有问题的平台 API（例如调用后可能导致用户计算机消耗过多 CPU 或磁盘空间的 API）时，就会产生基于 DOM 的拒绝服务漏洞。如果浏览器因此限制网站功能（例如拒绝向 `localStorage` 存储数据或终止繁忙脚本），则可能产生副作用。

## 哪些汇可能导致基于 DOM 的拒绝服务漏洞？

以下是可能导致基于 DOM 的拒绝服务漏洞的一些主要汇：

```js
requestFileSystem()
RegExp()
```
