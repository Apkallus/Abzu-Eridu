# 基于 DOM 的 WebSocket URL 投毒

在本节中，我们将介绍如何通过基于 DOM 的攻击对 WebSocket URL 进行投毒，讨论 WebSocket URL 投毒的影响，并提供减少此类攻击风险的建议。

## 什么是基于 DOM 的 WebSocket URL 投毒？

当脚本使用可控数据作为 WebSocket 连接的目标 URL 时，就会发生 WebSocket URL 投毒。攻击者可能利用此漏洞构造一个 URL，当其他用户访问时，会使用户的浏览器打开一个指向攻击者控制下的 URL 的 WebSocket 连接。

## WebSocket URL 投毒有何影响？

WebSocket URL 投毒的潜在影响取决于网站如何使用 WebSocket。如果网站通过 WebSocket 从用户浏览器传输敏感数据，则攻击者可能能够捕获这些数据。

如果应用程序从 WebSocket 服务器读取数据并以某种方式处理，则攻击者可能能够破坏网站的逻辑或对用户发起客户端攻击。
