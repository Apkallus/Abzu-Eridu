# 基于 DOM 的 Ajax 请求头操纵

在本节中，我们将介绍基于 DOM 的 Ajax 请求头操纵，分析此类攻击的潜在影响，并提供减少此类漏洞风险的建议。

## 什么是基于 DOM 的 Ajax 请求头操纵？

Ajax 允许网站向服务器发出异步请求，使 Web 应用程序能够动态更改页面内容，而无需重新加载整个页面。然而，当脚本将攻击者可控制的数据写入通过 `XMLHttpRequest` 对象发出的 Ajax 请求头时，就会产生 Ajax 请求头操纵漏洞。攻击者可能利用此漏洞构造一个 URL，当其他用户访问该 URL 时，会在后续的 Ajax 请求中设置任意的请求头。这可以作为链式利用其他类型攻击的起点，从而提升此漏洞的潜在严重性。

## 基于 DOM 的 Ajax 请求头操纵有何影响？

该漏洞的潜在影响取决于特定 HTTP 头部在 Ajax 请求服务器端处理中所起的作用。如果头部用于控制 Ajax 请求的行为结果，攻击者可能通过操纵头部使用户执行非预期操作。影响也取决于攻击者能够向头部注入的具体内容。

## 哪些汇可能导致基于 DOM 的 Ajax 请求头操纵漏洞？

以下是可能导致基于 DOM 的 Ajax 请求头操纵漏洞的一些主要汇：

```js
XMLHttpRequest.setRequestHeader()
XMLHttpRequest.open()
XMLHttpRequest.send()
jQuery.globalEval()
$.globalEval()
```
