# 基于 DOM 的 HTML5 存储操纵

在本节中，我们将介绍利用 DOM 进行的 HTML5 存储操纵，指出可能用于此类攻击的危险汇，并提供减少此类风险的建议。

## 什么是基于 DOM 的 HTML5 存储操纵？

当脚本将攻击者可控制的数据存储到 Web 浏览器的 HTML5 存储（`localStorage` 或 `sessionStorage`）中时，就会产生 HTML5 存储操纵漏洞。攻击者可能利用此行为构造一个 URL，当其他用户访问该 URL 时，会使用户的浏览器存储攻击者可控制的数据。

此行为本身并不构成安全漏洞。然而，如果应用程序稍后从存储中读取数据并以不安全的方式处理，攻击者可能借助存储机制传递其他基于 DOM 的攻击，例如[跨站脚本](/web-security/cross-site-scripting)和 JavaScript 注入。

## 哪些汇可能导致基于 DOM 的 HTML5 存储操纵漏洞？

以下是可能导致基于 DOM 的 HTML5 存储操纵漏洞的一些主要汇：

```js
sessionStorage.setItem()
localStorage.setItem()
```
