# 基于 DOM 的 Cookie 操纵

在本节中，我们将介绍基于 DOM 的 Cookie 操纵，分析其可能产生的影响，并提出减少此类漏洞风险的建议。

## 什么是基于 DOM 的 Cookie 操纵？

某些基于 DOM 的漏洞允许攻击者操纵他们通常无法控制的数据。这会将原本安全的数据类型（如 Cookie）转变为潜在的“源”。当脚本将攻击者可控制的数据写入 Cookie 的值时，就会产生基于 DOM 的 Cookie 操纵漏洞。

攻击者可能利用此漏洞构造一个 URL，当其他用户访问该 URL 时，会在用户的 Cookie 中设置任意值。许多“汇”本身在很大程度上是无害的，但基于 DOM 的 Cookie 操纵攻击展示了低严重性漏洞有时也可作为高严重性攻击利用链的一部分。例如，如果 JavaScript 未经清理就将来自源的数据写入 `document.cookie`，攻击者便可操纵单个 Cookie 的值以注入任意值：

```javascript
document.cookie = 'cookieName='+location.hash.slice(1);
```

如果网站不安全地反射来自 Cookie 的值且未进行 HTML 编码，攻击者便可利用 Cookie 操纵技术来利用该行为。

## 基于 DOM 的 Cookie 操纵攻击有何影响？

此漏洞的潜在影响取决于 Cookie 在网站中扮演的角色。如果 Cookie 用于控制某些用户操作的结果行为（例如生产模式与演示模式设置），则攻击者可通过操纵 Cookie 的值诱使用户执行非预期的操作。

如果 Cookie 用于跟踪用户会话，攻击者可能执行会话固定攻击：将 Cookie 的值设置为他们从网站获取的有效令牌，然后在受害者后续与网站的交互中劫持会话。此类 Cookie 操纵漏洞不仅可用于攻击存在漏洞的网站，还可用于攻击同一父域下的任何其他网站。

## 哪些汇可能导致基于 DOM 的 Cookie 操纵漏洞？

`document.cookie` 这个汇可能导致基于 DOM 的 Cookie 操纵漏洞。
