# 基于 DOM 的开放重定向

在本节中，我们将介绍什么是基于 DOM 的开放重定向，演示如何构造攻击，并提供减少此类漏洞风险的建议。

## 什么是基于 DOM 的开放重定向？

当脚本将攻击者可控制的数据写入可触发跨域导航的“汇”时，就会产生基于 DOM 的开放重定向漏洞。例如，以下代码由于不安全地处理 `location.hash` 属性而存在漏洞：

```javascript
let url = /https?:\/\/.+/.exec(location.hash);
if (url) {
  location = url[0];
}
```

攻击者可能利用此漏洞构造一个 URL，当其他用户访问该 URL 时，会导致重定向到任意外部域。

## 基于 DOM 的开放重定向有何影响？

例如，这种行为可被用于针对网站用户的网络钓鱼攻击。使用指向正确域且具有有效 TLS 证书（如果使用 TLS）的合法应用 URL，会为钓鱼攻击增加可信度，因为许多用户即使验证了这些特征，也可能不会注意到后续重定向到不同域名的过程。

如果攻击者能够控制传递给重定向 API 的字符串的开头部分，则有可能将此漏洞升级为 JavaScript 注入攻击。攻击者可以构造带有 `javascript:` 伪协议的 URL，当浏览器处理该 URL 时，即可执行任意代码。

## 哪些汇可能导致基于 DOM 的开放重定向漏洞？

以下是可能导致基于 DOM 的开放重定向漏洞的一些主要汇：

```
location
location.host
location.hostname
location.href
location.pathname
location.search
location.protocol
location.assign()
location.replace()
open()
element.srcdoc
XMLHttpRequest.open()
XMLHttpRequest.send()
jQuery.ajax()
$.ajax()
```
