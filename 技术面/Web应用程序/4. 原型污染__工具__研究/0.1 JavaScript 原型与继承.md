# JavaScript 原型与继承

JavaScript 使用原型继承模型，这与许多其他语言使用的基于类的模型有很大不同。在本节中，我们将提供其工作原理的基本概述，以帮助您理解我们关于[原型污染漏洞](https://portswigger.net/web-security/prototype-pollution)的学习材料。

## JavaScript 中的对象是什么？

JavaScript 对象本质上是 `key:value` 对的集合，称为“属性”。例如，以下对象可以表示一个用户：

```javascript
const user =  {
    username: "wiener",
    userId: 01234,
    isAdmin: false
}
```

您可以使用点表示法或方括号表示法来访问对象的属性，以引用它们各自的键：

```javascript
user.username     // "wiener"
user['userId']    // 01234
```

除了数据之外，属性还可以包含可执行的函数。此时，该函数被称为“方法”。

```javascript
const user =  {
    username: "wiener",
    userId: 01234,
    exampleMethod: function(){
        // do something
    }
}
```

上面的示例是一个“对象字面量”，这意味着它是使用花括号语法创建的，以显式声明其属性及其初始值。但重要的是要理解，JavaScript 中几乎所有东西本质上都是对象。在本文中，“对象”一词指代所有实体，而不仅仅是对象字面量。

## JavaScript 中的原型是什么？

JavaScript 中的每个对象都与另一个对象相关联，该对象被称为其原型。默认情况下，JavaScript 会自动为新对象分配其内置原型之一。例如，字符串会自动分配内置的 `String.prototype`。下面您可以看到这些全局原型的一些示例：

```javascript
let myObject = {};
Object.getPrototypeOf(myObject);    // Object.prototype

let myString = "";
Object.getPrototypeOf(myString);    // String.prototype

let myArray = [];
Object.getPrototypeOf(myArray);     // Array.prototype

let myNumber = 1;
Object.getPrototypeOf(myNumber);    // Number.prototype
```

对象会自动继承其分配原型的所有属性，除非它们自身已经拥有相同键的属性。这使得开发人员能够创建可重用现有对象的属性和方法的新对象。

内置原型提供了用于处理基本数据类型的有用属性和方法。例如，`String.prototype` 对象有一个 `toLowerCase()` 方法。因此，所有字符串都自动拥有一个现成的方法，用于将其转换为小写。这省去了开发人员为每个新字符串手动添加此行为的麻烦。

## JavaScript 中的对象继承是如何工作的？

每当您引用对象的属性时，JavaScript 引擎首先尝试直接在对象本身上访问该属性。如果该对象没有匹配的属性，JavaScript 引擎会转而在其原型上查找。给定以下对象，例如，这使您能够引用 `myObject.propertyA`：

您可以使用浏览器控制台来实际查看此行为。首先，创建一个完全空的对象：

```javascript
let myObject = {};
```

接下来，输入 `myObject` 并加上一个点。注意控制台会提示您从属性和方法列表中选择：

![在浏览器控制台中检查原型继承](https://portswigger.net/web-security/prototype-pollution/images/prototype-pollution-console-screenshot.png)

尽管该对象本身没有定义任何属性或方法，但它从内置的 `Object.prototype` 继承了一些属性和方法。

## 原型链

请注意，对象的原型只是另一个对象，它也应该有自己的原型，依此类推。由于 JavaScript 中几乎一切都是对象，这条链最终会追溯到顶层的 `Object.prototype`，其原型为 `null`。

![JavaScript 原型链](https://portswigger.net/web-security/prototype-pollution/images/prototype-pollution-prototype-chain.svg)

至关重要的是，对象不仅继承其直接原型的属性，还继承原型链中其上方所有对象的属性。在上面的示例中，这意味着 `username` 对象可以访问 `String.prototype` 和 `Object.prototype` 的属性和方法。

## 使用 `__proto__` 访问对象的原型

每个对象都有一个特殊属性，可用于访问其原型。尽管该属性没有正式的标准名称，但 `__proto__` 是大多数浏览器使用的事实标准。如果您熟悉面向对象语言，此属性既是对象原型的 getter 又是 setter。这意味着您可以使用它来读取原型及其属性，甚至在必要时重新分配它们。

与任何属性一样，您可以使用方括号表示法或点表示法来访问 `__proto__`：

```javascript
username.__proto__
username['__proto__']
```

您甚至可以链式引用 `__proto__` 来沿着原型链向上查找：

```javascript
username.__proto__                         // String.prototype
username.__proto__.__proto__               // Object.prototype
username.__proto__.__proto__.__proto__     // null
```

## 修改原型

尽管通常被认为是不良实践，但修改 JavaScript 的内置原型是可能的，就像修改任何其他对象一样。这意味着开发人员可以自定义或覆盖内置方法的行为，甚至添加新方法来执行有用的操作。

例如，现代 JavaScript 为字符串提供了 `trim()` 方法，使您可以轻松删除任何前导或尾随空白。在此内置方法引入之前，开发人员有时会通过类似以下方式将自定义实现添加到 `String.prototype` 对象中：

```javascript
String.prototype.removeWhitespace = function(){
    // remove leading and trailing whitespace
}
```

得益于原型继承，所有字符串随后都可以使用此方法：

```javascript
let searchTerm = "  example ";
searchTerm.removeWhitespace();    // "example"
```
