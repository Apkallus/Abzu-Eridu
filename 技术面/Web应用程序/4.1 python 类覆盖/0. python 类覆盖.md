# python 类覆盖

与 JavaScript 中的原型污染部分类似，当不可信输入修改类级别属性而非实例级别数据时，Python 可能会遭受类“覆盖”漏洞。由于 Python 类是可变的，对类的单次写入会影响所有依赖该属性的现有和未来实例。如果攻击者能够影响诸如 `setattr`、反序列化对象或任何直接写入类的逻辑等函数，他们就可以改变全局行为。

> 差异：
- JS 原型“污染”：
    - 实例属性未被设置
    - 添加新属性到原型
    - 实例查找属性时回溯原型链
- python 类“覆盖”
    - 直接设置类、方法、属性、全局变量的值（覆盖/替换）
    

易受攻击的代码示例：

```python
some_var = "change me!"

class Dummy:
    def __init__(self):
        pass

def merge(source, destination):
    for key, value in source.items():
        if hasattr(destination, "get"):
            if destination.get(key) and type(value) == dict:
                merge(value, destination.get(key))
            else:
                destination[key] = value
        elif hasattr(destination, key) and type(value) == dict:
            merge(value, getattr(destination, key))
        else:
            setattr(destination, key, value)

some_class = Dummy()

payload = {
    "__init__": {
        "__globals__": {
            "some_var": "polluted"
        }
    }
}

merge(payload, some_class)

print(some_var)  # 输出: polluted
```

攻击者使用此技术，将变量 `some_var` 覆盖为攻击者指定的新值。
