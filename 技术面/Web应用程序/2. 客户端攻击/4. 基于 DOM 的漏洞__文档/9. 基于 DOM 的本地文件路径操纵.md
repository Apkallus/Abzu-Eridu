# 基于 DOM 的本地文件路径操纵

在本节中，我们将介绍什么是基于 DOM 的本地文件路径操纵，分析攻击的潜在影响，列举可能导致此类漏洞的一些汇，并提供减少风险的建议。

## 什么是基于 DOM 的本地文件路径操纵？

当脚本将攻击者可控制的数据作为 `filename` 参数传递给文件处理 API 时，就会产生本地文件路径操纵漏洞。攻击者可能利用此漏洞构造一个 URL，当其他用户访问该 URL 时，会导致用户的浏览器打开任意的本地文件。

## 基于 DOM 的本地文件路径操纵有何影响？

此漏洞的潜在影响取决于网站如何使用打开的文件：

- 如果网站从文件中读取数据，攻击者可能能够检索这些数据。
- 如果网站将特定数据写入敏感文件，攻击者也可能将自己的数据写入该文件，例如操作系统的配置文件。

在这两种情况下，潜在漏洞的实际可利用性可能取决于网站上是否存在其他合适的功能。

## 哪些汇可能导致基于 DOM 的本地文件路径操纵漏洞？

以下是可能导致基于 DOM 的本地文件路径操纵漏洞的一些主要汇：

```js
FileReader.readAsArrayBuffer()
FileReader.readAsBinaryString()
FileReader.readAsDataURL()
FileReader.readAsText()
FileReader.readAsFile()
FileReader.root.getFile()
```
