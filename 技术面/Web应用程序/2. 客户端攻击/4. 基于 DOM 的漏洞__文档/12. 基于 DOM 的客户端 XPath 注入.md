# 基于 DOM 的客户端 XPath 注入

在本节中，我们将介绍什么是基于 DOM 的 XPath 注入，讨论此类漏洞的潜在影响，并提供减少风险的建议。

## 什么是基于 DOM 的 XPath 注入？

当脚本将攻击者可控制的数据合并到 XPath 查询中时，就会产生基于 DOM 的 XPath 注入漏洞。攻击者可能利用此行为构造一个 URL，当其他用户访问该 URL 时，会触发任意 XPath 查询的执行，从而导致网站检索和处理不同的数据。

## 基于 DOM 的 XPath 注入有何影响？

根据查询结果的使用目的，攻击者可能能够破坏网站的逻辑，或代表用户触发非预期操作。

## 哪些汇可能导致 XPath 注入漏洞？

以下是可能导致基于 DOM 的 XPath 注入漏洞的一些主要汇：

```js
document.evaluate()
element.evaluate()
```
