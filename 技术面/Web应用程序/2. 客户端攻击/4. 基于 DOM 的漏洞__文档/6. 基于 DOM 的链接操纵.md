# 基于 DOM 的链接操纵

在本节中，我们将介绍基于 DOM 的链接操纵是什么，分析攻击的影响，并提供预防此类攻击的建议。

## 什么是基于 DOM 的链接操纵？

当脚本将攻击者可控制的数据写入当前页面内的导航目标（例如可点击的链接或表单的提交 URL）时，就会产生基于 DOM 的链接操纵漏洞。攻击者可能利用此漏洞构造一个 URL，当其他用户访问该 URL 时，会修改响应中链接的目标地址。

## 基于 DOM 的链接操纵攻击有何影响？

攻击者可以利用此漏洞执行多种攻击，包括：

- 将用户重定向到任意外部 URL，从而助长网络钓鱼攻击。
- 诱使用户将敏感表单数据提交到攻击者控制的服务器。
- 更改与链接关联的文件或查询字符串，导致用户在应用程序内执行非预期操作。
- 通过注入包含 XSS 漏洞利用的站内链接，绕过浏览器反 XSS 防御机制。之所以有效，是因为反 XSS 防御通常不会识别站内链接。

## 哪些汇可能导致基于 DOM 的链接操纵漏洞？

以下是可能导致基于 DOM 的链接操纵漏洞的一些主要汇：

```
element.href
element.src
element.action
```
