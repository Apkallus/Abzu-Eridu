# 基于 DOM 的客户端 JSON 注入

在本节中，我们将介绍与 DOM 相关的客户端 JSON 注入，分析此类攻击可能造成的危害，并提供减少此类漏洞风险的建议。

## 什么是基于 DOM 的 JSON 注入？

当脚本将攻击者可控制的数据合并到被解析为 JSON 数据结构并由应用程序处理的字符串中时，就会产生基于 DOM 的 JSON 注入漏洞。攻击者可能利用此行为构造一个 URL，当其他用户访问该 URL 时，会导致任意 JSON 数据被处理。

## 基于 DOM 的 JSON 注入攻击有何影响？

根据这些数据的使用目的，攻击者可能能够破坏网站的逻辑，或代表其他用户触发非预期操作。

## 哪些汇可能导致基于 DOM 的 JSON 注入漏洞？

```js
JSON.parse()
jQuery.parseJSON()
$.parseJSON()
```
