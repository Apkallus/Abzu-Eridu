# 基于 DOM 的 JavaScript 注入

在本节中，我们将介绍基于 DOM 的 JavaScript 注入漏洞，讨论它们对受害者的潜在影响，并提供减少此类漏洞风险的建议。

## 什么是基于 DOM 的 JavaScript 注入？

当脚本将攻击者可控制的数据作为 JavaScript 执行时，就会产生基于 DOM 的 JavaScript 注入漏洞。攻击者可利用此漏洞构造一个 URL，当其他用户访问该 URL 时，攻击者提供的任意 JavaScript 将在用户浏览器会话的上下文中执行。

诱使用户访问攻击者构造的恶意 URL 的方式多种多样，与反射型跨站脚本漏洞的常见攻击传递向量类似。更多信息请参阅我们的 [DOM XSS](/web-security/cross-site-scripting/dom-based) 页面。

## 基于 DOM 的 JavaScript 注入攻击有何影响？

攻击者提供的代码可以执行多种操作，例如窃取受害者的会话令牌或登录凭据、代表受害者执行任意操作，甚至记录其按键输入。

## 哪些汇可能导致基于 DOM 的 JavaScript 注入漏洞？

以下是可能导致基于 DOM 的 JavaScript 注入漏洞的一些主要汇：

```js
eval()
Function()
setTimeout()
setInterval()
setImmediate()
execCommand()
execScript()
msSetImmediate()
range.createContextualFragment()
crypto.generateCRMFRequest()
```
