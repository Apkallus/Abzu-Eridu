# DOM 数据操纵

在本节中，我们将介绍什么是 DOM 数据操纵，讨论此类攻击的潜在影响，并提供减少此类漏洞风险的建议。

## 什么是 DOM 数据操纵？

当脚本将攻击者可控制的数据写入 DOM 中用于可见 UI 或客户端逻辑的字段时，就会产生 DOM 数据操纵漏洞。攻击者可能利用此漏洞构造一个 URL，当其他用户访问该 URL 时，会修改客户端 UI 的外观或行为。DOM 数据操纵漏洞可通过反射型或存储型 DOM 攻击加以利用。

## DOM 数据操纵有何影响？

在轻微程度上，攻击者可能利用此漏洞对网站进行虚拟破坏，例如更改特定页面上显示的文本或图像。但攻击可能更为严重。例如，如果攻击者能够更改元素的 `src` 属性，他们可能通过导入恶意 JavaScript 文件诱使用户执行非预期操作。

## 哪些汇可能导致 DOM 数据操纵漏洞？

以下是可能导致 DOM 数据操纵漏洞的一些主要汇：

```js
script.src
script.text
script.textContent
script.innerText
element.setAttribute()
element.search
element.text
element.textContent
element.innerText
element.outerText
element.value
element.name
element.target
element.method
element.type
element.backgroundImage
element.cssText
element.codebase
document.title
document.implementation.createHTMLDocument()
history.pushState()
history.replaceState()
```

## 如何防止 DOM 数据操纵漏洞？

除了[基于 DOM 的漏洞](/web-security/dom-based)页面中描述的常规措施外，还应避免允许来自任何不受信任来源的数据被动态写入 DOM 数据字段。

请注意，Burp Suite 会通过静态代码分析自动识别此问题，这可能会导致误报，即某些问题实际上并不可利用。应审查相关代码和执行路径，以确定此漏洞是否确实存在，或是否已有缓解措施能够防止其被利用。
