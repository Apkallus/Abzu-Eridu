# 核心技能

我们尽可能让 Web Security Academy 的实验室贴近真实场景，但请注意，每个实验室仅演示了某类漏洞的一种可能变体。在实践中，重要的是能够识别同一底层漏洞的细微不同表现，并知道如何相应地调整你所学到的技术。

在本节中，你将学习一些广泛适用的技能，帮助你将在实验室中学到的知识应用于其他真实目标。我们涵盖了各种通用技巧和窍门，以及如何使用 Burp 的一些鲜为人知的功能来优化你的工作流程。我们还提供了一些额外的实验室，供你亲自测试。

我们计划在近期扩展本节内容，涵盖更多核心技能。

## 使用编码混淆攻击

简单地从实验室解决方案中复制攻击，并在真实网站上尝试，效果有限。你测试的网站通常已经过其他用户的审计，并应用了许多补丁。要进一步提升技能，你需要调整所学技术以克服这些额外障碍，挖掘其他测试人员可能忽略的漏洞。

在本节中，我们将提供一些建议，说明如何混淆恶意负载以绕过输入过滤器和其他有缺陷的防御措施。具体来说，你将学习如何利用标准编码来利用配置错误和连接系统之间的处理差异。

## 在手动测试中使用 Burp Scanner

测试某些类型的漏洞可能相当乏味，尤其是那些涉及在每个可控输入中尝试多种注入技术的漏洞。由于现实中的时间限制，手动完成这些工作往往不切实际，可能导致你遗漏关键漏洞。

你可以通过多种方式，使用 Burp Scanner 来补充自己的知识和直觉，从而优化工作流程。这不仅降低了遗漏的风险，还能帮助你快速识别潜在攻击向量，从而节省宝贵时间。这意味着你可以将时间和精力集中在那些不易自动化的事情上，例如研究如何利用易受攻击的行为，或将其与你的其他发现串联起来。
