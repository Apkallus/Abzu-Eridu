我已经设置了基于地理位置的流量路由——你能智胜它吗？

你正试图获取 flag，但有一个陷阱：对真实服务的访问受你的地理位置限制。只有来自特定区域的请求才会被路由到存放 flag 的服务器。其他所有人则会被送到某个……不太有趣的地方。

你可以从[这里]开始你的旅程，尝试找到 flag。

供参考，本挑战使用的完整 Nginx 配置可在[这里]获取。

```log
load_module /usr/lib/nginx/modules/ngx_http_geoip2_module.so;

worker_processes 1;
events { worker_connections 1024; }

http {
    include       mime.types;
    default_type  application/octet-stream;

    geoip2 /etc/nginx/GeoLite2-Country.mmdb {
        auto_reload 5m;
        $geoip2_data_country_code default=ZZ country iso_code;
    }

    upstream north {
        server 127.0.0.1:8000;
    }

    upstream south {
        server 127.0.0.1:9000;
    }

    server {
        listen 80;

        location / {
            if ($geoip2_data_country_code = IS) {
                proxy_pass http://south;
            }

            proxy_pass http://north;
        }
    }
}

```
- `geoip2_data_country_code` 
    - 默认为 `ZZ`，路由到 `north` 的 `127.0.0.1:8000`
    - 当 `IS` 时，路由到 `south` 的 `127.0.0.1:9000`
        - `IS` 对应冰岛

## 探测

使用任意冰岛 IP 到 IP 覆盖头部
- 无效，无代理头部设置，查看原始 IP。或需使用 VPN
