凭据填充是指将窃取的用户名和密码对（“凭据”）自动注入网站登录表单，以欺诈方式获取用户账户的访问权限。

由于许多用户会重复使用相同的密码和用户名/电子邮件，当这些凭据泄露时（例如通过数据库泄露或钓鱼攻击），将这些被盗凭据集提交到数十或数百个其他网站，也可能让攻击者入侵那些账户。下载凭据转储[此处](https://challenge-files.cylabacademy.net/library/d7d3c2b21e2f63bc6503ec0e59e80bef4a22a182ad87d2151b4142ff84352955/creds-dump.txt)。

```

khalid;sting
...
```

格式为 `用户名;密码`（或对调）
