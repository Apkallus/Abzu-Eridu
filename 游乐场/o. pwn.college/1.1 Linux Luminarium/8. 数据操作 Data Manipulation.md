# 数据操作

你已经学习了管道数据、指定输入等。让我们开始把东西组合起来！在本模块中，你将学习若干用于操作数据的命令，它们将帮助你在 shell 中取得出色成果。

## 进一步学习的程序

shell 高手用来操作数据的程序数不胜数。每个程序做特定不同的事情，通常遵循 [Unix 哲学](https://en.wikipedia.org/wiki/Unix_philosophy)：只做一件事并把它做好。你可以将这些程序串联成非常棒的组合逻辑。以下是一些示例，你可以在完成 Linux Luminarium 后、准备好时自行学习：

- [awk](https://linux.die.net/man/1/awk) 用于复杂文本处理
- [cut](https://linux.die.net/man/1/cut) 用于提取行的一部分
- [less](https://linux.die.net/man/1/less) 用于交互式文件阅读器
- [more](https://linux.die.net/man/1/more) 用于一次读取文件的一部分
- [paste](https://linux.die.net/man/1/paste) 用于合并文件
- [sed](https://linux.die.net/man/1/sed) 用于复杂文本操作
- [sort](https://linux.die.net/man/1/sort) 用于排序数据
- [tail](https://linux.die.net/man/1/tail) 作为 `head` 的反向操作
- [uniq](https://linux.die.net/man/1/uniq) 用于过滤流中的唯一数据

## 挑战

### 转换字符

管道数据的目的之一是*修改*它。许多 Linux 命令能帮助你以非常酷的方式修改数据。其中之一是 `tr`，它转换通过标准输入接收的字符，并将它们打印到标准输出。

在最基本的用法中，`tr` 将第一个参数中提供的字符转换为第二个参数中提供的字符：

```console
hacker@dojo:~$ echo OWN | tr O P
PWN
hacker@dojo:~$
```

它也可以处理多个字符，将第一个参数中不同位置的字符替换为第二个参数中关联的字符。

```console
hacker@dojo:~$ echo PWM.COLLAGE | tr MA NE
PWN.COLLEGE
hacker@dojo:~$
```

现在，你来试试！在本关卡中，`/challenge/run` 将打印 flag，但会交换所有字符的大小写（例如，`A` 会变成 `a`，反之亦然）。你能用 `tr` 撤销它并获取 flag 吗？

### 删除字符

`tr` 还可以将字符转换为空（即*删除*它们）。这通过 `-d` 标志和一个指定要删除哪些字符的参数完成：

```console
hacker@dojo:~$ echo PAWN | tr -d A
PWN
hacker@dojo:~$
```

非常简单！现在你来试试。在 `/challenge/run` 的输出中，我会在 flag 字符之间穿插一些诱饵字符（具体是：`^` 和 `%`）。使用 `tr -d` 删除它们！

### 删除换行符

一类常见的要删除的字符是行分隔符。当你有一个数据流，想将其转换为单行以便进一步处理时，就会遇到这种情况。你可以像指定任何其他字符一样指定换行符，方法是*转义*它们：

```console
hacker@dojo:~$ echo "hello_world!" | tr _ "\n"
hello
world!
hacker@dojo:~$
```

这里，反斜杠（`\`）表示紧随其后的字符是某个通常难以输入 shell 的字符的替身。换行符当然难以输入，因为当你通常按 `Enter` 时，会运行命令本身。`\n` 是这个换行符的替身，并且它*必须*放在引号中，以防止 shell 解释器自己尝试解释它，而是将其传递给 `tr`。

现在，让我们将其与删除结合起来。在本挑战中，我们会向 flag 中注入一堆换行符。使用 `tr` 的 `-d` 标志和转义换行符指定来删除它们！

---

**有趣的事实！** 想*实际*替换反斜杠（`\`）字符吗？因为 `\` 是转义字符，所以你必须转义它！`\\` 会被 `tr` 视为一个反斜杠。这与本挑战无关，但仍然是个有趣的事实！

### 用 head 提取前几行

在你的 Linux 之旅中，你会遇到需要只获取非常冗长程序早期输出的情况。为此，你会用到 `head`！`head` 命令用于显示其输入的前几行：

```console
hacker@dojo:~$ cat /something/very/long | head
this
is
just
the
first
ten
lines
of
the
file
hacker@dojo:~$
```

默认情况下，它显示前 10 行，但你可以用 `-n` 选项控制：

```console
hacker@dojo:~$ cat /something/very/long | head -n 2
this
is
hacker@dojo:~$
```

本挑战的 `/challenge/pwn` 会输出一堆数据，你需要将其通过管道传给 `head`，只抓取前 7 行，然后将它们继续通过管道传给 `/challenge/college`；如果你做对了，它就会给你 flag！你的解决方案将是一个长复合命令，包含*两个*管道，连接三个命令。祝你好运！

### 提取文本的特定部分

有时，你想抓取特定的数据列，例如第一列、第三列或第 42 列。为此，有 `cut` 命令。

例如，假设你有以下数据文件：

```console
hacker@dojo:~$ cat scores.txt
hacker 78 99 67
root 92 43 89
hacker@dojo:~$
```

你可以使用 `cut` 提取特定列：

```console
hacker@dojo:~$ cut -d " " -f 1 scores.txt
hacker
root
hacker@dojo:~$ cut -d " " -f 2 scores.txt
78
92
hacker@dojo:~$ cut -d " " -f 3 scores.txt
99
43
hacker@dojo:~$
```

`-d` 参数指定列*分隔符*（列如何分隔）。在本例中，它是一个空格字符。当然，这里必须加引号，以便 shell 知道空格是一个参数，而不是分隔其他参数的空格！`-f` 参数指定*字段*编号（要提取哪一列）。

在本挑战中，`/challenge/run` 程序会给你一堆行，每行包含随机数字和单个字符（flag 的字符）作为列。使用 `cut` 提取 flag 字符，然后将它们通过管道传给 `tr -d "\n"`（像上一关一样！），将它们连接成单行。你的解决方案看起来会像 `/challenge/run | cut ??? | tr ???`，其中 `???` 由你填写。

### 排序数据

文件（或命令的输出行）并不总是按你需要的顺序排列！`sort` 命令帮助你组织数据。它从输入（或文件）读取行，并按排序顺序输出它们：

```console
hacker@dojo:~$ cat names.txt
  hack
  the
  planet
  with
  pwn
  college
hacker@dojo:~$ sort names.txt
  college
  hack
  planet
  pwn
  the
  with
hacker@dojo:~$
```

默认情况下，`sort` 按字母顺序排列行。参数可以改变这一点：

- `-r`：反向顺序（Z 到 A）
- `-n`：按数值排序（用于数字）
- `-u`：仅保留唯一行（删除重复项）
- `-R`：随机顺序！

在本挑战中，`/challenge/flags.txt` 文件中包含 100 个假 flag，真实 flag 混在其中。按字母顺序排序时，真实 flag 将位于末尾（我们在生成假 flag 时确保了这一点）。去获取它吧！
