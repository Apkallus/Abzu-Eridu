## 从文档中学习

你通常需要文档，只是为了弄清楚如何使用这些程序，而一个具体场景就是弄清楚在命令行上要指定哪些参数。本模块将主要深入这一概念，作为弄清如何总体使用程序的切入点。在本模块余下部分，你将通过多种方式向环境询问程序帮助，但首先，我们会深入阅读文档的概念。

程序的正确用法在很大程度上取决于是否正确指定参数。回想 `Basic Commands` 模块的 `hidden files` 挑战中 `ls -a` 的 `-a`：那个 `-a` 是一个*参数*，告诉 `ls` 列出隐藏文件和非隐藏文件。因为我们*想要*列出隐藏文件，所以在我们的场景中，带 `-a` 参数调用 `ls` 是正确的用法。

## 学习复杂用法

虽然大多数命令的使用都很直接，但有些命令的用法可能相当复杂。例如，`sed` 和 `awk` 这类命令的参数——我们现在肯定不会深入讨论——是用一种深奥编程语言写成的完整程序！在 `cd` 和 `awk` 之间的某个谱系上，有些命令会接受参数，而这些参数本身又接受参数……

这听起来很疯狂，但你在 `Basic Commands` 的 `find` 关卡中已经遇到过。`find` 有一个 `-name` 参数，而 `-name` 参数本身又接受一个参数，用来指定要搜索的名称。许多其他命令也类似。

以下是本关卡中 `/challenge/challenge` 的文档：

> 欢迎来到 `/challenge/challenge` 的文档！当给定 `--printfile` 参数时，此程序会将任意文件打印到终端。`--printfile` 的参数是要读取的文件路径。例如，`/challenge/challenge --printfile /etc/hostname` 将打印容器的主机名！

## 阅读手册

本关卡介绍 `man` 命令。`man` 是 `manual` 的缩写，会显示你作为参数传入的命令的手册（如果可用）。例如，假设我们想了解 `yes` 命令（*是的*，这是一个真实命令）：

```console
hacker@dojo:~$ man yes
```

这将显示 `yes` 的手册页，内容大致如下：

```text

SYNOPSIS

       yes OPTION

DESCRIPTION
```

重要的部分有：

```text
NAME(1)                           CATEGORY                          NAME(1)

NAME
	This gives the name (and short description) of the command or
	concept discussed by the page.

SYNOPSIS
	This gives a short usage synopsis. These synopses have a standard
	format. Typically, each line is a different valid invocation of the
	command, and the lines can be read as:

	COMMAND [OPTIONAL_ARGUMENT] SINGLE_MANDATORY_ARGUMENT
	COMMAND [OPTIONAL_ARGUMENT] MULTIPLE_ARGUMENTS...

	Other man pages or online resources that might be useful.

```

用方向键和 PgUp/PgDn 在手册页中滚动。阅读完手册页后，按 `q` 退出。

手册页存储在集中式数据库中。如果你好奇，这个数据库位于 `/usr/share/man` 目录，但你永远不需要直接与它交互：只需使用 `man` 命令查询它。`man` 命令的参数不是文件路径，而只是条目名称本身（例如，你运行 `man yes` 来查找 `yes` 手册页，而不是 `man /usr/bin/yes`——后者是 `yes` 程序的实际路径，但会导致 `man` 显示乱码）。

## 搜索手册

## 有用的程序

有些程序没有 man 手册页，但如果用特殊参数调用，它们可能会告诉你如何运行。通常这个参数是 `--help`，但也常常是 `-h`，或者在少数情况下是 `-?`、`help`，或其他奇特值，如 `/?`（不过后者在 Windows 上更常见）。

在本关卡中，你将练习使用 `--help` 阅读程序的文档。试试看！

## 内置命令的帮助

有些命令不是带有 man 手册页和帮助选项的程序，而是内置于 shell 本身。这些称为*内置命令*。内置命令的调用方式与命令一样，但由 shell 内部处理，而不是启动其他程序。通过运行*内置命令* `help` 来获取 shell 内置命令列表，如下所示：

```console
hacker@dojo:~$ help
```

通过将特定内置命令传给 `help` 内置命令来获取其帮助。让我们看看前面已经使用过的内置命令 `cd`！

```console
hacker@dojo:~$ help cd
cd: cd [-L|[-P [-e]] [-@]] [dir]
    Change the shell working directory.
    
    Change the current directory to DIR.  The default DIR is the value of the
    HOME shell variable.
...
```

一些不错的信息！在本挑战中，我们将练习使用 `help` 查找内置命令的帮助。本挑战的 `challenge` 命令是一个 shell 内置命令，而不是程序。和之前一样，你需要查找它的帮助，以弄清要传给它的秘密值！
