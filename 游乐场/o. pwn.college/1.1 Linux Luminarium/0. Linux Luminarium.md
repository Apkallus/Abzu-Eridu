# Linux Luminarium

https://pwn.college/linux-luminarium/

欢迎来到 `Linux Luminarium`！
这个 `dojo` 将温和地教你如何使用 `Linux` 命令行界面，并在此过程中植入一些核心 `Linux` 概念。
这远非互联网上唯一的此类资源，我们会努力在适当之处链接到其他资源。

我们尽力避免要求你具备任何 `Linux` 知识，但我们确实期望你已经学会了 [如何使用道场基础设施本身]。

**注意：** 这个 `dojo` 仍在开发中，*并且* 是一项社区协作成果！
如果你有兴趣贡献，请前往 [GitHub](https://github.com/pwncollege/challenges/tree/main/challenges/linux-luminarium)！
如果你有问题、评论、反馈等，请加入我们的 [Discord 频道](https://discord.com/channels/750635557666816031/1241436610369949758)。

**注意：** `Linux Luminarium` *非常* 入门。
如果你已经熟悉 `Linux`，可以随意跳过它（除非它是课程作业的一部分，这种情况下显然不要跳过）！

**注意：** 这个 `dojo` **并非** 旨在刁难！
有时，`pwn.college` 平台自身的升级和架构调整可能会破坏一些挑战。
如果某个挑战表现异常，请在 Discord 频道告知我们！
