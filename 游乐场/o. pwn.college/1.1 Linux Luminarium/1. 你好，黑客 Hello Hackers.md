# 你好，黑客们

https://pwn.college/linux-luminarium/hello/

本模块将教你与命令行交互的**最基础**知识！*命令行*让你可以执行*命令*。当你启动终端时，它会执行一个命令行 `shell`，看起来像这样：

```console
hacker@dojo:~$
```

这称为提示符（`prompt`），它在提示你输入命令。我们来看看这里各部分：

- 提示符中的 `hacker` 是当前用户的用户名（`username`）。在 pwn.college DOJO 环境中，它就是 “hacker”。
- 在上面的示例中，提示符里的 `dojo` 部分是 shell 所在机器的主机名（`hostname`）（如果你是一名每天要管理多台机器的系统管理员，这个提醒会很有用）。在上面的示例中，主机名是 `dojo`，但在 pwn.college 中，它会根据你正在尝试的挑战名称生成。
- 我们稍后会介绍 `~` 的含义 :-)
- 提示符末尾的 `$` 表示 `hacker` 不是管理用户。在 pwn.college 后续更靠后的模块中，当你学会使用漏洞利用成为管理用户时，你会看到提示符通过打印 `#` 而不是 `$` 来表示这一点，那时你就知道自己成功了！

总之，提示符正在等待你的命令。继续进入第一个挑战，学习如何实际执行命令吧！

#### 命令入门

在这个挑战中，你将调用第一条命令！当你输入一条命令并按回车时，命令就会被调用，如下所示：

```console
hacker@dojo:~$ whoami
hacker
hacker@dojo:~$
```

这里，用户执行了 `whoami` 命令，它会简单地把用户名（`hacker`）打印到终端。命令终止后，shell 会再次显示提示符，准备接收下一条命令。

在本关卡中，调用 `hello` 命令来获取 flag！请记住：Linux 中的命令区分大小写：`hello` 与 `HELLO` 不同。

#### 参数入门

让我们尝试更复杂一点的内容：带 `arguments`（参数）的命令。所谓参数，就是我们传给命令的额外数据。当你输入一行文本并按回车时，shell 实际上会把你的输入解析为命令及其 `arguments`（参数）。第一个词是命令，后续的词是参数。观察：

```console
hacker@dojo:~$ echo Hello
Hello
hacker@dojo:~$
```

在这个例子中，命令是 `echo`，参数是 `Hello`。`echo` 是一个简单命令，它会把自己的所有参数“回显”到终端上，就像上面的会话那样。

我们来看看带多个参数的 `echo`：

```console
hacker@dojo:~$ echo Hello Hackers!
Hello Hackers!
hacker@dojo:~$
```

在这个例子中，命令是 `echo`，`Hello` 和 `Hackers!` 是传给 `echo` 的两个参数。很简单！

在这个挑战中，要获取 flag，你必须运行 `hello` 命令（不是 `echo` 命令），并传入单个参数 `hackers`。现在就试试吧！

#### 命令历史

你会输入大量命令，每次从头输入所有内容会很烦人。幸运的是，shell 会保存你调用的每条命令的 `history`（历史记录）。

你可以用上/下方向键翻阅这些已保存的命令，我们将在本挑战中练习这一点。本挑战会把 flag 注入你的历史记录中。打开终端，按上方向键，然后抓住它！在其他挑战中，历史记录会包含你已运行命令的日志，因此如果你需要再次运行类似的命令，就可以用方向键翻阅并找到它！
