# 终端多路复用

是否曾因 `SSH` 连接断开而丢失所有工作？是否曾想运行多个终端，却不想打开十几个窗口？进入终端多路复用的世界吧！

#### 启动 Screen

让我们直接开始！

`screen` 是一个在你的终端内部创建虚拟终端的程序。它有点像拥有多个浏览器标签页，只不过是为你的命令行准备的！

启动 `screen` 非常简单：

```console
hacker@dojo:~$ screen
```

就这样！你现在已经在一个 `screen` 会话中了。它看起来*完全*像一个终端，但其中还有等待被发现的新能力。

在本挑战中，我们已经设置好，只需启动 `screen` 就能获得 flag。很简单！

---

**注意：**  
当你的命令行使用完毕后，输入 `exit` 或按 `Ctrl-D` 离开 `screen` 会话。然后 `screen` 将终止，并把你返回到*原始* shell。

#### 分离与重新连接

现在，我们将通过分离的魔法开始深入！

想象你正通过远程连接处理重要工作，而连接突然断开。在普通终端中（在这个很棒的 dojo 环境之外），一切都会丢失。使用 `screen`，你的工作会继续运行，你可以稍后重新连接！

你也可以故意分离，我们将在本挑战中这样做。按下 `Ctrl-A`，然后按 `d`（表示 detach）即可分离。这会让你返回普通终端，同时你的会话继续在后台运行。

```console
hacker@dojo:~$ screen
[doing some work...]
[Press Ctrl-A, then d]
[detached from 12345.pts-0.hostname]
hacker@dojo:~$ 
```

要重新连接，你可以使用 `screen` 的 `-r` 参数：

```console
hacker@dojo:~$ screen -r
```

在本挑战中，你需要：

1. 启动 `screen`
2. 从中分离。
3. 运行 `/challenge/run`（这会秘密地将 flag 发送到你已分离的会话！）
4. 重新连接以查看你的奖品

---

**趣闻：**  
在默认配置中，`Ctrl-A` 是 `screen` 所有快捷键的激活键。所有 `screen` 功能都通过以 `Ctrl-A` 开头的某种命令组合来激活。

**提示：**  
记住：按住 `Ctrl` 并按 `A`，然后松开两者并按 `d`。

**提示：**  
如果你看到 `[detached from...]`，就说明你做对了！

#### 查找会话

是时候做一些 `screen` 侦探工作了！

如果你成为 `screen` 的忠实用户，最终不可避免地会有多个会话在运行。如何找到正确的那个来重新连接呢？

我们可以列出它们：

```console
hacker@dojo:~$ screen -ls
There are screens on:
        23847.mysession   (Detached)
        23851.goodwork    (Detached)
        23855.morework    (Detached)
3 Sockets in /run/screen/S-hacker.
```

会话标识符由每个 `screen` 进程的 `PID`、一个点以及 `screen` 会话名称组成。要连接到特定会话，可以将它的名称或 `PID` 作为参数传给 `screen -r`。

```console
hacker@dojo:~$ screen -r goodwork
```

在本挑战中，我们为你创建了三个 `screen` 会话。其中一个包含 flag。另外两个是诱饵！

你需要逐个检查，直到找到它。不要忘记在尝试下一个会话前分离（`Ctrl-A d`）！

#### 切换窗口

好吧，到目前为止，`screen` 只是一种奇怪的“终端中的终端”。但它能做的远不止这些！

在单个 `screen` 会话中，你可以拥有多个窗口，就像浏览器有多个标签页一样。这对于组织不同任务非常方便！

这些窗口通过不同的键盘快捷键处理，全部以 `Ctrl-A` 开头：

- `Ctrl-A c`  
  创建新窗口

- `Ctrl-A n`  
  下一个窗口

- `Ctrl-A p`  
  上一个窗口

- `Ctrl-A 0` 到 `Ctrl-A 9`  
  直接跳转到窗口 0-9

- `Ctrl-A "`  
  调出所有窗口的选择菜单

在本挑战中，我们设置了一个包含两个窗口的 `screen` 会话：

- 窗口 0 有……好吧，你得切换到那里才能知道！
- 窗口 1 有一条欢迎消息

使用 `screen -r` 连接到该会话，然后使用上面的某个组合键切换到窗口 1。去拿 flag 吧！

#### 分离与重新连接（tmux）

让我们用 `tmux` 尝试同样的事情！

`tmux`（终端多路复用器）是 `screen` 更年轻、更现代的“表亲”。它做同样的事情，但使用一些不同的键绑定。最大的区别？`tmux` 使用 `Ctrl-B` 而不是 `Ctrl-A` 作为命令前缀。

因此，要从 `tmux` 分离，按下 `Ctrl-B`，然后按 `d`。

```console
hacker@dojo:~$ tmux
[doing some work...]
[Press Ctrl-B, then d]
[detached (from session 0)]
hacker@dojo:~$ 
```

命令也有所不同：

- `tmux ls`  
  列出会话

- `tmux attach` 或 `tmux a`  
  重新连接到会话

在本挑战中：

1. 启动 `tmux`
2. 从中分离。
3. 运行 `/challenge/run`（这会将 flag 发送到你已分离的会话！）
4. 重新连接以查看你的奖品

#### 切换窗口（tmux）

让我们学习在 `tmux` 中导航窗口！

就像 `screen` 一样，`tmux` 也有窗口。组合键不同，但概念相同：

- `Ctrl-B c`  
  创建新窗口

- `Ctrl-B n`  
  下一个窗口

- `Ctrl-B p`  
  上一个窗口

- `Ctrl-B 0` 到 `Ctrl-B 9`  
  跳转到窗口 0-9

- `Ctrl-B w`  
  查看一个漂亮的窗口选择器

`tmux` 会在底部的状态栏中显示你的窗口，看起来像：

```log
[0] 0:bash* 1:bash
```

`*` 表示当前窗口，每个条目还会显示创建该窗口时运行的程序。

我们创建了一个包含两个窗口的 `tmux` 会话：

- 窗口 0 有 flag！
- 窗口 1 有你的热情欢迎。

去拿 flag 吧！
