# 路径遍历

路径遍历（Path Traversal），也称为目录遍历，是一种安全漏洞，允许攻击者访问预期目录结构之外的文件和目录。当应用程序未能正确清理用户输入时，就会出现此漏洞，攻击者可以通过操纵文件路径逃逸出预期目录，从而访问系统上其他位置存储的文件。

## 基本路径遍历

假设你有一个包含以下代码的 Web 应用程序：

```php
<?php
// 用户输入
$note = $_GET['note']; 

// 获取用户提供的笔记
$file = 'files/notes/' . $note;

if ($note != '' && file_exists($file)) {
    // 输出文件内容
    echo file_get_contents($file);
} else {
    echo 'File does not exists.';
}
```

该代码存在路径遍历漏洞，因为代码从 `GET` 参数 `note` 中获取用户输入，并在未对用户提供的值进行清理的情况下直接将其插入到 `$file` 变量中。由于代码处理用户输入不当，攻击者可以使用双点斜杠（`../`）技术执行路径遍历。这种攻击技术用于利用路径遍历漏洞，使攻击者能够访问预期文件夹结构之外的文件。

此类载荷示例：

```
../../../../../../../etc/passwd
```

此载荷使用七个双点斜杠（`../`）模式，从预期的文件夹结构向上回退七层。在上述易受攻击的代码示例中，用户输入被放置在文件夹结构 `(unknown)files/notes` 中，其中 `unknown` 代表可能的未知子文件夹，这也是载荷包含七个双点斜杠模式的原因。

如果我们将此载荷发送到 Web 应用程序，变量 `$file` 将产生以下值：

```
files/notes/../../../../../../../etc/passwd
```

在这种情况下，文件夹 `files` 和 `notes` 会被逃逸并“消耗”两个双点斜杠模式。这意味着如果存在更多子文件夹，我们仍然可以再逃逸五个子文件夹。

## 具有弱保护机制的路径遍历

有时开发人员会添加针对路径遍历的保护措施，但无意中在这些防御中留下了漏洞。例如，如果我们使用与上述相同的 Web 应用程序代码，但从用户输入中移除所有双点斜杠模式……（注意：`str_replace(...)`）

```php
<?php
// 用户输入
$note = $_GET['note']; 

// 获取用户提供的笔记
$file = 'files/notes/' . str_replace('../', '', $note);

if ($note != '' && file_exists($file)) {
    // 输出文件内容
    echo file_get_contents($file);
} else {
    echo 'File does not exists.';
}
```

……你是否发现了问题？

如果我们将两个双点斜杠模式嵌套在一起，例如：

```
....//....//....//....//....//....//....//etc/passwd
```

会发生什么情况？

在这种情况下，只有第一个双点斜杠模式会被替换。但由于我们有两个嵌套的双点斜杠模式，一旦第一个被移除，第二个就会被触发，导致修改后的载荷利用路径遍历漏洞。

原始值：`"....//"`
修改后：`"../"`

### Absolute Path Traversal

Absolute path traversal

Found a way to escape the `/tmp/files/notes/` directory and access arbitary files on the vulnerable application!
Goal

Capture the flag! The flag can be found in the file: `/tmp/secret/flag.txt`

code

```py
import os
from urllib.parse import unquote
from jinja2 import Environment, FileSystemLoader
os.chdir('/tmp')

template = Environment(
    autoescape=True,
    loader=FileSystemLoader('templates'),
).get_template('index.tpl')

# User input
note = unquote("§输入§")

# Delete all dot-dot-slash (../)
while '../' in note:
    note = note.replace('../', '')

# Create the full path to the file
path = os.path.join("files/notes", note)

try:
    content = open(path, 'r').read()
except:
    content = 'File does not exist.'   

print( template.render(note=content) )
```

输入
```
/tmp/secret/flag.txt
```
- `os.path.join` 在后一个参数使用绝对路径时忽略之前的相对路径

Goal

code

```php
<?php
chdir('/tmp');

// User input
$url = urldecode("§输入§");

/* echo file_get_contents($url);
die();
 */
if ( $url != '' && preg_match('/^[a-z]+:\/\/.*$/', $url) && str_starts_with($url, "file") == false ) {
    $content = file_get_contents($url);
} else {
    $content = 'File was invalid or does not exists.';
}

// Render the HTML and note content
echo str_replace('__NOTE__', $content, file_get_contents('index.html'));

```

