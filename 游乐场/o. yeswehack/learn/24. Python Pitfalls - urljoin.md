# Python 陷阱 - urljoin

Python 的 [`urllib.parse.urljoin`](https://docs.python.org/3/library/urllib.parse.html#urllib.parse.urljoin) 函数用于通过组合基础 URL 来构造绝对 URL。它使用基础 URL 中的组件（例如路径）来提供相对 URL 中缺失的组件。

易受攻击代码示例：

```python
from urllib.parse import urljoin

url = "http://example.com/"
print(urljoin(url, "http://evil.com")) # 输出: http://evil.com
```

攻击者可以使用以下攻击技术，用新的指定 URL 覆盖原始 URL。这种行为为利用 [开放重定向 (CWE-601)](https://cwe.mitre.org/data/definitions/601.html) 和 [服务器端请求伪造 (SSRF) (CWE-918)](https://cwe.mitre.org/data/definitions/918.html) 漏洞打开了可能性。

from jinja2 import Environment, FileSystemLoader
template = Environment(
    autoescape=True,
    loader=FileSystemLoader('/tmp/templates'),
)

def main():
    # User input (url link to user profile)
    username = unquote("§输入§")
    
    message = ""

        if username != "":

    except:

main()
