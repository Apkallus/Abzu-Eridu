# WAF 绕过 - 编码

对载荷的部分内容进行编码是一种极其有用的技术，可操纵防火墙误认为载荷已终止。该技术的成功与否取决于能否找到一种 WAF “可见”但易受攻击的应用程序不会解码的编码格式。

在下图中，我们可以看到使用编码技术的示例。左侧的载荷使用字符 `/>` 来欺骗 WAF，使其认为 `img` 标签已经结束。随后，WAF 实际上“看到”的是右侧的载荷。由于 WAF “假设” `img` 标签已终止，它也会认为 `img` 标签之后的任何内容都不具有恶意性。这导致我们成功绕过了 WAF。

https://dojo-yeswehack.com/waf-bypass-encoding.png

不出所料，这种技术非常有效，因为除非针对每个部分进行专门配置（这种情况很少见），否则 WAF 很难理解应用程序会或不会解码哪些编码。

在下面的视频中，您可以观看 Brumens 在 Nahamcon 2024 上关于绕过 WAF 的演示，他在其中详细解释了该技术，并带领参与者逐步完成页面底部链接的相关实验。

### WAF Bypass - Encoding

WAF Bypass - Encoding
Description

The WAF supports a wide range of encodings to detect payloads in different forms
Goal

Bypass the WAF by taking advantage of a supported encoding that the WAF can detect but that the vulnerable application does not decode.

from urllib.parse import unquote
from jinja2 import Environment, FileSystemLoader
env = Environment(loader=FileSystemLoader('templates'))

# User payload input

if "WAF_BLOCKED" in payload:
    page = "waf.html"
else:
    page = "index.html"

# Render response content 
# 第二次 URL 解码
print( env.get_template(page).render(output=unquote(payload)) )
