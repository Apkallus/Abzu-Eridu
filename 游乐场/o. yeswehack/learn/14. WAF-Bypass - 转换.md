# WAF 绕过 - 转换

在此类利用中，载荷（payload）或载荷中的特定字符会以某种方式进行转换，从而在应用程序使用载荷时改变其值。当应用程序对载荷或部分载荷进行编码或解码、将字符转换为大写或小写等操作时，就会发生转换。

WAF 通常无法感知这些转换，因为它们发生在应用程序内部。这意味着，如果我们能够根据应用程序将执行的转换来调整载荷，就可以绕过 WAF，因为我们的“无效”载荷在应用程序执行转换后，将以预期的形式呈现。

你可以在下图中看到此利用的示例。攻击者发送模板注入载荷：`\x7B\x7B7*7\x7D\x7D`。然后，易受攻击的应用程序将其转换为：`{{7*7}}`。

### WAF Bypass - Transformation 

WAF Bypass - Transformation
Description

The firewall will block a wide range of prefix syntax used in template injection payloads
Goal

Bypass the firewall by exploiting the transformation that occurs in the back-end of the vulnerable application.

code

```py
from urllib.parse import unquote
from jinja2 import Environment, FileSystemLoader
env = Environment(loader=FileSystemLoader('templates'))

# User payload input
payload = unquote("§输入§")

# Return a response based on whether the payload was blocked or not
if "WAF_BLOCKED" in payload:
    page = env.get_template("waf.html").render()
else:
    # 进行一次 unicode 解码
    data = bytes(payload, "utf-8").decode("unicode_escape")
    page = env.get_template("index.html").render(output=data)

# Render response content 
print( env.from_string(page).render() )
```
