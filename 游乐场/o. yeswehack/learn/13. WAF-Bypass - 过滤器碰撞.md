# WAF 绕过 - 过滤器冲突

当存在漏洞的应用程序使用对载荷（payload）进行转换的过滤器（通常通过移除载荷的部分内容）时，就会发生过滤器冲突。这种过滤器行为中的缺陷可被利用来绕过 WAF。

想象一下如下图所示的场景：

https://dojo-yeswehack.com/waf-bypass-filter-collision.png

存在漏洞的应用程序会从客户端发送的载荷中移除双引号（`"`）。随后，这些内容会在响应中回显给我们。我们可以利用这一点，创建一个包含随机插入双引号的载荷，从而确保 WAF 无法检测到载荷中的恶意关键字或正则表达式模式。

除非应用程序将字符替换为其他字符，否则绝不应从载荷中移除字符。如果从恶意载荷中移除某个字符，任何在修改之前分析过该载荷的保护机制都将无法再检测到该载荷是恶意的。这是因为当载荷到达后端过滤器时，会生成与原始载荷不同的版本。

### WAF Bypass - Filter collision

WAF Bypass - Filter collision
Description

The firewall will detect a certain amount of patterns, but when the payload is handled by the backend server, the payload will be filtered and modified before being reflected in the response.
Goal

Bypass the firewall by exploiting the filter collision.

setup code

```py
import os

# Setup the ground file structure
os.chdir('/tmp')
os.mkdir('templates')


# Search page
with open('templates/index.html', 'w') as f:
    f.write('''
```

code

```py
from urllib.parse import unquote
from jinja2 import Environment, FileSystemLoader
env = Environment(loader=FileSystemLoader('templates'))

def filter(s):
    return s.replace('<', '').replace('>', '')


# User payload input
payload = unquote("§输入§")

# Return a response based on whether the payload was blocked or not
if "WAF_BLOCKED" in payload:
    page = "waf.html"
else:
    page = "index.html"

# Render response content 
print( env.get_template(page).render(output=filter(payload)) )
```

```re
<[a-zA-Z]+

on((.|\n)*)=
```
