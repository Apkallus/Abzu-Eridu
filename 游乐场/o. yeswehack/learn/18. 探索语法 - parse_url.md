# 利用未知语法 - `parse_url`

PHP 函数 `parse_url` 存在许多有趣的行为和无效的解析结果。这在 `parse_url` 的官方文档中也有提及。如果我们设置一个像 `000443` 这样的端口，大多数其他编程语言（包括浏览器）中的解析器都会去除前导零，因为端口号开头有零是没有意义的。然而，`parse_url` 不会这样做。相反，`parse_url` 将返回 `false`。这种行为可用于强制产生 `false` 值，从而有可能访问应用程序中可能存在漏洞的另一段代码部分。

该 Web 应用程序提供了一款在线游戏，你需要捕获旗帜并避开所有隐藏的地雷。你能成功捕获旗帜吗？

> **注意**：你可以通过感染 `localhost` 以外的主机来解决此挑战，但为了获得完整解决方案，请尝试通过利用跨站脚本（XSS）漏洞弹出 `alert` 对话框。

目标

找到一种方法，将你的主机地址注入到应用程序的 `<script>` 标签中，并利用跨站脚本（XSS）漏洞来捕获旗帜。
