# 实验室：间接提示注入

本实验室容易受到间接提示注入攻击。用户 `carlos` 经常使用实时聊天询问关于 Lightweight "l33t" Leather Jacket 产品。要解决本实验室，请删除用户 `carlos`。

> **所需知识**
> 要解决本实验，你需要了解：
> - LLM API 的工作原理。
> - 如何映射 LLM API 攻击面。
> - 如何执行间接提示注入攻击。
>
> 更多信息，请参阅我们的 [Web LLM 攻击 Academy 主题](/web-security/llm-attacks)。
