# 实验：通过 jwk 头部注入绕过 JWT 身份验证

本实验使用基于 JWT 的机制来处理会话。服务器支持 JWT 头部中的 `jwk` 参数。这有时用于直接将正确的验证密钥嵌入令牌中。然而，它未能检查所提供的密钥是否来自受信任的源。

要解决本实验，请修改并签署一个 JWT，使您能够访问 `/admin` 下的管理面板，然后删除用户 `carlos`。

您可以使用以下凭据登录自己的账户：`wiener:peter`

> **提示**
>
> 我们建议在尝试本实验之前，先熟悉[如何在 Burp Suite 中使用 JWT](/burp/documentation/desktop/testing-workflow/vulnerabilities/session-management/jwts)。

使用主题说明列出的步骤
1. 加载扩展后，在 Burp 的主标签栏中，转到 **JWT Editor Keys** 选项卡。
2. 生成一个新的 RSA 密钥
3. 将包含 JWT 的请求发送到 Burp Repeater。
4. 在消息编辑器中，切换到扩展生成的 **JSON Web Token** 选项卡
5. 此时可任意修改载荷
6. 点击 **Attack**，然后选择 **Embedded JWK**。在提示时，选择您新生成的 RSA 密钥。
7. 发送请求以测试服务器
    - 此时，原始 wiener 仍可成功访问账户页面
    - 修改 JWT 字段到 `"sub": "carlos"`
        - 成功访问 carlos 账户页面
    - 修改 JWT 字段到 `"sub": "administrator"`
        - 成功访问管理员账户
        - 应用 JWT 会话 cookie 到浏览器，访问管理员页面 `/admin`，使用删除功能
