# 实验室：通过浏览器 API 实现客户端原型污染

本实验室存在通过客户端原型污染导致的 DOM XSS 漏洞。网站的开发者注意到了潜在的小工具并尝试修复，但你可以绕过他们所采取的措施。

要解决本实验室：

1. 找到一个可用于向全局 `Object.prototype` 添加任意属性的源。
2. 识别一个允许执行任意 JavaScript 的小工具属性。
3. 结合这两者以调用 `alert()`。

你可以手动在浏览器中解决此实验，也可以使用 [DOM Invader](/burp/documentation/desktop/tools/dom-invader) 作为辅助。

本实验基于 PortSwigger Research 发现的真实漏洞。更多详情，请参阅 Gareth Heyes 的 [广泛存在的原型污染小工具](https://portswigger.net/research/widespread-prototype-pollution-gadgets)。

## 步骤

半自动
- 在首页启用 burp 浏览器的 DOM 插件
- 开发者工具的 DOM 插件面板显示源
    ```log
    Prototype pollution: __proto__[property]=value in search (1)

    Value
    d10w4yxb

    Prototype pollution: constructor[prototype][property]=value in search (1)

    Value
    d10w4yxb
    ```
    - 源：URL 查询字符串

- 查看源栈追踪的代码 `searchLoggerConfigurable.js`
    ```js
    async function searchLogger() {
        let config = {
            // 输入源
            params: deparam(new URL(location).searchParams.toString()),
            transport_url: false
        };
        // 工具-设置目标对象
        Object.defineProperty(config, 'transport_url', {
            configurable: false,
            writable: false
        });
        // 工具-被阻止直接设置
        if (config.transport_url) {
            let script = document.createElement('script');
            // 汇
            script.src = config.transport_url;
            document.body.appendChild(script);
        }
        if (config.params && config.params.search) {
            await logQuery('/logger', config.params);
        }
    }

    window.addEventListener("load", searchLogger);
    ```

- 使用源的搜索工具功能，新打开的搜索工具页面显示汇
    ```log
    script.src (1)

    Value
    d10w4yxb8prototypepollutionvalued10w4yxb
    ```
    - 汇：`script.src`
    - 工具：`value`
