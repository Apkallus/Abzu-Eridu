# 实验：修改序列化对象

https://portswigger.net/web-security/deserialization/exploiting/lab-deserialization-modifying-serialized-objects

本实验使用基于序列化的会话机制，因此存在权限提升漏洞。为了解决本实验，请编辑会话 Cookie 中的序列化对象以利用此漏洞并获得管理员权限。然后，删除用户 `carlos`。

你可以使用以下凭据登录自己的账户：`wiener:peter`

## 步骤

探测
- 使用登录功能
    - 服务器响应
        ```http
        HTTP/2 302 Found
        Location: /my-account?id=wiener
        Set-Cookie: session=Tzo0OiJVc2VyIjoyOntzOjg6InVzZXJuYW1lIjtzOjY6IndpZW5lciI7czo1OiJhZG1pbiI7YjowO30%3d; Secure; HttpOnly; SameSite=None
        ```
        - cookie 值为 base64 编码格式，解码后
            ```php
            O:4:"User":2:{s:8:"username";s:6:"wiener";s:5:"admin";b:0;}
            ```
            - 得到 php 序列化对象

- 尝试修改序列化对象属性 admin 的布尔值从 0到1，再编码
    - 访问账户页面看到管理员面板，cookie 的序列化字段设置状态成功

- 在浏览器开发者面板设置 cookie 值为伪造序列化串
    - 删除目标用户后通过挑战
