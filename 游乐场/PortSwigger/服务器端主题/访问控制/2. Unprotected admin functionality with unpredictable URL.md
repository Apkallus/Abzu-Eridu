# 实验：具有不可预测 URL 的未受保护管理员功能

本实验有一个未受保护的管理员面板。它位于一个不可预测的位置，但该位置在应用程序中的某处被披露了。

通过访问管理员面板并使用它删除用户 `carlos` 来解决本实验。

## 步骤

探测
- 访问主页，查看 HTML 代码
    ```html
    <script>
    var isAdmin = false;
    if (isAdmin) {
        var topLinksTag = document.getElementsByClassName("top-links")[0];
        var adminPanelTag = document.createElement('a');
        adminPanelTag.setAttribute('href', '/admin-hw0ox5');
        adminPanelTag.innerText = 'Admin panel';
        topLinksTag.append(adminPanelTag);
        var pTag = document.createElement('p');
        pTag.innerText = '|';
        topLinksTag.appendChild(pTag);
    }
    </script>
    ```
    - 页面基于变量 `isAdmin` 控制管理员面板渲染
    - 管理端点位于 `/admin-hw0ox5`

- 尝试访问管理端点
    - 成功访问，未被阻止，执行删除操作
