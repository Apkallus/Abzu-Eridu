# 实验：由请求参数控制的用户 ID

本实验在用户账户页面上存在水平权限提升漏洞。

为了解决本实验，请获取用户 `carlos` 的 API 密钥并将其作为解决方案提交。

你可以使用以下凭据登录自己的账户：`wiener:peter`

## 步骤

探测
- 使用登录功能，服务器响应
    ```http
    HTTP/2 302 Found
    Location: /my-account?id=wiener
    Set-Cookie: session=eO35OTw1HwYwHHCXGTGwAR77qnmvTRhv; Secure; HttpOnly; SameSite=None
    ```

- 尝试移除会话 cookie
    ```http
    GET /my-account?id=wiener HTTP/2
    ```
    - 仍可成功访问账户页面
    - 此处服务器不使用会话 cookie，而是使用请求参数返回账户页面。
    - 修改邮件功能使用会话 cookie 

- 修改请求参数 id 的值为目标用户
    - 成功返回目标用户信息
