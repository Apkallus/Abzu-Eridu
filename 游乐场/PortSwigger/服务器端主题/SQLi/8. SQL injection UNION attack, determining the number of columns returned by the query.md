# 实验：SQL 注入 UNION 攻击，确定查询返回的列数

本实验在产品类别过滤器中包含一个 SQL 注入漏洞。查询结果会返回在应用程序的响应中，因此你可以使用 UNION 攻击从其他表中检索数据。此类攻击的第一步是确定查询返回的列数。你将在随后的实验中利用此技术来构建完整的攻击。

为了解决本实验，请执行一个 SQL 注入 UNION 攻击，该攻击返回包含 null 值的额外行，以此来确定查询返回的列数。

## 步骤

探测
- 使用过滤功能
    ```http
    GET /filter?category=Gifts HTTP/2
    ```

- 使用经典的1/2个单引号测试 SQLi 字符型注入点
    - 存在典型行为

- 使用 order by 探测列数
    - 列数3

- 使用 UNION SELECT NULL 通过挑战
