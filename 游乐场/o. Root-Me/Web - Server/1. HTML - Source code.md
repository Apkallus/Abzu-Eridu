    - 翻译
        ```log
        欢迎来到这个门户，
        希望你们在此度过愉快的时光，更重要的是，离开时脑海中能装满收获……

        @ très bientôt
        很快再见

        <!--
        我觉得这真是太简单了！
        password : nZ^&@q5&sjJHev0

        -->
        ```

- 使用注释密码，请求
    ```http
    GET /web-serveur/ch1/?password=nZ%5E%26%40q5%26sjJHev0 HTTP/1.1
    ```
    - 响应
        ```html
        Vous pouvez valider ce challenge avec ce mot de passe / You can validate the challenge using this password
        ```
    - 翻译
        ```log
        你可以使用此密码验证挑战
        ```
    - 并非常见的 flag 格式，此处提交密码即通关
