# 关于

Hacker101 CTF（夺旗赛）是一款旨在让您在安全、有益的环境中学习黑客技术的游戏。[Hacker101](https://www.hacker101.com/) 是由 [HackerOne](https://www.hackerone.com/) 运营的免费黑客教育网站。这款 CTF 是我们计划的一部分，旨在一次一个漏洞地让世界变得更美好。

## 什么是 CTF？

CTF 代表 Capture The Flag（夺旗赛），是一种黑客竞技风格，您的目标只有一个：入侵并找到旗标（flag）。旗标被放置在各个位置——它们可能在文件中、数据库中、嵌入源代码中，或其他地方——您的目标是找到所有旗标。每个旗标看起来都像 `^FLAG^37ae568362f974017fa575f08cd215044cd6bb395c3f5e5e293ee5324ba6769c$FLAG$`，所以您一眼就能认出来。
