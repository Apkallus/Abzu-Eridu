# Python 陷阱 - joinpath

Python 的函数 [`pathlib.PurePath.joinpath`](https://docs.python.org/3/library/pathlib.html#pathlib.PurePath.joinpath) 与函数 [`os.path.join`](https://docs.python.org/3/library/os.path.html#os.path.join) 非常相似，`joinpath` 会将作为参数指定的路径进行拼接。然而，如果我们在函数的某个位置指定了一个以绝对路径开头的路径（例如 Linux 系统上的 `/etc/passwd`），那么我们的路径 `/etc/passwd` 将覆盖其后的所有路径，并成为新的绝对路径。

脆弱代码示例：

```python
from pathlib import Path
payload = "/etc/passwd"
file = Path("/var/www/html").joinpath("files", payload)
with open(file, "r") as f:
    print(f.read())  # 打印 “/etc/passwd” 文件内容
```
