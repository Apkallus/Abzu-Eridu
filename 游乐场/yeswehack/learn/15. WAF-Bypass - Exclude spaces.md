# WAF 绕过 - 排除空格

此类 WAF 绕过技术通过替换载荷中不必要的空格，使 WAF 更难检测载荷中的不同关键字和/或模式。

诸如 `; cat /etc/passwd;`、`<img src=x onerror=alert(1)>` 或 `' OR 1=1 -- ` 之类的载荷通常不需要其中包含的空格。在下图中，你可以看到空格已被新字符（以红色突出显示）替换的载荷，这些替换不会改变载荷的结构。这作为概念验证，表明空格实际上并非必需。

https://dojo-yeswehack.com/waf-bypass-exclude-space-payloads.png

用与载荷结构相符的其他字符替换空格，会使 WAF 难以理解载荷的各个部分。

### WAF Bypass - Exclude spaces 

WAF Bypass - Exclude spaces
Description

The WAF will block any request that contains a space, tab or newline
Goal

Bypass the firewall by exploiting the SQL injection in the vulnerable application without using any spaces and extract the flag that is set as the admin's note.

Note : The FLAG is in the form of : `FLAG{<four_digits>}`

```py
import sqlite3
from urllib.parse import unquote
from jinja2 import Environment, FileSystemLoader
env = Environment(
    loader=FileSystemLoader('templates'),
    autoescape=True
)
conn = sqlite3.connect("dojo.db")
cursor = conn.cursor()

# User payload input
payload = unquote("§输入§")

# Return a response based on whether the payload was blocked or not
result = ""
if "WAF_BLOCKED" in payload:
    page = "waf.html"
else:
    page = "index.html"
    # 输入拼接到 SQL 查询
    result = cursor.execute(f"SELECT username, note FROM users WHERE username = 'guest' and note LIKE '%{payload}%'").fetchone()

# Render response content 
print( env.get_template(page).render(output=payload, result=result) )
```
