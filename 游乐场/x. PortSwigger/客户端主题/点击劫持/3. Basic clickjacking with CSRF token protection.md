# 实验室：带有框架破坏脚本的点击劫持

本实验受框架破坏脚本保护，该脚本阻止网站被嵌入框架。你能绕过框架破坏脚本，通过点击劫持攻击更改用户的邮箱地址吗？

要解决本实验，请构造一些 HTML，将账户页面嵌入框架，并诱骗用户点击“Click me”来更改其邮箱地址。当邮箱地址被更改时，实验即被解决。

你可以使用以下凭据登录自己的账户：`wiener:peter`

> **注意**
> 受害者将使用 Chrome，因此请在该浏览器上测试你的漏洞利用。

> **提示**
> 你不能注册已被其他用户占用的邮箱地址。如果在测试漏洞利用时更改了自己的邮箱地址，请确保最终交付给受害者的漏洞利用中使用的是不同的邮箱地址。

## 步骤

侦察
- 登录后访问账户页面，且去除查询参数 id
    ```http
    GET /my-account HTTP/2
    Host: id.web-security-academy.net
    Cookie: session=XHau7UEOghRuUnsxaFBiVMleAZgioudk
    ```
    - 响应
        ```http
        HTTP/2 200 OK
        Content-Type: text/html; charset=utf-8
        Cache-Control: no-cache
        Content-Length: 3962

        <form class="login-form" name="change-email-form" action="/my-account/change-email" method="POST">
            <label>
                Email
            </label>
            <input required type="email" name="email" value="">
            <script>
                if (top != self) {
                    window.addEventListener("DOMContentLoaded", function() {
                            document.body.innerHTML = 'This page cannot be framed';
                        },
                        false);
                }
            </script>
            <input required type="hidden" name="csrf" value="vhEvCJ1grtPpif1uKBcucxLWL1Nppbwc">
            <button class='button' type='submit'>
                Update email
            </button>
        </form>
        ```
        - 响应不包含禁用框架头部
        - 页面 JS 检测当前页面是否为子框架，是则动态覆盖所有内容
            - 攻击者尝试禁用子框架 JS 代码
        - 之后测试 URL 预填充表单参数

测试 URL 预填充表单参数
- 请求
    ```http
    GET /my-account?email=foo@bar.net HTTP/2
    ```
    - 响应
        ```html
        <input required type="email" name="email" value="foo@bar.net">
        ```

使用 burp 点击劫持构造 HTML 页面
- 设置目标载荷 URL 
    `https://id.web-security-academy.net/my-account?email=foo@bar.net`
- 复制 burp JS 构造代码，并在浏览器控制台粘贴
- 选项中启用子框架沙盒，白名单仅保留表单 `allow-forms`。启用录制点击禁用
