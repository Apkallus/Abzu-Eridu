# 实验：文件路径遍历，使用绝对路径绕过被阻塞的遍历序列

本实验在产品图片显示功能中包含一个路径遍历漏洞。

应用程序会拦截遍历序列，但会将提供的文件名视为相对于默认工作目录的路径。

为了解决本实验，请检索 `/etc/passwd` 文件的内容。

## 步骤

探测
- 查看图片请求端点
    ```http
    GET /image?filename=52.jpg HTTP/2
    ```

- 尝试当前目录序列
    `./52.jpg`
    - 成功

- 尝试规范化遍历到本身的序列
    `foo/../52.jpg`
    - 失败

- 尝试绝对路径
    `/etc/passwd`
    - 成功
