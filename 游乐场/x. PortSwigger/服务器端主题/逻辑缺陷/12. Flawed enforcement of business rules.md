# 实验：业务规则执行缺陷

本实验的购买工作流程中存在逻辑缺陷。为了解决本实验，请利用此缺陷购买一件 "Lightweight l33t leather jacket"（轻量级 l33t 皮夹克）。

你可以使用以下凭据登录自己的账户：`wiener:peter`

## 步骤

探测
- 首页显示新用户折扣码
    `New customers use code at checkout: NEWCUST5`
- 首页底部存在注册新闻表单
    - 提交注册信息
    - 服务器重定向到注册已确认页面
    - 得到注册折扣码
        ```js
        alert('Use coupon SIGNUP30 at checkout!')
        ```

此时的两个折扣码仍不足以在额度内购买目标商品
- 尝试后发现：
    - NEWCUST5 为固定减免
    - SIGNUP30 为百分比减免

- 尝试连续应用1种优惠券
    - 失败
        `Coupon already applied`

- 尝试交叉应用2种优惠券
    - 此时优惠券可重复叠加


将两种优惠券的应用请求设置为一组，多次提交后价格降低到0

```http
POST /cart/coupon HTTP/2
Cookie: session=YBR0oSGmDdYS85Ni9mIqVgWzgYWfvBMO

csrf=KcHctKoy1qINJ0TsJFeFpGPrsiJkA4DQ&coupon=NEWCUST5
```
