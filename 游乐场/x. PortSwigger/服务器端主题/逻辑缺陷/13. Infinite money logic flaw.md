# 实验：无限金钱逻辑缺陷

本实验的购买工作流程中存在逻辑缺陷。为了解决本实验，请利用此缺陷购买一件 "Lightweight l33t leather jacket"（轻量级 l33t 皮夹克）。

你可以使用以下凭据登录自己的账户：`wiener:peter`

## 步骤

探测
- 首页下发现订阅新闻功能

    - 提交表单后得到优惠券
        ```js
        alert('Use coupon SIGNUP30 at checkout!')
        ```

- 登录账户后发现礼品卡兑换功能

- 礼品卡价格为10

尝试对礼品卡应用百分比折扣并兑换，步骤：
1. 添加礼品卡到购物车
2. 在购物车中应用优惠券
3. 提交订单
4. 访问账单页面，得到礼品卡兑换码
5. 兑换礼品卡

设置步骤自动化
- 其中 csrf 令牌重复使用，此时 POST 请求无需 GET 得到表单并更新 csrf 令牌
- 将步骤设置为 burp 的宏，步骤4提取兑换码设置为步骤5的同名参数，此时步骤5将使用从步骤4得到的动态礼品码。或此处构造 python 脚本
- 在攻击器中设置单线程，grep `/cart` 端点显示的账户余额
- 进行空载荷爆破，查看进度中持续显示的当前账户余额，直到足够购买目标商品
    - 可能的改进：之前的宏为单个礼品卡，修改为多个礼品卡订购与激活
