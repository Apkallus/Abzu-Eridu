# 实验：通过有缺陷的状态机绕过认证

本实验对登录过程中的事件序列做出了有缺陷的假设。为了解决本实验，请利用此缺陷绕过实验室的认证，访问管理员界面，并删除用户 `carlos`。

你可以使用以下凭据登录自己的账户：`wiener:peter`

## 步骤

使用常规登录流程
- 页面1：提交用户名/密码凭证
- 服务器重定向到角色选择端点
    ```http
    HTTP/2 302 Found
    Location: /role-selector
    Set-Cookie: session=YK3JxqbJtKNtnSmu9nsBuE976GouNgON; Secure; HttpOnly; SameSite=None
    ```

- 页面2：提交选择角色表单
    ```http
    POST /role-selector HTTP/2
    Cookie: session=6S0TWzUjwYWBW2oUj5TrFuPwij2o69hr

    role=content-author&csrf=CzfAs67HEYJeAxmWXVfbdo9hDmICIc6x
    ```
    - 若尝试修改角色为管理员将如何？
    - 若尝试跳过页面1，直接访问页面2如何？
    - 若尝试完成登录后，再回到页面2将如何？
    - 若强制导航，绕过角色选择将如何？


尝试执行页面1后，在页面2的表单中修改角色参数
- 设置 `admin`
    - 无效
- 设置 `administrator`
    - 无效


尝试跳过页面1，直接访问页面2
- 提示 
    `"No login credentials provided"`

尝试强制导航，绕过角色选择将
- 页面1提交凭证后保存中间会话 cookie，并阻止重定向
- 设置中间 cookie 后强制导航到账户页面
- 显示管理员面板
