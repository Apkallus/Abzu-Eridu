# 实验：通过加密预言机绕过认证

https://portswigger.net/web-security/logic-flaws/examples/lab-logic-flaws-authentication-bypass-via-encryption-oracle

本实验包含一个逻辑缺陷，该缺陷向用户暴露了一个加密预言机（encryption oracle）。为了解决本实验，请利用此缺陷获取管理员面板的访问权限，并删除用户 `carlos`。

你可以使用以下凭据登录自己的账户：`wiener:peter`

示例解决方案
- 仅16字节编码，设置9位填充即可。
- 64字节组似乎为 base64 类编码的特性，虽然设置了也不会错（仍为16的倍数）。但在 20-20-24 中，应当先尝试普通的 16 字节原始字符对应的 20 字节编码分段，若无效再尝试 48 字节原始字符对应的 64 字节编码组
