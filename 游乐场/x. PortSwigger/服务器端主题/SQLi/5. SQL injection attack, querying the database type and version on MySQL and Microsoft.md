# 实验：SQL 注入攻击，在 MySQL 和 Microsoft SQL Server 上查询数据库类型和版本

本实验在产品类别过滤器中包含一个 SQL 注入漏洞。你可以使用 UNION 攻击从注入的查询中检索结果。

为了解决本实验，请显示数据库版本字符串。

> **提示**
> 你可以在我们的 [SQL 注入速查表](https://portswigger.net/web-security/sql-injection/cheat-sheet) 中找到一些有用的 Payload。

## 步骤

探测
- 使用过滤功能
    ```http
    GET /filter?category=Gifts HTTP/2
    ```

- 测试经典的1/2个单引号
    - 出现典型的错误/正确字符串型 SQLi 行为

- 输入注释符
    - 当注释符后无空格时报错
    - 注释符后添加空格正常
    - 推断为 MySQL 数据库


测试
- 使用 ORDER BY 确认列数
    - 列数2

- 使用字符测试列类型
    - 列1为字符串型

- 构建最终版本查询载荷
    ```sql
    $category = 'Gifts' AND 1=0 UNION SELECT @@VERSION,NULL -- 
    ```
    - 设置原始查询为 false 以得到干净的伪造查询
