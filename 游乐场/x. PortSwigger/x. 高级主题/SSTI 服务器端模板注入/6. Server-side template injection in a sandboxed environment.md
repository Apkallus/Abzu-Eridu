# 实验：沙盒环境中的服务器端模板注入

本实验使用 Freemarker 模板引擎。由于其沙盒实现不佳，它存在服务器端模板注入漏洞。为了解决本实验，请突破沙盒以从 Carlos 的主目录中读取 `my_password.txt` 文件。然后提交该文件的内容。
