# 实验：通过算法混淆绕过 JWT 身份验证

本实验使用基于 JWT 的机制来处理会话。它使用一个健壮的 RSA 密钥对来签署和验证令牌。然而，由于实现缺陷，该机制容易受到算法混淆攻击。

要解决本实验，首先获取服务器的公钥。该公钥通过标准端点暴露。使用此密钥签署一个修改后的会话令牌，使您能够访问 `/admin` 下的管理面板，然后删除用户 `carlos`。

您可以使用以下凭据登录自己的账户：`wiener:peter`

> **提示**
>
> 我们建议在尝试本实验之前，先熟悉[如何在 Burp Suite 中使用 JWT](/burp/documentation/desktop/testing-workflow/vulnerabilities/session-management/jwts)。

> **提示**
>
> 您可以假设服务器将其公钥存储为 X.509 PEM 文件。

按照主题介绍的步骤，使用 Burp 中的 JWT Editor 扩展将 JWK 转换为 PEM：

1. 加载扩展后，在 Burp 的主标签栏中，转到 **JWT Editor Keys** 选项卡。
2. 点击 **New RSA Key**。在对话框中，粘贴您之前获取的 JWK 格式公钥。
3. 选择 **PEM** 单选按钮，并复制转换生成的 PEM 格式公钥。
4. 转到 **Decoder** 选项卡，对 PEM 格式公钥进行 Base64 编码。
5. 回到 **JWT Editor Keys** 选项卡，点击 **New Symmetric Key**。
6. 在对话框中，点击 **Generate** 以 JWK 格式生成一个随机新密钥。
7. 将生成的 `k` 参数值（对称算法秘密）替换为您刚刚复制的 Base64 编码的 PEM 密钥。
8. 保存密钥。

在重复器测试使用公钥作为秘密的对称加密签名
- 发送账户端点请求到重复器
- 使用对称加密密钥进行签名，勾选更新 `alg` 算法头部（应用 HS256）
    - 成功访问原用户的账户页面
- 修改用户字段到 `carlos`
    - 成功访问 carlos 账户页面

- 修改用户字段到 `administrator`
    ```json
    {
        "kid": "e8b3add7-89a5-4920-b046-7acf76bc7677",
        "alg": "HS256"
    }
    {
        "iss": "portswigger",
        "exp": 1786760769,
        "sub": "administrator"
    }
    ```
    - 成功访问管理员账户页面

- 设置管理员 JWT 会话 cookie 到浏览器，访问 `/admin` 管理页面，执行删除功能
