# 实验室：从 URL 参数预填表单数据的点击劫持

本实验是 [实验室：带有 CSRF 令牌防护的基本点击劫持](/web-security/clickjacking/lab-basic-csrf-protected) 的扩展。实验目标是通过 URL 参数预填表单，诱使用户不经意点击“更新邮箱”按钮，从而更改其邮箱地址。

要解决本实验，请构造一些 HTML，将账户页面嵌入框架，并诱骗用户点击“Click me”诱饵来更新其邮箱地址。当邮箱地址被更改时，实验即被解决。

你可以使用以下凭据登录自己的账户：`wiener:peter`

> **注意**
> 受害者将使用 Chrome，因此请在该浏览器上测试你的漏洞利用。

> **提示**
> 你不能注册已被其他用户占用的邮箱地址。如果在测试漏洞利用时更改了自己的邮箱地址，请确保最终交付给受害者的漏洞利用中使用的是不同的邮箱地址。

## 步骤

侦察
- 访问账户页面
    ```http
    GET /my-account?id=wiener HTTP/2
    Host: id.web-security-academy.net
    Cookie: session=ggOmYqwew98QFzasdr3T1OgOZdto5oq1
    ```

    - 响应
        ```http
        HTTP/2 200 OK
        Content-Type: text/html; charset=utf-8
        Cache-Control: no-cache
        Content-Length: 3638

        <form class="login-form" name="change-email-form" action="/my-account/change-email" method="POST">
            <label>
                Email
            </label>
            <input required type="email" name="email" value="">
            <input required type="hidden" name="csrf" value="NAWw2Omav4eAv3YEt9W66YcP9OhbMN9k">
            <button class='button' type='submit'>
                Update email
            </button>
        </form>
        ```
        - 响应无禁止框架头部
    
- 使用邮件修改功能
    ```http
    POST /my-account/change-email HTTP/2
    Host: id.web-security-academy.net
    Cookie: session=ggOmYqwew98QFzasdr3T1OgOZdto5oq1
    Content-Type: application/x-www-form-urlencoded

    email=a%40b&csrf=NAWw2Omav4eAv3YEt9W66YcP9OhbMN9k
    ```
    - 之后尝试预设表单参数


测试 URL 参数预设
- 请求
    ```http
    GET /my-account?email=foo@bar.net HTTP/2
    Host: id.web-security-academy.net
    Cookie: session=ggOmYqwew98QFzasdr3T1OgOZdto5oq1
    ```
    - 响应
        ```html
        <input required type="email" name="email" value="foo@bar.net">
        ```
    - 表单参数预设成功

使用 Burp 点击劫持功能
- 设置并访问载荷目标 URL 
    `https://id.web-security-academy.net/my-account?email=foo@bar.net`
- 在 burp 的点击劫持功能中复制 HTML 构造 JS 代码
- 在浏览器控制台粘贴构造代码
- 启用沙盒模式，禁用点击，录制点击
- 保存，得到 HTML 文件，复制文件内容到攻击者页面
