# 实验：通过用户提供的对象进行信息泄露的服务器端模板注入

由于将对象传递到模板的方式，本实验存在服务器端模板注入漏洞。可以利用此漏洞来访问敏感数据。

为了解决本实验，请窃取并提交框架的密钥（secret key）。

你可以使用以下凭据登录自己的账户：`content-manager:C0nt3ntM4n4g3r`
