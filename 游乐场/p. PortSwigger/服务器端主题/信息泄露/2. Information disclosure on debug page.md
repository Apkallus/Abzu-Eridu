# 实验室：调试页面上的信息泄露

本实验室包含一个调试页面，泄露了有关应用程序的敏感信息。要解决本实验，请获取并提交 `SECRET_KEY` 环境变量。

## 步骤

探测
- 访问首页
    ```http
    GET / HTTP/2
    Host: id.web-security-academy.net
    ```
    - 略读 HTML
        ```html
        <!-- <a href=/cgi-bin/phpinfo.php>Debug</a> -->
        ```

- 访问 HTML 注释揭示的配置信息端点
    ```http
    GET /cgi-bin/phpinfo.php HTTP/2
    Host: id.web-security-academy.net
    ```
    - 检索环境变量 `SECRET_KEY`
        ```html
        <tr>
            <td class="e">SECRET_KEY </td>
            <td class="v">sug43bdhj4rbd0x9hlokljqqg3bc266d </td>
        </tr>
        ```
