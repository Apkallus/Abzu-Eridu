## 描述

我们为您提供这个挑战，以检查您机器上的一切是否正常运行。为了在良好条件下参与 FCSC 和 Hackropole，我们建议您的机器配备 `nc`（或 `netcat`）工具以及 `docker`（或 `podman`）。

## 文件

- [`docker-compose.yml`](https://hackropole.fr/challenges/fcsc2024-misc-welcome-docker/docker-compose.public.yml)

## 挑战说明

1. 首先，下载 [`docker-compose.yml`](https://hackropole.fr/challenges/fcsc2024-misc-welcome-docker/docker-compose.public.yml)：

   ```bash
   curl https://hackropole.fr/challenges/fcsc2024-misc-welcome-docker/docker-compose.public.yml -o docker-compose.yml
   ```

2. 在同一文件夹中执行以下命令启动挑战：

   ```bash
   docker compose up
   ```

3. 然后，在另一个控制台中，使用 Netcat 访问挑战：

   ```bash
   nc localhost 4000
   ```

**⚠️ 重要：** 您必须通过暴露的网络端口与 Docker 容器交互来解决挑战。任何其他方式均视为无效。

如果您遇到问题，请查阅 [FAQ](https://hackropole.fr/en/faq)。

## Flag

Flag 输入框：`FCSC{}`  
提交按钮：`Submit`

如果未启用 JavaScript，没问题！您可以这样检查 flag：

```bash
echo -n 'PUT_THE_FLAG_HERE' | sha256sum
# 可能输出：0b3f4eff59b4da0e83efee63c66a1abd8bb4a5e1d989d1cc1ba31bf7a0e37257
```

## 步骤

配置文件内容
```yml
services:
  welcome-docker:
    image: anssi/fcsc2024-misc-welcome-docker:latest
    ports:
      - "4000:4000"
```

```powershell
# 下载 docker 构建文件
Invoke-WebRequest -Uri "https://hackropole.fr/challenges/fcsc2024-misc-welcome-docker/docker-compose.public.yml" -OutFile "docker-compose.yml"

# 使用 docker 构建命令
docker compose up
```
