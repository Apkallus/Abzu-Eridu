
docker 容器构建

1. 下载 docker 构建文件

    ```powershell
    Invoke-WebRequest -Uri "https://hackropole.fr/challenges/fcsc2020-web-babel-web/docker-compose.public.yml" -OutFile "docker-compose.yml"
    ```

2. 查看挑战 docker 构建文件 [`docker-compose.yml`](https://hackropole.fr/challenges/fcsc2020-web-babel-web/docker-compose.public.yml)

    ```dockerfile
    services:
    babel-web:
        image: anssi/fcsc2020-web-babel-web:latest
        ports:
        - "8000:80"

    ```

3. 使用 pull 而不是构建（拉取与构建似乎使用不同的配置）

    ```powershell
    docker pull anssi/fcsc2020-web-babel-web
    ```

4. 构建

    ```powershell
    docker compose up
    ```

flag 格式
- `FCSC{` + 32或64位字符序列 + `}`

docker 端口映射，对于模拟受害者的容器：
- `8000:80`
    http 默认80，仅需发送域名

- `8000:8000` 
    发送到 bot 的 URL 需添加端口

bot 型 XSS 挑战对主机与端点的设置不一，需实际查看 bot 代码以确认发送 URL 的格式

若挑战的变体使用相同代码/容器则一起进行
