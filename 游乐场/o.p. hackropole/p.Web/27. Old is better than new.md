## 代码审计

### `src\app\app.py`

```py
from flask import Flask, send_from_directory, session
import ntpath
import os

# Act as if we're on Windows (I can't run Windows in Docker, sadly)
path = ntpath
_original_join = os.path.join
os.path.join = lambda *parts: _original_join(*parts).replace("\\", "/") # 设置路径拼接包装函数并覆盖原函数，将反斜杠替换到普通斜杠

app = Flask(__name__)
app.secret_key = os.environ.get("APP_SECRET") # 应用密钥在环境变量中
PUBLIC_DIR = os.path.join(os.path.dirname(__file__), "public")

@app.route("/")
@app.route("/<path:path>")
def serve(path=None):
    # 调用函数从设置目录发送文件，然而覆盖路径拼接函数后安全代码失效：
    ## 检查普通斜杠，调用被覆盖的拼接函数是将反斜杠替换到普通斜杠。反斜杠路径遍历序列被构造为有效
    return send_from_directory(PUBLIC_DIR, path or "index.html")

if __name__ == "__main__":
    app.run(host="0.0.0.0", port=8000)

```
- 反斜杠路径遍历序列成功

找到[社区存储的 0.11 版源码](https://tedboy.github.io/flask/index.html)（当前挑战为 0.9）
- 核心代码：

    ```py
    def send_from_directory(directory, filename, **options):
        ...
        filename = safe_join(directory, filename)
    ```
    ```py
    def safe_join(directory, filename):
        # 使用正斜杠检查
        ...
        # 被覆盖后使用反斜杠合并
        return os.path.join(directory, filename)
    ```

- 查看[旧版更新日志](https://flaskr.readthedocs.io/ko/flas_kr/en/upgrading.html#version-0-10)
    ```log
    The biggest change going from 0.9 to 0.10 is that the cookie serialization format changed from pickle to a specialized JSON format. 
    ```
    - 已知 pickle 为 python 的经典反序化缺陷库

    ```py
    >>> from werkzeug.contrib.securecookie import SecureCookie
    >>> x = SecureCookie({"foo": 42, "baz": (1, 2, 3)}, "deadbeef")
    >>> value = x.serialize()
    ```

### `src\Dockerfile`

```dockerfile
FROM alpine:3.15.11
WORKDIR /app
COPY --chown=root:root   --chmod=400 ./flag.txt /root/flag.txt
COPY --chown=root:users  --chmod=550 ./get_flag /get_flag
COPY app /app
RUN apk add --update --no-cache                              \
        python2~=2.7.18                                   && \
    wget -q https://bootstrap.pypa.io/pip/2.7/get-pip.py  && \
    python2 get-pip.py                                    && \
    rm get-pip.py                                         && \
    pip2 install --upgrade --no-cache-dir                    \
        "pip<21.0"                                        && \
    chmod u+s /get_flag                                   && \
    pip2 install --no-cache-dir                              \
        -r /app/requirements.txt
USER guest
CMD ["python2", "app.py"]

```
- `/root/flag.txt`
    flag 文件位于 guest 无权限读取的目录
- `/get_flag` 
    设置 s 位，提权执行
