测试注释 `#`
- 载荷
    ```
    <@base64url>%"}}]}) { nodes { firstname }}} #</@base64url>
    ```
    - 成功返回仅 `firstname` 字段的查询

- 注意，由于输入被放入两个注入位置，而注释符仅覆盖一行。换行输入将分为3段的行为：
    - 仅注释符本身换行：段1有效，段2/3被注释。于是整体语法有效
    - 任意其他字符换行：段1有效，段2被注释，段3存在无效符号或字段
