## 挑战说明

1. 首先，下载 [`docker-compose.yml`](https://hackropole.fr/challenges/fcsc2020-web-babel-web/docker-compose.public.yml)：

   ```bash
   curl https://hackropole.fr/challenges/fcsc2020-web-babel-web/docker-compose.public.yml -o docker-compose.yml
   ```

2. 在同一文件夹中执行以下命令启动挑战：

   ```bash
   docker compose up
   ```

3. 在 <http://localhost:8000/> 访问挑战。

**⚠️ 重要：** 你必须通过暴露的网络端口与 Docker 容器交互来解决挑战。任何其他方式均视为无效。

如果遇到问题，请查阅 [FAQ](https://hackropole.fr/en/faq)。

## Flag

输入框占位符：`FCSC{}`  
提交按钮：`Submit`

如果未启用 JavaScript，没问题！你可以这样检查 flag：

```bash
echo -n 'PUT_THE_FLAG_HERE' | sha256sum
# 可能输出：a061095c06bc5a7f89fcdf5762f9f3c253dfe4952e9fd296f0e5921bd8f668c0
```

## 侦察

访问首页
- 请求
    ```http
    GET / HTTP/1.1
    Host: localhost:8000
    ```
- 响应
    ```http
    HTTP/1.1 200 OK
    Server: Apache/2.4.54 (Debian)
    X-Powered-By: PHP/7.4.33
    ```
    ```html
    <!-- <a href="?source=1">source</a> -->
    ```
    - 兴趣点
        - 注释端点 `/?source=1`
    
- 访问注释端点 `/?source=1`，响应
    ```php
    <?php
        if (isset($_GET['source'])) {
            @show_source(__FILE__);
        }  else if(isset($_GET['code'])) {
            print("<pre>");
            @system($_GET['code']);
            print("<pre>");
        } else {
    ?>
    <html>
        <head>
            <title>Bienvenue à Babel Web!</title>
        </head>    
        <body>
            <h1>Bienvenue à Babel Web!</h1>
            La page est en cours de développement, merci de revenir plus tard.
            <!-- <a href="?source=1">source</a> -->
        </body>
    </html>
    <?php
        }
    ?>
    ```
    - 分析
        - 方法 GET 
            - `show_source`
                - 参数 `source`
            - `system`
                - 参数 `code`

使用源码参数 `code`
