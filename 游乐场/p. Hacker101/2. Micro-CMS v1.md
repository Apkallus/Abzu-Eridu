## 步骤

侦察：首页
- 请求
    ```http
    GET / HTTP/1.1
    Host: id.ctf.hacker101.com
    ```
    - 响应
        ```html
        <ul>
            <li><a href="page/1">Testing</a></li>
            <li><a href="page/2">Markdown Test</a></li>
        </ul>
        <a href="page/create">Create a new page</a>
        ```
        - 首页仅作为导航


侦察：Testing 功能
- 请求
    ```http
    GET /page/1 HTTP/2
    Host: id.ctf.hacker101.com
    ```
    - 响应
        ```html
        <html>

        <head>
            <title>Testing</title>
        </head>

        <body>
            <a href="../">&lt;-- Go Home</a><br>
            <a href="edit/1">Edit this page</a>
            <h1>Testing</h1>
            <h1>Woo</h1>
            <p>Testing out this new micro-CMS!</p>
        </body>

        </html>
        ```
        - 回到首页使用 `../` 路径遍历序列很有趣

- 使用 edit
    ```http
    GET /page/edit/1 HTTP/2
    Host: id.ctf.hacker101.com
    ```
    - 响应
        ```html
        <html>

        <head>
            <title>Edit page</title>
        </head>

        <body>
            <a href="../../">&lt;-- Go Home</a>
            <h1>Edit Page</h1>
            <form method="POST">
                Title: <input type="text" name="title" value="Testing"><br>
                <textarea name="body" rows="10" cols="80">#Woo
        Testing out this new micro-CMS!</textarea><br>
                <input type="submit" value="Save">
                <div style="font-style: italic"><a href="https://github.com/adam-p/markdown-here/wiki/Markdown-Cheatsheet">Markdown</a> is supported, but scripts are not</div>
            </form>
        </body>

        </html>
        ```
        - 输入位置在 `title` 与 `body`
        - 提供 md 速查表链接
            - 其中 `Inline HTML` 与 `YouTube Videos` 提供 HTML 可能有趣的信息

    - 提交任意内容
        ```http
        POST /page/edit/1 HTTP/1.1
        Host: id.ctf.hacker101.com

        title=title+foo&body=body+bar
        ```
        - 响应 302 重定向与手动链接导航文本
    
    - 尝试再次提交修改时 404 或 500
    - 多次测试均得到异常，似乎此处的 edit 在初始提交后无法修改内容



侦察：Create a new page 功能
- 请求
    ```http
    GET /page/create HTTP/2
    Host: id.ctf.hacker101.com
    ```
    - 响应
        ```html
        <form method="POST">
            Title: <input type="text" name="title">
            <br>
            <textarea name="body" rows="10" cols="80">
        </textarea>
            <br>
            <input type="submit" value="Create">
        ```
        - 与 Testing 功能相同的表单


- 使用功能
    ```http
    POST /page/create HTTP/2
    Host: id.ctf.hacker101.com

    title=Create+Page+Title&body=Create+Page+body%0D%0A
    ```
    - 不包含任何与 id 相关的参数

    - 响应
        ```http
        Location: /page/14
        ```
        - 当前页面编号为 `14` 之前的测试页面编号为 `1`，推测页面 ID 递增
        - 之后在 page 端点测试资源索引

- 回到首页时，HTML
    ```html
    <a href="page/14">Create Page Title</a>
    ```
    - Create 的页面作为作为元素显示在首页

测试服务器端模板注入
- 设置引发异常载荷
    ```http
    POST /page/create HTTP/2
    Host: id.ctf.hacker101.com

    title=${{<%[%'"}}%\{var}+${var}+{{var}}+<%25var%25>+[%25+var+%25]&body=${{<%[%'"}}%\{var}+${var}+{{var}}+<%25var%25>+[%25+var+%25]
    ```
    - 探测注入点同时设置 title 与 body
    - 页面
        ```html
        <html>

        <head>
            <title>${{&lt;%[%'&quot;}}%\{var} ${var} {{var}} &lt;%var%&gt; [% var %]</title>
        </head>

        <body>
            <a href="../">&lt;-- Go Home</a><br>
            <a href="edit/18">Edit this page</a>
            <h1>${{&lt;%[%'&quot;}}%\{var} ${var} {{var}} &lt;%var%&gt; [% var %]</h1>
            <p>${{&lt;%[%'"}}%{var} ${var} {{var}} &lt;%var%&gt; [% var %]</p>
        </body>

        </html>
        ```
        - 兴趣点：之前，`<>` 标签字符直接提交或 HTML 编码均被解析为元字符返回，此处被 HTML 编码为普通字符
            - 再次测试发现，当提交提交包含内容的开闭标签 `<xss>` 时作为元字符，其他情况（单标签、开闭标签但无内容）被 HTML 编码
