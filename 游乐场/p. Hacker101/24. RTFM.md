- 访问 posts
    ```http
    GET /api/v1/user/posts/1 HTTP/1.1
    X-Token: e0d32cebff31f8bbadb5f6a5f5a23f5f
    ```

    - 响应 200
        ```json
        {
            "id": 1,
            "post": "You got the Post: ^FLAG^0b4fb2d00cb0ac4265d4774555f3e0b70436da6e9a9ceeb844589ecfb3d2eaac$FLAG$",
            "analytics": "\/api\/v1\/post-analytics\/3c8a6664b8203c2e0b2b24972ccf5ce3"

        - 得到 flag 6
    - v1 API 存在访问控制缺陷，使用 post id 即可访问其他用户的 post
    - 得到新端点 
        `/api/v1/post-analytics/3c8a6664b8203c2e0b2b24972ccf5ce3`

- 继续访问 post 分析端点

    - 响应

        - 新服务器名称 `Jupiter`

        }
        ```
        - 包含 hash 列表，若已知当前端点则立即可获得 hash

    
    - 尝试访问 v2 的对应端点
        - 不存在
- `/api/v1/post-analytics/` 作为两个服务器的交接点，并返回目录内容，模糊测试或手动测试路径遍历。得到特异载荷 `..\`

    - 确认跨服务器路径遍历与目录索引
