
## 侦察

访问首页
- 响应
    ```html
    <form action="index.php" method="GET">
        <input type="submit" value="Choose Red" />
    </form>
    <form action="index.php" method="POST">
        <input type="submit" value="Choose Blue" />
    </form>
    ```
    - 兴趣点
        - 到 `index.php` 的两个表单
            - GET 对应 red
            - POST 对应 blue


## 功能探测

使用首页的 idnex.php 端点的两个功能
- red
    ```http
    GET /index.php? HTTP/1.1
    ```
- blue
    ```http
    POST /index.php HTTP/1.1
    Content-Length: 0


    ```
- 分析
    - 无有趣内容
    - GET 与 POST 均缺乏参数

尝试添加参数 red 或 blue 到请求
- 无

尝试暴破 `/index.php` 的 HTTP 动词
- 有趣的请求
    ```http
    OPTIONS /index.php HTTP/1.1
    PUT /index.php HTTP/1.1
    ...
    ```
    - 响应
        ```html
        <title>?</title>
        ```
        - 并非之前的 red/blue

- 特异请求
    ```http
    HEAD /index.php HTTP/1.1
    ```
    - 响应
        ```http
        HTTP/1.1 200 OK
        Server: Apache/2.4.38 (Debian)
        X-Powered-By: PHP/7.2.34
        flag: picoCTF{r3j3ct_th3_du4l1ty_8b13f07}
        ```
