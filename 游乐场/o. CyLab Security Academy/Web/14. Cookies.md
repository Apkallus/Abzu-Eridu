

## 侦察

访问首页
- 响应 302
    ```http
    Location: /
    Set-Cookie: name=-1; Path=/
    ```

- 设置特异 cookie 后重定向到首页

    ```html
    <a href="/reset" class="btn btn-link pull-right">Home</a>

    ...

    <form role="form" action="/search" method="post">
        <div class="row">
            <div class="form-group">
                <input type="text" name="name" id="name" class="form-control input-lg" placeholder="snickerdoodle">
            </div>
        </div>
        <div class="row">
            <div class="col-xs-12 col-sm-12 col-md-12">
                <input type="submit" class="btn btn-lg btn-success btn-block" value="Search">
            </div>
        </div>
    </form>
    ```
    - 功能端点
        - `/reset` GET
        - `/search` POST
            - `name=`
    - 信息端点
    - 静态资源端点
    - 兴趣点


## 功能探测


使用搜索功能
- 提交任意表单
    ```http
    POST /search HTTP/1.1
    Cookie: name=-1

    name=b
    ```
    - 响应 302
        ```http
        Location: /
        Set-Cookie: session=eyJfZmxhc2hlcyI6W3siIHQiOlsiZGFuZ2VyIiwiVGhhdCBkb2Vzbid0IGFwcGVhciB0byBiZSBhIHZhbGlkIGNvb2tpZS4iXX1dfQ.arNekw.R3EKS_ghfVG3aXuE3qgHa_xetY4; HttpOnly; Path=/
        ```
        - 解码 cookie 第一个段
            ```json
            {
                "_flashes": [{
                    " t": ["danger", "That doesn't appear to be a valid cookie."]
                }]
            }
            ```
- 追踪重定向到 `/`，响应
    ```http
    Set-Cookie: session=; Expires=Thu, 01 Jan 1970 00:00:00 GMT; Max-Age=0; HttpOnly; Path=/
    ```
    - 清空当前 cookie

    ```html
    <!-- <strong>Title</strong> --> That doesn&#39;t appear to be a valid cookie.
    ```

- 提交占位符名称
    ```http
    POST /search HTTP/1.1
    Cookie: name=

    name=snickerdoodle
    ```
    - 响应 302
        ```http
        Location: /check
        Set-Cookie: name=0; Path=/
        ```

- 使用 cookie name=0 追踪重定向 `/check`，响应
    ```html
    <!-- <strong>Title</strong> --> That is a cookie! Not very special though...
    <b>I love snickerdoodle cookies!</b>
    ```

- 分析
    - 在 `/check` 端点，根据 cookie name 值拥有不同响应


- 在 `/check` 端点，暴破 cookie name 字段值。得到特异请求响应
    ```http
    GET /check HTTP/1.1
    Cookie: name=18
    ```
    - 响应
        ```html
        <b>
            Flag
        </b>
        : <code>
            picoCTF{3v3ry1_l0v3s_c00k135_a4dadb49}
        </code>
        ```
