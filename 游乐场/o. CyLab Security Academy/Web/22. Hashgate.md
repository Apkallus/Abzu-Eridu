## 侦察

访问首页 `/`
- 响应
    ```http
    HTTP/1.1 200 OK
    X-Powered-By: Express
    Accept-Ranges: bytes
    ```
    
    ```html
    <!-- Email: guest@cylabacademy.org Password: guest -->
    ```    
    - 特异注释，包含一组凭证

    ```js
    document.getElementById('loginForm').addEventListener('submit', async function(event) {
            event.preventDefault();

            const formData = {
                email: document.getElementById('email').value,
                password: document.getElementById('password').value
            };

            try {
                const response = await fetch('/login', {
                    method: 'POST',
                    headers: { 'Content-Type': 'application/json' },
                    body: JSON.stringify(formData),
                    redirect: 'follow'
                });
            ...
    ```
    - JS 代码包含
        - 端点 `/login` 
        - 参数 JSON
            - 邮件
            - 密码

使用注释密钥提交登录表单到 `/login`
- 请求
    ```http
    POST /login HTTP/1.1

    {
        "email": "guest@cylabacademy.org",
        "password": "guest"
    }
    ```
    - 响应
        ```http
        HTTP/1.1 302 Found
        X-Powered-By: Express
        Location: /profile/user/e93028bdc1aacdfb3687181f2031765d

        Found. Redirecting to /profile/user/e93028bdc1aacdfb3687181f2031765d
        ```
        - 注意，此处无 cookie 保存会话状态

- 追踪重定向，请求
    ```http
    GET /profile/user/e93028bdc1aacdfb3687181f2031765d HTTP/1.1
    ```
    - 响应
        ```http
        HTTP/1.1 200 OK
        X-Powered-By: Express

        Access level: Guest (ID: 3000). Insufficient privileges to view classified data. Only top-tier users can access the flag.
        ```
        - 查找 md5 hash `e93028bdc1aacdfb3687181f2031765d`，得到
            `3000`
        - 此处 `3000` 或对应响应的 `Guest (ID: 3000)`，或对应不安全的直接对象引用

查询 0 对应的 md5 hash
- 得到
    `cfcd208495d565ef66e7dff9f98764da`

- 设置 URL 后访问
    ```http
    GET /profile/user/cfcd208495d565ef66e7dff9f98764da HTTP/1.1
    ```
    - 响应
        ```http
        HTTP/1.1 404 Not Found

        User not found.
        ```
        - 的确使用 md5 作为用户资料访问，但并非0，或 0000
- 暴破 0-3000 的 md5 hash
    - 无效
