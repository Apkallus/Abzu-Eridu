使用注册功能
- 请求
    ```http
    POST / HTTP/1.1
    Cookie: session=eyJjc3JmX3Rva2VuIjoiZDBiN2VlODQxZDI0NTE4M2NmMzE2OGEwNWIzODI4MjkzOGQwYzQ4NiJ9.arM_hg.X3X1i-MsxE58yjtDyI28JevDy-E
    Connection: keep-alive

    csrf_token=ImQwYjdlZTg0MWQyNDUxODNjZjMxNjhhMDViMzgyODI5MzhkMGM0ODYi.arNAEw.yFNfZEEv_xdS0zc02qdatzcFpOc&full_name=1&username=2&phone_number=3&city=4&password=5&submit=Register
    ```
    - 分析 cookie 内容
        - 此处 cookie 第一段的 base64 解码
            ```json
            {"csrf_token":"d0b7ee841d245183cf3168a05b38282938d0c486"}
            ```
        - 请求体参数 csrf_token 的 base64 解码
            ```json
            "d0b7ee841d245183cf3168a05b38282938d0c486"
            ```
        - 使用相同序列

    - 响应
        ```http
        HTTP/1.1 302 FOUND
        Location: /dashboard
        Set-Cookie: session=.eJwti0kKAjEQAP_SZw_Zbf1MyNJBcSYZsiAi_t0WvFUV1BvSfb7gCgZOkEYvfrYHVQ5ZxDMRGpmVsRJ1Klo6DMJGjQrVRWMWyaDjr6xt8zXsxJtkb_NgckajVaxHGOPZeuZmf3prlXxde6TOSXNag_r_V_D5AkUVKoI.arNAZw.4ujJxJpAXpnWBdVEu2tdJUPuouQ; HttpOnly; Path=/
        Connection: close
        ```
        - 此处 cookie 第一段的 hackvertor 解码
            ```json
            <@base64url><@deflate_compress>
            {
                "city": "4",
                "csrf_token": "d0b7ee841d245183cf3168a05b38282938d0c486",
                "full_name": "1",
                "otp": "643852",
                "password": "5",
                "phone_number": "3",
                "username": "2"
            }
            </@deflate_compress></@base64url>
            ```

- 追踪重定向 `/dashboard`，响应
    ```html
    <h2>2fa authentication</h2>
    <form method="POST">
        <input type="text" name="otp" placeholder="Enter OTP">
        <button type="submit">Submit</button>
    </form>
    ```

- 提交任意 opt
    `Invalid OTP`
