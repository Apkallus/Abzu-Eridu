# 从这里开始：网络安全，在实践中学习。

无需经验。按自己的节奏学习，可以独自进行、与班级一起，或参加实时活动。**始终免费。**

## 平台如何协同运作

### 构建模块：挑战

CTF 风格的题目，按主题和难度组织。每道题都藏有一个 flag，即你解出后提交的一小段文本。阅读、思考，有时还要动手“破坏”，这就是找到它的方式。如果卡住了，可以一次揭示一条提示。

### 挑战如何衔接：学习路径

从简单到复杂逐步构建的精选挑战序列。每条路径都会明确告诉你接下来该做什么。有些还包含阅读材料、视频或互动游戏，帮助你学习。

### 实战压力：活动

题目按计时发布，有两种形式。竞技性活动有排行榜和奖品。注册、组队，然后向上攀升。非竞技性活动让你在没有风险的情况下练习抗压能力。两者都是可选的；平台上的其他一切均为自定进度。

### 面向教育者：课堂

教师可以为学生分配路径和挑战、跟踪进度，并监控限定到自己班级的活动。如果你的老师把你带到这里，他们可能已经为你准备好了一个课堂。

## 你的前三步

### 01：选择你的方向

不确定？如果你想要结构，先从学习路径开始。它会明确告诉你下一步该做什么。如果你想按主题或难度自由探索，就去挑战库。

### 02：解决挑战

每道挑战都有提示，你可以一次揭示一条。题库中的内容没有计时，也不评分。按自己的节奏前进。

### 03：升级

准备好竞争时就加入活动。如果老师已经创建课堂，就进入课堂。没有唯一正确的路径。跟随能让你保持投入的方向。

## 不确定从哪里开始？

### 学习路径：引导式起步

浏览按主题组织的精选路径：密码学、Web 利用、取证等。每条路径都会排列挑战顺序，让你始终知道下一步是什么。

[浏览学习路径](https://learn.cylabacademy.org/learning-paths)

### 挑战库：自由探索

数百道挑战按类别和难度组织。按“简单”筛选，找到跨所有主题的初学者友好题目。

[打开挑战库](https://learn.cylabacademy.org/library)

### 你将探索的主题

- **通用技能**：终端、bash 脚本，以及你在其他每个类别都会用到的工具。
- **AI 与机器学习**：机器学习模型可以被欺骗。提示注入、对抗样本、模型反演。随着 AI 无处不在，这是一个快速发展的领域。
- **密码学**：代码、密码和锁定数据。弄清加密和哈希如何工作，然后破解它们。
- **Web 利用**：网站对用户输入的信任往往超出应有程度。SQL 注入、XSS 和损坏的登录是攻击者进入的方式。
- **取证**：在文件、图像和网络流量中搜寻本不该被发现的数据。想想隐写术和数据包分析。
- **二进制利用**：程序使用内存。缓冲区溢出及类似技巧让你能破坏内存，使软件做出意想不到的事。
- **逆向工程**：你有程序但没有源代码。反汇编它、反编译它，并跟踪其执行，弄清它做什么。
- **区块链**：加密货币和智能合约运行在代码上。重入漏洞、整数溢出、糟糕逻辑。在别人利用之前找到漏洞。

## 常见初学者问题

- **这是免费的吗？** 是的。平台上的每道挑战、每条学习路径和每个活动都是免费的。
- **我需要编程经验吗？** 不需要。挑战覆盖所有技能水平，并包含可以一次揭示一条的提示。学习路径从基础开始，逐步提升。
- **什么是 CTF？** CTF 是 Capture the Flag 的缩写，是一种计算机安全竞赛形式，你通过解决挑战来考验创造力、技术能力和问题解决能力。这是一种安全、合法地培养安全技能的方式，被世界各地的团体使用。
- **什么是 flag？** flag 是一小段文本，通常格式为 `prefix{like_this}`，用来证明你解出了一道挑战。你会通过解题找到它，然后把它粘贴到挑战页面的提交框中。
- **CyLab Security Academy 上的活动是什么？** 按计时发布挑战。活动覆盖一个范围：一端是完整竞赛，有积分、排行榜、奖品，以及单人/团队玩法；另一端是非竞技性发布，更像一条带计时器的学习路径。猜错没有惩罚，活动始终可选。你可以无限期使用平台而不参加任何活动。
- **学习路径和挑战库有什么区别？** 学习路径是精选序列，有清晰进阶，适合你想要结构、不确定下一步做什么时。挑战库是自由探索目录：随时选择任意类别中的任意挑战。
- **需要多长时间？** 单道挑战根据难度从几分钟到几小时不等。如果每周投入几次，完整学习路径需要几天到几周。除了课堂和活动之外，没有截止日期或评分。
