# OWASP 移动应用安全测试指南（MASTG）

**OWASP 移动应用安全测试指南（MASTG）** 是一份面向移动应用安全测试与逆向工程的综合性手册。它描述了用于验证 [OWASP 移动安全弱点枚举（MASWE）](https://github.com/OWASP/maswe "MASWE") 弱点的技术流程，这些弱点与 [OWASP 移动应用验证标准（MASVS）](https://github.com/OWASP/masvs "MASVS") 中列出的控制项保持一致。

> [OWASP MAS](https://mas.owasp.org)：[OWASP MASVS](https://mas.owasp.org/MASVS) ➡ [OWASP MASWE](https://mas.owasp.org/MASWE) ➡ [OWASP MASTG](https://mas.owasp.org/MASTG)
