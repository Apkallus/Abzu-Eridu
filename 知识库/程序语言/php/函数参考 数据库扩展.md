## 针对各数据库系统对应的扩展 

### MySQL 

#### MySQLi 

##### mysqli

###### `mysqli::__construct` `mysqli::connect` `mysqli_connect` —— 打开到 MySQL 服务器的新连接

```php
<?php
# 对象化风格：对象构造器
$mysqli = new mysqli('localhost', 'my_user', 'my_password', 'my_db');

# 过程化风格：函数调用
$mysqli = mysqli_connect('localhost', 'my_user', 'my_password', 'my_db');
```
