## 主接口

`Requests` 的所有功能都可以通过这 7 个方法访问。它们都返回 `Response` 对象的实例。

### requests.request() → Response

```py
requests.request(method: str, url: _t.UriType, **kwargs: Unpack[_t.RequestKwargs]) → Response
```

构造并发送一个 `Request`。

- `method`  
    新 `Request` 对象的方法：`GET`、`OPTIONS`、`HEAD`、`POST`、`PUT`、`PATCH` 或 `DELETE`。

- `url`  
    新 `Request` 对象的 `URL`。

- `params`  
    （可选）字典、元组列表或字节，用于在 `Request` 的查询字符串中发送。

- `data`  
    （可选）字典、元组列表、字节或类文件对象，用于在 `Request` 正文中发送。

- `json`  
    （可选）可 JSON 序列化的 Python 对象，用于在 `Request` 正文中发送。

- `headers`  
    （可选）随 `Request` 发送的 HTTP 标头字典。

- `cookies`  
    （可选）随 `Request` 发送的字典或 `CookieJar` 对象。

- `files`  
    （可选）用于多部分编码上传的 `'name': file-like-objects`（或 `{'name': file-tuple}`）字典。`file-tuple` 可以是 2 元组 `('filename', fileobj)`、3 元组 `('filename', fileobj, 'content_type')` 或 4 元组 `('filename', fileobj, 'content_type', custom_headers)`，其中 `'content_type'` 是定义给定文件内容类型的字符串，`custom_headers` 是包含要为该文件添加的额外标头的类字典对象。

- `auth`  
    （可选）用于启用 Basic/Digest/自定义 HTTP 身份验证的身份验证元组。

- `timeout`（[`float`](https://docs.python.org/3/builtins/functions.html#float) 或 [`tuple`](https://docs.python.org/3/builtins/stdtypes.html#tuple)）  
    （可选）等待服务器发送数据的秒数，超过后放弃；可为浮点数，或 `（连接超时, 读取超时）` 元组。

- `allow_redirects`（[`bool`](https://docs.python.org/3/builtins/functions.html#bool)）  
    （可选）布尔值。启用/禁用 `GET`/`OPTIONS`/`POST`/`PUT`/`PATCH`/`DELETE`/`HEAD` 重定向。默认为 `True`。

- `proxies`  
    （可选）将协议映射到代理 `URL` 的字典。

- `verify`  
    （可选）布尔值，用于控制是否验证服务器的 TLS 证书；或字符串，此时必须是要使用的 CA 捆绑包路径。默认为 `True`。

- `stream`  
    （可选）如果为 `False`，响应内容将立即下载。

- `cert`  
    （可选）如果为字符串，则是 SSL 客户端证书文件（`.pem`）的路径。如果为元组，则是 `('cert', 'key')` 对。

返回：`Response` 对象  
返回类型：`requests.Response`

用法：

```pycon
>>> import requests
>>> req = requests.request('GET', 'https://httpbin.org/get')
>>> req
<Response [200]>
```

### requests.head() → Response

```py
requests.head(url: _t.UriType, **kwargs: Unpack[_t.RequestKwargs]) → Response
```

发送 `HEAD` 请求。

- `url`  
    新 `Request` 对象的 `URL`。

- `**kwargs`  
    `request` 接受的可选参数。如果未提供 `allow_redirects`，则会将其设为 `False`（与默认的 `request` 行为相反）。

返回：`Response` 对象  
返回类型：`requests.Response`
