## 配置

### class flask.Config()

```py
class flask.Config(root_path, defaults=None)
```

其行为与字典完全一样，但提供了从文件或特殊字典填充它的方法。填充 `config` 有两种常见模式。

可以从配置文件填充 `config`：

```py
app.config.from_pyfile('yourconfig.cfg')
```

或者，可以在调用 [`from_object()`] 的模块中定义配置选项，或提供应加载模块的导入路径。也可以让它使用同一个模块，并在调用前提供配置值：

```py
DEBUG = True
SECRET_KEY = 'development key'
app.config.from_object(__name__)
```

在这两种情况下（从任意 Python 文件加载或从模块加载），只有大写键会被添加到 `config`。这样可以在配置文件中使用小写值作为临时值，而不会添加到 `config`；也可以在实现应用的同一文件中定义 `config` 键。

加载配置最有趣的方式可能是从指向文件的环境变量加载：

```py
app.config.from_envvar('YOURAPPLICATION_SETTINGS')
```

在这种情况下，启动应用前必须将此环境变量设置为要使用的文件。在 Linux 和 OS X 上使用 `export` 语句：

```sh
export YOURAPPLICATION_SETTINGS='/path/to/config/file'
```

在 Windows 上改用 `set`。

**参数：**

- `root_path`（[`str`] | [`os.PathLike`][[`str`]]）  
    读取文件时相对的路径。当 `config` 对象由应用创建时，这是应用的 [`root_path`]。

- `defaults`（[`dict`][[`str`], `t.Any`] | `None`）  
    可选的默认值字典。

#### from_envvar()

```py
from_envvar(variable_name, silent=False)
```

从指向配置文件的环境变量加载配置。这基本上只是为下面这行代码提供更友好错误消息的快捷方式：

```py
app.config.from_pyfile(os.environ['YOURAPPLICATION_SETTINGS'])
```

**参数：**

- `variable_name`（[`str`]）  
    环境变量的名称。

- `silent`（[`bool`]）  
    如果希望文件缺失时静默失败，则设为 `True`。

**返回：**

如果文件加载成功，返回 `True`。

**返回类型：**

[`bool`]

#### from_prefixed_env()

```py
from_prefixed_env(prefix='FLASK', *, loads=json.loads)
```

加载任何以 `FLASK_` 开头的环境变量，并从环境变量键中去掉该前缀，作为 `config` 键。值会传给加载函数，以尝试将其转换为比字符串更具体的类型。

键按 [`sorted()`] 顺序加载。

默认加载函数会尝试将值解析为任何有效的 JSON 类型，包括字典和列表。

可以通过用双下划线（`__`）分隔键来设置嵌套字典中的特定项。如果中间键不存在，它将被初始化为空字典。

**参数：**

- `prefix`（[`str`]）  
    加载以该前缀开头、并用下划线（`_`）分隔的环境变量。

- `loads`（[`Callable`][[`str`], [`Any`]]）  
    将每个字符串值传给此函数，并使用返回值作为 `config` 值。如果引发任何错误，则忽略该错误，值仍为字符串。默认是 [`json.loads()`]。

**返回类型：**

[`bool`]

> **变更日志**
>
> 在 2.1 版本新增。

#### from_pyfile()

```py
from_pyfile(filename, silent=False)
```

从 Python 文件更新 `config` 中的值。此函数的行为就像使用 [`from_object()`] 函数将该文件作为模块导入一样。

**参数：**

- `filename`（[`str`] | [`PathLike`][[`str`]]）  
    配置的文件名。可以是绝对文件名，也可以是相对于根路径的文件名。

- `silent`（[`bool`]）  
    如果希望文件缺失时静默失败，则设为 `True`。

**返回：**

如果文件加载成功，返回 `True`。

**返回类型：**

[`bool`]

> **变更日志**
>
> 在 0.7 版本新增：`silent` 参数。

#### from_object()

```py
from_object(obj)
```

从给定对象更新值。对象可以是以下两种类型之一：

- 字符串  
    将导入具有该名称的对象。

- 实际对象引用  
    直接使用该对象。

对象通常是模块或类。[`from_object()`] 只加载模块/类的大写属性。`dict` 对象不能用于 [`from_object()`]，因为 `dict` 的键不是 `dict` 类的属性。

基于模块的配置示例：

```py
app.config.from_object('yourapplication.default_config')
from yourapplication import default_config
app.config.from_object(default_config)
```

加载前不会对对象做任何处理。如果对象是类且具有 `@property` 属性，则需要先实例化再传给此方法。

不应使用此函数加载实际配置，而应加载配置默认值。实际配置应使用 [`from_pyfile()`] 加载，最好从不在包内的位置加载，因为包可能已系统级安装。

有关使用 [`from_object()`] 进行基于类的配置的示例，请参见 [Development / Production]。

**参数：**

- `obj`（[`object`] | [`str`]）  
    导入名称或对象。

**返回类型：**

`None`

#### from_file()

```py
from_file(filename, load, silent=False, text=True)
```

使用 `load` 参数加载文件，并从中更新 `config` 中的值。加载的数据会传给 [`from_mapping()`] 方法。

```py
import json
app.config.from_file("config.json", load=json.load)

import tomllib
app.config.from_file("config.toml", load=tomllib.load, text=False)
```

**参数：**

- `filename`（[`str`] | [`PathLike`][[`str`]]）  
    数据文件的路径。可以是绝对路径，也可以是相对于 `config` 根路径的路径。

- `load`（`Callable[[Reader], Mapping]`，其中 `Reader` 实现 `read` 方法）  
    一个可调用对象，接受文件句柄并返回文件中已加载数据的映射。

- `silent`（[`bool`]）  
    如果文件不存在，则忽略该文件。

- `text`（[`bool`]）  
    以文本或二进制模式打开文件。

**返回：**

如果文件加载成功，返回 `True`。

**返回类型：**

[`bool`]

> **变更日志**
>
> 在 2.3 版本变更：新增 `text` 参数。
>
> 在 2.0 版本新增。

#### from_mapping()

```py
from_mapping(mapping=None, **kwargs)
```

像 `update()` 一样更新 `config`，但忽略键不是大写的项。

**返回：**

始终返回 `True`。

**参数：**

- `mapping`（[`Mapping`][[`str`], [`Any`]] | `None`）

- `kwargs`（[`Any`]）

**返回类型：**

[`bool`]

> **变更日志**
>
> 在 0.11 版本新增。

#### get_namespace()

```py
get_namespace(namespace, lowercase=True, trim_namespace=True)
```

返回一个字典，其中包含与指定命名空间/前缀匹配的配置选项子集。用法示例：

```py
app.config['IMAGE_STORE_TYPE'] = 'fs'
app.config['IMAGE_STORE_PATH'] = '/var/app/images'
app.config['IMAGE_STORE_BASE_URL'] = 'http://img.website.com'
image_store_config = app.config.get_namespace('IMAGE_STORE_')
```

结果字典 `image_store_config` 如下所示：

```py
{
    'type': 'fs',
    'path': '/var/app/images',
    'base_url': 'http://img.website.com'
}
```

当配置选项直接映射到函数或类构造函数的关键字参数时，这通常很有用。

**参数：**

- `namespace`（[`str`]）  
    配置命名空间。

- `lowercase`（[`bool`]）  
    指示结果字典的键是否应小写。

- `trim_namespace`（[`bool`]）  
    指示结果字典的键是否不应包含命名空间。

**返回类型：**

[`dict`][[`str`], [`Any`]]

> **变更日志**
>
> 在 0.11 版本新增。
