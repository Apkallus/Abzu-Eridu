## 有用的函数和类

### `flask.current_app`

当前正在处理请求的应用的代理。这对于无需导入应用即可访问应用很有用，或者在无法导入应用时（例如使用应用工厂模式、蓝图和扩展中）很有用。

仅在推送[应用上下文]时可用。这在请求和 CLI 命令期间自动发生。可通过 [app_context()] 手动控制。

这是一个代理。更多信息参见[代理说明]。

---

### `flask.has_request_context()`

如果你有代码想测试请求上下文是否存在，可以使用此函数。例如，如果请求对象可用，你可能想利用请求信息；如果不可用，则静默失败。

```python
class User(db.Model):

    def __init__(self, username, remote_addr=None):
        self.username = username
        if remote_addr is None and has_request_context():
            remote_addr = request.remote_addr
        self.remote_addr = remote_addr
```

或者，你也可以直接测试任何绑定上下文的对象的真值（例如 `request` 或 `g`）：

```python
class User(db.Model):

    def __init__(self, username, remote_addr=None):
        self.username = username
        if remote_addr is None and request:
            remote_addr = request.remote_addr
        self.remote_addr = remote_addr
```

**变更日志：** 在版本 0.7 中添加。

**返回类型：** [bool]

---

### `flask.copy_current_request_context()`

```python
flask.copy_current_request_context(f)
```

装饰一个函数，使其在当前请求上下文中运行。这可用于启动后台任务，否则后台任务将看不到父级中处于活动状态的应用和请求对象。

> **警告**
>
> 由于以下注意事项，通常更安全（也更简单）的做法是在启动任务时传递所需数据，而不是使用此方法并依赖上下文对象。

为避免在读取数据时执行切换，要么在启动任务前读取请求体（访问 `form`、`json`、`data` 等），要么使用锁。使用线程时这可能是个问题，但使用 greenlet/gevent 或 asyncio 时不应是问题。

如果任务将访问 `session`，请确保在父级中也这样做，以便设置 `Vary: cookie` 头。应避免在任务中修改 `session`，因为它可能在响应 cookie 已写入后执行。

```python
import gevent
from flask import copy_current_request_context

@app.route('/')
def index():
    @copy_current_request_context
    def do_some_work():
        # 在这里做一些工作，它可以像在视图函数中一样访问 flask.request 或 flask.session。
        ...
    gevent.spawn(do_some_work)
    return 'Regular response'
```

**变更日志：** 在版本 0.10 中添加。

**参数：**
- `f`（`F`）  
  要装饰的函数。

**返回类型：** `F`

### `flask.url_for()`

```python
flask.url_for(endpoint, *, _anchor=None, _method=None, _scheme=None, _external=None, **values)
```

为给定端点生成 URL。

这需要活动的请求或应用上下文，并调用 `current_app.url_for()`。完整文档参见该方法。

**参数：**
- `endpoint`（[str]）  
  与要生成的 URL 关联的端点名称。如果以 `.` 开头，将使用当前蓝图名称（如果有）。

- `_anchor`（[str] | `None`）  
  如果给定，将此作为 `#anchor` 附加到 URL。

- `_method`（[str] | `None`）  
  如果给定，为端点生成与此方法关联的 URL。

- `_scheme`（[str] | `None`）  
  如果给定，并且 URL 是外部的，则 URL 将具有此方案。

- `_external`（[bool] | `None`）  
  如果给定，优先 URL 为内部（`False`）或要求其为外部（`True`）。外部 URL 包括方案和域。当不在活动请求中时，URL 默认是外部的。

- `values`（[Any]）  
  用于 URL 规则可变部分的值。未知键作为查询字符串参数附加，如 `?a=b&c=d`。

**返回类型：** [str]

**变更日志：**
- 在版本 2.2 中更改：调用 `current_app.url_for`，允许应用覆盖行为。
- 在版本 0.10 中更改：添加了 `_scheme` 参数。
- 在版本 0.9 中更改：添加了 `_anchor` 和 `_method` 参数。
- 在版本 0.9 中更改：构建错误时调用 `app.handle_url_build_error`。

### `flask.abort()`

```python
flask.abort(code, *args, **kwargs)
```

为给定状态码引发 [HTTPException](https://werkzeug.palletsprojects.com/en/stable/exceptions/#werkzeug.exceptions.HTTPException)。

如果 `current_app` 可用，将调用其 `aborter` 对象，否则使用 [werkzeug.exceptions.abort()](https://werkzeug.palletsprojects.com/en/stable/exceptions/#werkzeug.exceptions.abort)。

**参数：**
- `code`（[int] | [Response](https://werkzeug.palletsprojects.com/en/stable/wrappers/#werkzeug.wrappers.Response)）  
  异常的状态码，必须在 `app.aborter` 中注册。

- `args`（[Any]）  
  传递给异常。

- `kwargs`（[Any]）  
  传递给异常。

**返回类型：** [NoReturn]

**变更日志：** 在版本 2.2 中添加：如果可用则调用 `current_app.aborter`，而不是始终使用 Werkzeug 默认的 `abort`。

### `flask.redirect()`

```python
flask.redirect(location, code=302, Response=None)
```

创建重定向响应对象。

如果 `current_app` 可用，将使用其 `redirect()` 方法，否则使用 [werkzeug.utils.redirect()](https://werkzeug.palletsprojects.com/en/stable/utils/#werkzeug.utils.redirect)。

**参数：**
- `location`（[str]）  
  要重定向到的 URL。

- `code`（[int]）  
  重定向的状态码。

- `Response`（[type][[Response](https://werkzeug.palletsprojects.com/en/stable/wrappers/#werkzeug.wrappers.Response)] | `None`）  
  要使用的响应类。当 `current_app` 活动时不使用，它使用 `app.response_class`。

**返回类型：** [Response](https://werkzeug.palletsprojects.com/en/stable/wrappers/#werkzeug.wrappers.Response)

**变更日志：** 在版本 2.2 中添加：如果可用则调用 `current_app.redirect`，而不是始终使用 Werkzeug 默认的 `redirect`。

### `flask.make_response()`

```python
flask.make_response(*args)
```

有时需要在视图中设置额外头。因为视图不必返回响应对象，而可以返回由 Flask 本身转换为响应对象的值，所以向其添加头变得棘手。可以调用此函数而不是使用 `return`，你将获得一个可用于附加头的响应对象。

如果视图如下，并且你想添加新头：

```python
def index():
    return render_template('index.html', foo=42)
```

现在可以这样做：

```python
def index():
    response = make_response(render_template('index.html', foo=42))
    response.headers['X-Parachutes'] = 'parachutes are cool'
    return response
```

此函数接受与视图函数可以返回的完全相同的参数。例如，以下代码创建带有 404 错误码的响应：

```python
response = make_response(render_template('not_found.html'), 404)
```

此函数的另一个用例是强制将视图函数的返回值转换为响应，这对视图装饰器很有帮助：

```python
response = make_response(view_function())
response.headers['X-Parachutes'] = 'parachutes are cool'
```

内部执行以下操作：

- 如果未传递参数，则创建一个新的响应参数。
- 如果传递一个参数，则用它调用 [flask.Flask.make_response()]。
- 如果传递多个参数，则将这些参数作为元组传递给 [flask.Flask.make_response()] 函数。

**变更日志：** 在版本 0.6 中添加。

**参数：** **`args`**（`t.Any`）

**返回类型：** [Response](https://werkzeug.palletsprojects.com/en/stable/wrappers/#werkzeug.wrappers.Response)

### `flask.after_this_request()`

```python
flask.after_this_request(f)
```

在此请求后执行函数。这可用于修改响应对象。函数接收响应对象，必须返回相同或新的响应对象。

示例：

```python
@app.route('/')
def index():
    @after_this_request
    def add_header(response):
        response.headers['X-Foo'] = 'Parachute'
        return response
    return 'Hello World!'
```

如果视图函数以外的函数想要修改响应，这更有用。例如，考虑一个装饰器想要添加一些头，而不将返回值转换为响应对象。

**变更日志：** 在版本 0.9 中添加。

**参数：**
- `f`（[Callable][[Any], Any] | [Callable][[Any], [Awaitable][Any]]）  
  要在此请求后执行的函数。

**返回类型：** [Callable][[Any], Any] | [Callable][[Any], [Awaitable][Any]]

### `flask.send_file()`

```python
flask.send_file(path_or_file, mimetype=None, as_attachment=False, download_name=None, conditional=True, etag=True, last_modified=None, max_age=None)
```

向客户端发送文件内容。

第一个参数可以是文件路径或类文件对象。大多数情况下首选路径，因为 Werkzeug 可以管理文件并从路径获取额外信息。传递类文件对象要求文件以二进制模式打开，并且主要在用 [io.BytesIO] 在内存中构建文件时有用。

永远不要传递用户提供的文件路径。路径被假定为可信的，因此用户可能构造路径访问你不打算访问的文件。使用 `send_from_directory()` 安全地从目录内提供用户请求的路径。

如果 WSGI 服务器在 `environ` 中设置了 `file_wrapper`，则使用它，否则使用 Werkzeug 内置包装器。或者，如果 HTTP 服务器支持 `X-Sendfile`，配置 Flask 为 `USE_X_SENDFILE = True` 将告诉服务器发送给定路径，这比在 Python 中读取它高效得多。

**参数：**
- `path_or_file`（[os.PathLike][`t.AnyStr`] | [str] | `t.IO[bytes]`）  
  要发送文件的路径，如果是相对路径则相对于当前工作目录。或者，以二进制模式打开的类文件对象。确保文件指针定位到数据开头。

- `mimetype`（[str] | `None`）  
  要发送文件的 MIME 类型。如果未提供，将尝试从文件名检测。

- `as_attachment`（[bool]）  
  向浏览器指示应提供保存文件而不是显示文件。

- `download_name`（[str] | `None`）  
  浏览器保存文件时将使用的默认名称。默认为传入的文件名。

- `conditional`（[bool]）  
  基于请求头启用条件响应和范围响应。需要传递文件路径和 `environ`。

- `etag`（[bool] | [str]）  
  为文件计算 ETag，需要传递文件路径。也可以是字符串以代替计算。

- `last_modified`（`datetime` | [int] | [float] | `None`）  
  要发送的文件的最后修改时间，以秒为单位。如果未提供，将尝试从文件路径检测。

- `max_age`（`None` | ([int] | `t.Callable[[str | None], int | None]`)）  
  客户端应缓存文件多长时间，以秒为单位。如果设置，`Cache-Control` 将为 `public`，否则为 `no-cache` 以优先条件缓存。

**返回类型：** [Response](https://werkzeug.palletsprojects.com/en/stable/wrappers/#werkzeug.wrappers.Response)

**变更日志：**
- 在版本 2.0 中更改：`download_name` 替换了 `attachment_filename` 参数。如果 `as_attachment=False`，则使用 `Content-Disposition: inline` 传递。
- 在版本 2.0 中更改：`max_age` 替换了 `cache_timeout` 参数。默认启用 `conditional`，并且默认不设置 `max_age`。
- 在版本 2.0 中更改：`etag` 替换了 `add_etags` 参数。它可以是字符串以代替生成。
- 在版本 2.0 中更改：传递继承自 [TextIOBase] 的类文件对象将引发 [ValueError]，而不是发送空文件。
- 在版本 2.0 中添加：将实现移至 Werkzeug。现在是一个传递一些 Flask 特定参数的包装器。
- 在版本 1.1 中更改：`filename` 可以是 [PathLike] 对象。
- 在版本 1.1 中更改：传递 [BytesIO] 对象支持范围请求。
- 在版本 1.0.3 中更改：文件名使用 ASCII 编码而不是 Latin-1，以更广泛兼容 WSGI 服务器。
- 在版本 1.0 中更改：支持 [RFC 2231](https://datatracker.ietf.org/doc/html/rfc2231.html) 指定的 UTF-8 文件名。
- 在版本 0.12 中更改：不再自动从文件对象推断文件名。如果要使用自动 MIME 和 etag 支持，请通过 `filename_or_fp` 或 `attachment_filename` 传递文件名。
- 在版本 0.12 中更改：MIME 检测优先使用 `attachment_filename` 而不是 `filename`。
- 在版本 0.9 中更改：`cache_timeout` 默认使用 `Flask.get_send_file_max_age()`。
- 在版本 0.7 中更改：移除了对类文件对象的 MIME 猜测和 etag 支持，因为它不可靠。如果能够，请传递文件名，否则自行附加 etag。
- 在版本 0.5 中更改：添加了 `add_etags`、`cache_timeout` 和 `conditional` 参数。默认行为是添加 etags。
- 在版本 0.2 中添加。

### `flask.send_from_directory()`

```python
flask.send_from_directory(directory, path, **kwargs)
```

使用 `send_file()` 从目录内发送文件。

```python
@app.route("/uploads/<path:name>")
def download_file(name):
    return send_from_directory(
        app.config['UPLOAD_FOLDER'], name, as_attachment=True
    )
```

这是从文件夹（如静态文件或上传）提供文件的安全方式。使用 [safe_join()](https://werkzeug.palletsprojects.com/en/stable/utils/#werkzeug.security.safe_join) 确保来自客户端的路径不是恶意构造指向指定目录之外。

如果最终路径不指向现有常规文件，则引发 404 [NotFound](https://werkzeug.palletsprojects.com/en/stable/exceptions/#werkzeug.exceptions.NotFound) 错误。

**参数：**
- `directory`（[os.PathLike][[str]] | [str]）  
  `path` 必须位于其下的目录，相对于当前应用的根路径。这*不能*是客户端提供的值，否则会变得不安全。

- `path`（[os.PathLike][[str]] | [str]）  
  要发送文件的路径，相对于 `directory`。

- `kwargs`（`t.Any`）  
  传递给 `send_file()` 的参数。

**返回类型：** [Response](https://werkzeug.palletsprojects.com/en/stable/wrappers/#werkzeug.wrappers.Response)

**变更日志：**
- 在版本 2.0 中更改：`path` 替换了 `filename` 参数。
- 在版本 2.0 中添加：将实现移至 Werkzeug。现在是一个传递一些 Flask 特定参数的包装器。
- 在版本 0.5 中添加。
