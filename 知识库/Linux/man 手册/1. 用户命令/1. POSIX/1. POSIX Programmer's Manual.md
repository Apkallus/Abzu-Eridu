### getconf — 获取配置值

https://man7.org/linux/man-pages/man1/getconf.1p.html

```sh
getconf [-v specification] system_var

getconf [-v specification] path_var pathname
```

#### 描述

在第一种概要形式中，`getconf` 实用程序应将 `system_var` 操作数所指定变量的值写入标准输出。

在第二种概要形式中，`getconf` 实用程序应将 `path_var` 操作数所指定变量针对 `pathname` 操作数所指定路径的值写入标准输出。

每个配置变量的值应如同通过调用 POSIX.1‐2017 本卷或 POSIX.1‐2017 系统接口卷中定义其可用的函数所获得的那样确定（参见“操作数”节）。该值应反映当前运行环境中的条件。

#### 选项

`getconf` 实用程序应符合 POSIX.1‐2017 基础定义卷 *第 12.2 节*，*实用程序语法指南*。

应支持以下选项：

- `-v specification`
    
    指示要确定配置变量的特定规范和版本。如果未指定此选项，返回的值对应于实现默认的符合规范的编译环境。
    
    如果命令：
    
    ```sh
    getconf _POSIX_V7_ILP32_OFF32
    ```
    
    不会将 `"-1\n"` 或 `"undefined\n"` 写入标准输出，则形式如下的命令：
    
    ```sh
    getconf -v POSIX_V7_ILP32_OFF32 ...
    ```
    
    确定与 [c99(1p)] 扩展描述中指定的 POSIX_V7_ILP32_OFF32 编译环境相对应的配置变量值。
    
    如果命令：
    
    ```sh
    getconf _POSIX_V7_ILP32_OFFBIG
    ```
    
    不会将 `"-1\n"` 或 `"undefined\n"` 写入标准输出，则形式如下的命令：
    
    ```sh
    getconf -v POSIX_V7_ILP32_OFFBIG ...
    ```
    
    确定与 [c99(1p)] 扩展描述中指定的 POSIX_V7_ILP32_OFFBIG 编译环境相对应的配置变量值。
    
    如果命令：
    
    ```sh
    getconf _POSIX_V7_LP64_OFF64
    ```
    
    不会将 `"-1\n"` 或 `"undefined\n"` 写入标准输出，则形式如下的命令：
    
    ```sh
    getconf -v POSIX_V7_LP64_OFF64 ...
    ```
    
    确定与 [c99(1p)] 扩展描述中指定的 POSIX_V7_LP64_OFF64 编译环境相对应的配置变量值。
    
    如果命令：
    
    ```sh
    getconf _POSIX_V7_LPBIG_OFFBIG
    ```
    
    不会将 `"-1\n"` 或 `"undefined\n"` 写入标准输出，则形式如下的命令：
    
    ```sh
    getconf -v POSIX_V7_LPBIG_OFFBIG ...
    ```
    
    确定与 [c99(1p)] 扩展描述中指定的 POSIX_V7_LPBIG_OFFBIG 编译环境相对应的配置变量值。

#### 操作数

应支持以下操作数：

- `path_var`
    
    配置变量名。应支持 POSIX.1‐2017 系统接口卷中定义的 `fpathconf`() 函数描述里表格“变量”列中的所有变量（去掉外层花括号）。实现可添加其他本地变量。

- `pathname`
    
    要针对其确定 `path_var` 所指定变量的路径名。

- `system_var`
    
    配置变量名。应支持以下所有变量：
    
    - POSIX.1‐2017 系统接口卷中 `sysconf`() 函数描述里表格“变量”列中的名称（去掉外层花括号），但对应于 `_SC_CLK_TCK`、`_SC_GETGR_R_SIZE_MAX` 和 `_SC_GETPW_R_SIZE_MAX` 的条目除外。
        
        为兼容早期版本，还应支持以下变量名：`POSIX2_C_BIND`、`POSIX2_C_DEV`、`POSIX2_CHAR_TERM`、`POSIX2_FORT_DEV`、`POSIX2_FORT_RUN`、`POSIX2_LOCALEDEF`、`POSIX2_SW_DEV`、`POSIX2_UPE`、`POSIX2_VERSION`，它们应等价于带下划线前缀的同名变量。此要求可能在未来版本中移除。
    
    - POSIX.1‐2017 系统接口卷中 `confstr`() 函数的 `name` 参数所使用的符号常量名称，去掉 `_CS_` 前缀。
    
    - POSIX.1‐2017 基础定义卷中 `<limits.h>` 头文件描述里“最大值”和“最小值”标题下列出的符号常量名称（去掉外层花括号）。
        
        为兼容早期版本，还应支持以下变量名：`POSIX2_BC_BASE_MAX`、`POSIX2_BC_DIM_MAX`、`POSIX2_BC_SCALE_MAX`、`POSIX2_BC_STRING_MAX`、`POSIX2_COLL_WEIGHTS_MAX`、`POSIX2_EXPR_NEST_MAX`、`POSIX2_LINE_MAX`、`POSIX2_RE_DUP_MAX`，它们应等价于带下划线前缀的同名变量。此要求可能在未来版本中移除。
    
    实现可添加其他本地值。

### 🔍 awk — 模式扫描与处理语言

https://www.man7.org/linux/man-pages/man1/awk.1p.html

```bash
awk [-F sepstring] [-v assignment]... program [argument...]

awk [-F sepstring] -f progfile [-f progfile]... [-v assignment]...
     [argument...]
```

`awk` 实用程序应执行用 `awk` 编程语言编写的程序，该语言专门用于文本数据操作。一个 `awk` 程序是一系列模式和对应的动作。当读取到与某个模式匹配的输入时，就执行与该模式关联的动作。

输入应被解释为一系列记录。默认情况下，一条记录是一行，不包括其终止的 `<newline>`，但这可以通过使用 `RS` 内置变量来改变。输入的每条记录应依次与程序中的每个模式进行匹配。对于每个匹配的模式，应执行关联的动作。

`awk` 实用程序应将每条输入记录解释为一系列字段，其中默认情况下，字段是一串非 `<blank>` 非 `<newline>` 字符。这个默认的 `<blank>` 和 `<newline>` 字段分隔符可以通过使用 `FS` 内置变量或 `-F sepstring` 选项来改变。`awk` 实用程序应将记录中的第一个字段表示为 `$1`，第二个表示为 `$2`，依此类推。符号 `$0` 应指代整条记录；设置任何其他字段会导致重新求值 `$0`。对 `$0` 赋值应重置所有其他字段的值以及 `NF` 内置变量。

> 例
```sh
# 提取列2，逐行打印
awk '{ print($2) }' 文件
# 提取列2，并作为字符串打印
awk '{ printf("%s",$2) }' 文件

# 读取进程信息并禁用截断，保留表头，正则表达式提取特定内容
ps auxww | awk 'NR==1 || /dont_/'
```

#### 选项

`awk` 实用程序应符合 POSIX.1‐2017 基础定义卷的 *第 12.2 节*、*实用程序语法指南*。

应支持以下选项：

- `-F sepstring`  
  定义输入字段分隔符。此选项应等价于：

  `-v FS=sepstring`

  但若同时使用 `-F sepstring` 和 `-v FS=sepstring`，则未规定由 `-F sepstring` 产生的 `FS` 赋值是按命令行顺序处理，还是在最后一个 `-v FS=sepstring` 之后处理。关于 `FS` 内置变量的描述及其使用方式，请参见扩展描述部分。

- `-f progfile`  
  指定包含 `awk` 程序的文件的路径名 `progfile`。路径名 `'-'` 应表示标准输入。如果指定了此选项的多个实例，则按指定顺序将指定为 `progfile` 的文件连接起来作为 `awk` 程序。`awk` 程序也可以作为单个参数在命令行中指定。

- `-v assignment`  
  应用程序应确保 `assignment` 参数与赋值操作数的形式相同。指定的变量赋值应在执行 `awk` 程序之前发生，包括与 `BEGIN` 模式（如果有）关联的动作。此选项可以多次出现。


#### 示例

对于使用 `sh` 的应用程序，在命令行中指定的 `awk` 程序最容易用单引号（例如 `'program'`）指定，因为 `awk` 程序通常包含对 shell 有特殊含义的字符，包括双引号。在 `awk` 程序包含单引号字符的情况下，通常最容易将程序的大部分指定为单引号内的字符串，并由 shell 与带引号的单引号字符连接。例如：

```sh
awk '/'\''/ { print "quote:", $0 }'
```

这会打印标准输入中包含单引号字符的所有行，并在前面加上 `quote:`。

以下是一些简单 `awk` 程序的示例：

1. 将所有第 3 个字段大于 5 的输入行写入标准输出：  

    ```awk
    $3 > 5
    ```

2. 写入每第十行：  

    ```awk
    (NR % 10) == 0
    ```

3. 写入任何包含匹配该正则表达式的子串的行：  

    ```awk
    /(G|D)(2[0-9][[:alpha:]]*)/
    ```

4. 打印任何包含子串的行，该子串包含 `'G'` 或 `'D'`，后跟一串数字和字符。此示例使用字符类 `digit` 和 `alpha` 分别匹配与语言无关的数字字符和字母字符：  

    ```awk
    /(G|D)([[:digit:][:alpha:]]*)/
    ```

5. 写入第二字段匹配该正则表达式而第四字段不匹配的任何行：  

    ```awk
    $2 ~ /xyz/ && $4 !~ /xyz/
    ```

6. 写入第二字段包含反斜杠（`\`）的任何行：  

    ```awk
    $2 ~ /\\/
    ```

7. 写入第二字段包含反斜杠（`\`）的任何行。注意，反斜杠转义会被解释两次；一次在字符串的词法处理中，一次在正则表达式的处理中：  

    ```awk
    $2 ~ "\\\\"
    ```

8. 写入每行倒数第二个字段和最后一个字段。字段之间用冒号（`:`）分隔：  

    ```awk
    {OFS=":";print $(NF-1), $NF}
    ```

9. 写入每行的行号和字段数。表示行号、冒号（`:`）和字段数的三个字符串会连接起来，并将该字符串写入标准输出：  

    ```awk
    {print NR ":" NF}
    ```

10. 写入长度超过 72 个字符的行：  

    ```awk
    length($0) > 72
    ```

11. 按相反顺序写入前两个字段，并用 `OFS` 分隔：  

    ```awk
    { print $2, $1 }
    ```

12. 同上，但输入字段用逗号（`,`）或空格和制表符（`\t`）字符，或两者分隔：  

    ```awk
    BEGIN { FS = ",[ \t]*|[ \t]+" }
          { print $2, $1 }
    ```

13. 累加第一列，打印总和与平均值：  

    ```awk
          {s += $1 }
    END   {print "sum is ", s, " average is", s/NR}
    ```

14. 按相反顺序写入字段，每行一个（对于每一输入行会输出多行）：  

    ```awk
    { for (i = NF; i > 0; --i) print $i }
    ```

15. 写入字符串 `start` 和 `stop` 出现之间的所有行：  

    ```awk
    /start/, /stop/
    ```

16. 写入第一字段与前一个不同的所有行：  

    ```awk
    $1 != prev { print; prev = $1 }
    ```

17. 模拟 `echo`：  

    ```awk
    BEGIN  {
            for (i = 1; i < ARGC; ++i)
            printf("%s%s", ARGV[i], i==ARGC-1?"\n":" ")
    }
    ```

18. 写入 `PATH` 环境变量中包含的路径前缀，每行一个：  

    ```awk
    BEGIN  {
            n = split (ENVIRON["PATH"], path, ":")
            for (i = 1; i <= n; ++i)
            print path[i]
    }
    ```

19. 如果有一个名为 `input` 的文件，包含形式为 `Page #` 的页眉，并且有一个名为 `program` 的文件，包含：  

    ```awk
    /Page/   { $2 = n++; }
             { print }
    ```

    那么命令行：  

    ```sh
    awk -f program n=5 input
    ```

    会打印文件 `input`，从 5 开始填写页码。
