# `chmod` — 更改文件模式位

## 概要

```sh
chmod [OPTION]... MODE[,MODE]... FILE...
chmod [OPTION]... OCTAL-MODE FILE...
chmod [OPTION]... --reference=RFILE FILE...
```

## 描述

本手册页记录 GNU 版本的 `chmod`。`chmod` 根据 `mode` 更改每个给定文件的文件模式位，`mode` 可以是表示要进行的更改的符号表示，也可以是表示新模式位位模式的八进制数。

符号模式的格式为 `[ugoa...][[-+=][perms...]...]`，其中 `perms` 要么是集合 `rwxXst` 中的零个或多个字母，要么是集合 `ugo` 中的单个字母。可以给出多个符号模式，以逗号分隔。

字母 `ugoa` 的组合控制将更改哪些用户对文件的访问：文件所有者（`u`）、文件组中的其他用户（`g`）、不在文件组中的其他用户（`o`）或所有用户（`a`）。如果这些字母都未给出，效果等同于给出 `a`，但 umask 中设置的位不受影响。

运算符 `+` 使选定的文件模式位添加到每个文件的现有文件模式位；`-` 使它们被移除；`=` 使它们被添加，并使未提及的位被移除，但目录未提及的设置用户和组 ID 位不受影响。

字母 `rwxXst` 为受影响的用户选择文件模式位：读（`r`）、写（`w`）、执行（或对目录搜索）（`x`）、仅当文件是目录或已对某用户具有执行权限时才执行/搜索（`X`）、执行时设置用户或组 ID（`s`）、受限删除标志或粘滞位（`t`）。也可以不指定这些字母中的一个或多个，而是恰好指定 `ugo` 中的一个字母：授予文件所有者的权限（`u`）、授予文件组成员的其他用户的权限（`g`），以及授予不属于前两个类别中任何一个的用户的权限（`o`）。

数字模式由一到四位八进制数字（0-7）组成，通过将值为 4、2 和 1 的位相加得出。省略的数字假定为前导零。第一位选择设置用户 ID（4）、设置组 ID（2）和受限删除或粘滞（1）属性。第二位选择文件所有者的权限：读（4）、写（2）和执行（1）；第三位选择文件组中其他用户的权限，值相同；第四位选择不在文件组中的其他用户的权限，值相同。

`chmod` 不更改符号链接的权限；`chmod` 系统调用在大多数系统上无法更改其权限，且大多数系统忽略符号链接的权限。然而，对于命令行上列出的每个符号链接，`chmod` 会更改所指向文件的权限。相比之下，`chmod` 忽略递归目录遍历期间遇到的符号链接。修改此行为的选项在选项部分描述。

## 设置用户 ID 和设置组 ID 位

如果文件的组 ID 与用户的有效组 ID 或用户的补充组 ID 之一不匹配，`chmod` 会清除常规文件的设置组 ID 位，除非用户具有适当特权。其他限制可能导致 `MODE` 或 `RFILE` 的设置用户 ID 和设置组 ID 位被忽略。此行为取决于底层 `chmod` 系统调用的策略和功能。如有疑问，请检查底层系统行为。

对于目录，`chmod` 会保留设置用户 ID 和设置组 ID 位，除非你明确指定否则。你可以使用 `u+s` 和 `g-s` 等符号模式设置或清除这些位。要使用数字模式清除目录的这些位，需要额外的前导零（如 `00755`）、前导减号（如 `-6000`）或前导等号（如 `=755`）。

## 受限删除标志或粘滞位

受限删除标志或粘滞位是单个位，其解释取决于文件类型。对于目录，它防止非特权用户删除或重命名目录中的文件，除非他们拥有该文件或目录；这称为目录的*受限删除标志*，常见于 `/tmp` 等全局可写目录。对于某些较旧系统上的常规文件，该位将程序的文本映像保存在交换设备上，以便运行时更快加载；这称为*粘滞位*。

## 选项

将每个 FILE 的模式更改为 MODE。使用 `--reference` 时，将每个 FILE 的模式更改为 RFILE 的模式。

- `-c`, `--changes`  
  与 verbose 类似，但仅在做出更改时报告

- `-f`, `--silent`, `--quiet`  
  抑制大多数错误消息

- `-v`, `--verbose`  
  对处理的每个文件输出诊断信息

- `--dereference`  
  影响每个符号链接的引用对象，而不是符号链接本身

- `-h`, `--no-dereference`  
  影响每个符号链接，而不是引用对象

- `--no-preserve-root`  
  不特殊对待 `/`（默认）

- `--preserve-root`  
  拒绝对 `/` 进行递归操作

- `--reference=RFILE`  
  使用 RFILE 的模式而不是指定 MODE 值。如果 RFILE 是符号链接，总是解引用

- `-R`, `--recursive`  
  递归更改文件和目录

以下选项修改在还指定了 `-R` 选项时遍历层次结构的方式。如果指定了多个，只有最后一个生效。`-H` 是默认值。

- `-H`  
  如果命令行参数是指向目录的符号链接，则遍历它

- `-L`  
  遍历遇到的每个指向目录的符号链接

- `-P`  
  不遍历任何符号链接

- `--help`  
  显示此帮助并退出

- `--version`  
  输出版本信息并退出

每个 MODE 的形式为 `[ugoa]*([-+=]([rwxXst]*|[ugo]))+|[-+=][0-7]+`。
