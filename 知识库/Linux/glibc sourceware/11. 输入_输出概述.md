# 11 输入/输出概述

https://sourceware.org/glibc/manual/latest/html_node/I_002fO-Overview.html

大多数程序为了完成任何有用的工作，都需要执行输入（读取数据）或输出（写入数据），或者最常见的是两者兼有。GNU C 库提供了如此丰富的输入和输出函数，以至于最难的部分往往是决定哪个函数最合适！

本章介绍与输入和输出相关的概念和术语。

- [输入/输出概念]
- [文件名]

其他与 GNU `I/O` 设施相关的章节包括：

- [流上的输入/输出]  
    涵盖操作流的高级函数，包括格式化输入和输出。
- [低级输入/输出]  
    涵盖文件描述符上的基本 `I/O` 和控制函数。
- [文件系统接口]  
    涵盖用于操作目录以及处理访问模式和所有权等文件属性的函数。
- [管道和 FIFO]  
    包含有关基本进程间通信设施的信息。
- [套接字]  
    涵盖更复杂的进程间通信设施，支持网络功能。
- [低级终端接口]  
    涵盖用于更改终端或其他串行设备的输入和输出处理方式的函数。
