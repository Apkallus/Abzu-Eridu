## 9.1 Bash 历史功能

启用 `set` 内建命令的 `-o history` 选项时（参见 [Set 内建命令]），shell 会提供对*命令历史*的访问，即此前输入过的命令列表。`HISTSIZE` shell 变量的值用作历史列表中保存的命令数：shell 保存最后 `$HISTSIZE` 条命令的文本（默认 500）。shell 在参数和变量扩展之前、但在执行历史扩展之后，将每条命令存入历史列表，具体取决于 shell 变量 `HISTIGNORE` 和 `HISTCONTROL` 的值。

shell 启动时，Bash 通过从 `HISTFILE` 变量指定的文件（默认为 `~/.bash_history`）读取历史条目来初始化历史列表。该文件称为*历史文件*。必要时，历史文件会被截断，使其包含的历史条目不超过 `HISTFILESIZE` 变量值所指定的数量。如果 `HISTFILESIZE` 未设置，或设置为空、非数值或小于零的数值，则历史文件不会被截断。

读取历史文件时，以历史注释字符开头并紧跟一个数字的行，会被解释为后续历史条目的时间戳。这些时间戳是否显示取决于 `HISTTIMEFORMAT` 变量的值（参见 [Bash 变量]）。存在时间戳时，它们会分隔历史条目，从而使多行条目成为可能。

启用历史的 shell 退出时，Bash 会将历史列表中最后 `$HISTSIZE` 个条目复制到 `$HISTFILE` 指定的文件。如果设置了 `histappend` shell 选项（参见 [Bash 内建命令]），Bash 会将条目追加到历史文件；否则会覆盖历史文件。如果 `HISTFILE` 未设置或为空，或者历史文件不可写，则不会保存历史。保存历史后，Bash 会按上述方式将历史文件截断为不超过 `$HISTFILESIZE` 行。

如果设置了 `HISTTIMEFORMAT` 变量，shell 会将与每个历史条目关联的时间戳信息写入历史文件，并用历史注释字符标记，从而跨 shell 会话保留时间戳。读取历史文件时，以历史注释字符开头并紧跟一个数字的行，会被解释为后续历史条目的时间戳。如上所述，使用 `HISTTIMEFORMAT` 时，时间戳会分隔多行历史条目。

`fc` 内建命令将列出或编辑并重新执行历史列表的一部分。`history` 内建命令可以显示或修改历史列表，并操作历史文件。使用命令行编辑时，每个编辑模式中都有可访问历史列表的搜索命令（参见 [操作历史的命令]）。

shell 允许控制哪些命令保存到历史列表。`HISTCONTROL` 和 `HISTIGNORE` 变量用于仅保存所输入命令的一个子集。如果启用了 `cmdhist` shell 选项，shell 会尝试将多行命令的每一行保存在同一历史条目中，并在必要时添加分号以保持语法正确。`lithist` shell 选项会修改 `cmdhist`，保存命令时使用嵌入换行符而不是分号。使用 `shopt` 内建命令设置这些选项。有关 `shopt` 的说明，参见 [Shopt 内建命令]。

## 9.2 Bash 历史内建命令

Bash 提供两个内建命令，用于操作历史列表和历史文件。

### fc() —— 修改历史命令后执行

```bash
fc [-e ename] [-lnr] [first] [last]
fc -s [pat=rep] [command]
```

```sh
fc [-e ename] [-lnr] [first] [last]
```

第一种形式从历史列表中选择从 `first` 到 `last` 的一段命令，并显示或编辑后重新执行它们。`first` 和 `last` 都可以指定为字符串（用于定位以该字符串开头的最新命令）或数字（历史列表中的索引，其中负数用作当前命令号的偏移量）。

列出时，`first` 或 `last` 为 `0` 等价于 `-1`，`-0` 等价于当前命令（通常是 `fc` 命令）；否则 `0` 等价于 `-1`，而 `-0` 无效。

如果未指定 `last`，列出时它设为当前命令，否则设为 `first`。如果未指定 `first`，编辑时它设为前一条命令，列出时设为 `-16`。

如果提供 `-l` 标志，命令会列到标准输出。`-n` 标志在列出时抑制命令编号。`-r` 标志反转列出顺序。

否则，`fc` 对包含这些命令的文件调用由 `ename` 命名的编辑器。如果未提供 `ename`，`fc` 使用以下变量扩展的值：`${FCEDIT:-${EDITOR:-vi}}`。这表示如果设置了 `FCEDIT` 变量则使用其值，否则如果设置了 `EDITOR` 变量则使用其值，如果两者都未设置则使用 `vi`。编辑完成后，`fc` 读取编辑后的命令文件，并回显并执行它们。

```sh
fc -s [pat=rep] [command]
```

在第二种形式中，`fc` 将所选命令中每个 `pat` 实例替换为 `rep` 后重新执行 `command`。`command` 的解释与上面的 `first` 相同。

与 `fc` 命令一起使用的一个有用别名是 `r='fc -s'`，这样输入 `r cc` 会运行以 `cc` 开头的最新命令，输入 `r` 会重新执行最后一条命令（参见 [别名]）。

如果使用第一种形式，返回值是 0，除非遇到无效选项，或者 `first` 或 `last` 指定的历史行超出范围。编辑并重新执行命令文件时，返回值是最后执行的命令的值，如果临时文件发生错误则返回失败。如果使用第二种形式，返回状态是重新执行的命令的状态，除非 `command` 未指定有效的历史条目，此时 `fc` 返回非零状态。

示例

```console
$ echo "first"
first
$ fc -s first=second
echo "second"
second
```

### history() —— 设置历史命令

```bash
history [n]
history -c
history -d offset
history -d start-end
history [-anrw] [filename]
history -ps arg
```

无选项时，显示带编号的历史列表。以 `*` 为前缀的条目已被修改。参数 `n` 只列出最后 `n` 个条目。如果 shell 变量 `HISTTIMEFORMAT` 已设置且非空，则它用作 `strftime(3)` 的格式字符串，以显示每个显示的历史条目关联的时间戳。如果 `history` 使用 `HISTTIMEFORMAT`，则不会在格式化时间戳和历史条目之间打印中间空格。

如果提供选项，其含义如下：

- `-c`  
    清除历史列表。这可以与其他选项组合以替换历史列表。
- `-d offset`  
    删除位置 `offset` 处的历史条目。如果 `offset` 为正，则应按历史显示时出现的形式指定。如果 `offset` 为负，则它相对于最后一个历史位置加一解释，因此负索引从历史末尾倒数，索引 `-1` 指当前 `history -d` 命令。
- `-d start-end`  
    删除位置 `start` 和 `end` 之间（含两端）的历史条目范围。`start` 和 `end` 的正值和负值按上述方式解释。
- `-a`  
    将“新”历史行追加到历史文件。这些是自当前 Bash 会话开始以来输入、但尚未追加到历史文件的历史行。
- `-n`  
    读取尚未从历史文件读取的历史行，并将它们添加到当前历史列表。这些是自当前 Bash 会话开始以来追加到历史文件的行。
- `-r`  
    读取历史文件并将其内容追加到历史列表。
- `-w`  
    将当前历史列表写入历史文件，覆盖历史文件。
- `-p`  
    对 `args` 执行历史替换，并将结果显示到标准输出，而不将结果存入历史列表。
- `-s`  
    将 `args` 作为单个条目添加到历史列表末尾。在添加 `args` 之前，移除历史列表中的最后一条命令。

如果随 `-w`、`-r`、`-a` 或 `-n` 任一选项提供 `filename` 参数，Bash 使用 `filename` 作为历史文件。否则使用 `HISTFILE` 变量的值。如果 `HISTFILE` 未设置或为空，这些选项没有效果。

如果设置了 `HISTTIMEFORMAT` 变量，`history` 会将与每个历史条目关联的时间戳信息写入历史文件，并用如上所述的历史注释字符标记。读取历史文件时，以历史注释字符开头并紧跟一个数字的行，会被解释为后续历史条目的时间戳。

返回值为 0，除非遇到无效选项、读取或写入历史文件时发生错误、向 `-d` 提供无效的 `offset` 或范围，或者向 `-p` 提供的历史扩展失败。
