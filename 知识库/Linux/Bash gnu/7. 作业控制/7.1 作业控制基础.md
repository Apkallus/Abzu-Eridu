# 7.1 作业控制基础

https://www.gnu.org/software/bash/manual/html_node/Job-Control-Basics.html

作业控制指的是有选择地停止（挂起）进程执行并在稍后继续（恢复）其执行的能力。用户通常通过操作系统内核的终端驱动程序和 Bash 共同提供的交互界面来使用此功能。

shell 将 `job` 与每个管道关联。它维护一个当前正在执行的作业表，`jobs` 命令会显示该表。每个作业都有一个 `job number`，`jobs` 会在方括号中显示它。作业号从 1 开始。当 Bash 异步启动作业时，它会打印一行类似如下内容：

```text
[1] 25647
```

表示此作业是作业号 1，并且与此作业关联的管道中最后一个进程的进程 ID 是 25647。单个管道中的所有进程都是同一作业的成员。Bash 使用 `job` 抽象作为作业控制的基础。

为便于实现作业控制的用户界面，每个进程都有一个 `process group ID`，操作系统维护当前终端进程组 ID 的概念。此终端进程组 ID 与 `controlling terminal` 关联。

具有相同进程组 ID 的进程被称为属于同一 `process group`。前台进程组的成员（进程组 ID 等于当前终端进程组 ID 的进程）接收键盘生成的信号，如 `SIGINT`。前台进程组中的进程称为前台进程。后台进程是其进程组 ID 与控制终端的进程组 ID 不同的进程；此类进程不受键盘生成的信号影响。只有前台进程才允许从控制终端读取，或者在用户通过 `stty tostop` 如此指定时，向控制终端写入。系统会向尝试从终端读取（或在 `tostop` 生效时写入终端）的后台进程发送 `SIGTTIN`（`SIGTTOU`）信号，除非该信号被捕获，否则会挂起该进程。

如果运行 Bash 的操作系统支持作业控制，Bash 就包含使用它的设施。在进程运行时输入 `suspend` 字符（通常是 `^Z`，Control-Z）会停止该进程并将控制权返回给 Bash。输入 `delayed suspend` 字符（通常是 `^Y`，Control-Y）会使进程在尝试从终端读取输入时停止，并将控制权返回给 Bash。然后用户操作此作业的状态，使用 `bg` 命令在后台继续它，使用 `fg` 命令在前台继续它，或使用 `kill` 命令终止它。挂起字符立即生效，并具有丢弃任何待处理输出和预输入的额外副作用。如果你想强制停止后台进程，或停止与你的终端会话无关的进程，请使用 `kill` 向其发送 `SIGSTOP` 信号。

在 shell 中有多种方式引用作业。`%` 字符引入 `job specification`（jobspec）。作业号 `n` 可以称为 `%n`。作业也可以通过用于启动它的名称前缀来引用，或通过其命令行中出现的子串来引用。例如，`%ce` 指命令名以 `ce` 开头的作业。另一方面，使用 `%?ce` 指命令行中包含字符串 `ce` 的任何作业。如果前缀或子串匹配多个作业，Bash 会报告错误。

符号 `%%` 和 `%+` 指 shell 概念中的 `current job`。单个 `%`（不附带作业规范）也指当前作业。`%-` 指 `previous job`。当作业在后台启动、作业在前台停止，或作业在后台恢复时，它成为当前作业。原本的当前作业成为前一个作业。当前作业终止时，前一个作业成为当前作业。如果只有一个作业，`%+` 和 `%-` 都可以用来指该作业。在与作业相关的输出中（例如 `jobs` 命令的输出），当前作业始终用 `+` 标记，前一个作业用 `-` 标记。

简单地命名一个作业即可将其带入前台：`%1` 是 `fg %1` 的同义词，将作业 1 从后台带入前台。类似地，`%1 &` 在后台恢复作业 1，等价于 `bg %1`。

shell 会立即获知作业何时改变状态。通常，Bash 会等到即将打印提示符时才通知用户作业状态的变化，以免打断任何其他输出；不过，它会在列表中的前台命令完成后、执行列表中的下一条命令之前，通知作业状态的变化。如果启用了 `set` 内建命令的 `-b` 选项，Bash 会立即报告状态变化（参见 [The Set Builtin]）。Bash 会为每个终止的子进程执行 `SIGCHLD` 上的任何 trap。

当作业终止且 Bash 通知用户后，Bash 会将该作业从作业表中移除。它不会出现在 `jobs` 输出中，但只要向 `wait` 提供与该作业关联的进程 ID 作为参数，`wait` 就会报告其退出状态。当表为空时，作业号从 1 重新开始。

如果用户在作业已停止（或如果启用了 `checkjobs` 选项，则在作业正在运行）时尝试退出 Bash，shell 会打印警告消息；如果启用了 `checkjobs` 选项，还会列出作业及其状态。然后可以使用 `jobs` 命令检查它们的状态。如果用户立即再次尝试退出，且中间没有执行命令，Bash 不会再次打印警告，并终止任何已停止的作业。

当 shell 使用 `wait` 内建命令等待作业或进程，且启用了作业控制时，`wait` 会在作业改变状态时返回。`-f` 选项使 `wait` 等到作业或进程终止后才返回。
