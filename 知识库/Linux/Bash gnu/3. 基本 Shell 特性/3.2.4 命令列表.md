# 3.2.4 命令列表

`list` 是由一个或多个管道组成的序列，这些管道由操作符 `;`、`&`、`&&` 或 `||` 之一分隔，并且可选地由 `;`、`&` 或 `newline` 之一终止。

在这些列表操作符中，`&&` 和 `||` 优先级相同，其次是 `;` 和 `&`，二者优先级相同。

`list` 中可以出现一个或多个换行符组成的序列来分隔命令，等价于分号。

如果命令由控制操作符 `&` 终止，shell 会在子 shell 中异步执行该命令。这称为在**后台**执行命令，这些命令称为**异步**命令。shell 不等待命令完成，返回状态为 `0`（真）。当作业控制未激活（见[作业控制]）时，异步命令的标准输入在没有任何显式重定向的情况下从 `/dev/null` 重定向。

由 `;` 分隔的命令顺序执行；shell 等待每个命令依次终止。返回状态是最后执行命令的退出状态。

`AND` 列表和 `OR` 列表分别是由控制操作符 `&&` 和 `||` 分隔的一个或多个管道序列。`AND` 列表和 `OR` 列表按左结合方式执行。

`AND` 列表的形式为

```sh
command1 && command2
```

仅当 `command1` 返回退出状态 `0`（成功）时，才执行 `command2`。

`OR` 列表的形式为

```sh
command1 || command2
```

仅当 `command1` 返回非零退出状态时，才执行 `command2`。

`AND` 列表和 `OR` 列表的返回状态是列表中最后执行命令的退出状态。
