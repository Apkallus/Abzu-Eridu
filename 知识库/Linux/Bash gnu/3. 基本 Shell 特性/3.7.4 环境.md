# 3.7.4 环境

https://www.gnu.org/software/bash/manual/html_node/Environment.html

程序被调用时，会获得一个称为 `environment`（环境）的字符串数组。这是一个名称-值对列表，形式为 `name=value`。

Bash 提供了多种操作环境的方式。在启动时，shell 会扫描自己的环境，并为找到的每个名称创建一个参数，自动将其标记为向子进程 `export`。被执行的命令会继承该环境。`export`、`declare -x` 和 `unset` 命令通过添加和删除参数与函数来修改环境。如果环境中某个参数的值被修改，新值会自动成为环境的一部分，并替换旧值。任何被执行命令所继承的环境由以下部分组成：shell 的初始环境（其值可能在 shell 中被修改），减去由 `unset` 和 `export -n` 命令移除的任何对，再加上通过 `export` 和 `declare -x` 命令添加的任何内容。

如果任何参数赋值语句（如 [Shell 参数] 中所述）出现在简单命令之前，则这些变量赋值在该命令执行期间属于该命令的环境。这些赋值语句只影响该命令所看到的环境。如果这些赋值出现在对 shell 函数的调用之前，则这些变量对该函数是局部的，并会导出给该函数的子进程。

如果设置了 `-k` 选项（参见 [Set 内建命令]），则所有参数赋值都会放入命令的环境中，而不仅仅是那些位于命令名之前的赋值。

当 Bash 调用外部命令时，变量 `$_` 会被设置为该命令的完整路径名，并在该命令的环境中传递给它。
