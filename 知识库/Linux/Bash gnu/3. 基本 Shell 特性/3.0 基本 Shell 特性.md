# 3 基本 Shell 特性

`Bash` 是 `Bourne-Again SHell` 的缩写。Bourne shell 是最初由 Stephen Bourne 编写的传统 Unix shell。所有 Bourne shell 内建命令在 Bash 中均可用，并且求值和引用规则取自 POSIX 规范中的“标准”Unix shell。

本章简要概述 shell 的“构建块”：命令、控制结构、shell 函数、shell 参数、shell 扩展、重定向（一种将输入和输出定向到命名文件或从命名文件定向的方法），以及 shell 如何执行命令。
