# 3.5.4 命令替换

命令替换允许命令的输出替换命令本身。命令替换的标准形式是在命令被如下包围时出现：

```bash
$(command)
```

或（已弃用）

```bash
`command`.
```

Bash 通过在子 shell 环境中执行 `command`，并用该命令的标准输出（删除末尾所有换行符）替换命令替换来执行命令替换。嵌入的换行符不会被删除，但在分词期间可能会被移除。命令替换 `$(cat file)` 可以替换为等价但更快的 `$(< file)`。

使用旧式反引号替换形式时，反斜杠保留其字面含义，但后跟 `$`、`` ` `` 或 `\` 时除外。第一个前面没有反斜杠的反引号 `` ` `` 会终止命令替换。使用 `$(command)` 形式时，括号之间的所有字符构成命令；没有任何字符被特殊处理。

还有一种命令替换的替代形式：

```bash
${c command; }
```

它在当前执行环境中执行 `command` 并捕获其输出，同样删除末尾换行符。

左花括号后的字符 `c` 必须是空格、制表符、换行或 `|`，并且右花括号必须位于保留字可以出现的位置（即前面有命令终止符，例如分号 `;`）。Bash 允许右花括号与单词中的其余字符连接，而其后不需要跟 shell 元字符，而保留字通常需要如此。

`command` 的任何副作用都会立即在当前执行环境中生效，并在命令完成后持续存在于当前环境中（例如，`exit` 内建命令会退出 shell）。

这种命令替换表面上类似于执行一个未命名的 shell 函数：局部变量的创建方式与执行 shell 函数时相同，并且 `return` 内建命令会强制 `command` 完成；然而，执行环境的其余部分（包括位置参数）与调用者共享。

如果左花括号后的第一个字符是 `|`，则该结构在 `command` 执行后展开为 `REPLY` shell 变量的值，不删除任何末尾换行符，并且 `command` 的标准输出与调用 shell 中相同。当 `command` 执行时，Bash 将 `REPLY` 创建为初始未设置的局部变量，并在 `command` 完成后将 `REPLY` 恢复为命令替换之前的值，如同任何局部变量一样。

例如，以下结构展开为 `12345`，并在当前执行环境中保持 shell 变量 `X` 不变：

```bash
${ local X=12345 ; echo $X; }
```

（不将 `X` 声明为 `local` 会修改其在当前环境中的值，如同正常的 shell 函数执行），而以下结构不需要任何输出即可展开为 `12345`：

```bash
${| REPLY=12345; }
```

并将 `REPLY` 恢复为命令替换之前的值。

命令替换可以嵌套。使用反引号形式嵌套时，用反斜杠转义内层反引号。

如果替换出现在双引号内，Bash 不会对结果执行分词和文件名扩展。
