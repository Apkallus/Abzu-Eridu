#### 3.4.2 特殊参数

shell 会特殊处理若干参数。这些参数只能被引用；不允许对它们赋值。特殊参数由下列字符之一表示。

- `*`  
    （`$*`）展开为从 1 开始的位置参数。当展开不在双引号内时，每个位置参数展开为单独的单词。在执行单词展开的上下文中，这些单词还会进一步进行分词和文件名扩展。当展开发生在双引号内时，它展开为单个单词，其中各参数的值由 `IFS` 变量的第一个字符分隔。也就是说，`"$*"` 等价于 `"$1c$2c…"`，其中 `c` 是 `IFS` 变量值的第一个字符。如果 `IFS` 未设置，则参数由空格分隔。如果 `IFS` 为空，则参数连接时不在其间插入分隔符。

- `@`  
    （`$@`）展开为从 1 开始的位置参数。在执行分词的上下文中，这会将每个位置参数展开为单独的单词；如果不在双引号内，这些单词还会进行分词。在不执行分词的上下文中，例如赋值语句的值部分，它展开为单个单词，其中每个位置参数由空格分隔。当展开发生在双引号内并且执行分词时，每个参数展开为单独的单词。也就是说，`"$@"` 等价于 `"$1" "$2" …`。如果双引号展开发生在单词内部，则第一个参数的展开会与原单词开头部分的展开连接，最后一个参数的展开会与原单词末尾部分的展开连接。当没有位置参数时，`"$@"` 和 `$@` 展开为空（即被移除）。

- `#`  
    （`$#`）以十进制展开为位置参数的数量。

- `?`  
    （`$?`）展开为最近执行命令的退出状态。

- `-`  
    （`$-`，连字符。）展开为当前选项标志，这些标志在调用时指定、由 `set` 内建命令指定，或由 shell 自身设置（例如 `-i` 选项）。

- `$`  
    （`$$`）展开为 shell 的进程 ID。在子 shell 中，它展开为调用 shell 的进程 ID，而不是子 shell 的进程 ID。

- `!`  
    （`$!`）展开为最近放入后台的作业的进程 ID，无论该作业是作为异步命令执行，还是使用 `bg` 内建命令执行（参见“作业控制内建命令”）。

- `0`  
    （`$0`）展开为 shell 或 shell 脚本的名称。这在 shell 初始化时设置。如果 Bash 通过命令文件调用（参见“Shell 脚本”），则 `$0` 设置为该文件的名称。如果 Bash 使用 `-c` 选项启动（参见“调用 Bash”），则 `$0` 设置为要执行的字符串之后的第一个参数（如果存在）。否则，它设置为用于调用 Bash 的文件名，即由参数零给出的名称。
