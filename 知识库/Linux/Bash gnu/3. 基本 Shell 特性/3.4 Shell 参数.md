# 3.4 Shell 参数

https://www.gnu.org/software/bash/manual/html_node/Shell-Parameters.html

*参数*是存储值的实体。它可以是 `name`、一个数字，或下面列出的特殊字符之一。*变量*是由 `name` 表示的参数。变量有一个 `value` 和零个或多个 `attributes`。属性使用 `declare` 内置命令赋值（参见 [Bash 内置命令] 中 `declare` 内置命令的描述）。`export` 和 `readonly` 内置命令赋予特定属性。

如果参数已被赋值，则称该参数已设置。空字符串是有效值。变量一旦设置，只能通过使用 `unset` 内置命令取消设置。

变量通过如下形式的语句赋值：

```bash
name=[value]
```

如果未给出 `value`，则将变量赋值为空字符串。所有 `value` 都会经历波浪号展开、参数和变量展开、命令替换、算术展开以及引号移除（参见 [Shell 参数展开]）。如果变量设置了 `integer` 属性，则即使未使用 `$((…))` 展开，`value` 也会作为算术表达式求值（参见 [算术展开]）。不执行单词拆分和文件名展开。赋值语句也可以作为 `alias`、`declare`、`typeset`、`export`、`readonly` 和 `local` 内置命令（*声明命令*）的参数出现。当处于 POSIX 模式时（参见 [Bash 与 POSIX]），这些内置命令可以出现在一个或多个 `command` 内置命令实例之后的命令中，并保留这些赋值语句属性。例如，

```bash
command export var=value
```

在赋值语句为 shell 变量或数组索引赋值的上下文中（参见 [数组]），`+=` 运算符会追加到或加到变量的先前值。这包括接受赋值语句的声明命令（如 `declare`）的参数。当对已设置 `integer` 属性的变量应用 `+=` 时，变量的当前值和 `value` 都会作为算术表达式求值，并将结果之和赋值为变量的值。当前值通常是整数常量，但也可以是表达式。当使用复合赋值对数组变量应用 `+=` 时（参见 [数组]），变量的值不会被取消设置（与使用 `=` 时一样），新值会追加到数组中，对于索引数组从大于数组最大索引的位置开始，对于关联数组则作为额外的键值对添加。当应用于字符串值变量时，`value` 会被展开并追加到变量的值后。

可以使用 `declare` 或 `local` 内置命令的 `-n` 选项为变量赋予 `nameref` 属性（参见 [Bash 内置命令]），以创建 *nameref*，即对另一个变量的引用。这允许间接操作变量。每当引用、赋值、取消设置 nameref 变量，或修改其属性时（使用或更改 nameref 属性本身除外），实际操作都会针对 nameref 变量的值所指定的变量执行。nameref 常用于 shell 函数中，以引用名称作为参数传递给函数的变量。例如，如果将变量名作为第一个参数传递给 shell 函数，则在函数内运行

```bash
declare -n ref=$1
```

会创建一个局部 nameref 变量 `ref`，其值是作为第一个参数传递的变量名。对 `ref` 的引用和赋值，以及对其属性的更改，都会被视为对名称作为 `$1` 传递的变量的引用、赋值和属性修改。

如果 `for` 循环的控制变量具有 nameref 属性，则单词列表可以是一个 shell 变量列表，并且在循环执行时，会依次为列表中的每个单词建立名称引用。数组变量不能赋予 nameref 属性。但是，nameref 变量可以引用数组变量和带下标的数组变量。可以使用 `unset` 内置命令的 `-n` 选项取消设置 nameref（参见 [Bourne Shell 内置命令]）。否则，如果以 nameref 变量的名称作为参数执行 `unset`，则会取消设置 nameref 变量所引用的变量。

## 3.4.1 位置参数

https://www.gnu.org/software/bash/manual/html_node/Positional-Parameters.html

`位置参数`是由一个或多个数字表示的参数，但不包括单个数字 `0`。位置参数在 shell 被调用时从 shell 的参数赋值，并且可以使用 `set` 内置命令重新赋值。位置参数 `N` 可以引用为 `${N}`，或者当 `N` 由单个数字组成时引用为 `$N`。位置参数不能通过赋值语句赋值。`set` 和 `shift` 内置命令用于设置和取消设置它们（参见 [Shell 内置命令]）。执行 shell 函数时，位置参数会被临时替换（参见 [Shell 函数]）。

当展开由多于一个数字组成的位置参数时，必须将其括在花括号中。如果没有花括号，`$` 后的数字只能指前九个位置参数之一（`$1`-`$9`）或特殊参数 `$0`（见下文）。

## 3.4.2 特殊参数

https://www.gnu.org/software/bash/manual/html_node/Special-Parameters.html

shell 会特殊对待若干参数。这些参数只能被引用；不允许对它们赋值。特殊参数由以下字符之一表示。

- **`*`**  
  （`$*`）展开为从 1 开始的位置参数。当展开不在双引号内时，每个位置参数展开为单独的单词。在执行单词展开的上下文中，这些单词还要进行进一步的单词拆分和文件名展开。当展开发生在双引号内时，它展开为单个单词，每个参数的值由 `IFS` 变量的第一个字符分隔。也就是说，`"$*"` 等价于 `"$1c$2c…"`，其中 `c` 是 `IFS` 变量值的第一个字符。如果 `IFS` 未设置，参数由空格分隔。如果 `IFS` 为空，参数连接在一起，中间没有分隔符。

- **`@`**  
  （`$@`）展开为从 1 开始的位置参数。在执行单词拆分的上下文中，这会将每个位置参数展开为单独的单词；如果不在双引号内，这些单词还要进行单词拆分。在不执行单词拆分的上下文中（例如赋值语句的值部分），它展开为单个单词，每个位置参数由空格分隔。当展开发生在双引号内，并且执行单词拆分时，每个参数展开为单独的单词。也就是说，`"$@"` 等价于 `"$1" "$2" …`。如果双引号展开发生在单词内部，第一个参数的展开与原单词开头部分的展开连接，最后一个参数的展开与原单词最后部分的展开连接。当没有位置参数时，`"$@"` 和 `$@` 展开为空（即被移除）。

- **`#`**  
  （`$#`）展开为十进制的位置参数个数。

- **`?`**  
  （`$?`）展开为最近执行命令的退出状态。

- **`-`**  
  （`$-`，连字符）展开为当前选项标志，这些标志在调用时指定、由 `set` 内置命令指定，或由 shell 自身设置（例如 `-i` 选项）。

- **`$`**  
  （`$$`）展开为 shell 的进程 ID。在子 shell 中，它展开为调用 shell 的进程 ID，而不是子 shell 的进程 ID。

- **`!`**  
  （`$!`）展开为最近放入后台的作业的进程 ID，无论是作为异步命令执行，还是使用 `bg` 内置命令执行（参见 [作业控制内置命令]）。

- **`0`**  
  （`$0`）展开为 shell 或 shell 脚本的名称。这在 shell 初始化时设置。如果 Bash 以命令文件方式调用（参见 [Shell 脚本]），则 `$0` 设置为该文件的名称。如果 Bash 以 `-c` 选项启动（参见 [调用 Bash]），则 `$0` 设置为要执行的字符串之后的第一个参数（如果存在）。否则，它设置为用于调用 Bash 的文件名，即参数零给出的名称。
