# 3.5.6 进程替换

https://www.gnu.org/software/bash/manual/html_node/Process-Substitution.html

进程替换允许使用文件名来引用进程的输入或输出。其形式为

```bash
<(list)
```

或

```bash
>(list)
```

进程 `list` 会异步运行，其输入或输出会表现为一个文件名。作为扩展的结果，此文件名会作为参数传递给当前命令。

如果使用 `>(list)` 形式，则写入该文件会为 `list` 提供输入。如果使用 `<(list)` 形式，则读取该文件会获得 `list` 的输出。注意，`<` 或 `>` 与左括号之间不能出现空格，否则该结构会被解释为重定向。

进程替换在支持命名管道（`FIFO`）或 `/dev/fd` 命名打开文件方法的系统上受支持。

在可用时，进程替换与参数和变量扩展、命令替换以及算术扩展同时执行。
