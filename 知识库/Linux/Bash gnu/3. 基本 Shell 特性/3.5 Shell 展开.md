# 3.5 Shell 扩展

https://www.gnu.org/software/bash/manual/html_node/Shell-Expansions.html

命令行在被拆分为 `token` 之后会执行展开。Bash 会执行以下展开：

- 花括号展开
- 波浪号展开
- 参数和变量展开
- 命令替换
- 算术展开
- 单词拆分
- 文件名展开
- 引号移除

展开顺序为：花括号展开；波浪号展开、参数和变量展开、算术展开以及命令替换（从左到右执行）；单词拆分；文件名展开；以及引号移除。

在支持该功能的系统上，还有一种额外的展开可用：*进程替换*。它与波浪号展开、参数展开、变量展开、算术展开以及命令替换同时执行。

*引号移除*总是最后执行。它移除原始单词中存在的引号字符，而不是由其他展开之一产生的引号字符，除非这些字符本身已被引用。更多细节参见[引号移除]。

只有花括号展开、单词拆分和文件名展开可以增加展开后的单词数量；其他展开将单个单词展开为单个单词。唯一的例外是 `"$@"` 和 `$*` 的展开（参见[特殊参数]），以及 `"${name[@]}"` 和 `${name[*]}` 的展开（参见[数组]）。
