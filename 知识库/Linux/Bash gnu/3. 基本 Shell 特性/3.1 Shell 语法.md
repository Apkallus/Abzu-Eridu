# 3.1 Shell 语法

https://www.gnu.org/software/bash/manual/html_node/Shell-Syntax.html

当 shell 读取输入时，它会经历一系列操作。如果输入表明注释的开始，shell 会忽略注释符号（`#`）以及该行其余内容。

否则，粗略地说，shell 会读取输入并将其划分为单词和操作符，运用引用规则来选择为各种单词和字符赋予何种含义。

然后，shell 将这些 token 解析为命令和其他结构，移除某些单词或字符的特殊含义，扩展其他内容，按需重定向输入和输出，执行指定命令，等待命令的退出状态，并使该退出状态可供进一步检查或处理。

## 3.1.2 引用

引用用于移除某些字符或单词对 shell 的特殊含义。引用可用于禁用特殊字符的特殊处理，防止保留字被识别为保留字，以及防止参数扩展。

每个 shell 元字符（参见[定义]）对 shell 都有特殊含义；若要表示其自身，就必须对其进行引用。

当使用命令历史扩展功能时（参见[历史扩展]），*历史扩展*字符（通常是 `!`）必须被引用，以防止历史扩展。有关历史扩展的更多细节，参见[Bash 历史设施]。

有四种引用机制：`转义字符`、单引号、双引号和美元单引号。

### 3.1.2.1 转义字符

未加引号的反斜杠 `\` 是 Bash 转义字符。它保留紧随其后的下一个字符的字面值，移除该字符具有的任何特殊含义，但 `newline` 除外。如果出现 `\newline` 对，且反斜杠本身未被引用，则 `\newline` 被视为行继续（即从输入流中移除并实际忽略）。

> 常见于编写复杂参数的命令，末尾使用 `\换行` 清晰区分参数

### 3.1.2.2 单引号

用单引号（`'`）包围字符会保留引号内每个字符的字面值。单引号不能出现在单引号之间，即使前面有反斜杠也是如此。

> 单引号将消除其中字符的特殊含义，包括转义符

### 3.1.2.3 双引号

用双引号（`"`）包围字符会保留引号内所有字符的字面值，但 `$`、`` ` ``、`\` 以及启用历史扩展时的 `!` 除外。当 shell 处于 `POSIX` 模式时（参见 [Bash 与 POSIX]），即使启用了历史扩展，`!` 在双引号内也没有特殊含义。字符 `$` 和 `` ` `` 在双引号内保留其特殊含义（参见 [Shell 扩展]）。反斜杠仅在其后跟以下字符之一时才保留特殊含义：`$`、`` ` ``、`"`、`\` 或 `newline`。在双引号内，后跟这些字符之一的反斜杠会被移除。位于没有特殊含义字符之前的反斜杠保持不变。

双引号可以通过在其前面加反斜杠来在双引号内被引用。如果启用，除非双引号内出现的 `!` 使用反斜杠转义，否则将执行历史扩展。`!` 前的反斜杠不会被移除。

特殊参数 `*` 和 `@` 在双引号内具有特殊含义（参见 [Shell 参数扩展]）。
