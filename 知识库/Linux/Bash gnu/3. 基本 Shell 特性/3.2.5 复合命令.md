# 3.2.5 Compound Commands —— 复合命令

https://www.gnu.org/software/bash/manual/html_node/Compound-Commands.html

复合命令是 `shell` 编程语言中的构造。每个构造以保留字或控制操作符开始，并以相应的保留字或操作符结束。与复合命令关联的任何重定向（参见 [重定向]）都会应用于该复合命令中的所有命令，除非显式覆盖。

在大多数情况下，复合命令描述中的命令列表可以用一个或多个换行符与命令的其余部分分隔，并且可以用换行符代替分号。

`Bash` 提供循环结构、条件命令，以及将命令分组并作为一个单元执行的机制。

## 3.2.5.1 循环结构

https://www.gnu.org/software/bash/manual/html_node/Looping-Constructs.html

Bash 支持以下循环结构。

注意，在命令语法的描述中，只要出现 `;`，都可以替换为一个或多个换行符。

### `until`

`until` 命令的语法为：

```bash
until test-commands; do consequent-commands; done
```

只要 `test-commands` 的退出状态非零，就执行 `consequent-commands`。返回状态是 `consequent-commands` 中执行的最后一条命令的退出状态；如果未执行任何命令，则为 0。

### `while`

`while` 命令的语法为：

```bash
while test-commands; do consequent-commands; done
```

只要 `test-commands` 的退出状态为零，就执行 `consequent-commands`。返回状态是 `consequent-commands` 中执行的最后一条命令的退出状态；如果未执行任何命令，则为 0。

示例：

```bash
# 循环输出 0x01 与 0xff 两个字节
while true; do
    echo -ne "\x01\xff";
done | hd
```

### `for`

`for` 命令的语法为：

```bash
for name [ [in words ...] ; ] do commands; done
```

展开 `words`（参见 [Shell 扩展]），然后对结果列表中的每个单词执行一次 `commands`，并将 `name` 绑定到当前单词。如果未出现 `in words`，则 `for` 命令会对每个已设置的位置参数执行一次 `commands`，就像指定了 `in "$@"` 一样（参见 [特殊参数]）。

返回状态是最后执行的命令的退出状态。如果 `words` 的展开结果中没有项目，则不执行任何命令，返回状态为零。

`for` 命令还有一种类似 C 语言的替代形式：

```bash
for (( expr1 ; expr2 ; expr3 )) [;] do commands ; done
```

首先，按照下面描述的规则求值算术表达式 `expr1`（参见 [Shell 算术]）。然后，重复求值算术表达式 `expr2`，直到其求值为零。每当 `expr2` 求值为非零值时，执行 `commands` 并求值算术表达式 `expr3`。如果省略任何表达式，则其行为如同求值为 1。返回值是 `commands` 中执行的最后一条命令的退出状态；如果任何表达式无效，则返回非零值。

使用 `break` 和 `continue` 内建命令（参见 [Bourne Shell 内建命令]）来控制循环执行。

示例

```sh
# 间隔 0.1s 每次打印一个 `.`，共 10次
for i in {1..10}
do
    echo -n "."
    sleep 0.1
done
```
