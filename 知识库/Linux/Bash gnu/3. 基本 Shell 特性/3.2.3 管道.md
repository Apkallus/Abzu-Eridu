# 3.2.3 管道

https://www.gnu.org/software/bash/manual/html_node/Pipelines.html

`pipeline`（管道）是由一个或多个命令组成的序列，命令之间由一个控制操作符 `|` 或 `|&` 分隔。

管道的格式为

```bash
[time [-p]] [!] command1 [ | or |& command2 ] ...
```

管道中每个命令的输出都通过管道连接到下一个命令的输入。也就是说，每个命令读取前一个命令的输出。此连接在 `command1` 指定的任何重定向之前执行。

如果管道操作符是 `|&`，则除了标准输出之外，`command1` 的标准错误也通过管道连接到 `command2` 的标准输入；它是 `2>&1 |` 的简写。这种将标准错误隐式重定向到标准输出的行为，在 `command1` 指定的任何重定向之后执行，与该简写形式一致。

如果保留字 `time` 位于管道之前，Bash 会在管道完成后打印管道的计时统计信息。统计信息目前包括经过的（挂钟）时间，以及命令执行消耗的用户时间和系统时间。`-p` 选项将输出格式更改为 `POSIX` 指定的格式。当 shell 处于 `POSIX` 模式时（参见 [Bash 与 POSIX]），如果下一个 token 以 `-` 开头，它不会将 `time` 识别为保留字。`TIMEFORMAT` 变量的值是一个格式字符串，指定计时信息的显示方式。可用格式的说明参见 [Bash 变量]。将 `time` 作为保留字提供，允许对 shell 内建命令、shell 函数和管道计时。外部 `time` 命令很难对这些内容计时。

当 shell 处于 `POSIX` 模式时（参见 [Bash 与 POSIX]），你可以单独将 `time` 用作简单命令。在这种情况下，shell 会显示 shell 及其子进程消耗的总用户时间和系统时间。`TIMEFORMAT` 变量指定时间信息的格式。

如果管道不是异步执行的（参见 [命令列表]），shell 会等待管道中的所有命令完成。

在多命令管道中（会创建管道），每个命令都在自己的 `subshell`（子 shell）中执行，子 shell 是一个单独的进程（参见 [命令执行环境]）。如果使用 `shopt` 内建命令启用了 `lastpipe` 选项（参见 [Shopt 内建命令]），并且作业控制未激活，则管道的最后一个元素可能由 shell 进程运行。

管道的退出状态是管道中最后一个命令的退出状态，除非启用了 `pipefail` 选项（参见 [Set 内建命令]）。如果启用了 `pipefail`，管道的返回状态是最后一个（最右侧）以非零状态退出的命令的值；如果所有命令都成功退出，则为零。如果保留字 `!` 位于管道之前，则退出状态是上述退出状态的逻辑否定。如果管道不是异步执行的（参见 [命令列表]），shell 会等待管道中的所有命令终止后才返回值。异步管道的返回状态为 0。
