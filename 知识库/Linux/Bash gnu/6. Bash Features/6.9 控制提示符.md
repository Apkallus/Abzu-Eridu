# 6.9 控制提示符

此外，下表描述了可出现在提示变量 `PS0`、`PS1`、`PS2` 和 `PS4` 中的特殊字符：

- `\a`
    
    响铃字符。

- `\d`
    
    日期，格式为 "Weekday Month Date"（例如 "Tue May 26"）。

- `\D{format}`
    
    `format` 会传递给 `strftime`(3)，结果会插入提示符字符串；空的 `format` 会生成与区域设置相关的时间表示。花括号是必需的。

- `\e`
    
    转义字符。

- `\h`
    
    主机名，截至第一个 `.`。

- `\H`
    
    完整主机名。

- `\j`
    
    当前由 shell 管理的作业数。

- `\l`
    
    shell 终端设备名的基名（例如 "ttys0"）。

- `\n`
    
    换行。

- `\r`
    
    回车。

- `\s`
    
    shell 的名称：`$0` 的基名（最后一个斜杠之后的部分）。

- `\t`
    
    时间，24 小时制 HH:MM:SS 格式。

- `\T`
    
    时间，12 小时制 HH:MM:SS 格式。

- `\@`
    
    时间，12 小时制 am/pm 格式。

- `\A`
    
    时间，24 小时制 HH:MM 格式。

- `\u`
    
    当前用户的用户名。

- `\v`
    
    Bash 版本（例如 2.00）。

- `\V`
    
    Bash 发行版，版本 + 补丁级别（例如 2.00.0）。

- `\w`
    
    `PWD` shell 变量的值（`$PWD`），其中 `$HOME` 用波浪号缩写（使用 `$PROMPT_DIRTRIM` 变量）。

- `\W`
    
    `$PWD` 的基名，其中 `$HOME` 用波浪号缩写。

- `\!`
    
    此命令的历史编号。

- `\#`
    
    此命令的命令编号。

- `\$`
    
    如果有效 uid 为 0，则为 `#`，否则为 `$`。

- `\nnn`
    
    ASCII 码为八进制值 `nnn` 的字符。

- `\\`
    
    反斜杠。

- `\[`
    
    开始非打印字符序列。这可用于将终端控制序列嵌入提示符。

- `\]`
    
    结束非打印字符序列。

命令编号和历史编号通常不同：命令的历史编号是它在历史列表中的位置，该列表可能包含从历史文件恢复的命令（参见 [Bash History Facilities]）；而命令编号是它在当前 shell 会话中执行的命令序列中的位置。

字符串解码后，会根据 `promptvars` shell 选项的值，通过参数展开、命令替换、算术展开和引号移除进行展开（参见 [The Shopt Builtin]）。如果字符串中被转义的部分出现在命令替换中，或者包含对单词展开有特殊含义的字符，这可能会产生不必要的副作用。
