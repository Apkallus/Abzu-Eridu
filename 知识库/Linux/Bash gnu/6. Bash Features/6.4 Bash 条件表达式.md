# 6.4 Bash 条件表达式

条件表达式由 `[[` 复合命令（参见 [Conditional Constructs]）以及 `test` 和 `[` 内建命令（参见 [Bourne Shell Builtins]）使用。`test` 和 `[` 命令根据参数数量决定其行为；其他命令特定操作见这些命令的描述。

表达式可以是一元或二元，由下面列出的初等表达式组成。一元表达式常用于检查文件或 shell 变量的状态。二元运算符用于字符串、数值和文件属性比较。

当表达式中使用若干文件名时，Bash 会特殊处理它们。如果运行 Bash 的操作系统提供这些特殊文件，Bash 使用它们；否则在内部模拟，行为如下：如果某个初等表达式的 `file` 参数形式为 `/dev/fd/N`，则 Bash 检查文件描述符 `N`。如果 `file` 参数是 `/dev/stdin`、`/dev/stdout` 或 `/dev/stderr` 之一，则 Bash 分别检查文件描述符 0、1 或 2。

与 `[[` 一起使用时，`<` 和 `>` 运算符使用当前区域设置按字典序排序。`test` 命令使用 `ASCII` 顺序。

除非另有说明，操作文件的初等表达式遵循符号链接，并操作链接目标，而不是链接本身。

- `-a file`  
    若 `file` 存在则为真。

- `-b file`  
    若 `file` 存在且为块特殊文件则为真。

- `-c file`  
    若 `file` 存在且为字符特殊文件则为真。

- `-d file`  
    若 `file` 存在且为目录则为真。

- `-e file`  
    若 `file` 存在则为真。

- `-f file`  
    若 `file` 存在且为常规文件则为真。

- `-g file`  
    若 `file` 存在且其 `set-group-id` 位已设置则为真。

- `-h file`  
    若 `file` 存在且为符号链接则为真。

- `-k file`  
    若 `file` 存在且其 `sticky` 位已设置则为真。

- `-p file`  
    若 `file` 存在且为命名管道（`FIFO`）则为真。

- `-r file`  
    若 `file` 存在且可读则为真。

- `-s file`  
    若 `file` 存在且大小大于零则为真。

- `-t fd`  
    若文件描述符 `fd` 已打开并指向终端则为真。

- `-u file`  
    若 `file` 存在且其 `set-user-id` 位已设置则为真。

- `-w file`  
    若 `file` 存在且可写则为真。

- `-x file`  
    若 `file` 存在且可执行则为真。

- `-G file`  
    若 `file` 存在且由有效组 ID 拥有则为真。

- `-L file`  
    若 `file` 存在且为符号链接则为真。

- `-N file`  
    若 `file` 存在且自上次访问后被修改则为真。

- `-O file`  
    若 `file` 存在且由有效用户 ID 拥有则为真。

- `-S file`  
    若 `file` 存在且为套接字则为真。

- `file1 -ef file2`  
    若 `file1` 和 `file2` 指向相同设备和 `inode` 编号则为真。

- `file1 -nt file2`  
    若 `file1` 比 `file2` 新（根据修改日期），或 `file1` 存在且 `file2` 不存在则为真。

- `file1 -ot file2`  
    若 `file1` 比 `file2` 旧，或 `file2` 存在且 `file1` 不存在则为真。

- `-o optname`  
    若 shell 选项 `optname` 已启用则为真。选项列表见 `set` 内建命令的 `-o` 选项说明（参见 [The Set Builtin]）。

- `-v varname`  
    若 shell 变量 `varname` 已设置（已赋值）则为真。如果 `varname` 是由 `@` 或 `*` 下标的索引数组变量名，则当数组有任何已设置元素时返回真。如果 `varname` 是由 `@` 或 `*` 下标的关联数组变量名，则当具有该键的元素已设置时返回真。

- `-R varname`  
    若 shell 变量 `varname` 已设置且为名称引用则为真。

- `-z string`  
    若 `string` 的长度为零则为真。

- 
    ```
    -n string
    string
    ```

    若 `string` 的长度非零则为真。

- 
    ```
    string1 == string2
    string1 = string2
    ```

    若字符串相等则为真。与 `[[` 命令一起使用时，这会执行上文所述的模式匹配（参见 [Conditional Constructs]）。

    `=` 应与 `test` 命令一起使用以符合 `POSIX` 规范。

- `string1 != string2`  
    若字符串不相等则为真。

- `string1 < string2`  
    若 `string1` 按字典序排在 `string2` 之前则为真。

- `string1 > string2`  
    若 `string1` 按字典序排在 `string2` 之后则为真。

- `arg1 OP arg2`  
    `OP` 是 `-eq`、`-ne`、`-lt`、`-le`、`-gt` 或 `-ge` 之一。这些算术二元运算符分别当 `arg1` 等于、不等于、小于、小于或等于、大于、大于或等于 `arg2` 时返回真。`Arg1` 和 `arg2` 可以是正整数或负整数。与 `[[` 命令一起使用时，`arg1` 和 `arg2` 会按算术表达式求值（参见 [Shell Arithmetic]）。由于 `[[` 命令对 `arg1` 和 `arg2` 执行的展开可能产生空字符串，算术表达式求值会将它们视为求值为 0 的表达式。
