### 6.1 调用 Bash

```sh
bash [long-opt] [-ir] [-abefhkmnptuvxdBCDHP] [-o option]
    [-O shopt_option] [argument ...]
bash [long-opt] [-abefhkmnptuvxdBCDHP] [-o option]
    [-O shopt_option] -c string [argument ...]
bash [long-opt] -s [-abefhkmnptuvxdBCDHP] [-o option]
    [-O shopt_option] [argument ...]
```

与 `set` 内建命令一起使用的所有单字符选项（参见“Set 内建命令”）都可以在调用 shell 时作为选项使用。此外，还有若干多字符选项可供使用。这些选项必须出现在命令行中的单字符选项之前才能被识别。

- `--debugger`  
    安排在执行 shell 启动前运行调试器配置（profile）。打开扩展调试模式（参见“Shopt 内建命令”中关于 `shopt` 内建命令的 `extdebug` 选项的说明）。

- `--dump-po-strings`  
    以 GNU `gettext` PO（portable object，可移植对象）文件格式在标准输出上打印所有以 `$` 开头的双引号字符串的列表。除输出格式外，等价于 `-D`。

- `--dump-strings`  
    等价于 `-D`。

- `--help`  
    在标准输出上显示用法消息并成功退出。

- 
    ```
    --init-file filename
    --rcfile filename
    ```

    在交互式 shell 中从 `filename` 执行命令（而不是从 `~/.bashrc`）。

- `--login`  
    等价于 `-l`。

- `--noediting`  
    当 shell 为交互式时，不要使用 `GNU Readline` 库（参见“命令行编辑”）读取命令行。

- `--noprofile`  
    当 Bash 作为登录 shell 调用时，不要加载系统级启动文件 `/etc/profile`，也不要加载任何个人初始化文件 `~/.bash_profile`、`~/.bash_login` 或 `~/.profile`。

- `--norc`  
    在交互式 shell 中不要读取 `~/.bashrc` 初始化文件。如果 shell 以 `sh` 调用，则默认开启此行为。

- `--posix`  
    启用 `POSIX` 模式；在默认操作与 `POSIX` 标准不同的地方改变 Bash 的行为，使其与标准匹配。其目的是让 Bash 表现为该标准的严格超集。关于 Bash `POSIX` 模式的说明，参见“Bash 与 POSIX”。

- `--restricted`  
    等价于 `-r`。使 shell 成为受限 shell（参见“受限 Shell”）。

- `--verbose`  
    等价于 `-v`。在读取 shell 输入行时打印它们。

- `--version`  
    在标准输出上显示此 Bash 实例的版本信息并成功退出。

还有一些单字符选项可以在调用时提供，但 `set` 内建命令不支持这些选项。

- `-c`  
    从第一个非选项参数 `command_string` 读取并执行命令，然后退出。如果 `command_string` 之后还有参数，则第一个参数赋值给 `$0`，其余参数赋值给位置参数。对 `$0` 的赋值设置 shell 的名称，该名称用于警告和错误消息。

- `-i`  
    强制 shell 以交互方式运行。交互式 shell 在“交互式 Shell”中描述。

- `-l`  
    使此 shell 表现得如同由登录过程直接调用。当 shell 为交互式时，这等价于使用 `exec -l bash` 启动登录 shell。当 shell 非交互式时，它将读取并执行登录 shell 启动文件。`exec bash -l` 或 `exec bash --login` 将用 Bash 登录 shell 替换当前 shell。关于登录 shell 的特殊行为说明，参见“Bash 启动文件”。

- `-r`  
    使 shell 成为受限 shell（参见“受限 Shell”）。

- `-s`  
    如果存在此选项，或者在选项处理之后没有剩余参数，则 Bash 从标准输入读取命令。此选项允许在调用交互式 shell 时或通过管道读取输入时设置位置参数。

- `-D`  
    在标准输出上打印所有以 `$` 开头的双引号字符串的列表。当当前区域设置不是 `C` 或 `POSIX` 时，这些字符串会接受语言翻译（参见“区域设置特定翻译”）。此选项隐含 `-n` 选项；不会执行任何命令。

- `[-+]O [shopt_option]`  
    `shopt_option` 是 `shopt` 内建命令接受的 shell 选项之一（参见“Shopt 内建命令”）。如果提供了 `shopt_option`，`-O` 设置该选项的值；`+O` 取消设置它。如果未提供 `shopt_option`，Bash 在标准输出上打印 `shopt` 接受的 shell 选项的名称和值。如果调用选项是 `+O`，则输出以可重新用作输入的格式显示。

- `--`  
    `--` 表示选项结束，并禁用后续选项处理。`--` 之后的任何参数都被视为 shell 脚本文件名（参见“Shell 脚本”）以及传递给该脚本的参数。

- `-`  
    等价于 `--`。

**登录 shell** 是参数零的第一个字符为 `-` 的 shell，或者使用 `--login` 选项调用的 shell。

**交互式 shell** 是在未指定 `-s` 的情况下不带非选项参数启动的 shell，未指定 `-c` 选项，并且其标准输入和标准错误都连接到终端（由 `isatty(3)` 判定），或者使用 `-i` 选项启动的 shell。更多信息参见“交互式 Shell”。

如果在选项处理之后仍有参数，并且既未提供 `-c` 也未提供 `-s` 选项，则第一个参数被视为包含 shell 命令的文件名（参见“Shell 脚本”）。当以这种方式调用 Bash 时，`$0` 设置为该文件的名称，位置参数设置为其余参数。Bash 从此文件读取并执行命令，然后退出。Bash 的退出状态是脚本中执行的最后一条命令的退出状态。如果未执行任何命令，则退出状态为 0。Bash 首先尝试在当前目录中打开该文件；如果未找到文件，则在 `PATH` 的目录中搜索该脚本。
