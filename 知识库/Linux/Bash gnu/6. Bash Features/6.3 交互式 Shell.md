### 6.3 交互式 Shell

- “什么是交互式 Shell？”
- “此 Shell 是交互式的吗？”
- “交互式 Shell 的行为”

#### 6.3.1 什么是交互式 Shell？

交互式 shell 是指不带非选项参数启动（除非指定了 `-s`）且未指定 `-c` 选项、其输入和错误输出都连接到终端（由 `isatty(3)` 判定）的 shell，或者使用 `-i` 选项启动的 shell。

交互式 shell 通常从用户终端读取并向用户终端写入。

当交互式 shell 启动时，可使用 `-s` 调用选项设置位置参数。

#### 6.3.2 此 Shell 是交互式的吗？

要在启动脚本中判断 Bash 是否以交互方式运行，请测试特殊参数 `-` 的值。当 shell 为交互式时，它包含 `i`。例如：

```sh
case "$-" in
*i*)	echo This shell is interactive ;;
*)	echo This shell is not interactive ;;
esac
```

或者，启动脚本可以检查变量 `PS1`；它在非交互式 shell 中未设置，在交互式 shell 中已设置。因此：

```sh
if [ -z "$PS1" ]; then
        echo This shell is not interactive
else
        echo This shell is interactive
fi
```

#### 6.3.3 交互式 Shell 的行为

当 shell 以交互方式运行时，它会在多个方面改变其行为。

1. Bash 会按照“Bash 启动文件”中所述读取并执行启动文件。

2. 默认启用作业控制（参见“作业控制”）。启动作业控制后，Bash 会忽略键盘生成的作业控制信号 `SIGTTIN`、`SIGTTOU` 和 `SIGTSTP`。

3. 在打印主提示符 `$PS1` 之前，Bash 会将 `PROMPT_COMMAND` 数组变量中已设置元素的值作为命令执行（参见“Bash 变量”）。

4. Bash 在读取命令第一行之前展开并显示 `PS1`，在读取多行命令的第二行及后续行之前展开并显示 `PS2`。Bash 在读取命令之后、执行命令之前展开并显示 `PS0`。提示符字符串转义序列的完整列表参见“控制提示符”。

5. Bash 使用 Readline（参见“命令行编辑”）从用户终端读取命令。

6. 当读取命令时在标准输入上收到 `EOF`，Bash 会检查 `set -o` 的 `ignoreeof` 选项的值，而不是立即退出（参见“Set 内建命令”）。

7. 默认启用命令历史（参见“Bash 历史设施”）和历史扩展（参见“历史扩展”）。启用历史记录的 shell 退出时，Bash 会将命令历史保存到由 `$HISTFILE` 命名的文件中。

8. 默认执行别名扩展（参见“别名”）。

9. 在没有任何 trap 的情况下，Bash 忽略 `SIGTERM`（参见“信号”）。

10. 在没有任何 trap 的情况下，`SIGINT` 会被捕获并处理（参见“信号”）。`SIGINT` 会中断某些 shell 内建命令。

11. 如果启用了 `huponexit` shell 选项，交互式登录 shell 会在退出时向所有作业发送 `SIGHUP`（参见“信号”）。

12. 无论在调用时还是使用 `set -n` 时，`-n` 选项都没有效果（参见“Set 内建命令”）。

13. Bash 会根据 `MAIL`、`MAILPATH` 和 `MAILCHECK` shell 变量的值定期检查邮件（参见“Bash 变量”）。

14. 启用 `set -u` 后，由于引用未绑定的 shell 变量而导致的展开错误不会使 shell 退出（参见“Set 内建命令”）。

15. 在 `${var:?word}` 展开中，由于 `var` 未设置或为空而导致的展开错误不会使 shell 退出（参见“Shell 参数展开”）。

16. shell 内建命令遇到的重定向错误不会导致 shell 退出。

17. 在 POSIX 模式下运行时，特殊内建命令返回错误状态不会导致 shell 退出（参见“Bash 与 POSIX”）。

18. 失败的 `exec` 不会导致 shell 退出（参见“Bourne Shell 内建命令”）。

19. 解析器语法错误不会导致 shell 退出。

20. 如果启用了 `cdspell` shell 选项，shell 会尝试对 `cd` 内建命令的目录参数进行简单的拼写纠正（参见“Shopt 内建命令”中关于 `shopt` 内建命令的 `cdspell` 选项的说明）。`cdspell` 选项仅在交互式 shell 中有效。

21. shell 会检查 `TMOUT` 变量的值，如果在打印 `$PS1` 后指定的秒数内未读取到命令，则退出（参见“Bash 变量”）。
