# 4.2 Bash 内建命令

https://www.gnu.org/software/bash/manual/html_node/Bash-Builtins.html

本节描述 Bash 中独有的或已扩展的内建命令。其中一些命令在 POSIX 标准中规定。

## alias —— 打印或设置命令别名

```bash
alias [-p] [name[=value] ...]
```

不带参数或带 `-p` 选项时，`alias` 在标准输出上打印别名列表，其形式允许它们作为输入重用。如果提供了参数，则为每个给定 `value` 的 `name` 定义别名。如果未给出 `value`，则打印别名 `name` 的名称和值。`value` 中的尾随空格会导致在命令解析期间展开别名时检查下一个单词是否进行别名替换。除非给出了一个 `name`（没有对应的 `=value`）且未定义该别名，否则 `alias` 返回 true。别名在 [别名] 中描述。

```sh
# 设置 ls 开启终端输出高亮
alias ls='ls --color=auto'
```

## `bind`

```bash
bind [-m keymap] [-lsvSVX]
bind [-m keymap] [-q function] [-u function] [-r keyseq]
bind [-m keymap] -f filename
bind [-m keymap] -x keyseq[: ]shell-command
bind [-m keymap] keyseq:function-name
bind [-m keymap] keyseq:readline-command
bind [-m keymap] -p|-P [readline-command]
bind readline-command-line
```

显示当前 Readline（参见 [命令行编辑]）键和函数绑定，将键序列绑定到 Readline 函数或宏或 shell 命令，或设置 Readline 变量。每个非选项参数是一个键绑定或命令，如同它出现在 Readline 初始化文件中一样（参见 [Readline 初始化文件]），但每个绑定或命令必须作为单独的参数传递；例如 `"\C-x\C-r":re-read-init-file`。

在以下描述中，以可重新读取的形式显示输出的选项会将输出格式化为 Readline 初始化文件中出现的命令，或作为单独参数提供给 `bind` 命令的命令。

选项（如果提供）具有以下含义：

- `-m keymap`
  使用 `keymap` 作为后续绑定所影响的键映射。可接受的 `keymap` 名称有 `emacs`、`emacs-standard`、`emacs-meta`、`emacs-ctlx`、`vi`、`vi-move`、`vi-command` 和 `vi-insert`。`vi` 等价于 `vi-command`（`vi-move` 也是同义词）；`emacs` 等价于 `emacs-standard`。
- `-l`
  列出所有 Readline 函数的名称。
- `-p`
  以可用作后续 `bind` 命令参数或 Readline 初始化文件参数的方式显示 Readline 函数名称和绑定。如果选项处理后还有参数，`bind` 将它们视为 readline 命令名称，并将输出限制为这些名称。
- `-P`
  列出当前 Readline 函数名称和绑定。如果选项处理后还有参数，`bind` 将它们视为 readline 命令名称，并将输出限制为这些名称。
- `-s`
  以可用作后续 `bind` 命令参数或 Readline 初始化文件参数的方式显示绑定到宏的 Readline 键序列及其输出的字符串。
- `-S`
  显示绑定到宏的 Readline 键序列及其输出的字符串。
- `-v`
  以可用作后续 `bind` 命令参数或 Readline 初始化文件参数的方式显示 Readline 变量名称和值。
- `-V`
  列出当前 Readline 变量名称和值。
- `-f filename`
  从 `filename` 读取键绑定。
- `-q function`
  显示调用命名 Readline `function` 的键序列。
- `-u function`
  解除绑定到命名 Readline `function` 的所有键序列。
- `-r keyseq`
  移除 `keyseq` 的任何当前绑定。
- `-x keyseq:shell-command`
  每当输入 `keyseq` 时，导致执行 `shell-command`。`keyseq` 和 `shell-command` 之间的分隔符是空白或冒号后可选跟空白。如果分隔符是空白，`shell-command` 必须用双引号括起来，并且 Readline 在保存之前在 `shell-command` 中展开任何特殊反斜杠转义。如果分隔符是冒号，任何括起的双引号都是可选的，并且 Readline 在保存之前不展开命令字符串。由于整个键绑定表达式必须是单个参数，它应该用单引号括起来。当执行 `shell-command` 时，shell 将 `READLINE_LINE` 变量设置为 Readline 行缓冲区的内容，并将 `READLINE_POINT` 和 `READLINE_MARK` 变量分别设置为插入点的当前位置和保存的插入点（标记）。shell 将用户提供的任何数字参数赋值给 `READLINE_ARGUMENT` 变量。如果没有参数，则不设置该变量。如果执行的命令更改了 `READLINE_LINE`、`READLINE_POINT` 或 `READLINE_MARK` 中的任何一个值，这些新值将反映在编辑状态中。
- `-X`
  列出绑定到 shell 命令的所有键序列及相关命令，格式可重用为后续 `bind` 命令的参数。

除非提供了无效选项或发生错误，否则返回状态为零。

## `builtin`

```bash
builtin [shell-builtin [args]]
```

执行指定的 shell 内建命令 `shell-builtin`，传递 `args`，并返回其退出状态。当定义与 shell 内建命令同名的 shell 函数时，这很有用，可以在函数内保留内建命令的功能。如果 `shell-builtin` 不是 shell 内建命令，则返回状态非零。

## `caller`

```bash
caller [expr]
```

返回任何活动子例程调用（shell 函数或使用 `.` 或 `source` 内建命令执行的脚本）的上下文。

不带 `expr` 时，`caller` 显示当前子例程调用的行号和源文件名。如果提供非负整数作为 `expr`，`caller` 显示当前执行调用栈中该位置对应的行号、子例程名称和源文件。例如，此额外信息可用于打印堆栈跟踪。当前帧是帧 0。

除非 shell 未在执行子例程调用或 `expr` 不对应于调用栈中的有效位置，否则返回值为 0。

## command —— 执行或显示命令

```bash
command [-pVv] command [arguments ...]
```

`command` 内建命令运行 `command` 及 `arguments`，忽略任何名为 `command` 的 shell 函数。仅执行 shell 内建命令或通过搜索 `PATH` 找到的命令。如果有一个名为 `ls` 的 shell 函数，在函数内运行 `command ls` 将执行外部命令 `ls`，而不是递归调用该函数。`-p` 选项表示使用 `PATH` 的默认值，保证找到所有标准实用程序。在这种情况下，如果找不到 `command` 或发生错误，返回状态为 127；否则为 `command` 的退出状态。

如果提供了 `-V` 或 `-v` 选项，`command` 打印 `command` 的描述。`-v` 选项显示一个单词，指示用于调用 `command` 的命令或文件名；`-V` 选项产生更详细的描述。在这种情况下，如果找到 `command`，返回状态为零；如果未找到，则非零。

示例
```sh
command id
# uid=1000(hacker) gid=1000(hacker) groups=1000(hacker)

command -v id
# /run/dojo/bin/id

command -V id
# id is /run/dojo/bin/id
```
- `-v` 可用来寻找命令路径

## `declare`

```bash
declare [-aAfFgiIlnrtux] [-p] [name[=value] ...]
```

声明变量并赋予它们属性。如果未给出 `name`，则显示变量或 shell 函数的值。

`-p` 选项将显示每个 `name` 的属性和值。当 `-p` 与 `name` 参数一起使用时，除 `-f` 和 `-F` 之外的附加选项将被忽略。

当 `-p` 不带 `name` 参数提供时，`declare` 将显示具有附加选项指定属性的所有变量的属性和值。如果 `-p` 未提供其他选项，`declare` 将显示所有 shell 变量的属性和值。`-f` 选项将显示限制为 shell 函数。

`-F` 选项禁止显示函数定义；只打印函数名称和属性。如果使用 `shopt` 启用了 `extdebug` shell 选项（参见 [Shopt 内建命令]），则还会显示定义每个 `name` 的源文件名和行号。`-F` 隐含 `-f`。

`-g` 选项强制在全局作用域创建或修改变量，即使在 shell 函数中执行 `declare`。当 `declare` 不在 shell 函数中执行时，它被忽略。

`-I` 选项使局部变量继承周围作用域中任何同名现有变量的属性（`nameref` 属性除外）和值。如果不存在现有变量，则局部变量最初未设置。

以下选项可用于将输出限制为具有指定属性的变量，或为变量赋予属性：

- `-a`
  每个 `name` 是索引数组变量（参见 [数组]）。
- `-A`
  每个 `name` 是关联数组变量（参见 [数组]）。
- `-f`
  每个 `name` 指代一个 shell 函数。
- `-i`
  变量将被视为整数；当变量被赋值时执行算术求值（参见 [Shell 算术]）。
- `-l`
  当变量被赋值时，所有大写字符转换为小写。大写属性被禁用。
- `-n`
  给每个 `name` 赋予 `nameref` 属性，使其成为对另一个变量的名称引用。该另一个变量由 `name` 的值定义。对 `name` 的所有引用、赋值和属性修改（除了使用或更改 `-n` 属性本身）都在 `name` 的值所引用的变量上执行。nameref 属性不能应用于数组变量。
- `-r`
  使 `name` 只读。这些名称随后不能通过赋值语句或 unset 赋值。
- `-t`
  给每个 `name` 赋予 `trace` 属性。被跟踪的函数从调用 shell 继承 `DEBUG` 和 `RETURN` 陷阱。trace 属性对变量没有特殊含义。
- `-u`
  当变量被赋值时，所有小写字符转换为大写。小写属性被禁用。
- `-x`
  标记每个 `name` 以通过环境导出到后续命令。

使用 `+` 代替 `-` 会关闭指定的属性，但 `+a` 和 `+A` 不能用于销毁数组变量，`+r` 不会移除只读属性。

在函数中使用时，`declare` 使每个 `name` 成为局部变量，如同 `local` 命令，除非提供了 `-g` 选项。如果变量名后跟 `=value`，则变量的值设置为 `value`。

当使用 `-a` 或 `-A` 以及复合赋值语法创建数组变量时，附加属性在后续赋值之前不会生效。

除非遇到无效选项、尝试使用 `-f foo=bar` 定义函数、尝试给只读变量赋值、尝试不使用复合赋值语法给数组变量赋值（参见 [数组]）、其中一个 `name` 不是有效的 shell 变量名、尝试关闭只读变量的只读状态、尝试关闭数组变量的数组状态，或尝试使用 `-f` 显示不存在的函数，否则返回状态为零。

## echo —— 打印参数

```bash
echo [-neE] [arg ...]
```

输出 `arg`，以空格分隔，以换行符结尾。除非发生写入错误，否则返回状态为 0。如果指定了 `-n`，则不打印尾随换行符。

如果给出 `-e` 选项，`echo` 解释以下反斜杠转义字符。`-E` 选项禁用这些转义字符的解释，即使在默认解释它们的系统上也是如此。`xpg_echo` shell 选项决定 `echo` 是否解释任何选项并展开这些转义字符。`echo` 不将 `--` 解释为选项结束。

`echo` 解释以下转义序列：

- `\a`
  警报（响铃）
- `\b`
  退格
- `\c`
  抑制进一步输出
- `\e`
- `\E`
  转义
- `\f`
  换页
- `\n`
  换行
- `\r`
  回车
- `\t`
  水平制表符
- `\v`
  垂直制表符
- `\\`
  反斜杠
- `\0nnn`
  值为八进制值 `nnn` 的八位字符（零到三个八进制数字）。
- `\xHH`
  值为十六进制值 `HH` 的八位字符（一个或两个十六进制数字）。
- `\uHHHH`
  值为十六进制值 `HHHH` 的 Unicode（ISO/IEC 10646）字符（一到四个十六进制数字）。
- `\UHHHHHHHH`
  值为十六进制值 `HHHHHHHH` 的 Unicode（ISO/IEC 10646）字符（一到八个十六进制数字）。

`echo` 原样写入任何未识别的反斜杠转义字符。

## `enable`

```bash
enable [-a] [-dnps] [-f filename] [name ...]
```

启用和禁用内建 shell 命令。禁用内建命令允许与 shell 内建命令同名的可执行文件在不指定完整路径名的情况下执行，即使 shell 通常在内建命令之前搜索文件。

如果提供 `-n`，则禁用 `name`。否则启用 `name`。例如，要使用通过 `$PATH` 找到的 `test` 二进制文件而不是 shell 内建版本，请输入 `enable -n test`。

如果提供 `-p` 选项，或未提供 `name` 参数，则打印 shell 内建命令列表。没有其他参数时，列表包含所有启用的 shell 内建命令。`-n` 选项表示仅打印禁用的内建命令。`-a` 选项表示列出每个内建命令并指示其是否启用。`-s` 选项表示将 `enable` 限制为 POSIX 特殊内建命令。

`-f` 选项表示在支持动态加载的系统上从共享对象 `filename` 加载新的内建命令 `name`。如果 `filename` 不包含斜杠，Bash 将使用 `BASH_LOADABLES_PATH` 变量的值作为冒号分隔的目录列表来搜索 `filename`。`BASH_LOADABLES_PATH` 的默认值取决于系统，可能包含 `.` 以强制搜索当前目录。`-d` 选项将删除使用 `-f` 加载的内建命令。如果 `-s` 与 `-f` 一起使用，新的内建命令成为 POSIX 特殊内建命令（参见 [特殊内建命令]）。

如果未提供选项且 `name` 不是 shell 内建命令，`enable` 将尝试从名为 `name` 的共享对象加载 `name`，如同命令是 `enable -f name name`。

除非 `name` 不是 shell 内建命令或从共享对象加载新内建命令时出错，否则返回状态为零。

## `help`

```bash
help [-dms] [pattern]
```

显示有关内建命令的有用信息。如果指定了 `pattern`，`help` 给出与 `pattern` 匹配的所有命令的详细帮助，如下所述；否则显示所有内建命令和 shell 复合命令的列表。

选项（如果提供）具有以下含义：

- `-d`
  显示每个 `pattern` 的简短描述
- `-m`
  以类似手册页的格式显示每个 `pattern` 的描述
- `-s`
  仅显示每个 `pattern` 的简短用法概要

如果 `pattern` 包含模式匹配字符（参见 [模式匹配]），它被视为 shell 模式，`help` 打印与 `pattern` 匹配的每个帮助主题的描述。

如果不是，并且 `pattern` 与帮助主题的名称完全匹配，`help` 打印与该主题关联的描述。否则，`help` 执行前缀匹配并打印所有匹配帮助主题的描述。

除非没有命令匹配 `pattern`，否则返回状态为零。

## `let`

```bash
let expression [expression ...]
```

`let` 内建命令允许对 shell 变量执行算术运算。每个 `expression` 根据下面 [Shell 算术] 中给出的规则作为算术表达式求值。如果最后一个 `expression` 求值为 0，`let` 返回 1；否则 `let` 返回 0。

## `local`

```bash
local [option] name[=value] ...
```

对于每个参数，创建名为 `name` 的局部变量，并为其赋值 `value`。`option` 可以是 `declare` 接受的任何选项。`local` 只能在函数内使用；它使变量 `name` 具有限于该函数及其子级的可见作用域。在函数外使用 `local` 是错误的。

如果 `name` 是 `-`，它使 shell 选项集局部于调用 `local` 的函数：在调用 `local` 后，函数内使用 `set` 内建命令更改的任何 shell 选项在函数返回时恢复为其原始值。恢复的执行方式如同执行了一系列 `set` 命令来恢复函数之前的值。

不带操作数时，`local` 将局部变量列表写入标准输出。

除非在函数外使用 `local`、提供了无效的 `name`，或 `name` 是只读变量，否则返回状态为零。

## `logout`

```bash
logout [n]
```

退出登录 shell，向 shell 的父进程返回状态 `n`。

## `mapfile`

```bash
mapfile [-d delim] [-n count] [-O origin] [-s count]
    [-t] [-u fd] [-C callback] [-c quantum] [array]
```

从标准输入读取行，或者如果提供 `-u` 选项则从文件描述符 `fd` 读取，到索引数组变量 `array` 中。变量 `MAPFILE` 是默认的 `array`。选项（如果提供）具有以下含义：

- `-d`
  使用 `delim` 的第一个字符终止每个输入行，而不是换行符。如果 `delim` 是空字符串，`mapfile` 在读取 NUL 字符时终止一行。
- `-n`
  最多复制 `count` 行。如果 `count` 为 0，则复制所有行。
- `-O`
  从索引 `origin` 开始赋值给 `array`。默认索引为 0。
- `-s`
  丢弃读取的前 `count` 行。
- `-t`
  从读取的每一行中删除尾随的 `delim`（默认为换行符）。
- `-u`
  从文件描述符 `fd` 而不是标准输入读取行。
- `-C`
  每读取 `quantum` 行时求值 `callback`。`-c` 选项指定 `quantum`。
- `-c`
  指定每次调用 `callback` 之间读取的行数。

如果指定了 `-C` 而没有 `-c`，默认 quantum 为 5000。当求值 `callback` 时，它被提供下一个要赋值的数组元素的索引以及要赋值给该元素的行作为附加参数。`callback` 在读取行之后但在赋值数组元素之前求值。

如果未提供显式 origin，`mapfile` 将在赋值之前清除 `array`。

除非提供了无效选项或选项参数、`array` 无效或不可赋值，或 `array` 不是索引数组，否则 `mapfile` 返回零。

## `printf`

```bash
printf [-v var] format [arguments]
```

在 `format` 的控制下将格式化的 `arguments` 写入标准输出。`-v` 选项将输出赋值给变量 `var`，而不是打印到标准输出。

`format` 是一个字符串，包含三种类型的对象：普通字符，直接复制到标准输出；字符转义序列，转换并复制到标准输出；格式规范，每个都会导致打印下一个连续的 `argument`。除了标准 `printf(3)` 格式字符 `cCsSndiouxXeEfFgGaA` 之外，`printf` 还解释以下附加格式说明符：

- `%b`
  使 `printf` 以与 `echo -e` 相同的方式展开相应 `argument` 中的反斜杠转义序列（参见 [Bash 内建命令]）。
- `%q`
  使 `printf` 以可重用为 shell 输入的格式输出相应的 `argument`。如果参数字符串中的任何字符需要，`%q` 和 `%Q` 使用 ANSI-C 引用风格（参见 [ANSI-C 引用]），否则使用反斜杠引用。如果格式字符串使用 `printf` 替代形式，这两种格式使用单引号引用参数字符串。
- `%Q`
  类似于 `%q`，但在引用之前对 `argument` 应用任何提供的精度。
- `%(datefmt)T`
  使 `printf` 输出使用 `datefmt` 作为 `strftime(3)` 格式字符串得到的日期时间字符串。相应的 `argument` 是表示自纪元以来的秒数的整数。此格式说明符识别两个特殊参数值：-1 表示当前时间，-2 表示 shell 被调用的时间。如果未指定参数，转换行为如同提供了 -1。这是对通常 `printf` 行为的例外。

%b、%q 和 %T 格式说明符都使用格式规范中的字段宽度和精度参数，并从展开的参数中写入那么多字节（或使用那么宽的字段），展开的参数通常包含比原始字符更多的字符。

%n 格式说明符接受一个相应参数，该参数被视为 shell 变量名。

%s 和 %c 格式说明符接受 l（长）修饰符，强制它们将参数字符串转换为宽字符串，并按字符而不是字节应用任何提供的字段宽度和精度。%S 和 %C 格式说明符分别等价于 %ls 和 %lc。

非字符串格式说明符的参数被视为 C 语言常量，但允许前导加号或减号，并且如果前导字符是单引号或双引号，则值是按当前区域设置的下一个字符的数值。

`format` 根据需要重复使用以消耗所有 `arguments`。如果 `format` 需要的 `arguments` 多于提供的数量，多余的格式规范的行为如同提供了零值或空字符串（视情况而定）。成功时返回值为零，如果提供了无效选项或发生写入或赋值错误，则返回非零。

## read —— 读取 stdin 或 fd，并赋值到变量

```bash
read [-Eers] [-a aname] [-d delim] [-i text] [-n nchars]
    [-N nchars] [-p prompt] [-t timeout] [-u fd] [name ...]
```

从标准输入读取一行，或者从作为 `-u` 选项参数提供的文件描述符 `fd` 读取，按照上面 [单词拆分] 中所述将其拆分为单词，并将第一个单词赋值给第一个 `name`，第二个单词赋值给第二个 `name`，依此类推。如果单词多于名称，剩余的单词及其之间的分隔符赋值给最后一个 `name`。如果从输入流读取的单词少于名称，剩余的名称赋空值。`IFS` 变量值中的字符用于按照 shell 用于扩展的相同规则（上面 [单词拆分] 中所述）将行拆分为单词。反斜杠字符 `\` 移除下一个读取字符的任何特殊含义，并用于行延续。

选项（如果提供）具有以下含义：

- `-a aname`
  单词被赋值给数组变量 `aname` 的连续索引，从 0 开始。在赋值之前，所有元素都从 `aname` 中移除。其他 `name` 参数被忽略。
- `-d delim`
  `delim` 的第一个字符终止输入行，而不是换行符。如果 `delim` 是空字符串，`read` 在读取 NUL 字符时终止一行。
- `-e`
  如果标准输入来自终端，`read` 使用 Readline（参见 [命令行编辑]）获取行。Readline 使用当前（或默认，如果之前未激活行编辑）编辑设置，但使用 Readline 的默认文件名补全。
- `-E`
  如果标准输入来自终端，`read` 使用 Readline（参见 [命令行编辑]）获取行。Readline 使用当前（或默认，如果之前未激活行编辑）编辑设置，但使用 Bash 的默认补全，包括可编程补全。
- `-i text`
  如果使用 Readline 读取行，`read` 在编辑开始之前将 `text` 放入编辑缓冲区。
- `-n nchars`
  `read` 在读取 `nchars` 个字符后返回，而不是等待完整的输入行，除非遇到 EOF 或 `read` 超时，但如果它在分隔符之前读取的字符少于 `nchars`，则遵守分隔符。
- `-N nchars`
  `read` 在恰好读取 `nchars` 个字符后返回，而不是等待完整的输入行，除非遇到 EOF 或 `read` 超时。输入中的分隔符字符不被特殊处理，也不会导致 `read` 返回，直到它读取了 `nchars` 个字符。结果不会在 `IFS` 中的字符上拆分；目的是变量被赋值为恰好读取的字符（反斜杠除外；参见下面的 `-r` 选项）。
- `-p prompt`
  在尝试读取任何输入之前显示 `prompt`，不带尾随换行符，但仅当输入来自终端时。
- `-r`
  如果给出此选项，反斜杠不充当转义字符。反斜杠被视为行的一部分。特别是，反斜杠-换行对不能用作行延续。
- `-s`
  静默模式。如果输入来自终端，字符不回显。
- `-t timeout`
  导致 `read` 如果在 `timeout` 秒内未读取完整的输入行（或指定数量的字符），则超时并返回失败。`timeout` 可以是带小数部分的十进制数。此选项仅在 `read` 从终端、管道或其他特殊文件读取输入时有效；从常规文件读取时无效。如果 `read` 超时，它将读取的任何部分输入保存到指定的变量 `name` 中，并返回大于 128 的状态。如果 `timeout` 为 0，`read` 立即返回，不尝试读取任何数据。在这种情况下，如果指定文件描述符上有输入可用，或读取将返回 EOF，则退出状态为 0，否则为非零。
- `-u fd`
  从文件描述符 `fd` 而不是标准输入读取输入。

除了 `delim` 是空字符串的情况外，`read` 忽略输入中的任何 NUL 字符。

如果未提供 `name`，`read` 将读取的行（不带结束分隔符，但其他方面未修改）赋值给变量 `REPLY`。

除非遇到文件结束、`read` 超时（在这种情况下状态大于 128）、发生变量赋值错误（例如赋值给只读变量），或作为 `-u` 参数提供了无效文件描述符，否则退出状态为零。

示例

```sh
read FLAG </flag
```

## `type`

```bash
type [-afptP] [name ...]
```

指示如果用作命令名，每个 `name` 将如何被解释。

如果使用 `-t` 选项，`type` 打印一个单词，如果 `name` 分别是别名、shell 保留字、shell 函数、shell 内建命令或可执行文件，则为 `alias`、`keyword`、`function`、`builtin` 或 `file` 之一。如果未找到 `name`，`type` 不打印任何内容并返回失败状态。

如果使用 `-p` 选项，`type` 要么返回通过搜索 `$PATH` 找到的可执行文件的名称，要么如果 `-t` 不会返回 `file`，则不返回任何内容。

`-P` 选项强制对每个 `name` 进行路径搜索，即使 `-t` 不会返回 `file`。

如果 `name` 存在于哈希命令表中，选项 `-p` 和 `-P` 打印哈希值，该值不一定是 `$PATH` 中首先出现的文件。

如果使用 `-a` 选项，`type` 返回包含名为 `name` 的命令的所有位置。这包括别名、保留字、函数和内建命令，但可以提供路径搜索选项（`-p` 和 `-P`）以将输出限制为可执行文件。如果 `-a` 与 `-p` 一起提供，`type` 不查看哈希命令表，仅对 `name` 执行 `PATH` 搜索。

如果使用 `-f` 选项，`type` 不尝试查找 shell 函数，如同 `command` 内建命令。

如果找到所有 `name`，返回状态为零；如果任何未找到，则非零。

## `ulimit`

```bash
ulimit [-HS] -a
ulimit [-HS] [-bcdefiklmnpqrstuvxPRT] [limit]
```

`ulimit` 在允许此类控制的系统上提供对 shell 及其启动的进程可用资源的控制。如果给出选项，其解释如下：

- `-S`
  更改并报告与资源关联的软限制。
- `-H`
  更改并报告与资源关联的硬限制。
- `-a`
  报告所有当前限制；不设置限制。
- `-b`
  最大套接字缓冲区大小。
- `-c`
  创建的核心文件的最大大小。
- `-d`
  进程数据段的最大大小。
- `-e`
  最大调度优先级（"nice"）。
- `-f`
  shell 及其子进程写入的文件的最大大小。
- `-i`
  待处理信号的最大数量。
- `-k`
  可分配的最大 kqueue 数量。
- `-l`
  可锁定到内存中的最大大小。
- `-m`
  最大常驻集大小（许多系统不遵守此限制）。
- `-n`
  最大打开文件描述符数量（大多数系统不允许设置此值）。
- `-p`
  管道缓冲区大小。
- `-q`
  POSIX 消息队列中的最大字节数。
- `-r`
  最大实时调度优先级。
- `-s`
  最大栈大小。
- `-t`
  最大 CPU 时间（秒）。
- `-u`
  单个用户可用的最大进程数。
- `-v`
  shell 可用的最大虚拟内存量，在某些系统上，其子进程也可用。
- `-x`
  最大文件锁数量。
- `-P`
  最大伪终端数量。
- `-R`
  实时进程在阻塞前可运行的最长时间，以微秒为单位。
- `-T`
  最大线程数。

如果提供了 `limit`，且未使用 `-a` 选项，则 `limit` 是指定资源的新值。特殊 `limit` 值 `hard`、`soft` 和 `unlimited` 分别代表当前硬限制、当前软限制和无限制。非 root 用户一旦设置硬限制就不能增加；软限制可以增加到硬限制的值。否则，`ulimit` 打印指定资源的软限制的当前值，除非提供 `-H` 选项。当指定多个资源时，如果适用，限制名称和单位在值之前打印。设置新限制时，如果既未提供 `-H` 也未提供 `-S`，`ulimit` 同时设置硬限制和软限制。如果未提供选项，则假定为 `-f`。

值以 1024 字节为增量，除了 `-t`（以秒为单位）、`-R`（以微秒为单位）、`-p`（以 512 字节块为单位）、`-P`、`-T`、`-b`、`-k`、`-n` 和 `-u`（未缩放的值）；以及在 POSIX 模式（参见 [Bash 和 POSIX]）下，`-c` 和 `-f`（以 512 字节为增量）。

除非提供了无效选项或参数，或设置新限制时发生错误，否则返回状态为零。
