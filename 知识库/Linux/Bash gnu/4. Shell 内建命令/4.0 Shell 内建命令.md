# 4 Shell 内建命令

https://www.gnu.org/software/bash/manual/html_node/Shell-Builtin-Commands.html

内建命令包含在 shell 本身之中。当内建命令的名称用作简单命令的第一个词时（参见 [简单命令]），shell 直接执行该命令，而不调用另一个程序。内建命令对于实现无法或不便通过独立实用程序获得的功能是必需的。

本节简要描述 Bash 从 Bourne Shell 继承的内建命令，以及 Bash 中独有的或已扩展的内建命令。

其他章节描述了若干内建命令：提供 Bash 作业控制接口的内建命令（参见 [作业控制内建命令]）、目录栈（参见 [目录栈内建命令]）、命令历史（参见 [Bash 历史内建命令]）以及可编程补全功能（参见 [可编程补全内建命令]）。

许多内建命令已由 POSIX 或 Bash 扩展。

除非另有说明，每个被记录为接受以 `-` 开头的选项的内建命令都接受 `--` 来表示选项结束。`:`、`true`、`false` 和 `test`/`[` 内建命令不接受选项，也不特殊对待 `--`。`exit`、`logout`、`return`、`break`、`continue`、`let` 和 `shift` 内建命令接受并处理以 `-` 开头的参数，而不要求 `--`。其他接受参数但未指定为接受选项的内建命令，会将以 `-` 开头的参数解释为无效选项，并要求 `--` 来防止这种解释。
