### sshd_config — OpenSSH 守护进程配置文件

https://www.man7.org/linux/man-pages/man5/sshd_config.5.html

- 公钥验证文件
	`~/.ssh/authorized_keys`

- 服务器配置文件
	`/etc/ssh/sshd_config`

	```log
	# 开启公钥验证
	PubkeyAuthentication yes
	# 关闭密码登录
	PasswordAuthentication no
	# 关闭 root 登录
	PermitRootLogin no
	```
- 客户端配置文件
	`~/.ssh/config`
	`/etc/ssh/ssh_config`

	<https://linux.die.net/man/5/ssh_config>

    ```log
	HostName 主机名
	User 用户名
	IdentityFile 私钥文件
	```
