# 11.4 `mv`：移动（重命名）文件

`mv` 移动或重命名文件（或目录）。用法：

```sh
mv [option]... [-T] source dest
mv [option]... source... directory
mv [option]... -t directory source...
```

- 如果给出两个文件名，`mv` 将第一个文件移动到第二个。

- 如果给出 `--target-directory`（`-t`）选项，或者未给出该选项时，如果最后一个文件是目录且未给出 `--no-target-directory`（`-T`）选项，则 `mv` 将每个 `source` 文件移动到指定目录，并使用各 `source` 的名称。

要移动文件，`mv` 通常只是重命名它。然而，如果由于目标文件系统不同而无法重命名，`mv` 会回退到像 `cp -a` 那样复制，然后（假设复制成功）删除原始文件。如果复制失败，`mv` 会删除目标中任何部分创建的副本。如果你要将三个目录从一个文件系统复制到另一个文件系统，第一个目录的复制成功，但第二个失败，那么第一个将留在目标文件系统上，第二个和第三个将留在原始文件系统上。

`mv` 始终尝试复制扩展属性（`xattr`），其中可能包括 `SELinux` 上下文、`ACL` 或 `Capabilities`。失败时会发出所有警告，但不修改退出状态。

如果目标文件存在但通常不可写，标准输入是终端，并且未给出 `-f` 或 `--force` 选项，`mv` 会提示用户是否替换该文件。（你可能拥有该文件，或对其目录有写权限。）如果回答不是肯定的，则跳过该文件。

当源名称可能是指向目录的符号链接时，避免在源名称末尾指定斜杠。否则，`mv` 可能会做出非常令人意外的行为，因为其行为取决于底层 `rename` 系统调用。在基于现代 Linux 内核的系统上，它会失败并返回 `errno=ENOTDIR`。然而，在其他系统上（至少 FreeBSD 6.1 和 Solaris 10），它会静默地重命名符号链接所引用的目录，而不是符号链接本身。参见 [尾随斜杠]。

`mv` 命令仅在目标目录为空时替换它们。有冲突的非空目录会被跳过并给出诊断。

程序接受以下选项。另见 [常用选项]。

- `-b`, `--backup[=method]`  
  参见 [备份选项]。对否则会被覆盖或删除的每个文件进行备份。

- `--debug`  
  向标准输出打印额外信息，解释文件如何复制。此选项隐含 `--verbose` 选项。

- `-f`, `--force`  
  替换目标文件前不提示用户。如果指定多个 `-i`、`-f`、`-n` 选项，仅最后一个生效。

- `-i`, `--interactive`  
  无论权限如何，提示是否覆盖每个现有目标文件，如果回答不是肯定则失败。如果指定多个 `-i`、`-f`、`-n` 选项，仅最后一个生效。

- `-n`, `--no-clobber`  
  不覆盖现有文件；静默跳过。如果指定多个 `-i`、`-f`、`-n` 选项，仅最后一个生效。此选项与 `-b` 或 `--backup` 选项互斥。此选项已弃用，因为其退出状态与其他平台不同。另见 `--update` 选项，它将对如何处理目标中的现有文件以及特别是退出状态提供更多控制。

- `--no-copy`  
  如果因目标文件系统不同而无法重命名文件，则失败并给出诊断，而不是复制然后删除文件。

- `--exchange`  
  交换源和目标，而不是将源重命名为目标。两个文件必须存在；它们不必是同一类型。这会交换所有数据和元数据。  
  此选项可用于用一个目录替换另一个目录。这样使用时，应与 `--no-target-directory`（`-T`）组合，以避免对目标位置产生混淆。例如，可以使用以下命令交换两个目录 `d1` 和 `d2`：  
    ```sh
    mv -T --exchange d1 d2
    ```
  如果源和目标都位于支持原子交换的单一文件系统中，则交换是原子的。尚不支持非原子交换。  
  如果源和目标可能不在同一文件系统上，使用 `--no-copy` 将阻止未来版本的 `mv` 通过复制实现交换。

- `-u`, `--update[=which]`  
  不要移动已存在目标且修改时间戳相同或更新的非目录；而是静默跳过文件而不失败。如果跨文件系统边界移动，则比较时会将源时间戳截断到目标文件系统以及用于更新时间戳的系统调用的分辨率；如果多次使用相同源和目标执行 `mv -u`，这可避免重复工作。如果同时指定 `-n` 或 `--no-clobber`，则忽略此选项。  
  `which` 提供更多控制，用于决定目标中哪些现有文件被替换，其值可以是以下之一：  
    - `all`  
      这是未指定 `--update` 选项时的默认操作，结果为替换目标中的所有现有文件。  
    - `none`  
      这类似于已弃用的 `--no-clobber` 选项，不替换目标中的任何文件，且跳过文件不会导致失败。  
    - `none-fail`  
      这类似于 `none`，不替换目标中的任何文件，但任何被跳过的文件都会被诊断并导致失败。  
    - `older`  
      这是指定 `--update` 时的默认操作，结果为如果文件比相应源文件旧，则替换该文件。

- `-v`, `--verbose`  
  移动前打印每个文件的名称。

- `--strip-trailing-slashes`  
  从每个 `source` 参数中移除任何尾随斜杠。参见 [尾随斜杠]。

- `-S suffix`, `--suffix=suffix`  
  将 `suffix` 追加到使用 `-b` 创建的每个备份文件。参见 [备份选项]。

- `-t directory`, `--target-directory=directory`  
  指定目标 `directory`。参见 [目标目录]。

- `-T`, `--no-target-directory`  
  当最后一个操作数是目录或指向目录的符号链接时，不要特殊对待它。参见 [目标目录]。

- `-Z`, `--context`  
  此选项的功能类似于 `restorecon` 命令，根据目标文件和每个创建目录的系统默认类型调整 `SELinux` 安全上下文。

退出状态为零表示成功，非零表示失败。
