# 词法分析

Python 程序将由一个 *解析器* 来读取。 输入解析器的是 [词元] 的流，由 *词法分析器* (或称 *分词器*) 生成。 本章将介绍词法分析器是如何产生词元的。

## 2.5. String and Bytes literals

### 2.5.4. 转义序列

- `\N{name}`
    字符串转义 - 命名字符

#### 🥷 2.5.4.5. 命名Unicode字符

序列 `\N{name}` 表示具有给定 `name` 的Unicode字符:

```py
'\N{LATIN CAPITAL LETTER P}'
# 'P'

'\N{SNAKE}'
# '🐍'
```

此序列不能出现在 [字节串字面量] 中。

> 使用 `unicodedata` 标准库转换字符与名称

### 2.5.7. f-strings

https://docs.python.org/3.14/reference/lexical_analysis.html#f-strings

`f'...{val:08b}...'`

格式说明 `:`  
`:[[fill]align][sign][#][0][width][grouping_option][.precision][type]`
- `0`：如果不够 8 位，用 0 在左侧补齐。
- `8`：宽度为 8 个字符。

进制：
- `b`：以二进制形式输出，只包含 0/1。
- `x`:十六进制

例：
```py
# 以拥有 `0x` 前缀的十六进制打印数字
f"{int_number:#x}"

# 打印无 `0x`前缀的十六进制数字，使用0填充到8位
f"{num:08x}"
```
