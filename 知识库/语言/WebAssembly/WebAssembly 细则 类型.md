# 类型

WebAssembly 中的各种实体按类型进行分类。类型会在[验证]、[实例化]以及可能的[执行]过程中被检查。

## 数字类型

*数字类型*对数值进行分类。

```text
numtype ::= i32 | i64 | f32 | f64
```

类型 `i32` 和 `i64` 分别对 32 位和 64 位整数进行分类。整数本身没有固有的有符号或无符号之分，其解释由各个操作决定。

类型 `f32` 和 `f64` 分别对 32 位和 64 位浮点数据进行分类。它们对应于各自对应的二进制浮点表示，也称为*单*精度和*双*精度，由 IEEE 754 标准（第 3.3 节）定义。

数字类型是*透明的*，这意味着它们的位模式可以被观察到。数字类型的值可以存储在[内存]中。

### 约定

- 记号 `|t|` 表示数字类型 `t` 的*位宽*。也就是说，`|i32| = |f32| = 32`，`|i64| = |f64| = 64`。

## 向量类型

*向量类型*对由向量指令（也称为*SIMD*指令，即单指令多数据）处理的[数字]值向量进行分类。

```text
vectype ::= v128
```

类型 `v128` 对应于 128 位的打包整数或浮点数据向量。打包数据可以被解释为有符号或无符号整数、单精度或双精度浮点值，或单个 128 位类型。解释由各个操作决定。

向量类型与[数字类型]一样是*透明的*，这意味着它们的位模式可以被观察到。向量类型的值可以存储在[内存]中。

### 约定

- 用于[位宽]的记号 `|t|` 也扩展到向量类型，即 `|v128| = 128`。

## 类型使用

*类型使用*是[类型索引]的使用位置，该索引引用[模块]中[定义]的[复合类型]。它对相应类型的对象进行分类。

```text
typeuse ::= typeidx | ...
```

类型使用的语法经过[扩展]，增加了用于指定[验证]和[执行]的额外形式。

## 堆类型

*堆类型*对运行时[存储]中的对象进行分类。堆类型有三个不相交的层次结构：

- *函数类型*对[函数]进行分类，
- *聚合类型*对动态分配的*托管*数据进行分类，例如*结构体*、*数组*或*未装箱标量*，
- *外部类型*对可能由[嵌入器]拥有的*外部*引用进行分类。

后两个层次结构中的值可以通过 `extern.convert_any` 和 `any.convert_extern` 指令相互转换。也就是说，这两个类型层次结构由同构的值集合构成，但在实践中可能具有不同且不兼容的表示。

```text
absheaptype ::= any | eq | i31 | struct | array | none
              | func | nofunc
              | exn | noexn
              | extern | noextern
              | ...
heaptype ::= absheaptype | typeuse
```

堆类型要么是*抽象的*，要么是*具体的*。具体堆类型由[类型使用]组成，该类型使用对模块中定义的相应[类型]的对象进行分类。抽象类型由各自的关键字表示。

类型 `func` 表示所有[函数类型]的公共超类型，无论其具体定义如何。对偶地，类型 `nofunc` 表示所有[函数类型]的公共子类型，无论其具体定义如何。此类型没有值。

类型 `exn` 表示所有[异常引用]的公共超类型。此类型没有具体子类型。对偶地，类型 `noexn` 表示所有形式的异常引用的公共子类型。此类型没有值。

类型 `extern` 表示通过[嵌入器]接收的所有外部引用的公共超类型。此类型没有具体子类型。对偶地，类型 `noextern` 表示所有形式的外部引用的公共子类型。此类型没有值。

类型 `any` 表示所有聚合类型的公共超类型，以及可能通过*内化*类型为 `extern` 的外部引用产生的抽象值。对偶地，类型 `none` 表示所有形式的聚合类型的公共子类型。此类型没有值。

类型 `eq` 是 `any` 的子类型，包含所有可以比较引用的类型，即聚合值和 `i31`。

类型 `struct` 和 `array` 分别表示所有[结构体]和[数组]聚合的公共超类型。

类型 `i31` 表示*未装箱标量*，即注入到引用中的整数。其可观察的值范围限制为 31 位。

> **注意**
>
> 类型 `i31` 的值实际上并不分配在存储中，而是以一种允许它们与存储中的实际引用混合而不产生歧义的方式表示。引擎需要执行某种形式的*指针标记*来实现这一点，这就是保留一位的原因。由于此类型需要在 WebAssembly 支持的所有硬件平台上可靠地拆箱，因此它不能宽于 32 位减去标记位。
>
> 尽管类型 `none`、`nofunc`、`noexn` 和 `noextern` 没有任何值，但它们可以用于形成各自层次结构中所有空[引用]的类型。例如，`(ref null nofunc)` 是与所有函数引用类型兼容的空引用的泛型类型。

抽象堆类型的语法经过[扩展]，增加了用于指定[验证]和[执行]的额外形式。

## 引用类型

*引用类型*对作为运行时[存储]中对象的一等引用的[值]进行分类。

```text
reftype ::= ref null? heaptype
```

引用类型的特征在于它指向的[堆类型]。

此外，形式为 `ref null ht` 的引用类型是*可空的*，这意味着它既可以是指向 `ht` 的正式引用，也可以是[空]。其他引用是*非空*的。

引用类型是*不透明的*，这意味着它们的大小和位模式都无法被观察到。引用类型的值可以存储在[表]中，但不能存储在[内存]中。

### 约定

- 引用类型 `anyref` 是 `(ref null any)` 的缩写。
- 引用类型 `eqref` 是 `(ref null eq)` 的缩写。
- 引用类型 `i31ref` 是 `(ref null i31)` 的缩写。
- 引用类型 `structref` 是 `(ref null struct)` 的缩写。
- 引用类型 `arrayref` 是 `(ref null array)` 的缩写。
- 引用类型 `funcref` 是 `(ref null func)` 的缩写。
- 引用类型 `exnref` 是 `(ref null exn)` 的缩写。
- 引用类型 `externref` 是 `(ref null extern)` 的缩写。
- 引用类型 `nullref` 是 `(ref null none)` 的缩写。
- 引用类型 `nullfuncref` 是 `(ref null nofunc)` 的缩写。
- 引用类型 `nullexnref` 是 `(ref null noexn)` 的缩写。
- 引用类型 `nullexternref` 是 `(ref null noextern)` 的缩写。

## 值类型

*值类型*对 WebAssembly 代码可以计算的各个值以及变量接受的值进行分类。它们要么是[数字类型]、[向量类型]，要么是[引用类型]。

```text
consttype ::= numtype | vectype
valtype ::= numtype | vectype | reftype | ...
```

值类型的语法经过[扩展]，增加了用于指定[验证]的额外形式。

### 约定

- 元变量 `t` 在上下文中明确时，取值范围为值类型或其子类。

## 结果类型

*结果类型*对[执行][指令]或[函数]的结果进行分类，结果是一个值序列，用方括号书写。

```text
resulttype ::= list(valtype)
```

## 块类型

*块类型*对限定指令[块]的结构化[控制指令]的*输入*和*输出*进行分类。

```text
blocktype ::= valtype?
            | typeidx
```

它们要么以[类型索引]的形式给出，该索引引用被重新解释为[指令类型]的合适[函数类型]；要么以内联的可选[值类型]形式给出，这是指令类型 `ϵ → valtype?` 的简写。

## 复合类型

*复合类型*是由更简单的类型组成的所有类型，包括*函数类型*、*结构体类型*和*数组类型*。

```text
comptype ::= struct list(fieldtype)
           | array fieldtype
           | func resulttype → resulttype

fieldtype ::= mut? storagetype
storagetype ::= valtype | packtype
packtype ::= i8 | i16
```

函数类型对[函数]的签名进行分类，将参数列表映射到结果列表。它们也用于对[指令]的输入和输出进行分类。

*聚合类型*（如结构体类型或数组类型）由一组可能可变、可能打包的*字段类型*组成，描述其组成部分。结构体是异构的，但需要静态索引；而数组需要是同构的，但允许动态索引。

### 约定

- 用于[值类型] `t` 的[位宽]记号 `|t|` 也扩展到打包类型，即 `|i8| = 8` 和 `|i16| = 16`。
- 辅助函数 `unpack` 将存储类型映射到访问字段时获得的[值类型]：

```text
unpack(valtype) = valtype
unpack(packtype) = i32
```

## 递归类型

*递归类型*表示一组相互递归的[复合类型]，每个复合类型可以选择性地声明一个其[匹配]的超类型的[类型使用]列表。每个类型还可以声明为*最终*，以防止进一步的子类型化。

```text
rectype ::= rec list(subtype)
subtype ::= sub final? typeuse* comptype
```

在[模块]中，递归类型的每个成员被分配一个单独的[类型索引]。

## 地址类型

*地址类型*是[数字类型]的子集，对可用作[内存]和[表]中偏移量的值进行分类。

```text
addrtype ::= i32 | i64
```

### 约定

两个地址类型的*最小值*定义为位宽为两者中最小值的地址类型。

```text
min(at1, at2) = at1   if |at1| ≤ |at2|
min(at1, at2) = at2   否则
```

## 限制

*限制*对与[内存类型]和[表类型]相关的可调整大小存储的大小范围进行分类。

```text
limits ::= [ u64 .. u64? ]
```

如果不存在最大值，则相应的存储可以增长到任何有效大小。

## 标签类型

*标签类型*对[标签]的签名进行分类，使用一个[类型使用]引用[函数类型]的定义，该函数类型声明与标签关联的参数值和结果值的类型。对于异常标签，结果类型为空。

```text
tagtype ::= typeuse
```

## 全局类型

*全局类型*对[全局]变量进行分类，全局变量持有一个值，可以是可变的或不可变的。

```text
globaltype ::= mut? valtype
```

## 内存类型

*内存类型*对线性[内存]及其大小范围进行分类。

```text
memtype ::= addrtype limits page
```

限制约束了内存的最小大小以及可选的最大大小。限制以[页大小]为单位给出。

## 表类型

*表类型*对一定大小范围内基于[引用类型]元素的[表]进行分类。

```text
tabletype ::= addrtype limits reftype
```

与内存一样，表受最小大小和可选最大大小的限制约束。限制以条目数量给出。

## 数据类型

*数据类型*对[数据段]进行分类。由于数据段的内容不需要进一步分类，它们仅由一个通用标记 `ok` 组成，表示良构性。

```text
datatype ::= ok
```

## 元素类型

*元素类型*按其元素的[引用类型]对[元素段]进行分类。

```text
elemtype ::= reftype
```

## 外部类型

*外部类型*对[导入]和[外部地址]及其各自的类型进行分类。

```text
externtype ::= tag tagtype | global globaltype | mem memtype | table tabletype | func typeuse
```

对于函数，[类型使用]必须引用[函数类型]的定义。

> **注意**
>
> WebAssembly 的未来版本可能会为标签增加额外用途，并可能允许标签的函数类型中包含非空结果类型。

### 约定

以下辅助记号定义为用于外部类型序列。它按保持顺序的方式过滤出特定类型的条目：

```text
funcs(ϵ) = ϵ
funcs((func dt) xt*) = dt funcs(xt*)
funcs(externtype xt*) = funcs(xt*)   否则

tables(ϵ) = ϵ
tables((table tt) xt*) = tt tables(xt*)
tables(externtype xt*) = tables(xt*)   否则

mems(ϵ) = ϵ
mems((mem mt) xt*) = mt mems(xt*)
mems(externtype xt*) = mems(xt*)   否则

globals(ϵ) = ϵ
globals((global gt) xt*) = gt globals(xt*)
globals(externtype xt*) = globals(xt*)   否则

tags(ϵ) = ϵ
tags((tag jt) xt*) = jt tags(xt*)
tags(externtype xt*) = tags(xt*)   否则
```
