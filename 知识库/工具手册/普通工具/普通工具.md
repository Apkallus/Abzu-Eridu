# 普通工具

## youtube URL 与下载

嵌入 URL 修改为普通 URL，虽然嵌入 URL 被广泛支持
- `/embed/ID` -> `/watch?v=ID`

导出频道的播放列表 `https://www.youtube.com/@pwncollege`
- https://exportyoutubeplaylist.com/tools/youtube-channel-playlist-extractor

导出频道或播放列表中的视频链接
- https://touhfa.art/tools/youtube-channel-video-links-extractor/

使用视频链接下载视频与字幕
- https://vd6s.net/en5/
