# 3 调用 GNU `tar`

本章介绍如何调用 GNU `tar` 命令，从命令概要开始（参见“`tar` 通用概要”）。选项众多，书写风格也多种多样。有一个必需选项用于指定 `tar` 应执行的操作（参见“操作”），其他选项用于详细说明该操作应如何执行（参见“`tar` 选项”）。非选项参数并不总是以相同方式解释，具体取决于操作是什么。

本章将介绍选项风格及书写规则的全部内容（参见“三种选项风格”）。另一方面，操作和选项在其他章节中有完整描述。这里只给出操作和选项的简要说明，并指向 `tar` 手册的其他部分。

有些选项非常特殊，本章会直接完整描述。它们会抑制 `tar` 的正常操作，或者全局改变用户收到的关于当前进展的反馈量。这些选项是 `--help` 和 `--version`（参见“GNU `tar` 文档”）、`--verbose`（参见“检查 `tar` 进度”）以及 `--interactive`（参见“在操作期间请求确认”）。
