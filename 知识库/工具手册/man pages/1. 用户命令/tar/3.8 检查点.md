# 3.8 检查点

一个*检查点*是在将第 `n` 条记录写入归档之前（*写检查点*），或在从归档读取第 `n` 条记录之前（*读检查点*）的时刻。检查点允许定期执行任意动作。

检查点功能通过以下选项启用：

- `--checkpoint[=n]`  
    在每个第 `n` 条记录写入或读取之前安排检查点。`n` 的默认值为 10。

可以在每个检查点执行一组任意*动作*。这些动作包括：暂停、显示文本消息，以及执行任意外部程序。动作使用 `--checkpoint-action` 选项定义。

- `--checkpoint-action=action`  
    在每个检查点执行一个 `action`。

最简单的 `action` 值是 `echo`。它指示 `tar` 在到达每个检查点时在标准错误流上显示默认消息。对于写检查点，默认消息为（在 POSIX 区域设置中）`Write checkpoint n`；对于读检查点，为 `Read checkpoint n`。这里，`n` 表示检查点的序号。

在其他区域设置中，使用此消息的翻译版本。

这是默认动作，因此运行：

```console
$ tar -c --checkpoint=1000 --checkpoint-action=echo /var
```

等价于：

```console
$ tar -c --checkpoint=1000 /var
```

`echo` 动作还允许提供自定义消息。为此，在等号后紧跟消息，例如：

```sh
--checkpoint-action="echo=Hit %s checkpoint #%u"
```

上述示例中的 `%s` 和 `%u` 是*格式说明符*。`%s` 说明符会被替换为检查点的*类型*：`write` 或 `read`（或在非 POSIX 区域设置中的相应翻译版本）。`%u` 说明符会被替换为检查点的序号。因此，上述示例与 `--create` 选项一起使用时可能产生以下输出：

```log
tar: Hit write checkpoint #10
tar: Hit write checkpoint #20
tar: Hit write checkpoint #30
```

可用格式说明符的完整列表如下。其中一些可以接受可选参数。如果给出这些参数，则放在百分号和说明符字母之间的花括号中。

- `%s`  
    打印检查点类型（`write` 或 `read`）。

- `%u`  
    打印检查点编号。

- `%{r,w,d}T`  
    打印到目前为止传输的字节数和近似传输速度。可选参数分别提供在读取、写入和删除字节数之前使用的前缀。如果缺失，它们分别默认为 `R`、`W`、`D`。可以省略任意或全部，因此例如 `%{}T` 表示打印相应统计信息而不带任何前缀。任何多余参数（如果存在）会被静默忽略。

    ```console
    $ tar --delete -f f.tar --checkpoint-action=echo="#%u: %T" main.c
    tar: #1: R: 0 (0B, 0B/s),W: 0 (0B, 0B/s),D: 0
    tar: #2: R: 10240 (10KiB, 19MiB/s),W: 0 (0B, 0B/s),D: 10240
    ```

    另请参见下文描述的 `totals` 动作。

- `%{fmt}t`  
    使用 `fmt` 作为 `strftime` 的格式输出当前本地时间（参见《strftime(3) 手册页》中的 `strftime`）。`{fmt}` 部分可选。如果不存在，默认格式为 `%c`，即当前区域设置首选的日期和时间表示。

- `%{n}*`  
    用空格填充输出到第 `n` 列。如果省略 `{n}` 部分，则假定当前屏幕宽度。

- `%c`  
    这是 `%{%Y-%m-%d %H:%M:%S}t: %ds, %{read,wrote}T%*\r` 的快捷方式，主要用于 `ttyout` 动作（见下文）。

除格式扩展外，消息字符串还会经历*去引号*，期间反斜杠*转义序列*被替换为相应的 ASCII 字符（参见“转义序列”）。例如，以下动作将在每个检查点产生可听铃声和上述消息：

```sh
--checkpoint-action='echo=\aHit %s checkpoint #%u'
```

还有一个产生可听信号的特殊动作：`bell`。它不等同于 `echo='\a'`，因为 `bell` 直接将铃声发送到控制台（`/dev/tty`），而 `echo='\a'` 将其发送到标准错误。

`ttyout=string` 动作将 `string` 输出到 `/dev/tty`，因此即使标准输出重定向到其他地方也可使用。`string` 经历与 `echo` 动作相同的修改。与后者不同，`ttyout` 不会在字符串前添加 `tar` 可执行文件名，也不会在其后输出换行。例如，以下动作将在同一屏幕行打印检查点消息，覆盖任何先前消息：

```sh
--checkpoint-action="ttyout=Hit %s checkpoint #%u%*\r"
```

注意使用 `%*` 格式说明符清除先前输出行的任何残留。作为更复杂的示例，考虑：

```sh
--checkpoint-action=ttyout='%{%Y-%m-%d %H:%M:%S}t (%d sec): #%u, %T%*\r'
```

这会打印当前本地时间、自 `tar` 启动以来经过的秒数、检查点序号、已传输字节和平均计算 I/O 速度。

另一个可用检查点动作是 `dot`（或 `.`）。它指示 `tar` 在标准列表流上打印单个点，例如：

```console
$ tar -c --checkpoint=1000 --checkpoint-action=dot /var
...
```

为了与旧版 GNU `tar` 兼容，此动作可以通过在检查点频率前放置一个点来缩写，如上一节所示。

`totals` 动作打印到目前为止传输的总字节数。数据格式与 `--totals` 选项相同（参见“`totals`”）。另请参见 `echo` 或 `ttyout` 动作的 `%T` 格式说明符。

还有一个动作 `sleep` 会暂停 `tar` 指定秒数。以下示例将在每个检查点停止 30 秒：

```console
$ tar -c --checkpoint=1000 --checkpoint-action=sleep=30
```

`wait=signo` 动作停止进一步执行，直到信号 `signo` 被送达。`signo` 的有效值为：`SIGHUP`、`SIGQUIT`、`SIGINT`、`SIGUSR1` 和 `SIGUSR2`。`SIG` 前缀可选。例如：

```console
$ tar -c -f arc --checkpoint=1000 --checkpoint-action wait=USR1 .
```

在此示例中，GNU `tar` 将在每第 1000 个检查点停止归档，等待 `SIGUSR1` 信号被送达，然后恢复处理。

此动作用于 `genfile` 实用程序在到达某些检查点时对输入文件执行修改（参见“`genfile`”）。

最后，`exec` 动作执行给定的外部命令。例如：

```console
$ tar -c --checkpoint=1000 --checkpoint-action=exec=/sbin/cpoint
```

提供的命令可以是任何有效命令调用，带或不带额外命令行参数。如果它确实包含参数，别忘了引用它，以防止被 shell 拆分。更多细节参见“运行外部命令”。

该命令会获得 `tar` 环境的副本，以及以下变量：

- `TAR_VERSION`  
    GNU `tar` 版本号。

- `TAR_ARCHIVE`  
    `tar` 正在处理的归档名称。

- `TAR_BLOCKING_FACTOR`  
    当前阻塞因子（参见“阻塞”）。

- `TAR_CHECKPOINT`  
    检查点编号。

- `TAR_SUBCOMMAND`  
    描述 `tar` 正在执行操作的短选项。参见“五种高级 `tar` 操作”，获取子命令选项的完整列表。

- `TAR_FORMAT`  
    正在处理的归档格式。参见“控制归档格式”，获取归档格式名称的完整列表。

这些环境变量也可以作为参数传递给命令，前提是它们被正确转义，例如：

```sh
tar -c -f arc.tar \
     --checkpoint-action='exec=/sbin/cpoint $TAR_CHECKPOINT'
```

注意单引号可防止变量名在调用 `tar` 时被 shell 展开。

可以通过在命令行中提供多个 `--checkpoint-action` 选项来定义任意数量的动作。例如，下面的命令显示两条消息、暂停执行 30 秒并执行 `/sbin/cpoint` 脚本：

```console
$ tar -c -f arc.tar \
       --checkpoint-action='\aecho=Hit %s checkpoint #%u' \
       --checkpoint-action='echo=Sleeping for 30 seconds' \
       --checkpoint-action='sleep=30' \
       --checkpoint-action='exec=/sbin/cpoint'
```

此示例还说明 `--checkpoint-action` 可以在没有 `--checkpoint` 的情况下使用。在这种情况下，假定默认检查点频率（每第 10 条记录）。
