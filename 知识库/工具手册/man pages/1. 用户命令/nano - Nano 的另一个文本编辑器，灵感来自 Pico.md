## 名称

`nano` - Nano 的另一个文本编辑器，灵感来自 Pico

## 概要

```sh
nano [options] [[+line[,column]] file]...

nano [options] [[+[crCR]{/|?}string] file]...
```

## 描述

`nano` 是一个小巧友好的文本编辑器。它模仿 Pico 的外观和操作方式，但属于自由软件，并实现了 Pico 所缺少的一些功能，例如：打开多个文件、按行滚动、撤销/重做、语法着色、行号显示，以及对过长行进行软换行。

在命令行上给出文件名时，可以通过在文件名前加上带加号（`+`）的行号，将光标放到指定行；还可以用逗号加上列号，将光标放到指定列。负数表示从文件末尾或行末尾开始计数。

可以通过在文件名前使用 `+/` 或 `+?` 后跟字符串，将光标放到该字符串第一次或最后一次出现的位置。在 `+` 号后插入 `c` 和/或 `r`，可以使字符串区分大小写和/或被解释为正则表达式。使用这些字母的大写形式 `C` 和/或 `R`，可以显式禁用这些搜索模式。当字符串包含空格时，需要用引号括起来。举例来说，要在单词 “Foo” 第一次出现的位置打开文件，可以执行：

```sh
nano +c/Foo file
```

特殊情况：如果给出的不是文件名而是短横线（`-`），`nano` 将从标准输入读取数据。

## 注意事项

自 9.0 版起，当光标接近边缘时，所有行会一起水平滚动，且只滚动所需的最小量，而不是只将当前行大幅滚动。如果你更喜欢旧行为，可以在命令行上使用 `--solo`，或在 `nanorc` 中设置 `set solosidescroll`。

同样自 9.0 版起，按键 `M-<` 和 `M->` 已被重新分配给 `scrollleft` 和 `scrollright` 功能。如果你希望这些按键执行 9.0 版之前的行为，请在 `nanorc` 文件末尾添加以下两行：

```nanorc
bind M-< prevbuf main
bind M-> nextbuf main
```

自 8.0 版起，为了对新手更友好，`^F` 开始向前搜索，`^B` 开始向后搜索，`M-F` 向前搜索下一次出现，`M-B` 向后搜索下一次出现。如果你希望这些按键执行 8.0 版之前的行为，请在 `nanorc` 文件末尾添加以下四行：

```nanorc
bind ^F forward main
bind ^B back main
bind M-F formatter main
bind M-B linter main
```

## 编辑

输入文本和在文件中移动都很直接：输入字母并使用常规光标移动键。命令通过 Control（`^`）以及 Alt 或 Meta（`M-`）键输入。输入 `^K` 会删除当前行并将其放入剪切缓冲区。连续输入 `^K` 会将所有删除的行一起放入剪切缓冲区。任何光标移动或执行任何其他命令都会导致下一次 `^K` 覆盖剪切缓冲区。`^U` 会将剪切缓冲区的当前内容粘贴到当前光标位置。

当需要剪切或复制更精确的一段文本时，可以用 `^6` 标记其开头，将光标移动到其末尾（被标记的文本会高亮显示），然后使用 `^K` 剪切它，或使用 `M-6` 将其复制到剪切缓冲区。还可以使用 `^O` 将标记的文本保存到文件，或使用 `^T^T` 对其进行拼写检查。

在某些终端上，还可以在按住 `Shift` 的同时使用方向键来选择文本。按住 `Ctrl` 或 `Alt` 键也会增大步幅。任何不按住 `Shift` 的光标移动都会取消此类选择。

通过输入 `M-V` 后跟码点的十六进制数字（当少于六位数字时，以 `<Space>` 或 `<Enter>` 结束），可以将任何有效的 Unicode 码点插入缓冲区。通过输入 `M-V` 后跟相应的按键，可以插入字面控制代码（`^J` 除外）。

屏幕底部的两行显示了一些重要命令；内置帮助（`^G`）列出了所有可用命令。默认键绑定可以通过 `nanorc` 文件更改——参见 `nanorc(5)`。

使用 `^S^X` 可以保存缓冲区并退出 `nano`。

## 选项

- `-A`, `--smarthome`  
    使 Home 键更智能。当在行中非空白字符的真正开头以外的任何位置按下 Home 时，光标会跳到该开头（向前或向后）。如果光标已在该位置，则跳到行的真正开头。

- `-B`, `--backup`  
    保存文件时，备份其先前版本，使用当前文件名加上波浪号（`~`）后缀。

- `-C directory`, `--backupdir=directory`  
    不仅制作并保留一个备份文件，而是在每次保存文件时制作并保留一个唯一编号的备份文件——当启用备份（`-B`）时。这些唯一编号的文件存储在指定的 `directory` 中。

- `-D`, `--boldtext`  
    对于界面，使用粗体而不是反色显示。可以通过在 `nanorc` 文件中设置 `titlecolor`、`statuscolor`、`promptcolor`、`minicolor`、`keycolor`、`numbercolor` 和/或 `selectedcolor` 选项，为特定元素覆盖此行为。参见 `nanorc(5)`。

- `-E`, `--tabstospaces`  
    将输入的每个制表符转换为空格——转换数量等于该位置上的制表符所占的空格数。（注意：粘贴的制表符不会被转换。）

- `-F`, `--newbuffer`  
    默认将文件读入新缓冲区。（此选项的旧形式 `--multibuffer` 已弃用。）

- `-G`, `--locking`  
    编辑文件时使用 vim 风格的文件锁定。

- `-H`, `--historylog`  
    保存最近一百个搜索字符串、替换字符串和已执行命令，以便在后续会话中轻松重用。

- `-I`, `--ignorercfiles`  
    不查看系统的 `nanorc`，也不查看用户的 `nanorc`。

- `-J number`, `--guidestripe=number`  
    在给定列绘制一条垂直条纹，以帮助判断文本宽度。（条纹颜色可以通过 `nanorc` 文件中的 `set stripecolor` 更改。）

- `-K`, `--rawsequences`  
    直接解释转义序列，而不是让 `ncurses` 翻译它们。（如果你需要此选项才能让某些键正常工作，这意味着所使用的 `terminfo` 终端描述不能完全匹配终端的实际行为。例如，当你 ssh 到 BSD 机器时可能发生这种情况。）使用此选项会禁用 `nano` 的鼠标支持。

- `-L`, `--nonewlines`  
    当文本不以换行符结尾时，不自动添加换行符。（这可能导致你保存非 POSIX 文本文件。）

- `-M`, `--trimblanks`  
    当发生自动硬换行或文本被两端对齐时，剪掉换行行尾的空白。

- `-N`, `--noconvert`  
    禁用从 DOS 格式自动转换文件。

- `-O`, `--bookstyle`  
    进行两端对齐时，将任何以空白开头的行视为段落开头（除非开启了自动缩进）。

- `-P`, `--positionlog`  
    对于最近 200 个文件，记录光标的最后位置，并在重新打开此类文件时再次将光标放到该位置。同时保存和恢复任何锚点的位置。

- `-Q "regex"`, `--quotestr="regex"`  
    设置用于匹配行引用部分的正则表达式。默认值为 `"^([ \t]*([!#%:;>|}]|//))+"`。（注意 `\t` 表示实际的 Tab。）这使得在撰写电子邮件时重新对齐引用的文本块，以及在编写源代码时重新换行行注释块成为可能。

- `-R`, `--restricted`  
    只读写命令行上指定的*文件*（或文件）。这意味着：不读写历史文件；不允许挂起；不允许拼写检查；不允许在 shell 中执行任何命令；不允许以不同名称保存当前缓冲区；不允许向任何文件追加或前置内容；并且不创建备份文件。

    作为例外，在指定文件之前，会读取 `nanorc` 文件以允许自定义。如果不允许自定义，请同时使用 `-I`（`--ignorercfiles`）选项。

    当命令行上未指定*文件*时，受限模式允许你将输入到新缓冲区的内容以任意名称保存，但不得覆盖现有文件。如果应限制创建此新文件的位置，请同时使用 `-o`（`--operatingdir`）选项。

    受限模式也可以通过以 `r` 开头的名称调用 `nano` 来激活（例如：`rnano`）。

- `-S`, `--softwrap`  
    在多个屏幕行上显示超过屏幕宽度的行。（你还可以使用 `--atblanks`，让软换行在空白处发生，而不是粗暴地在屏幕边缘发生。）

- `-T number`, `--tabsize=number`  
    将制表符的大小（宽度）设置为 `number` 列。`number` 的值必须大于 0。默认值为 `8`。

- `-U`, `--quickblank`  
    使状态栏消息在 1 次按键后消失，而不是 20 次后。注意选项 `-c`（`--constantshow`）会覆盖此设置。当选项 `--minibar` 或 `--zero` 生效时，`--quickblank` 会使消息在 0.8 秒后消失，而不是默认的 1.5 秒后。

- `-V`, `--version`  
    显示当前版本号并退出。

- `-W`, `--wordbounds`  
    通过将标点字符视为单词的一部分，以不同方式检测单词边界。

- `-X "characters"`, `--wordchars="characters"`  
    指定除常规字母数字字符外，还有哪些其他字符应被视为单词的一部分。使用此选项时，你可能希望省略 `-W`（`--wordbounds`）。

- `-Y name`, `--syntax=name`  
    指定从 `nanorc` 文件中定义的语法高亮中选择要使用的语法名称。

- `-Z`, `--zap`  
    让未修改的 Backspace 或 Delete 删除标记区域（而不是单个字符，且不影响剪切缓冲区）。

- `-a`, `--atblanks`  
    进行软换行时，在空白处换行，而不是始终在屏幕边缘换行。

- `-b`, `--breaklonglines`  
    当当前行变得过长时自动硬换行，即：当它变得比 `-r`（`--fill`）给出的值更宽时。`-r` 的默认值是终端宽度减去八列。（此选项与 `-w`（`--nowrap`）相反——最后给出的选项生效。）

- `-c`, `--constantshow`  
    在状态栏上持续报告光标位置。注意这会覆盖选项 `-U`（`--quickblank`）。

- `-d`, `--rebinddelete`  
    以不同方式解释 Delete 和 Backspace 键，使 Backspace 和 Delete 都能正常工作。仅当你的系统上 Backspace 表现得像 Delete，或 Delete 表现得像 Backspace 时，才应使用此选项。

- `-e`, `--emptyline`  
    不使用标题栏下方的那一行，使其完全空白。

- `-f file`, `--rcfile=file`  
    只读取此 `file` 来设置 `nano` 的选项，而不是同时读取系统级和用户的 `nanorc` 文件。

- `-g`, `--showcursor`  
    使光标在文件浏览器（放在高亮项上）和帮助查看器中可见。对盲文用户和视力不佳的人有用。

- `-h`, `--help`  
    显示可用命令行选项摘要并退出。

- `-i`, `--autoindent`  
    自动将新创建的行缩进到与上一行相同数量的制表符和/或空格（如果上一行是段落开头，则与下一行相同）。

- `-j`, `--jumpyscrolling`  
    按半屏而不是按行滚动缓冲区内容。

- `-k`, `--cutfromcursor`  
    使“剪切”命令（`^K`）从光标处剪切到行尾，而不是剪切整行。当光标已在行尾时，则剪切换行符本身。

- `-l`, `--linenumbers`  
    在文本区域左侧显示行号。（任何带锚点的行还会在边距中显示一个标记。）

- `-m`, `--mouse`  
    启用鼠标支持。这意味着：在编辑窗口中单击会放置光标，在同一位置双击会切换标记，单击帮助行会执行所触及的快捷方式，单击“滚动条”会将缓冲区滚动到大致该位置，滚动滚轮会滚动视口而不是移动光标。（鼠标在 X Window System 中以及运行 `gpm` 时的控制台上有效。在 X 下，仍然可以在按住 `Shift` 键的同时通过拖动选择文本。）

- `-n`, `--noread`  
    将命令行上给出的任何名称视为新文件。这允许 `nano` 写入命名管道：它从空白缓冲区开始，并在用户保存“文件”时写入管道。这样 `nano` 可以与例如 `gpg` 结合用作编辑器，而无需先将敏感数据写入磁盘。

- `-o directory`, `--operatingdir=directory`  
    切换到给定 `directory`，并仅允许在此目录及其子目录中读写文件。

- `-p`, `--preserve`  
    保留 XOFF 和 XON 序列（`^S` 和 `^Q`），以便它们被终端捕获（停止和恢复输出）。注意选项 `-/`（`--modernbindings`）会覆盖此设置。

- `-q`, `--indicator`  
    在编辑窗口右侧显示一个“滚动条”。它显示视口在缓冲区中的位置，以及视口覆盖了缓冲区的多少。

- `-r number`, `--fill=number`  
    将两端对齐和自动硬换行的目标宽度设置为此 `number` 列。如果值为 0 或更小，则换行发生在屏幕宽度减去 `number` 列的位置，允许换行点随屏幕宽度变化而变化（如果屏幕被调整大小）。默认值为 `-8`。

- `-s "program [argument ...]"`, `--speller="program [argument ...]"`  
    使用此命令执行拼写检查和纠正，而不是使用调用 `hunspell(1)` 或 `spell(1)` 的内置纠正器。

- `-t`, `--saveonexit`  
    保存已更改的缓冲区而不提示（当使用 `^X` 退出时）。

- `-u`, `--unix`  
    默认以 Unix 格式保存文件。这会覆盖 `nano` 以文件原有格式保存文件的默认行为。（当你同时使用 `--noconvert` 时，此选项无效。）

- `-v`, `--view`  
    仅查看文件并禁止编辑：只读模式。此模式允许用户也打开其他文件进行查看，除非同时给出 `--restricted`。

- `-w`, `--nowrap`  
    当当前行变得过长时，不自动硬换行。这是默认值。（此选项与 `-b`（`--breaklonglines`）相反——最后给出的选项生效。）

- `-x`, `--nohelp`  
    不显示屏幕底部的两行帮助。

- `-y`, `--afterends`  
    使 `Ctrl+Right` 和 `Ctrl+Delete` 停在单词末尾而不是开头。

- `-z`, `--listsyntaxes`  
    列出可用语法的名称并退出。

- `-!`, `--magic`  
    当文件名和第一行都无法提供线索时，尝试使用 `libmagic` 确定适用的语法。

- `-@`, `--colonparsing`  
    当命令行上给出的文件名以冒号加数字结尾且此文件名不存在时，则剪掉冒号和数字，并将数字理解为行号。如果修剪后的文件名也不存在，则重复该过程，并将得到的两个数字理解为行号和列号。但如果双重修剪后的文件名也不存在，则放弃修剪，按原样接受原始文件名。要对某个文件禁用此冒号解析，请在该文件名前使用 `+1` 或类似内容。

- `-%`, `--stateflags`  
    使用屏幕右上角显示一些状态标志：自动缩进时显示 `I`，标记开启时显示 `M`，硬换行（断开长行）时显示 `L`，录制宏时显示 `R`，软换行时显示 `S`。当缓冲区被修改时，标题栏中央的文件名后会显示一个星号（`*`）。

- `-_`, `--minibar`  
    抑制标题栏，改为在屏幕底部状态栏空间显示当前缓冲区信息。在此“迷你栏”中，左侧显示文件名，如果缓冲区已被修改则后跟星号。右侧显示当前行号和列号、光标下字符的代码（Unicode 格式：`U+xxxx`）、与 `--stateflags` 显示的相同标志，以及表示光标在文件中（按行计）深入程度的百分比。当加载或保存文件，以及在缓冲区之间切换时，文件名后会显示缓冲区中的行数。此数字在下次按键时清除，或在打开多个缓冲区时替换为 `[i/n]` 计数器。行号加列号和字符代码仅在使用 `--constantshow` 时显示，并可用 `M-C` 切换开和关。状态标志仅在使用 `--stateflags` 时显示。

- `-0`, `--zero`  
    隐藏界面的所有元素（标题栏、状态栏和帮助行），并使用终端的所有行显示缓冲区内容。状态栏仅在出现重要消息时出现，并在 1.5 秒后或下次按键时消失。使用 `M-Z` 可以切换标题栏加状态栏。使用 `M-X` 可以切换帮助行。

- `-1`, `--solosidescroll`  
    当光标接近编辑窗口右边缘时，仅将当前行大幅横向滚动，而不是将所有可见行横向滚动仅使光标保持可见所需的最小量。后一种整窗口平滑横向滚动是新的默认行为。此选项启用的单行急动横向滚动是旧行为——`nano` 唯一知道的行为。

- `-/`, `--modernbindings`  
    使用类似于大多数现代程序的键绑定：`^X` 剪切，`^C` 复制，`^V` 粘贴，`^Z` 撤销，`^Y` 重做，`^F` 向前搜索，`^G` 搜索下一个，`^S` 保存，`^O` 打开文件，`^Q` 退出，并且（当终端允许时）`^H` 显示帮助。此外，`^A` 设置标记，`^B` 向后搜索，`^D` 搜索上一个，`^R` 进行替换，`^P` 显示位置，`^T` 转到某行，`^W` 写出文件，`^E` 执行命令。注意此选项会覆盖选项 `-p`（`--preserve`）。

## 开关

上述若干选项也可以在 `nano` 运行时打开和关闭。例如，`M-L` 切换长行的硬换行，`M-S` 切换软换行，`M-N` 切换行号，`M-M` 切换鼠标，`M-I` 切换自动缩进，`M-X` 切换帮助行。完整列表请参见 `^G` 帮助文本末尾。

`M-X` 切换是特殊的：它在除帮助查看器和 linter 之外的所有菜单中都有效。所有其他切换仅在主菜单中有效。

## 文件

当给出 `--rcfile` 时，`nano` 仅读取指定的文件来设置其选项、语法和键绑定。没有该选项时，`nano` 读取两个配置文件：首先是系统的 `nanorc`（如果存在），然后是用户的 `nanorc`（如果存在），即 `~/.nanorc` 或 `$XDG_CONFIG_HOME/nano/nanorc` 或 `~/.config/nano/nanorc`，以先遇到者为准。有关这些文件可能内容的更多信息，请参见 `nanorc(5)`。

可用语法着色定义请参见 `/usr/share/nano/` 和 `/usr/share/nano/extra/`。

## 退出状态

- `0`  
    编辑器正常结束。

- `1`  
    给出了无效的选项或选项参数。

- `2`  
    最后一个打开的缓冲区被丢弃（使用 `^O^Q` 或 `^X^Q`）。

## 备注

默认启用挂起，可通过 `^T^Z` 触发。（如果你希望直接按 `^Z` 挂起 nano，请将 `bind ^Z suspend main` 添加到 `nanorc` 中。）

在“是/否”提示中，`^Y` 可用于“是”，`^N` 可用于“否”，`^A` 可用于“全部”。（退出时，`^Q` 可用于“带错误退出”。）这些未列出的绑定在任何区域设置中都有效。

当你想要将 `nano` 中标记的文本复制到系统剪贴板时，请参见 `nanorc(5)` 手册页中的示例之一。

如果命令行和任何 `nanorc` 文件中都未指定替代拼写检查命令，`nano` 会检查 `SPELL` 环境变量。

在某些情况下，`nano` 会尝试将缓冲区转储到紧急文件。这主要发生在 `nano` 收到 SIGHUP 或 SIGTERM，或内存耗尽时。如果缓冲区尚未命名，它会将缓冲区写入名为 `nano.save` 的文件；否则会在当前文件名后添加 `.save` 后缀。如果当前目录中已存在该名称的紧急文件，则会在当前文件名后添加 `.save` 加数字（例如：`.save.1`），以使其唯一。当打开多个缓冲区时，`nano` 会将每个已修改的缓冲区写入各自的紧急文件。

完整手册以 Texinfo 格式维护。你可以使用 `info nano` 阅读，或访问 <https://nano-editor.org/dist/latest/nano.html>。

如果你对在特定情况下如何使用 `nano` 有任何疑问，可以在 `help-nano@gnu.org` 上提问。

## 缺陷

键盘宏的录制和回放仅在终端模拟器上正常工作，在 Linux 控制台（VT）上不能正常工作，因为后者默认不区分修改过的方向键和未修改的方向键。

请通过以下地址报告你遇到的任何其他缺陷：<https://savannah.gnu.org/bugs/?group=nano>。

当 `nano` 崩溃时，它会将任何已修改的缓冲区保存到紧急 `.save` 文件中。如果你能够重现崩溃并希望获取回溯，请定义环境变量 `NANO_NOCATCH`。
