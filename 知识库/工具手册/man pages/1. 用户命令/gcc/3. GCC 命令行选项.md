## 3 GCC 命令行选项

调用 GCC 时，它通常会执行预处理、编译、汇编和链接。“总体选项”允许你在中间阶段停止此过程。例如，`-c` 选项表示不运行链接器。此时输出由汇编器生成的目标文件组成。参见“控制输出种类的选项”。

其他选项会传递给一个或多个处理阶段。有些选项控制预处理器，另一些控制编译器本身。还有一些选项控制汇编器和链接器；其中大多数未在此文档中说明，因为你很少需要使用它们。

大多数可与 GCC 一起使用的命令行选项对 `C` 程序有用；当某个选项仅对另一种语言（通常是 `C++`）有用时，说明中会明确指出。如果某个特定选项的描述未提及源语言，则可以在所有受支持的语言中使用该选项。

运行 GCC 的通常方式是运行名为 `gcc` 的可执行文件；交叉编译时运行 `machine-gcc`；或运行 `machine-gcc-version` 以使用特定版本的 GCC。编译 C++ 程序时，应改为以 `g++` 调用 GCC。参见“编译 C++ 程序”，了解编译 C++ 程序时 `gcc` 与 `g++` 行为差异的信息。

`gcc` 程序接受选项和文件名作为操作数。许多选项具有多字母名称；因此多个单字母选项*不能*组合：`-dv` 与 `-d -v` 非常不同。

你可以混合使用选项和其他参数。大多数情况下，顺序无关紧要。当你使用多个同类选项时，顺序确实重要；例如，如果多次指定 `-L`，则按指定顺序搜索目录。此外，`-l` 选项的位置也很重要。

许多选项具有以 `-f` 或 `-W` 开头的长名称——例如 `-fmove-loop-invariants`、`-Wformat` 等。其中大多数都有肯定形式和否定形式；`-ffoo` 的否定形式是 `-fno-foo`。本手册只记录这两种形式中的一种，即非默认的那一种。

有些选项接受一个或多个参数，这些参数通常用空格或等号（`=`）与选项名分隔。除非另有说明，参数可以是数字或字符串。数字参数通常必须是小型的无符号十进制或十六进制整数。十六进制参数必须以 `0x` 前缀开头。用于指定某种大小阈值的选项的参数，可以是任意大的十进制或十六进制整数，后跟表示字节倍数的字节大小后缀，例如 `kB` 和 `KiB` 分别表示千字节和基比字节，`MB` 和 `MiB` 表示兆字节和兆比字节，`GB` 和 `GiB` 表示吉字节和吉比字节，等等。此类参数在下文中由 `byte-size` 表示。有关二进制和十进制字节大小前缀的完整列表和说明，请参阅 NIST、IEC 以及其他相关国家和国际标准。
