# `hexdump` - 以十六进制、十进制、八进制或 ASCII 显示文件内容

## 概要

```sh
hexdump [options] file ...
hd [options] file ...
```

## 描述

`hexdump` 实用程序是一个过滤器，用于以用户指定的格式显示指定文件；如果未指定文件，则显示标准输入。

## 选项

下文中的 `length` 和 `offset` 参数后面可以跟乘法后缀 `KiB`（=1024）、`MiB`（=1024*1024），以及 `GiB`、`TiB`、`PiB`、`EiB`、`ZiB` 和 `YiB`（其中 `iB` 是可选的，例如 `K` 与 `KiB` 含义相同），或者后缀 `KB`（=1000）、`MB`（=1000*1000），以及 `GB`、`TB`、`PB`、`EB`、`ZB` 和 `YB`。

- `-b`, `--one-byte-octal`  
    单字节八进制显示。以十六进制显示输入偏移量，随后每行显示十六个以空格分隔、三列、零填充的八进制输入数据字节。

- `-X`, `--one-byte-hex`  
    单字节十六进制显示。以十六进制显示输入偏移量，随后每行显示十六个以空格分隔、两列、零填充的十六进制输入数据字节。

- `-c`, `--one-byte-char`  
    单字节字符显示。以十六进制显示输入偏移量，随后每行显示十六个以空格分隔、三列、空格填充的输入数据字符。

- `-C`, `--canonical`  
    规范十六进制 + ASCII 显示。以十六进制显示输入偏移量，随后显示十六个以空格分隔、两列、十六进制字节，然后以 `%_p` 格式显示同样的十六个字节，并用 `|` 字符括起来。以 `hd` 名称调用程序意味着启用此选项。

- `-d`, `--two-bytes-decimal`  
    两字节十进制显示。以十六进制显示输入偏移量，随后每行显示八个以空格分隔、五列、零填充的两字节输入数据单元，以无符号十进制表示。

- `-e`, `--format` `format_string`  
    指定用于显示数据的格式字符串。

- `-f`, `--format-file` `file`  
    指定一个文件，其中包含一个或多个以换行分隔的格式字符串。空行以及第一个非空白字符为井号（`#`）的行会被忽略。

- `-L`, `--color[=when]`  
    接受输出的颜色单元。可选参数 `when` 可以是 `auto`、`never` 或 `always`。如果省略 `when` 参数，则默认为 `auto`。可以禁用颜色；当前内置默认值请参见 `--help` 输出。另请参见下文的“颜色”子节和“颜色”章节。

- `-n`, `--length` `length`  
    仅解释输入的 `length` 字节。

- `-o`, `--two-bytes-octal`  
    两字节八进制显示。以十六进制显示输入偏移量，随后每行显示八个以空格分隔、六列、零填充的两字节输入数据量，以八进制表示。

- `-s`, `--skip` `offset`  
    从输入开头跳过 `offset` 字节。

- `-v`, `--no-squeezing`  
    `-v` 选项使 `hexdump` 显示所有输入数据。不使用 `-v` 时，任意数量的、与紧邻前一组输出行相同（输入偏移量除外）的输出行组，都会替换为仅包含一个星号的一行。

- `-x`, `--two-bytes-hex`  
    两字节十六进制显示。以十六进制显示输入偏移量，随后每行显示八个以空格分隔、四列、零填充的两字节输入数据量，以十六进制表示。

- `-h`, `--help`  
    显示帮助文本并退出。

- `-V`, `--version`  
    显示版本并退出。

对于每个输入文件，`hexdump` 会按指定顺序，依次将输入复制到标准输出，并根据 `-e` 和 `-f` 选项指定的格式字符串转换数据。

## 格式

格式字符串包含任意数量的格式单元，格式单元之间由空白分隔。一个格式单元最多包含三项：迭代次数、字节数和格式。

迭代次数是一个可选的正整数，默认为一。每个格式会被应用迭代次数次。

字节数是可选的正整数。如果指定，它定义格式的每次迭代要解释的字节数。

如果指定了迭代次数和/或字节数，则必须在迭代次数之后和/或字节数之前放置一个斜杠，以消除歧义。斜杠前后的任何空白都会被忽略。

格式是必需的，并且必须用双引号（`"`）括起来。它被解释为 `fprintf` 风格的格式字符串（参见 `fprintf(3)`），但有以下例外：

1. 星号（`*`）不能用作字段宽度或精度。

2. 每个 `s` 转换字符都要求提供字节数或字段精度（不同于 `fprintf(3)` 的默认行为：如果未指定精度，则打印整个字符串）。

3. 不支持转换字符 `h`、`l`、`n`、`p` 和 `q`。

4. 支持 C 标准中描述的单字符转义序列：

- `\0`  
    NULL
- `\a`  
    警报字符
- `\b`  
    退格
- `\f`  
    换页
- `\n`  
    换行
- `\r`  
    回车
- `\t`  
    制表符
- `\v`  
    垂直制表符

### 转换字符串

`hexdump` 实用程序还支持以下附加转换字符串。

- `_a[dox]`  
    显示下一个要显示的字节的输入偏移量，该偏移量跨输入文件累计。附加字符 `d`、`o` 和 `x` 分别指定显示基数为十进制、八进制或十六进制。

- `_A[dox]`  
    与 `_a` 转换字符串几乎相同，区别在于它仅在所有输入数据处理完毕后执行一次。

- `_c`  
    按默认字符集输出字符。不可打印字符显示为三字符、零填充的八进制，但可以用标准转义表示法（见上文）表示的字符除外，这些字符显示为两字符字符串。

- `_p`  
    按默认字符集输出字符。不可打印字符显示为单个 `.`。

- `_u`  
    输出 US ASCII 字符，但控制字符使用以下小写名称显示。大于十六进制 `0xff` 的字符显示为十六进制字符串。

| `00` | `nul` | `08` | `bs` | `10` | `dle` | `18` | `can` |
| `01` | `soh` | `09` | `ht` | `11` | `dc1` | `19` | `em` |
| `02` | `stx` | `0A` | `lf` | `12` | `dc2` | `1A` | `sub` |
| `03` | `etx` | `0B` | `vt` | `13` | `dc3` | `1B` | `esc` |
| `04` | `eot` | `0C` | `ff` | `14` | `dc4` | `1C` | `fs` |
| `05` | `enq` | `0D` | `cr` | `15` | `nak` | `1D` | `gs` |
| `06` | `ack` | `0E` | `so` | `16` | `syn` | `1E` | `rs` |

### 颜色

当放在格式说明符末尾时，`hexdump` 会用指定颜色高亮相应字符串。条件（如果存在）会在高亮之前求值。

`_L[color_unit_1,color_unit_2,...,color_unit_n]`

颜色单元的完整语法如下：

```
[!]COLOR[:VALUE][@OFFSET_START[-END]]
```

- `!`  
    对条件取反。请注意，只有在同时指定了值/字符串和偏移量时，对单元取反才有意义。在这种情况下，当且仅当值/字符串与偏移量处的值/字符串不匹配时，相应输出字符串才会被高亮。

- `COLOR`  
    8 种基本 shell 颜色之一。

- `VALUE`  
    要匹配的值，以十六进制、八进制或字符串指定。请注意，`hexdump` 不会解释 `color_units` 内部的常规 C 转义序列。

- `OFFSET`  
    用于检查匹配的偏移量或偏移量范围。请注意，单独的 `OFFSET_START` 使用与 `END` 偏移量相同的值。

### 计数器

转换字符的默认和支持的字节计数如下：

- `%_c`, `%_p`, `%_u`, `%c`  
    仅一字节计数。

- `%d`, `%i`, `%o`, `%u`, `%X`, `%x`  
    默认四字节，支持一、二和四字节计数。

- `%E`, `%e`, `%f`, `%G`, `%g`  
    默认八字节，支持四字节计数。

每个格式字符串解释的数据量是每个格式单元所需数据量之和；格式单元所需数据量为迭代次数乘以字节数，如果未指定字节数，则为迭代次数乘以格式所需的字节数。

输入按块处理，块定义为任意格式字符串指定的最大数据量。解释的数据量少于一个输入块的数据量、且最后一个格式单元既解释一定数量的字节又没有指定迭代次数的格式字符串，会递增迭代次数，直到整个输入块都被处理完，或者块中剩余数据不足以满足该格式字符串。

如果由于用户指定或 `hexdump` 按上述方式修改迭代次数，使得迭代次数大于一，则在最后一次迭代期间不输出尾随空白字符。

除非除一个转换字符或字符串之外的所有转换字符或字符串都是 `_a` 或 `_A`，否则同时指定字节数以及多个转换字符或字符串是错误的。

如果由于指定了 `-n` 选项或到达文件末尾，输入数据仅部分满足某个格式字符串，则输入块会用零填充到足以显示所有可用数据（即，任何与数据末尾重叠的格式单元都会显示一定数量的零字节）。

此类格式字符串的后续输出会替换为等量的空格。等量空格定义为：使用与原始转换字符或转换字符串具有相同字段宽度和精度、但移除任何 `+`、空格、`#` 转换标志字符并引用 NULL 字符串的 `s` 转换字符所输出的空格数。

如果未指定格式字符串，默认显示与 `-x` 输出格式非常相似（`-x` 选项导致格式单元之间使用比默认输出更多的空格）。

请注意，默认格式以及 `-x`、`-d` 和 `-o` 选项使用多字节格式单元，这些单元按系统本机字节序（端序）显示。这意味着相同的输入在小端序（例如 x86、ARM64）和大端序（例如 s390x）系统上可能产生不同的输出。对于与字节序无关的输出，请使用单字节格式，例如 `-b`、`-c`、`-C` 或 `-X`。

## 退出状态

`hexdump` 成功时退出码为 0，发生错误时大于 0。

## 符合标准

`hexdump` 实用程序预期与 IEEE Std 1003.2（“POSIX.2”）兼容。

## 示例

以浏览格式显示输入：

```
"%06.6_ao "  12/1 "%3_u "
"\t" "%_p "
"\n"
```

实现 `-x` 选项：

```
"%07.7_Ax\n"
"%07.7_ax  " 8/2 "%04x " "\n"
```

MBR 引导签名示例：将地址高亮为青色，并将偏移量 510 和 511 处的字节在其值为 `0xAA55` 时高亮为绿色，否则高亮为红色。

```
"%07.7_Ax_L[cyan]\n"
"%07.7_ax_L[cyan]  " 8/2 "   %04x_L[green:0xAA55@510-511,!red:0xAA55@510-511] " "\n"
```

## 颜色

输出着色由 `terminal-colors.d(5)` 功能实现。可以通过空文件 `/etc/terminal-colors.d/hexdump.disable` 为 `hexdump` 命令禁用隐式着色，或通过 `/etc/terminal-colors.d/disable` 为所有工具禁用。

自版本 `2.41` 起，还支持 `$NO_COLOR` 环境变量来禁用输出着色，除非通过命令行选项显式启用。

用户特定的 `$XDG_CONFIG_HOME/terminal-colors.d` 或 `$HOME/.config/terminal-colors.d` 会覆盖全局设置。

请注意，输出着色可能默认启用，在这种情况下，`terminal-colors.d` 目录不必已经存在。
