## smartdns - 本地 DNS 服务器

<https://github.com/pymumu/smartdns>

1. docker 设置镜像后 pull 容器
2. 设置本地文件夹映射到 `/etc/smartdns`

    ```powershell
    docker run -d `
        --name smartdns `
        --restart=always `
        -p 53:53/udp `
        -p 6080:6080/tcp `
        -v E:\Abzu-Eridu\tool\smartdns\config:/etc/smartdns `
        -v E:\Abzu-Eridu\.cache\smartdns\datalib:/var/lib/smartdns `
        pymumu/smartdns:latest
    ```
    - `-d` 后台运行，`--name 容器名称`
    - `--restart=always` 总是重启
    - 53 dns 查询端口
    - 6080 web 界面端口
    - `-v` 映射文件，主配置与数据库

3. 设置本机的 DNS 服务器地址为本机 
    - ipv4 `127.0.0.1`
    - ipv6 `::1`

## Steamcommunity 302 —— CDN本地反向代理 

[Steamcommunity 302](https://www.dogfight360.com/blog/18682/)
- 劫持 DNS 到本机导致异常
    - 浏览器同源策略导致异常
    - 容器 DNS 解析为本地回环导致异常
        - 宿主机关闭本地反代，或设置容器 hosts
    - cloudflare 的 IP 双栈信息均被 DNS 重定向到 ipv4 地址，导致 ipv6 地址解析为 ipv4
    - cloudflare/google 验证码异常
        - 反选验证码规则
        
- 添加黑名单规则 
    ```log
    // cloudflare ip 双栈解析
    *.radar.cloudflare.com
    // 可选：cloudflare ip 测速到普通连接而不是优选
    *.turn.cloudflare.com
    // 可选：cloudflare 挑战
    *.challenges.cloudflare.com
    ```

- 除将对应 CDN CIDR 网段的 DNS 重定向到优选 IP 外，还包括设置域名到非普通 DNS 查询结果的对应 IP
    - 使用网站公布的 IP 列表，如 github、微软
    - 似乎使用侦察技术获取了 IP 与 host 别名
    - 从作者服务器拉取信息
