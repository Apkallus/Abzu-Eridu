## 02.1 首次运行 Vim

要启动 Vim，输入以下命令：

```sh
gvim file.txt
```

在 UNIX 中，你可以在任何命令提示符下输入。如果你运行 Microsoft Windows，打开命令提示符并输入该命令。无论哪种情况，Vim 开始编辑名为 `file.txt` 的文件。因为这是一个新文件，你会得到一个空白窗口。你的屏幕看起来会像这样：

```text
+---------------------------------------+
|#                                      |
|~                                      |
|~                                      |
|~                                      |
|~                                      |
|"file.txt" [New file]                 |
+---------------------------------------+
    （`#` 是光标位置。）
```

波浪线（`~`）表示文件中没有的行。换句话说，当 Vim 没有文件内容可显示时，它会显示波浪线。在屏幕底部，消息行显示文件名为 `file.txt`，并表明你正在创建一个新文件。消息信息是临时的，其他信息会覆盖它。

### VIM 命令

`gvim` 命令会让编辑器创建一个新窗口进行编辑。如果你使用以下命令：

```sh
vim file.txt
```

编辑会在你的命令窗口内进行。换句话说，如果你在 xterm 中运行，编辑器会使用你的 xterm 窗口。如果你使用 MS-Windows 命令提示符窗口，编辑会在该窗口内进行。两种版本中窗口内的文本看起来相同，但使用 `gvim` 时你有额外功能，比如菜单栏。稍后会更多介绍。

## 02.2 插入文本

Vim 编辑器是模态编辑器。这意味着编辑器会根据你所在的模式而表现不同。两个基本模式称为普通模式和插入模式。在普通模式下，你输入的字符是命令。在插入模式下，字符作为文本插入。因为你刚启动 Vim，它会处于普通模式。要开始插入模式，输入 `i` 命令（i 代表 Insert）。然后你可以输入文本。文本会被插入到文件中。不要担心犯错；你以后可以改正。要输入下面这首程序员打油诗，你需要输入：

```text
iA very intelligent turtle
Found programming UNIX a hurdle
```

输入 `turtle` 后按 `<Enter>` 键开始新行。最后按 `<Esc>` 键停止插入模式并返回普通模式。现在你的 Vim 窗口中有两行文本：

```text
+---------------------------------------+
|A very intelligent turtle              |
|Found programming UNIX a hurdle        |
|~                                      |
|~                                      |
|                                       |
+---------------------------------------+
```

### 当前是什么模式？

为了能看到你处于什么模式，输入以下命令：

```vim
:set showmode
```

你会注意到，输入冒号时 Vim 将光标移动到窗口最后一行。那是在哪里输入冒号命令（以冒号开头的命令）。按 `<Enter>` 键完成此命令（所有以冒号开头的命令都这样完成）。现在，如果你输入 `i` 命令，Vim 会在窗口底部显示 `--INSERT--`。这表明你处于插入模式。

```text
+---------------------------------------+
|A very intelligent turtle              |
|Found programming UNIX a hurdle        |
|~                                      |
|~                                      |
|-- INSERT --                           |
+---------------------------------------+
```

如果你按 `<Esc>` 返回普通模式，最后一行会变为空白。

### 摆脱困境

Vim 新手的问题之一是模式混淆，原因是忘记自己处于哪个模式，或意外输入了切换模式的命令。无论你处于什么模式，要返回普通模式，按 `<Esc>` 键。有时你需要按两次。如果 Vim 对你响铃，说明你已经处于普通模式。

## 02.3 四处移动

返回普通模式后，你可以使用这些键移动：

- `h` 左
- `j` 下
- `k` 上
- `l` 右

起初，这些命令看起来可能是随机选择的。毕竟，谁听说过用 `l` 表示右？但实际上，这些选择有很好的理由：移动光标是你在编辑器中最常做的事情，而这些键位于你右手的基准行上。换句话说，这些命令放在你可以最快输入的位置（尤其是用十指打字时）。

> **注意：**
> 你也可以使用方向键移动光标。然而，如果这样做，你会大大减慢编辑速度，因为按方向键时，你必须把手从文本键移到方向键。考虑到你可能每小时做数百次，这会花费大量时间。
> 此外，有些键盘没有方向键，或者方向键位于不寻常的位置；因此，了解 `hjkl` 键的用法在这些情况下有帮助。

记住这些命令的一种方法是：`h` 在左边，`l` 在右边，`j` 指向下。如图所示：

```text
       k
   h     l
     j
```

学习这些命令的最好方法就是使用它们。使用 `i` 命令再插入几行文本。然后使用 `hjkl` 键移动，并在某处插入一个单词。别忘了按 `<Esc>` 返回普通模式。`[vimtutor]` 也是一种很好的边做边学方式。

对于日语用户，Hiroshi Iwatani 建议使用：

```text
            Komsomolsk
                ^
                |
   Huan Ho  <--- --->  Los Angeles
(Yellow river)      |
                v
              Java (the island, not the programming language)
```

## 02.4 删除字符

要删除一个字符，将光标移到它上面并输入 `x`。（这是对旧打字机时代的致敬，那时你通过在字符上输入 xxxx 来删除东西。）例如，将光标移到第一行开头，输入 `xxxxxxx`（七个 x）删除 `A very `。结果应如下所示：

```text
+---------------------------------------+
|intelligent turtle                     |
|Found programming UNIX a hurdle        |
|~                                      |
|~                                      |
|                                       |
+---------------------------------------+
```

现在你可以插入新文本，例如输入：

```text
iA young <Esc>
```

这会开始插入（`i`），插入单词 `A young`，然后退出插入模式（最后的 `<Esc>`）。结果：

```text
+---------------------------------------+
|A young intelligent turtle             |
|Found programming UNIX a hurdle        |
|~                                      |
|~                                      |
|                                       |
+---------------------------------------+
```

### 删除一行

要删除整行，使用 `dd` 命令。下一行会向上移动填补空缺：

```text
+---------------------------------------+
|Found programming UNIX a hurdle        |
|~                                      |
|~                                      |
|~                                      |
|                                       |
+---------------------------------------+
```

### 删除换行

在 Vim 中，你可以将两行连接在一起，这意味着它们之间的换行被删除。`J` 命令执行此操作。以下面两行为例：

```text
A young intelligent 
turtle 
```

将光标移到第一行并按 `J`：

```text
A young intelligent turtle 
```

## 02.5 撤销与重做

假设你删除了太多内容。好吧，你可以重新输入，但存在更简单的方法。`u` 命令撤销上一次编辑。看看实际操作：使用 `dd` 删除第一行后，`u` 将它恢复。另一个例子：将光标移到第一行的 `A`：

```text
A young intelligent turtle 
```

现在输入 `xxxxxxx` 删除 `A young`。结果如下：

```text
 intelligent turtle 
```

输入 `u` 撤销上一次删除。那次删除移除了 `g,`，所以撤销会恢复该字符。

```text
g intelligent turtle 
```

下一个 `u` 命令恢复倒数第二个被删除的字符：

```text
ng intelligent turtle 
```

下一个 `u` 命令给你 `u`，依此类推：

```text
ung intelligent turtle 
oung intelligent turtle 
young intelligent turtle 
 young intelligent turtle 
A young intelligent turtle 
```

> **注意：**
> 如果你输入两次 `u`，结果得到相同的文本，说明你的 Vim 配置为以 Vi 兼容方式工作。查看这里修复：[`not-compatible`]。
> 本文假设你以“Vim 方式”工作。你可能更喜欢使用旧的 Vi 方式，但那样你就必须注意文本中的细微差异。

### 重做

如果你撤销太多次，可以按 `CTRL-R`（重做）来反转前一个命令。换句话说，它撤销撤销。要看到实际操作，按两次 `CTRL-R`。字符 `A` 和它后面的空格消失：

```text
young intelligent turtle 
```

还有一个特殊版本的撤销命令，即 `U`（撤销行）命令。撤销行命令撤销最后编辑行上所做的所有更改。输入此命令两次会取消前一个 `U`。

```text
A very intelligent turtle 
  xxxx              删除 very

A intelligent turtle 
              xxxxxx        删除 turtle

A intelligent 
                    用 `U` 恢复行
A very intelligent turtle 
                    用 `u` 撤销 `U`
A intelligent 
```

`U` 命令本身也是一次更改，`u` 命令会撤销它，`CTRL-R` 会重做它。这可能有点令人困惑。别担心，使用 `u` 和 `CTRL-R`，你可以回到你曾经有过的任何状态。更多内容见 32.2 节。

## 02.6 其他编辑命令

Vim 有大量用于更改文本的命令。参见 [`Q_in`] 及下文。以下是几个常用命令。

### 追加

`i` 命令在光标下字符之前插入一个字符。这很好用；但如果你想在行尾添加内容呢？为此，你需要在光标之后插入文本。这通过 `a`（追加）命令完成。例如，要将行

```text
and that's not saying much for the turtle. 
```

改为

```text
and that's not saying much for the turtle!!! 
```

将光标移到行尾的句点上。然后输入 `x` 删除句点。现在光标位于行尾，在 `turtle` 的 `e` 上。现在输入

```text
a!!!<Esc>
```

在 `turtle` 的 `e` 后追加三个感叹号：

```text
and that's not saying much for the turtle!!! 
```

### 打开新行

`o` 命令在光标下方创建一个新的空行，并将 Vim 置于插入模式。然后你可以为新行输入文本。假设光标位于下面两行中的第一行某处：

```text
A very intelligent turtle 
Found programming UNIX a hurdle 
```

如果你现在使用 `o` 命令并输入新文本：

```text
oThat liked using Vim<Esc>
```

结果是：

```text
A very intelligent turtle 
That liked using Vim 
Found programming UNIX a hurdle 
```

`O` 命令（大写）在光标上方打开一行。

### 使用计数

假设你想向上移动九行。你可以输入 `kkkkkkkkk`，也可以输入命令 `9k`。事实上，你可以在许多命令前加一个数字。例如，本章前面，你通过输入 `a!!!<Esc>` 在行尾添加了三个感叹号。另一种方法是使用命令 `3a!<Esc>`。计数 3 告诉后面的命令将其效果重复三次。类似地，要删除三个字符，使用命令 `3x`。计数总是位于它所应用的命令之前。

## 02.7 退出

要退出，使用 `ZZ` 命令。此命令写入文件并退出。

> **注意：**
> 与许多其他编辑器不同，Vim 不会自动创建备份文件。如果你输入 `ZZ`，你的更改会被提交，无法回头。你可以配置 Vim 编辑器生成备份文件；参见 07.4。

### 放弃更改

有时你会做一系列更改，然后突然意识到开始之前更好。别担心；Vim 有一个退出并丢弃更改的命令。它是：

```vim
:q!
```

别忘了按 `<Enter>` 完成命令。

对于对细节感兴趣的人，此命令的三个部分是：冒号（`:`），进入命令行模式；`q` 命令，告诉编辑器退出；以及覆盖命令修饰符（`!`）。需要覆盖命令修饰符，因为 Vim 不愿意丢弃更改。如果你只输入 `:q`，Vim 会显示错误消息并拒绝退出：

```text
E37: No write since last change (use ! to override) 
```

通过指定覆盖，你实际上是在告诉 Vim：“我知道我正在做的事情看起来愚蠢，但我真的想这样做。”

如果你想继续用 Vim 编辑：`:e!` 命令会重新加载文件的原始版本。

## 02.8 查找帮助

你一直想知道的一切都可以在 Vim 帮助文件中找到。不要害怕提问！

如果你知道自己在找什么，通常使用帮助系统搜索比使用 Google 更容易。因为主题遵循一定的风格指南。帮助还有一个优势：它属于你的特定 Vim 版本。你不会看到后来添加的命令的帮助，那些命令对你不起作用。

要获取通用帮助，使用以下命令：

```vim
:help
```

你也可以使用第一个功能键 `<F1>`。如果你的键盘有 `<Help>` 键，它也可能有效。如果你不提供主题，`:help` 会显示通用帮助窗口。Vim 的创建者在帮助系统上做了非常聪明（或非常偷懒）的事情：他们让帮助窗口成为一个正常的编辑窗口。你可以使用所有正常的 Vim 命令在帮助信息中移动。因此 `h`、`j`、`k` 和 `l` 分别向左、下、上和右移动。要退出帮助窗口，使用与退出编辑器相同的命令：`ZZ`。这只会关闭帮助窗口，不会退出 Vim。

当你阅读帮助文本时，你会注意到一些文本被竖线包围（例如 `[help]`）。这表示一个超链接。如果你将光标定位在竖线之间的任何位置，并按 `CTRL-]`（跳转到标签），帮助系统会带你到指示的主题。（由于这里不讨论的原因，Vim 中超链接的术语是标签。所以 `CTRL-]` 跳转到光标下单词所给出的标签位置。）经过几次跳转后，你可能想返回。`CTRL-T`（弹出标签）会带你回到前一个位置。`CTRL-O`（跳转到较旧位置）在这里也很好用。在帮助屏幕顶部，有记法 `*help.txt*`。这个位于 `*` 字符之间的名称被帮助系统用来定义标签（超链接目标）。关于使用标签的细节参见 29.1。

要获取给定主题的帮助，使用以下命令：

```vim
:help {subject}
```

例如，要获取 `x` 命令的帮助，输入以下内容：

```vim
:help x
```

要了解如何删除文本，使用此命令：

```vim
:help deleting
```

要获取所有 Vim 命令的完整索引，使用以下命令：

```vim
:help index
```

当你需要获取控制字符命令（例如 `CTRL-A`）的帮助时，需要用前缀 `CTRL-` 拼写它：

```vim
:help CTRL-A
```

Vim 编辑器有许多不同的模式。默认情况下，帮助系统显示普通模式命令。例如，以下命令显示普通模式 `CTRL-H` 命令的帮助：

```vim
:help CTRL-H
```

要标识其他模式，使用模式前缀。如果你想要命令的插入模式版本的帮助，使用 `i_`。对于 `CTRL-H`，这给出以下命令：

```vim
:help i_CTRL-H
```

启动 Vim 编辑器时，你可以使用几个命令行参数。它们都以短横线（`-`）开头。例如，要查找 `-t` 参数的作用，使用命令：

```vim
:help -t
```

Vim 编辑器有许多选项，使你能够配置和自定义编辑器。如果你想要某个选项的帮助，需要将其括在单引号中。例如，要查找 `'number'` 选项的作用，使用以下命令：

```vim
:help 'number'
```

所有模式前缀的表格可以在下面找到：[`help-summary`]。

特殊键括在尖括号中。例如，要获取插入模式下上箭头键的帮助，使用此命令：

```vim
:help i_<Up>
```

如果你看到不理解的错误消息，例如：

```text
E37: No write since last change (use ! to override) 
```

你可以使用开头的错误 ID 来查找相关帮助：

```vim
:help E37
```

### 摘要

1. 输入主题后使用 Ctrl-D，让 Vim 显示所有可用主题。或按 `<Tab>` 补全：

   ```vim
   :help some<Tab>
   ```

   有关如何使用帮助的更多信息：

   ```vim
   :help helphelp
   ```

2. 跟随竖线中的链接查看相关帮助。你可以从详细帮助转到用户文档，后者从用户角度描述某些命令，且不太详细。例如，在：

   ```vim
   :help pattern.txt
   ```

   之后，你可以在引言中看到用户指南主题 03.9 和 [`usr_27.txt`]。

3. 选项括在单引号中。要转到 `list` 选项的帮助主题：

   ```vim
   :help 'list'
   ```

   如果你只知道自己在寻找某个选项，也可以这样做：

   ```vim
   :help options.txt
   ```

   打开描述所有选项处理的帮助页，然后使用正则表达式搜索，例如 `textwidth`。某些选项有自己的命名空间，例如：

   ```vim
   :help cpo-<letter>
   ```

   对于 `'cpoptions'` 设置的相应标志，用特定标志替换 `<letter>`，例如：

   ```vim
   :help cpo-;
   ```

   对于 `'guioptions'` 标志：

   ```vim
   :help go-<letter>
   ```

4. 普通模式命令没有前缀。要转到 `gt` 命令的帮助页：

   ```vim
   :help gt
   ```

5. 插入模式命令以 `i_` 开头。删除单词的帮助：

   ```vim
   :help i_CTRL-W
   ```

6. 可视模式命令以 `v_` 开头。跳到可视区域另一侧的帮助：

   ```vim
   :help v_o
   ```

7. 命令行编辑和参数以 `c_` 开头。使用命令参数 `%` 的帮助：

   ```vim
   :help c_%
   ```

8. Ex 命令总是以 `:` 开头，所以要转到 `:s` 命令帮助：

   ```vim
   :help :s
   ```

9. 专门用于调试的命令以 `>` 开头。要转到 `cont` 调试命令的帮助：

   ```vim
   :help >cont
   ```

10. 键组合。它们通常以单个字母开头，表示可用于哪种模式。例如：

    ```vim
    :help i_CTRL-X
    ```

    带你到插入模式的 `CTRL-X` 命令家族，可用于自动补全不同内容。注意，某些键总是写成相同形式，例如 Control 总是 `CTRL`。对于普通模式命令，没有前缀，主题位于 `:h CTRL-<Letter>`。例如

    ```vim
    :help CTRL-W
    ```

    相反

    ```vim
    :help c_CTRL-R
    ```

    将描述在命令行输入命令时 `CTRL-R` 做什么，而

    ```vim
    :help v_CTRL-A
    ```

    讨论可视模式下递增数字，而

    ```vim
    :help g_CTRL-A
    ```

    讨论 `g<C-A>` 命令（例如你必须先按 `g` 再按 `<CTRL-A>`）。这里的 `g` 代表普通命令 `g`，它总是期待第二个键，然后才做类似于以 `z` 开头的命令的事情。

11. 正则表达式项总是以 `/.` 开头。所以要在 Vim 正则表达式中获取 `\+` 量词的帮助：

    ```vim
    :help /\+
    ```

    如果你需要了解关于正则表达式的一切，从以下开始阅读：

    ```vim
    :help pattern.txt
    ```

12. 寄存器总是以 `quote` 开头。要了解特殊的 `:` 寄存器：

    ```vim
    :help quote:
    ```

13. Vim 脚本可在以下位置获得：

    ```vim
    :help eval.txt
    ```

    语言的某些方面可在 `:h expr-X` 获得，其中 `X` 是单个字母。例如

    ```vim
    :help expr-!
    ```

    将带你到描述 Vim 脚本中 `!`（Not）运算符的主题。同样重要的是

    ```vim
    :help function-list
    ```

    以找到所有可用函数的简短描述。Vim 脚本函数的帮助主题总是包含 `()`，所以：

    ```vim
    :help append()
    ```

    讨论 append Vim 脚本函数，而不是如何在当前缓冲区中追加文本。

14. 映射在帮助页 `:h map.txt` 中讨论。使用

    ```vim
    :help mapmode-i
    ```

    了解 `:imap` 命令。也可以使用 `:map-topic` 了解映射特有的某些子主题。例如：

    ```vim
    :help :map-local
    ```

    用于缓冲区局部映射，或

    ```vim
    :help map-bar
    ```

    用于映射中如何处理 `|`。

15. 命令定义在 `:h command-topic` 中讨论，所以使用

    ```vim
    :help command-bang
    ```

    了解自定义命令的 `!` 参数。

16. 窗口管理命令总是以 `CTRL-W` 开头，因此你可以在 `:h CTRL-W_letter` 找到相应帮助。例如

    ```vim
    :help CTRL-W_p
    ```

    用于移动到上一次访问的窗口。你也可以访问

    ```vim
    :help windows.txt
    ```

    如果你在寻找窗口处理命令，可以通读。

17. 使用 `:helpgrep` 在所有帮助页（以及任何已安装插件的帮助页）中搜索。用法参见 [`：helpgrep`]。要搜索主题：

    ```vim
    :helpgrep topic
    ```

    这会带你到第一个匹配。要转到下一个：

    ```vim
    :cnext
    ```

    所有匹配都可在快速修复窗口中使用，可通过以下命令打开：

    ```vim
    :copen
    ```

    移动到喜欢的匹配处并按 Enter 跳转到该帮助。

18. 用户手册。它以相当友好的方式为初学者描述帮助主题。从 [`usr_toc.txt`] 开始查找目录（你可能已经猜到了）：

    ```vim
    :help usr_toc.txt
    ```

    浏览内容以找到有趣的主题。“Digraphs”和“Entering special characters”项在第 24 章，所以要转到那个特定帮助页：

    ```vim
    :help usr_24.txt
    ```

    另外，如果你想访问帮助中的某一章，可以直接访问章节号，如下所示：

    ```vim
    :help 10.1
    ```

    这会转到 [`usr_10.txt`] 中的第 10.1 章，讨论录制宏。

19. 高亮组。总是以 `hl-groupname` 开头。例如

    ```vim
    :help hl-WarningMsg
    ```

    讨论 WarningMsg 高亮组。

20. 语法高亮命名空间为 `:syn-topic`。例如

    ```vim
    :help :syn-conceal
    ```

    讨论 `:syn` 命令的 `conceal` 参数。

21. 快速修复命令通常以 `:c` 开头，而位置列表命令通常以 `:l` 开头。

22. 自动命令事件可以通过名称找到：

    ```vim
    :help BufWinLeave
    ```

    要查看所有可能事件：

    ```vim
    :help autocommand-events
    ```

23. 命令行开关总是以 `-` 开头。因此，要获取 Vim 的 `-f` 命令行开关的帮助，使用：

    ```vim
    :help -f
    ```

24. 可选特性总是以 `+` 开头。要了解 `conceal` 特性，使用：

    ```vim
    :help +conceal
    ```

25. 包含的文件类型特定功能的文档通常以 `ft-<filetype>-<functionality>` 形式提供。所以

    ```vim
    :help ft-c-syntax
    ```

    讨论 C 语法文件及其提供的选项。有时，还会有用于全向补全的附加节

    ```vim
    :help ft-php-omni
    ```

    或文件类型插件

    ```vim
    :help ft-tex-plugin
    ```

    可用。

26. 错误和警告代码可以直接在帮助中查找。所以

    ```vim
    :help E297
    ```

    直接带你到交换错误消息的描述，而

    ```vim
    :help W10
    ```

    讨论警告“Changing a readonly file”。然而，有时这些错误代码没有描述，而是列在通常导致此错误的 Vim 命令处。所以：

    ```vim
    :help E128
    ```

    带你到 `:function` 命令。

27. Vim 随附包的文档形式为 `package-<name>`。所以

    ```vim
    :help package-comment
    ```

    将带你到包含的 comment 插件的帮助节以及如何启用它。
