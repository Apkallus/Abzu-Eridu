#### Windows KMS

[KMS 激活服务器与密钥](https://kms.cx/)
- 打开“终端管理员”，输入的命令：  
    1. `slmgr /skms 服务器地址`：设置 KMS 服务器地址 
    2. `slmgr /ipk 密钥`：设置密钥
    3. `slmgr /ato`：连接 KMS 服务器，进行激活  
    4. `slmgr /xpr`：查询激活状态

#### 系统设置

- `时间&语言 - 语言&区域 - 中文 - 语言选项 - 键盘` 
    设置中文输入法，或安装 rime
    - ps 命令强制应用语言设置
        ```powershell
        Install-Language zh-CN
        ```
- `系统 - 屏幕 - 高级显示器设置 - 选择刷新率`
    调整显示器刷新率 120hz，若144hz则更可能花屏
- `控制面板 - 硬件和声音 - 电源选项 - 系统设置 - 更改当前不可用的设置 - 关机设置`
    关闭快速启动 
- `个性化 - 动态光效`
    关闭鼠标等设备光效

### 浏览器插件

- [Darkreader 网页暗黑模式](https://darkreader.org/)
    [Github 仓库](https://github.com/darkreader/darkreader/releases/)

- FDM 扩展来源于 Chrome 插件

- [沉浸式翻译](https://immersivetranslate.com/zh-Hans/download/)
    ⚠️ 虽然相对 Edge 内置网页翻译对格式破坏更少，但仍然丢失大量链接。    
    开启双语翻译同时查看原文与译文。    
    - 插件中设置译文字体 微软雅黑 `设置-基本设置-设置字体`
        设置字体颜色为 github 文档的淡蓝色 `rgb(202, 225, 244)` 或  `#cae1f4`   

- 有道灵动翻译
    同样丢失大量链接
    ⚠️ 曾经使部分网页内容消失
    翻译质量与沉浸式翻译使用的 GLM-4 各有优劣

- 篡改猴
    添加自定义脚本到特定域名  
    ⚠️ 若在单页面设置脚本可能冲突，确保脚本设置条件检查（URL路径或元素选择器）以返回。

- ublock  
    自定义静态规则：
    - youtube 暂停时弹出推荐视频
        `youtube.com##.ytp-pause-overlay-container`
        `youtube-nocookie.com##.ytp-pause-overlay-container`
